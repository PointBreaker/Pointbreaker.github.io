PointBreaker查看 Skill 源码

Course generator

从本地资料，到一门可发布的课程。

generate-course-site-pr 会盘点本地课程资源、建立可追溯的课程计划、生成统一的 Dashboard 与阅读页、完成质量检查，并向 PointBreaker 提交一个可审阅的 PR。

01

准备资源文件夹

放入已下载的官方 PDF、PPT/PPTX、作业、Lab、代码和笔记。另准备官方课程主页 URL。

02

安装 Skill

从仓库复制 Skill 到 Codex skills 目录。

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/generate-course-site-pr "${CODEX_HOME:-$HOME/.codex}/skills/"
03

在资源目录启动 Codex

直接调用 Skill；它会默认把当前目录当作课程来源。

Use $generate-course-site-pr to build this course and open a PR.
04

等待完整流水线

Codex 会整理来源、生成内容与前端、检查公式和交互、创建课程分支，并返回 PR 链接与已知资料缺口。

Skill 永远不会访问 Google Drive 或 Google Docs。遇到这类官方链接时，请先把资料下载到本地资源文件夹。
