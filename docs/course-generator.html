Course generator

从一个官方链接，到一门可发布的课程。

generate-course-site-pr 会从官方课程主页发现当前学期的一手资料，建立可追溯的 source map，判断是新建还是迁移现有课程，再在 courses/<slug>/ 生成完整的中文教材、Engineering Workbooks 与必要的数学图形，完成阅读体验和质量检查后提交一个可审阅的 PR。

01

准备官方课程链接

只需当前课程主页 URL。Skill 会沿官方链接发现公开 slides、handouts、repositories、changelogs 与 archive；本地已有 PDF、PPT/PPTX、作业、Lab、代码或笔记时，可以作为补充证据。

02

安装 Skill

从仓库复制 Skill 到 Codex skills 目录。安装后每次使用都会先校验并同步仓库中的最新版；离线时继续使用本地版本，手工改动不会被覆盖。

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/generate-course-site-pr "${CODEX_HOME:-$HOME/.codex}/skills/"
03

在 CourseStack 仓库启动 Codex

直接把官方链接交给 Skill，不必先整理资源目录。

Use $generate-course-site-pr on https://example.edu/course/ and open a PR.
04

等待完整流水线

Codex 会先完成版本、教学深度与阅读流审计，再逐课建立 mental model、推导与练习，按工程阶段组织作业，生成真正需要的 HTML/CSS/SVG 图，检查当前学期主线、公式、交互与移动端体验，最后创建课程分支并返回 PR。

公开资料的工作副本只保存在 .course-build/，不会随网站提交。仓库策略不允许访问或再分发的资料会被记录为 coverage gap；这不会让 Skill 用旧学期内容或第三方摘要静默替代。
