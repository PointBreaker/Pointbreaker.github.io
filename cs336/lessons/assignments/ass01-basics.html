这个 Assignment 要你做什么？

一句话总结：从零实现一个完整的 Transformer 语言模型——包括 tokenizer、模型架构、优化器、训练循环——不使用 PyTorch 的高级模块（nn.Linear、nn.Embedding、nn.Transformer 等）。

Assignment 提供了一个测试框架，所有待实现函数最初都是 raise NotImplementedError。你的目标是让所有测试通过。

如何开始？

0

读 handout

Handout（PDF）是 assignment 的权威描述。先通读一遍，了解每个函数的输入输出格式和约束条件。Handout 中通常包含重要的实现提示和边界情况说明。

1

理解测试

在写任何代码之前，先读测试文件。测试告诉你函数应该做什么：

# 例：tests/test_nn_utils.py 会测试 run_linear
# 它构造特定的 weights 和 in_features，检查你的输出是否正确

重点关注：输入 tensor 的 shape、输出的 shape 和数值、边界情况（空输入、单元素、大 batch）。

2

从最简单开始

建议的实现顺序：

  1. run_silu — 一个元素级函数，最简单
  2. run_linear — 一次矩阵乘法
  3. run_embedding — 一次查表
  4. run_swiglu — 组合以上
  5. run_softmax、run_cross_entropy — 数学函数
  6. run_rmsnorm — 归一化
  7. run_scaled_dot_product_attention — 注意力的核心
  8. ...逐步推进到完整的 Transformer
3

小数据调试

用最小的输入测试你的实现：batch_size=1, sequence_length=1, d_model=2, num_heads=2。手工计算预期结果，对比你的输出。

常见陷阱

Weight matrix 的方向： Assignment 中很多 weight 的 shape 是 (d_out, d_in)，计算时需要转置。这是最常见的 bug 来源。

Numerical stability： Softmax 和 cross-entropy 要注意数值溢出。直接计算 exp(x) 在大数值时会溢出。

Attention mask： 因果 mask（causal mask）确保位置 i 只能 attend 到 ≤i 的位置。注意 mask 的应用方式（加到 softmax 前的 logits 上）。

RoPE 的维度： RoPE 应用在 head 维度上（d_model // num_heads），不是整个 d_model。

测试与调试策略

运行测试

# 运行单个测试文件
uv run pytest tests/test_nn_utils.py -v

# 运行单个测试函数
uv run pytest tests/test_nn_utils.py::test_linear -v

# 运行全部测试
uv run pytest -v

调试技巧

  • 从最小例子开始：用 2-3 个 token 测试 BPE，而不是整个文件
  • 打印中间结果：每轮合并后打印 splits 和 pair_counts
  • 对比参考实现：用 tiktoken 对同一文本做 tokenize，对比结果
  • 注意边界情况：空文本、单个字符、特殊 token 在开头/结尾
  • 用 assert 验证 shape：在每个函数开头断言输入 shape 符合预期

学习心态

这个 assignment 很难。 去年的学生评价说："第一次作业的工作量约等于 CS224n 所有 5 次作业加期末项目的总和。"

这是正常的。不要因为一开始卡住而沮丧。每个函数都对应课程中的一个概念——回头复习课程，理解原理后再写代码。
