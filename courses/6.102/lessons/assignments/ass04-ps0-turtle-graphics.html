PS0：Turtle Graphics

6.102 的第一个问题集：通过海龟绘图熟悉 TypeScript、VS Code、Mocha 测试与 Git 工作流，写出安全免于缺陷、易于理解的代码。

实验目标

  • 掌握 6.102 的工具链：TypeScript、VS Code、Mocha、Git。
  • 熟悉问题集的获取、开发、测试、提交流程。
  • 练习用 TypeScript 编写安全免于 bugs（safe from bugs）且易于理解（easy to understand）的代码。
  • 开始使用标准库中的 Math 函数与简单几何。

先修知识

  • 完成 Getting Started 环境配置。
  • 完成 Git 1 与 Basic TypeScript 模块。
  • 基本的编程经验（任何语言均可）。

获取代码

  1. 在 didit.mit.edu/6.102/sp26/ 的 psets/ps0 点击创建仓库。
  2. 复制页面顶部的 git clone 命令，在终端运行。
  3. cd ps0-<username>，运行 npm install。
  4. 用 code . 在 VS Code 中打开。

任务概述

在 src/turtlesoup.ts 中实现若干函数，通过海龟绘图 API 绘制图形。主要任务：

  • drawSquare(turtle, sideLength)：用 forward 与 turn 画正方形。
  • chordLength(radius, chords)：推导并计算圆的弦长。弦长公式：对于半径 \(r\)、分成 \(n\) 弦的正多边形，弦长 = \(2r \sin(\pi/n)\)。
  • drawApproximateCircle(turtle, radius, chords)：用弦逼近圆。
  • distance(p1, p2)：两点间欧氏距离 \(\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\)。
  • findPath(turtle, points)：计算访问一系列点的路径（转向+前进序列）。
  • drawPersonalArt(turtle)：自由创作，至少 20 行非重复代码，需使用辅助函数或循环。

分步指引

  1. 先实现 drawSquare，在 main 中调用并用 npm start 查看 output.html。
  2. 推导弦长公式，实现 chordLength，用 npm test 跑公开测试。观察失败时的红色错误与堆栈跟踪。
  3. 实现 drawApproximateCircle，注意不要破坏 drawSquare 的规格（可 DRY 但须谨慎）。
  4. 实现 distance 与 findPath。可单独跑某个测试：npm test -- -f "findPath"。
  5. 用 Git 在关键节点 commit 并 push。
  6. 最后实现 drawPersonalArt，可使用 color 方法变色。

测试要点

  • npm test 运行 Mocha 测试；通过显示 ✓，失败显示红色。
  • assertAlmostEqual(actual, expected, delta) 在误差容限内比较浮点数（默认 delta=0.001）。
  • 故意破坏实现再跑测试，读懂错误信息与堆栈跟踪。

提交与验收

  • 必须在 github.mit.edu 的仓库中 commit 并 push。评分使用截止时间（9:00pm）时的仓库状态。
  • Didit push 后会运行部分自动评分器，但不保证即时返回结果。
  • 通过 Didit 公开测试不等于通过全部评分测试；但几乎必然扣分。

评分构成

  • ~30% alpha 自动评分（含在线练习）
  • ~20% alpha 人工评分
  • ~25% beta 自动评分
  • ~25% beta 人工评分（含代码审查）

常见陷阱

  • 修改函数签名：会导致得零分。
  • 忘记 push：本地提交不会自动上传。
  • 浮点数直接用 === 比较：应使用 assertAlmostEqual。
  • 海龟初始朝向向上（遵循 Logo 惯例），不是向右。
  • drawPersonalArt 只画几行或简单多边形不满足"至少 20 行非重复代码"的要求。
