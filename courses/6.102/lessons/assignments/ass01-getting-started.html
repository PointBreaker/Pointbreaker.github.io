Getting Started：配置开发环境

安装 Node.js、TypeScript、VS Code 与 Git，连接 github.mit.edu，为全学期的 TypeScript 软件工程实践做好准备。

实验目标

  • 安装并验证 Node.js (LTS 24.x.y)、TypeScript 5、Visual Studio Code、Git。
  • 配置 Git 身份、commit 编辑器与 git lol 别名。
  • 生成 SSH 密钥并连接 MIT GitHub Enterprise (github.mit.edu)。
  • 安装课程专用工具 Praxis Tutor 与 Constellation。

先修知识

  • 无。这是 6.102 的第一个模块，适合从零开始。
  • 你需要一台能运行终端（Terminal / Git Bash）的电脑，以及一个 MIT 账号。

分步指引

1. 安装 Node.js

前往 Node.js Downloads，选择 LTS 24.x.y 安装。注意不要装 "Current" 版本。安装后在终端验证：

node --version   # 应输出 v24.x.y

若需多版本共存，使用 nvm 管理。

2. 安装 TypeScript

# macOS / Linux
sudo -H npm install -g typescript@5
# Windows
npm install -g typescript@5
tsc --version

3. 安装 Visual Studio Code

下载并安装 VS Code（或 VSCodium）。课程工具 Praxis Tutor 与 Constellation 依赖 VS Code 扩展。安装后确认能从命令行启动：

code .

4. 安装 Git

Windows 用户应安装 Git Bash。验证：

git --version

5. 配置 Git

git config --global user.name "Your Name"
git config --global user.email username@mit.edu
git config --global core.editor "code --wait"
git config --global alias.lol "log --graph --oneline --decorate --color --all"

Windows 还需让 npm 使用 Git Bash：

npm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"

6. 连接 github.mit.edu

  1. 登录 github.mit.edu（MIT GitHub Enterprise）。
  2. 进入 Settings → SSH and GPG keys，生成并添加 SSH 密钥。
  3. 测试连接：ssh -T git@github.mit.edu。

7. 安装 Praxis Tutor 与 Constellation

  • Praxis Tutor：下载 praxis.vsix，在 VS Code 中 View → Extensions → … → Install from VSIX 安装。配置 personal start URL。
  • Constellation：下载 constellation-vscode-0.4.8.vsix 安装，用于课堂结对编程。

验证清单

  • node --version 输出 v24.x.y
  • tsc --version 输出 5.x.y
  • git --version 正常
  • git config --list 含 alias.lol
  • SSH 连接 github.mit.edu 成功
  • VS Code 中能看到 Praxis Tutor 面板

常见陷阱

  • 装了 Node "Current" 而非 LTS 24：课程工具依赖 LTS，Current 是实验版。
  • Windows 用 CMD 而非 Git Bash：命令语法不同，会导致问题。
  • 忘记配置 user.name / user.email：commit 时会报错。
  • SSH 密钥加到了 github.com 而非 github.mit.edu：这是两个不同的系统。
