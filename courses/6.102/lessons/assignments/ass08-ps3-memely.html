MIT 6.102 · PS3 · Assignment 8

PS3：Memely

探索解析器（parser）、递归数据类型与不可变类型的相等性：构建一个 meme 表达式语言，解析表达式并生成图片。

实验目标

  • 定义不可变的递归 ADT 表示表达式抽象语法树（AST）。
  • 用 ParserLib 编写语法并实现解析器。
  • 实现结构相等性 equalValue 与递归的 toString。
  • 用 Canvas API 计算尺寸与生成图片。
  • 练习迭代开发：先实现最小语言子集，再扩展。

先修知识

  • PS2 的 ADT 经验。
  • 阅读材料：递归数据类型、语法与解析。

任务概述：Meme 表达式语言

表达式的含义是一张生成的图片（二维像素数组）。

  • 原语：文件名（如 myroom.jpg）、标题（如 "hello"）。
  • 并排粘合 |：水平拼接。
  • 上下粘合 ---：垂直拼接（至少 3 个短横）。
  • 覆盖 ^（顶对齐）、_（底对齐）。
  • 缩放 @：red.jpg @ 300x200，可用 ? 保持宽高比。

优先级（高→低）：@ > ^ > _ > | > ---。括号可覆盖。

分步指引

Problem 1：表示表达式

在 expression-impls.ts 定义不可变递归 ADT MemeExpression，为每种表达式定义变体类。实现 toString()（输出合法表达式）与 equalValue()（结构相等）。AST 中不得出现具体语法（括号、空白）。

Problem 2：解析表达式

在 expressionparser.ts 写 ParserLib 语法，实现 parse()。处理合法与非法输入，给出合理错误信息。

Problem 3：尺寸

在 MemeExpression 添加尺寸操作（递归，不用 instanceof），实现 commands.ts 的 size()（不超过 3 行粘合代码）。

Problem 4：图片生成

在 MemeExpression 添加图片操作（递归），实现 commands.ts 的 image()。使用 imagelibrary.ts API，不要直接 import canvas/fs。

迭代开发建议

  1. 先实现最小子集：文件名、|、@ 用数字（不含 ?）。
  2. 通过 Didit 公开测试与 alpha 评分后，再扩展：标题、---、^、_、@ 用 ?。

用户界面

  • 控制台 UI：npm start，输入表达式，!size/!image/!quit 命令。
  • Web UI：npm run web，浏览器访问 localhost:8080，输入表达式点击 Generate。

提交与验收

  • commit 并 push 到 github.mit.edu，评分使用 9:00pm EDT 截止时的仓库状态。
  • 正确性完全由你自己负责。

评分构成

  • ~30% alpha 自动评分（含在线练习）
  • ~20% alpha 人工评分
  • ~25% beta 自动评分
  • ~25% beta 人工评分（含代码审查）

Alpha 自动评分权重集中在最小子集（文件名、|、@ 数字）；beta 覆盖整个语言。

常见陷阱

  • 在 AST 中保留括号或空白：AST 应只表示抽象结构。
  • toString 用 instanceof：不允许，应多态。
  • equalValue 不用 instanceof：这里应该用。
  • 直接 import canvas/fs：会破坏 Web UI，应用 imagelibrary.ts。
  • size()/image() 超过 3 行：说明 ADT 操作设计得不够强大。
