Basic TypeScript

从 Python 过渡到 TypeScript：掌握快照图、可变性、const/let、Array/Map/Set、泛型与迭代，建立静态检查思维。

实验目标

  • 掌握 TypeScript 基本语法，从 Python 迁移。
  • 用快照图（snapshot diagram）刻画程序运行时的栈与堆状态。
  • 区分可变（mutable）与不可变（immutable）、可重新赋值（reassignable）与不可重新赋值（unreassignable）。
  • 熟练使用 Array、Map、Set、泛型（generics）与迭代。

快照图

快照图用于描绘程序某时刻的内部状态：栈（进行中的方法与局部变量）和堆（当前存在的对象）。

  • 变量名 + 箭头 → 值。
  • 对象用圆圈标注类型，内部写字段名与箭头。
  • 不可变值（如 string）用双边框；不可重新赋值引用用双箭头。

可变 vs 不可变，重新赋值 vs 重新绑定

let s: string = "a";
s = s + "b";          // 重新赋值：s 指向新字符串 "ab"（string 不可变）

const arr: Array<string> = ["a"];
arr.push("b");        // 可变：同一个数组对象内容改变
// arr = ["x"];        // 错误：const 禁止重新绑定
  • 不可变类型：string、number 等，值一旦创建不能改变。
  • 可变类型：Array、自定义对象，内容可以改变。
  • const 让引用不可重新绑定，但不保证值不可变。

Array / Map / Set

// Array 类似 Python list
const cities: Array<string> = ["Boston", "Bogotá"];
cities.push("Barcelona");
console.log(cities[0]);     // Boston

// Map 类似 Python dict
const fruits: Map<string, number> = new Map([
  ["apple", 5],
  ["banana", 7],
]);
fruits.set("apple", fruits.size);
console.log(fruits.get("apple"));   // 2

// Set：无序唯一集合
const nums: Set<number> = new Set();
nums.add(42);
console.log(nums.has(42));  // true

泛型

let cities: Array<string>;
let numbers: Set<number>;
let turtles: Map<string, Turtle>;
// 等价写法：let cities: string[];

泛型让编译器在添加和取出时做静态类型检查。

迭代

for (const city of cities) { console.log(city); }
for (const num of numbers) { console.log(num); }
for (const [key, value] of turtles.entries()) { console.log(key, value); }

警告：不要用 for...in，它遍历的是键/索引而非元素。避免在迭代时修改集合。

缺失值

prices.get("banana");  // undefined（键不存在）
fruits[2];             // undefined（越界索引）

注意：JavaScript 数组默认是稀疏（sparse）的，但 Array<T> 类型约定为稠密、从 0 开始连续索引。

相等性

  • === 严格相等（比较值或引用身份）。
  • assert.deepStrictEqual 比较数据结构内容。
  • 不可变值用 strictEqual；对象内容用 deepStrictEqual。

常见陷阱

  • s.concat("x") 不修改 s，而是返回新字符串——忘记赋值等于什么都没做。
  • 函数内对参数 n++ 不影响调用者的变量（基本类型按值传递）。
  • for...in 与 for...of 行为完全不同。
  • 空数组/Map/Set 在布尔上下文中仍为 truthy，不能用来判空。

工具链速览
