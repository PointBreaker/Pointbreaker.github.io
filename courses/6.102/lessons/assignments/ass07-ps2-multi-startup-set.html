PS2：Multi-Startup Set

练习设计、测试与实现抽象数据类型（ADT）：用两种 rep 实现 IntervalSet，构建 MultiIntervalSet，并度量相似度。

实验目标

  • 为可变类型设计、测试、实现 ADT，规格由题目给出。
  • 用两种不同 rep 实现同一 ADT，练习选择抽象函数（AF）与 rep 不变量（RI）。
  • 防止 rep 暴露（rep exposure），实现 checkRep 与 toString。
  • 使用泛型让 ADT 支持任意标签类型。

先修知识

  • PS0、PS1 的 TypeScript 与测试经验。
  • 阅读材料：抽象数据类型、抽象函数与 rep 不变量、接口与子类型。

任务概述

本问题集构建两个 ADT：

  • IntervalSet<Label>：可变集合，每个标签关联数轴上一个不重叠的半开区间 \([start, end)\)。
  • MultiIntervalSet<Label>：可变集合，每个标签可关联多个全局不重叠的区间。

例如 \(\{ A = [0,5), B = [10,30), C = [30,35) \}\) 可画为：

" A"      " B"                                " C"
0         10       20       30      35

分步指引

Problem 1：测试 IntervalSet<string>

在 test/intervalset.test.ts 设计、记录并实现测试。测试必须针对 IntervalSet 规格的合法客户端，使用 new SomeIntervalSet<string>(..) 构造实例。对输入 this 的状态做划分。

Problem 2：实现 RepMapIntervalSet

使用给定 rep：startMap: Map<string, bigint>、endMap: Map<bigint, bigint>。必须写 AF、RI、防 rep 暴露说明、checkRep、toString。先实现 string 标签版，再泛化为 RepMapIntervalSet<Label>。

Problem 3：实现 RepArrayIntervalSet

使用给定 rep：labelList: Array<Label>、valueList: Array<bigint>。实现泛型版，并用 makeIntervalSet() 暴露一个实现给客户端。

Problem 4：MultiIntervalSet<Label>

用 IntervalSet 作为 rep 构建 MultiIntervalSet。测试并实现，只能依赖 IntervalSet 的规格，通过 makeIntervalSet() 工厂获取实例。

Problem 5：相似度 similarity

实现 similarity(..) 度量两个 multi-interval set 的相似度，支持客户端自定义标签相似度。必须设计并使用一个辅助 ADT 提升代码质量。

文档要求

  • 所有类型与方法必须有 TypeDoc 格式的规格注释。
  • 所有实现必须有 AF、RI、防 rep 暴露说明。
  • 所有类型使用 checkRep 检查 RI，实现有用的 toString。
  • 实现接口方法时用 @inheritdoc 指向接口规格。

提交与验收

  • commit 并 push 到 github.mit.edu，评分使用 9:00pm 截止时的仓库状态。
  • Didit 反馈有限——正确性完全由你自己负责。
  • 尽早 push：截止前 Didit 构建可能延迟。

评分构成

  • ~30% alpha 自动评分（含在线练习）
  • ~20% alpha 人工评分
  • ~25% beta 自动评分
  • ~25% beta 人工评分（含代码审查）

常见陷阱

  • 修改已有规格：不允许。只能强化 similarity 的规格。
  • 给 rep 加字段或不用指定字段：不允许。
  • 测试直接调用具体实现的构造函数：应使用 SomeIntervalSet。
  • 泛型标签用 toString()：泛型对象不能直接调 toString，用 "" + lbl 或模板字符串。
  • 从 bigint 转 number 的时机：注意精度后置条件。
