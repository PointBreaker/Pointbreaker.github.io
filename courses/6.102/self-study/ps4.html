规格说明

Board 文件格式

第一行 ROWSxCOLUMNS，随后恰好 ROWS*COLUMNS 行卡片标记（行优先）。Board.parseFromFile(filename) 返回 Promise。

Board-state 线协议

响应以 ROWSxCOLUMNS 开始，然后每行一个空格：

  • none — 无卡片
  • down — 背面朝上
  • up CARD — 正面朝上但不受请求玩家控制
  • my CARD — 正面朝上且受请求玩家控制

翻牌规则（摘要）

第一张牌：

  • 空格：失败
  • 背面朝上：翻为正面，该玩家获得控制权
  • 正面朝上且无人控制：该玩家获得控制权
  • 正面朝上且他人控制：异步等待直到可获得或失败。其他玩家继续正常操作

第二张牌：

  • 空格：失败并释放第一张牌
  • 任何已控制的正面牌（含自己的第一张）：立即失败，释放第一张
  • 否则揭示候选牌。匹配则保留两张控制权；不匹配则释放控制权，牌保持正面朝上直到玩家下一步操作

下一张第一张牌之前：

  • 匹配：移除两张牌
  • 不匹配：每张前次非匹配牌仅在仍存在、正面朝上且无人控制时翻回背面

命令 API

look(board, playerId): Promise<string>
flip(board, playerId, row, column): Promise<string>
map(board, playerId, f): Promise<string>
watch(board, playerId): Promise<string>
  • look 返回该玩家视角的当前 board 状态
  • flip 执行一次翻牌尝试，失败时 reject。坐标为零基 (row,column)
  • map 异步替换每个卡片字符串。两个匹配的牌在 map 开始时，玩家不得观察到只改了一个的中间态（成对一致性）
  • watch 等待有意义的 board 变更，返回新状态。必须基于 Promise 而非轮询/忙等

server.ts — 调试服务器

import http from 'node:http';
import type { Board } from './board.js';
import { flip, look, map, watch } from './commands.js';

/** Small independently-written debug server using a simple JSON-ish query protocol. */
export function startServer(board:Board, port:number):http.Server {
  const server=http.createServer(async (req,res)=>{
    try {
      const url=new URL(req.url ?? '/', `http://${req.headers.host ?? 'localhost'}`);
      const player=url.searchParams.get('player') ?? 'player'; let body:string;
      if(url.pathname==='/look') body=await look(board,player);
      else if(url.pathname==='/flip') body=await flip(board,player,Number(url.searchParams.get('row')),Number(url.searchParams.get('col')));
      else if(url.pathname==='/watch') body=await watch(board,player);
      else if(url.pathname==='/map') body=await map(board,player, async card => card);
      else { res.statusCode=404; body='not found'; }
      res.setHeader('content-type','text/plain; charset=utf-8'); res.end(body);
    } catch(e) { res.statusCode=400; res.end(e instanceof Error ? e.message : String(e)); }
  });
  server.listen(port); return server;
}
