自学期支架

一套干净室重建的 MIT 6.102 问题集练习环境，包含 5 个 TypeScript 问题集的规格说明、源码骨架、测试框架与课程地图。所有实现均从 TODO 开始——这是故意的。

关于此支架

本项目不是 MIT 私有 github.mit.edu 起始仓库的副本，也不包含学生解答。它从公开讲义和 TypeDoc 重建了公开的 API 接口、练习序列、可运行的 TypeScript 设置，以及少量原创的冒烟测试基础设施。

问题集

PS0 · Turtle Graphics

海龟绘图

熟悉工具链与 TypeScript 标准库，用 drawSquare、drawApproximateCircle 等函数创作个人艺术作品。

 PS1 · Specific Graphics

特定图形

测试先行开发，用 lerp 与弱/强规格说明绘制复杂静态图形，引入 Bézier 曲线与动画工具箱。

 PS2 · Multi-Startup Set

多起点集合

IntervalSet 的两种 rep 实现、泛型 MultiIntervalSet、similarity 函数，深入抽象数据类型。

 PS3 · Memely

Memely

递归 ADT 与 ParserLib：immutable AST、结构等价性、表达式解析、Canvas 渲染。

 PS4 · Memory Scramble

记忆扰乱

Board ADT、HTTP 并发交互、异步等待与 watch 回调——并发与网络的实战。
