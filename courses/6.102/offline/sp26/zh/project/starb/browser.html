Web 浏览器中的 TypeScript

本页介绍如何在 Web 浏览器中使用 TypeScript。

编译与打包

下面是一种在网页内运行 TypeScript 的方法：

  • 将 TypeScript 代码编译成 JavaScript
  • 将所有通过 import 引入的 JavaScript 文件打包成一个单独的 JavaScript 文件（通常称为 bundle.js 或类似名称）
  • 使用 <script> 标签将打包后的 JavaScript 文件加载到网页中

在项目设置中，前两个步骤由一个名为 esbuild 的工具配合 TypeScript 编译器完成。 当你运行 npm run compile 时，它会同时生成：

  • dist/starb-server.js（由 npm run server 运行）以及所有其他 .ts 文件编译后的 .js 文件，还有
  • dist/client-bundle.js，由 starb-client.html 加载。

但由于软件开发是非常迭代的——编辑 TypeScript 源码，然后运行它，然后再编辑，再运行，等等——如果每次编辑时编译和打包都能自动完成，那就更方便了。

要使用这种设置，首先运行一个 watch 脚本：

npm run watch-example      # 如果你在编辑 example-page.ts
npm run watch-client       # 如果你在编辑 starb-client.ts

它会编译和打包代码，在 dist/ 文件夹中生成一个打包文件（example-bundle.js 或 client-bundle.js）。如果你查看 example-page.html 和 starb-client.html，你会在末尾看到一个对应的 <script> 标签，它将打包文件加载到网页中。 所以你的下一步是：

  • 在 Web 浏览器中打开 example-page.html（或 starb-client.html）

你将在浏览器中看到 Web 用户界面，你用 npm run watch-... 编译和打包的代码将在该网页中运行。

重要的是，npm run watch-... 命令会持续运行。 它会监视你的 TypeScript 源文件的变化。 每当你编辑并保存了 example-page.ts（或 starb-client.ts）所依赖的任何 .ts 文件时，它就会自动重新编译和打包。

所以，一旦你启动了一个 watch，并将相应的 HTML 文件加载到浏览器中，你的正常开发流程将是：

  • 编辑 TypeScript 代码
  • 保存到磁盘（你会看到 tsc 和 esbuild 都输出了重新编译和打包的信息）
  • 在浏览器中重新加载网页

重新加载后的网页将运行更新后的代码。

如果网页向服务器发出请求，该服务器也必须正在运行。 如果你更改了服务器端的代码，不要忘记停止并重新启动服务器（可能除了重新加载网页以重置其状态之外），以便测试新代码。

无 Node 依赖

以下代码不会正常工作：

puzzle.ts

import fs from 'node:fs';

export class Puzzle { ... }

export async function fromFile(...): Promise<Puzzle> {
  // 使用 fs.promises.readFile 读取文件
  //   并根据其内容创建一个 Puzzle
}

export function fromString(...): Puzzle {
  // 根据给定的字符串创建一个 Puzzle，
  //   完全不使用文件系统
}

starb-server.ts

import { fromFile } from './puzzle.ts';

// 调用 fromFile 以通过读取文件来创建 Puzzle
//


starb-client.ts

import { fromString } from './puzzle.ts'; // 哎呀！

// 调用 fromString 以根据服务器发送的字符串创建 Puzzle
//

当你尝试为浏览器打包 starb-client.ts 时，你会看到一个错误：

✘ [ERROR] Could not resolve "fs"
src/puzzle.ts:1:15:       
  1 │ import fs from 'fs';
    ╵                ~~~~ 
在文件系统中找不到包 "fs"，但它已内置于 node 中。你是要为 node 打包吗？你可以使用 "--platform=node" 来这样做，这将消除此错误。

错误消息中的建议没有帮助，因为你不是在尝试为 Node 打包：你是在尝试为浏览器打包。 虽然在这个例子中 starb-client.ts 只使用了 fromString，但它不能导入任何导入了 fs 的文件（也不能导入导入了又导入了 fs 的文件，等等），所以它不能导入 puzzle.ts。

这里有一个快速修复方法。 考虑一下在你们组的设计中实现相同目标的最佳方式，这可能涉及额外的模块：

puzzle.ts

export class Puzzle { ... }

export function fromString(...): Puzzle {       
  // 根据给定的字符串创建一个 Puzzle
}

starb-server.ts

import fs from 'node:fs';
import { fromString } from './puzzle.ts';

async function fromFile(...): Promise<Puzzle> {
  // 使用 fs.promises.readFile 读取文件，
  //   然后调用 fromString 来创建 Puzzle
}


starb-client.ts

import { fromString } from './puzzle.ts'; // 没问题！

// 调用 fromString 以根据服务器发送的字符串创建 Puzzle
//

查看控制台输出

当你的 TypeScript 代码在 Web 浏览器中运行时，调试输出会出现在开发者控制台中。 以下是在常用浏览器中打开开发者控制台的方法：

  • Chrome：查看 → 开发者 → JavaScript 控制台
  • Firefox：工具 → 浏览器工具 → Web 开发者工具，然后在打开的开发者面板中选择控制台标签页。
  • Safari：开发 → 显示 JavaScript 控制台。（如果你在菜单栏中没有看到"开发"菜单，请选择 Safari → 偏好设置，点击高级，然后选择"在菜单栏中显示'开发'菜单"。）
