入门指南

6.102 要求你快速上手。 本页帮助你搭建软件开发环境。

如果你有任何问题，或在按照下面的说明操作时遇到任何困难，请寻求帮助。

安装 Node

前往 Node.js 下载页面，然后：

  • 对于 Windows 或 macOS：使用 Windows 或 macOS 安装程序

  • 对于 Linux：点击页面底部的“Installing Node.js via package manager”，并找到适合你的 Linux 发行版的软件包

    • 对于 Arch Linux：建议的 nodejs 软件包是 Node 的“Current”版本，这不是你想要的； 请改为查找并安装合适的 nodejs-lts 软件包

确保你安装的是 Node 的 LTS 版本，即 24.x.y 版本。 不要安装“Current”版本，它是一个前沿的开发版本，不受长期支持。

  • 如果你之前已经安装了旧版本的 Node，安装程序会将其替换为 Node 24。 如果你需要保留旧版本的 Node 因为你正在处理其他某个项目， 那么请使用 nvm 来管理多个 Node 版本，以便你在本课程中使用 Node 24。

如果安装程序在安装过程中询问问题，你可以接受默认选项，只需点击下一步。

你的 Node 版本

安装 Node 后，打开终端或命令提示符并运行以下命令来确认安装情况和版本：

node --version

在下面输入你的 Node 版本。 它的形式应该是“x.y.z”，其中 x、y、z 是数字。

安装 TypeScript

安装 Node 后，打开终端或命令提示符，然后运行：

  • 对于 macOS 或 Linux：

    sudo -H npm install -g typescript@5

  • 对于 Windows：

    npm install -g typescript@5

你可能会看到一条警告说“a new version of npm is available”，你可以忽略它。

安装 Visual Studio Code

Visual Studio Code 是一款开源编程编辑器，支持多种编程语言（不仅仅是 TypeScript）。 你必须安装它，因为 6.102 有几个工具是作为 Visual Studio Code 的扩展设计的（特别是 Praxis Tutor 和 Constellation，将在本页后面安装）。 虽然欢迎你在 6.102 的作业中使用其他编辑器，但你需要安装 VS Code 才能使用 Praxis Tutor 和 Constellation。

前往 Visual Studio Code 下载页面，下载并安装适合你平台的安装程序。

  • 如果你更愿意安装 VSCodium，那也可以。
  • 如果安装程序在安装过程中询问问题，你可以接受默认选项，只需点击下一步。

如果你已经安装了 Visual Studio Code 或 VSCodium，你不需要重新安装，只需通过下面的说明确保它是最新版本。

确保你安装了最新版本。 运行 Visual Studio Code，然后执行以下任一操作：

  • macOS：Code → Check for Updates…（或 Restart to Update）
  • Windows/Linux：Help → Check for Updates…（或 Restart to Update）

它应该要么显示“No updates available”，要么帮助你更新到最新版本。

安装 Praxis Tutor

Praxis Tutor 是 6.102 用来学习 TypeScript 语法和语义的工具。

  1. 下载 Praxis Tutor 扩展，它将作为一个名为 praxis.vsix 的文件保存到你的笔记本电脑上。

  2. 运行 Visual Studio Code，然后转到 View → Extensions。

  3. 在出现的扩展面板的右上角，点击 ...，然后点击 Install from VSIX…，然后找到并安装你刚刚下载的 praxis.vsix 文件。

  4. 关闭 Visual Studio Code 并重新启动。

  5. 转到 View → Command Palette，搜索 praxis，然后点击 Explorer: Focus on Praxis Tutor View。你应该会在左侧边栏看到一个 PRAXIS TUTOR 面板。Tutor 面板可能正在显示错误消息，例如“No such tutor”或“The Tutor doesn’t know who you are”。没关系，你仍然需要使用接下来的几个步骤进行配置。

  6. 打开设置面板：

    • Windows/Linux：File → Preferences → Settings
    • macOS：Code → Settings… → Settings
      • 如果你安装的是 VSCodium，请在菜单栏中查找 VSCodium，而不是 Code。
      • 在 macOS 12 及更早版本中，请在第一个菜单中查找 Preferences，而不是 Settings
         

  7. 设置面板顶部有一个搜索框。搜索 praxis，它应该只显示 Praxis Tutor 的设置。

  8. 点击这里获取你的个人启动 URL。

  9. 在标有 Location: Personal Link 的框中，复制并粘贴你的个人启动 URL。
    你应该会看到 Praxis Tutor 立即重新加载并显示一个顶部带有“Basic TypeScript”的页面，这意味着它已准备好使用。

  10. 关闭设置面板。

安装 Constellation

Constellation 是 6.102 用来与同伴一起完成课堂编程练习的系统。

  1. 下载 Constellation 扩展 constellation-vscode-0.4.8.vsix。

  2. 在 VS Code 中，转到 View → Extensions，点击 ...，然后点击 Install from VSIX…，并选择 constellation-vscode-0.4.8.vsix。

  3. 再次关闭 VS Code 并重新启动。

  4. 转到 View → Command Palette，这会弹出一个搜索框，允许你查找和运行 VS Code 中的任何命令。 输入“set up constellation”并选择 Set up Constellation。

    • 如果出现一个窗口，询问“Do you want Code to open the external website”，请点击 Configure Trusted Domains 和 Trust https://constellation.mit.edu。

    • Windows/Linux：如果出现错误“certificate has expired”，请再次打开 VS Code 设置面板并搜索 systemcertificates。取消勾选 Http: System Certificates 选项，然后重新启动 VS Code 并重试。

  5. 你的网页浏览器应该会打开一个需要 MIT Touchstone 登录的 Constellation 页面。 点击红色的 Go! 按钮。

  6. 按照提示操作后，你应该会在 VS Code 中看到一条“successfully authenticated and connected”通知，以确认 Constellation 已准备好使用。

设置 Git 和 github.mit.edu

我们将从命令行使用 Git，所以请确保你在本节以及在本课程中每次使用 Git 时都处于命令行环境中：

  • 在 macOS 和 Linux 上，打开 Terminal 应用程序。
  • 在 Windows 上，打开 Git Bash。
    • 不要使用 Windows 命令提示符，也不要使用 Windows Subsystem for Linux。

配置 npm 以使用 Git Bash（仅限 Windows）

如果你使用的是 Windows，请运行以下命令，以便你的 npm 命令能够构建问题集：

npm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"

重要：请使用复制粘贴将此命令放入你的 Git Bash 终端，不要重新输入。在 Git Bash 中，通常的 Ctrl-V 粘贴快捷方式可能默认不起作用，因此请尝试使用右键菜单并选择 Paste。

如果你使用的是 macOS 或 Linux，请不要运行此命令。

设置偏好

在使用 Git 之前，我们将进行一些必要的设置，让它用起来更顺手。

  1. 你是谁？

    每次 Git 提交都包含作者的姓名和电子邮件。 确保 Git 知道你的姓名和电子邮件，方法是运行以下两个命令：

    git config --global user.name "Your Name"
git config --global user.email username@mit.edu    # 或者任何能收到邮件的地址

    你不一定非要用你的 MIT 电子邮件地址；只需要它是一个你能收到邮件的地址即可。

  2. 编辑提交信息。

    每次 Git 提交都有一条描述性消息，称为提交信息。 默认情况下，Git 使用一个流行但相当难用的编辑器 Vim 来编辑这些消息。 如果你从未使用过 Vim，我们建议你改用 Visual Studio Code 作为提交信息编辑器。

    首先确保你的 VS Code 已配置为可以从命令行启动，方法是运行：

    code

    （或者如果你安装的是 VS Codium 而不是 VS Code，则使用 codium）。

    Visual Studio Code 或 VSCodium 应该会启动。如果你反而收到错误消息，请运行 VS Code，将其配置为从命令行启动，关闭并重新打开终端，然后再次尝试运行 code 或 codium。

    现在配置 git 的提交编辑器：

    git config --global core.editor "code --wait"
    • 如果你安装的是 VS Codium，请在命令中使用 "codium --wait"。
    • 如果你已经知道如何使用 Vim，也可以继续使用 Vim，或者配置任何其他你更习惯使用的编辑器。

  3. LOL。

    git log 是一个用于查看仓库历史的命令。

    为了创建一个特殊版本的 git log 来总结你的仓库历史，让我们使用以下命令创建一个 git lol 别名（全部在一行）：

    git config --global alias.lol "log --graph --oneline --decorate --color --all"

    现在，在任何仓库中，你都可以使用：

    git lol

    来查看提交历史的 ASCII 艺术图。

连接到 github.mit.edu

  1. 访问 github.mit.edu 并登录。

    GitHub（github.com） 是一个流行的托管远程 Git 仓库的网站。MIT 的 GitHub Enterprise 站点（github.mit.edu）运行着相同的软件，但你使用 MIT 账户登录。

    你 6.102 的问题集和项目仓库将存储在 github.mit.edu 上。

  2. 从页面右上角的菜单中，转到 Settings，然后选择 SSH and GPG keys。

  3. 按照GitHub Enterprise 的 SSH 设置说明操作：

    1. 检查你是否已有 SSH 密钥

    2. 如果你没有，请生成一个 SSH 密钥

    3. 将 SSH 密钥添加到你的账户 —— 确保你是在 github.mit.edu 上操作，而不是 github.com
