快照图

为了理解微妙的问题，画出运行时正在发生的情况对我们来说很有用。 快照图表示程序在运行时的内部状态：它的 栈（正在执行的方法及其局部变量）和它的 堆（当前存在的对象）。

以下是在 6.102 中使用快照图的原因：

  • 通过图形相互交流（在课堂上和团队会议中）。
  • 阐明不可变值与不可重新赋值的引用、指针别名、堆与栈、抽象与具体表示等概念。
  • 为后续课程中更丰富的设计表示法奠定基础。 例如，快照图在 6.104 [原 6.170] 中推广为对象模型。

虽然本课程中的图表示例使用的是 TypeScript，但这种表示法可以应用于任何现代编程语言，例如 Python、Java、C++、Ruby。

最简单的快照图显示一个变量名，带有一个箭头指向该变量的值：

let n: number = 1;
let x: number = 3.5;

当我们想显示值的类型，或显示其更多内部结构时，我们使用一个标有其类型的圆圈：

let val: BigInt = BigInt("1234567890");

快照图的语法旨在灵活，并非一定要始终显示所有细节，这样我们就可以画出简单的图，聚焦于我们想要讨论的程序状态的特定方面。

例如，右边的图都是在快照图中显示字符串变量的合理方式。

let s: string = "hello";

在不同的上下文中，我们可能会使用不同的图。 有时我们关心字符串的特定值，有时则不关心。 有时我们想强调字符串是一个对象值，有时这并不相关。

当我们想显示对象值的更多细节时，我们会在对象圆圈内写下字段名，并用箭头指向它们的值。

let pt: Point = new Point(5, -3);

为了显示更多细节，字段可以包含其声明的类型。

更改变量的值与重新赋值变量

快照图为我们提供了一种方式来可视化改变变量和改变值之间的区别：

  • 当你给变量或字段赋值时，你是在改变变量箭头的指向。 你可以将它指向一个不同的值。

  • 当你改变一个可变对象（例如数组）的内容时，你是通过改变其内部的引用来改变它的值。

重新赋值和不可变值

例如，如果我们有一个字符串变量 s，我们可以将它从 "a" 重新赋值为 "ab"。

let s: string = "a";
s = s + "b";

string 类型是不可变类型的一个例子，这种类型的值一旦创建就永远不可更改。 不可变性是本课程的一个主要设计原则，我们将在未来的阅读中更多地讨论它。

在快照图中，当我们想强调字符串等对象的不可变性时，我们给它画上双线边框，如上图所示。

可变值

相比之下，数组是一个可变对象，它有改变对象值的方法：

let arr: Array<string> = ["a"];
arr.push("b");

可变性和不可变性之间的区别将在使我们的代码免受 bug 侵害方面发挥重要作用。

不可重新赋值的引用

TypeScript 还为引用提供了不可变性：只能被赋值一次且永远不会被重新赋值的变量。 要使一个引用不可重新赋值，请使用关键字 const 来声明它：

const n: number = 5;

在这段代码中，n 永远不能被重新赋值；它的整个生命周期都将引用值 5。 如果 TypeScript 编译器不能确定你的 const 变量在运行时只会被赋值一次，那么它会产生一个编译器错误。 因此，const 为你提供了对不可重新赋值的引用的静态检查。

在快照图中，当我们想聚焦于可重新赋值性时，我们会对不可重新赋值的引用使用双箭头。 右边的图显示了一个对象，其 id 永远不会改变（它不能被重新赋值为另一个数字），但其 age 可以改变。

请注意，我们可以有一个不可重新赋值的引用指向一个可变的值，即使我们指向的是同一个对象，它的值也可以改变：

const arr: Array<string> = ["a"]
arr.push("b");

我们也可以有一个可重新赋值的引用指向一个不可变的值，其中变量的值可以改变，因为它可以被重新指向另一个对象：

let s: string = "a";
s = "ab";

双线有助于强调快照图中各部分的不可更改性。 但是，当可重新赋值性或可变性是显而易见的，或与讨论无关时，我们会保持图的简单，只使用单线箭头和对象边框。

数组、Map 和 Set

TypeScript 的 Array 类似于 Python 列表。 Array 包含一个由零个或多个对象组成的有序集合，同一个对象可能出现多次。 我们可以向 Array 中添加和删除项目，它会相应地增长和收缩以容纳其内容。

Array 操作示例：

TypeScript 说明 Python
lst[2] 获取元素 lst[2]
lst[2] = e 设置元素 lst[2] = e
lst.length 计算元素数量 len(lst)
lst.push(e) 在末尾添加元素 lst.append(e)
lst.pop() 从末尾移除元素 lst.pop()
if (lst.length === 0) ... 测试数组是否为空* if not lst: ...
lst.includes(e) 测试元素是否在数组中 e in lst
lst.splice(i, 1) 移除索引 i 处的元素 del lst[i]
lst.slice(i, j) 获取从索引 i 到 j（不包含）的元素的浅拷贝 lst[i:j]

* 请注意，在 TypeScript 中，if ( ! lst ) ... 不能用于测试数组是否为空。 这是与 Python 的一个重要区别。 TypeScript 的数组、map 和 set 总是truthy，即使 它们为空也是如此。

在快照图中，我们将 Array 表示为一个对象，其索引被绘制为字段。

这个 cities 数组可能表示一次从波士顿到波哥大再到巴塞罗那的旅行。

Map 类似于 Python 字典。 在 Python 中，map 的 键必须是可哈希的。 TypeScript 有更严格的要求，当我们讨论对象之间的相等性如何工作时会谈到它；目前，最安全的做法是只使用字符串和数字作为键，而不是任意的对象。

Map 操作示例：

TypeScript 说明 Python
map.set(key, val) 添加映射 key → val map[key] = val
map.get(key) 获取键对应的值 map[key]
map.has(key) 测试 map 是否包含某个键 key in map
map.delete(key) 删除映射 del map[key]
map.size 计算映射的数量 len(map)

Set 是一个由零个或多个唯一对象组成的无序集合。 像数学中的 集合 或 Python set 一样——而与 Array 不同——一个对象不能在集合中出现多次。 要么在，要么不在。 像 map 的键一样，Python set 中的对象必须是可哈希的。 类似地，TypeScript 的 Set 应该与一种可以用作 Map 键的类型一起使用，这意味着（目前）是字符串和数字。

Set 操作示例：

s.add(e) 添加元素 s.add(e)
s.delete(e) 移除元素 s.remove(e)
s.size 计算元素数量 len(s)

字面量

Python 提供了方便的语法来创建列表：

letters = ["a", "b", "c"]

以及 map：

fruits = {"apple": 5, "banana": 7 }

TypeScript 有相同的数组字面量语法：

let letters: Array<string> = ["a", "b", "c"];

但是创建 Map 字面量的语法稍微复杂一些。 最佳方法是使用键值对数组，如下所示：

let fruits: Map<string, number> = new Map([
    ["apple", 5],
    ["banana", 7],
]);

泛型：声明 Array、Set 和 Map 变量

与 Python 的集合类型不同，使用 TypeScript 的集合，我们可以限制集合中包含的对象类型。 当我们添加一个项目时，编译器可以执行静态检查，以确保我们只添加适当类型的项目。 然后，当我们取出一个项目时，我们可以确信它的类型会是我们期望的类型。

以下是声明一些保存集合的变量的语法：

let cities: Array<string>;        // 一个字符串 Array
let numbers: Set<number>;         // 一个数字 Set
let turtles: Map<string, Turtle>; // 一个键为 string、值为 Turtle 的 Map

TypeScript 提供了另一种声明 Array 类型的语法，将方括号放在元素类型之后：

let cities: string[]; // 也是一个字符串 Array

我们通常会使用 Array<T> 形式，以使代码含义更清楚，但 T[] 形式也可以。 请注意，Array<T> 和 T[] 在 TypeScript 中表示完全相同的含义（与你可能遇到的其他语言不同）。

迭代

一个非常常见的任务是遍历我们的 cities/numbers/turtles 等。

在 Python 中：

for city in cities:
    print(city)

for num in numbers:
    print(num)

for key in turtles:
    print("%s: %s" % (key, turtles[key]))

TypeScript 提供了类似的语法来遍历数组和集合中的项目，但使用的是 of 而不是 in：

for (const city of cities) {
    console.log(city);
}

for (const num of numbers) {
    console.log(num);
}

TypeScript 也允许 let city of cities，但最好使用 const，因为它可以防止你在循环体中无意中重新赋值 city。 TypeScript 不允许声明变量的类型（例如使用 const city: string of cities）；city 的类型会自动从 cities 的元素类型推断。

警告：避免在 TypeScript 中使用 for...in。 它是合法的语法，但它的作用与你期望的非常不同。 例如，对于数组 ["a", "b"]，for...in 不会遍历数组的元素（"a"、"b"），而是遍历数组的索引（0、1）。 对于集合或 map，for...in 会静默地什么都不做，导致你以为集合或 map 是空的，而实际上并不是。 避免使用 for...in，请使用 for...of 代替。

我们也可以像在 Python 中一样遍历 Map 的键或值：

for (const key of turtles.keys()) {
    console.log(key + ": " + turtles.get(key));
}

for (const value of turtles.values()) {
    console.log(value); // 打印每个 Turtle
}

for (const [key, value] of turtles.entries()) {
    console.log(key + ": " + value);
}

在底层，这种 for 循环使用的是Iterator，这是我们在本课程后面会看到的一种设计模式。

警告：在遍历集合时，注意不要改变它。 添加、移除或替换元素会扰乱迭代，甚至可能导致程序崩溃。 我们将在未来的课堂上更详细地讨论其原因。 请注意，这个警告同样适用于 Python。 下面的 Python 代码并不做你可能期望的事情：

numbers = [100, 200, 300]
for num in numbers:
    numbers.remove(num) # 危险！！！改变了我们正在遍历的数组
print(numbers) # 数组在这里应该是空的 —— 是吗？

使用索引迭代

如果你愿意，TypeScript 提供了不同的 for 循环，我们可以使用索引来遍历数组：

for (let ii = 0; ii < cities.length; ii++) {  // 类似于 Python 代码 `for ii in range(len(cities))`
    console.log(cities[ii]);
}

除非我们确实需要索引值 ii，否则这段代码很冗长，并且有更多隐藏 bug 的地方（从 1 开始而不是从 0 开始，使用 <= 而不是 <，对 ii 的某次出现使用了错误的变量名称，……）。 如果可以避免，请避免这样做。如果你确实需要索引以及元素值，你可以改用 entries()（它类似于 Python 中的 enumerate()）：

for (const [ii, city] of cities.entries()) {
    console.log(ii + ": " + city);
}

这可以防止上面提到的一些 bug，但你仍然应该避免遍历索引，除非你确实需要它们，即使使用 entries() 也是如此。

map 和数组中缺失的值

如果你尝试使用 get() 来获取一个未定义的键，它会返回特殊值 undefined：

const prices: Map<string, number> = new Map();
prices.set("apple", 5);
prices.get("apple")   // 返回 5
prices.get("banana")  // 返回 undefined

同样，如果你使用非法索引访问数组，结果是 undefined：

const fruits: Array<string> = ["apple", "banana"];
fruits[0]   // 返回 "apple"
fruits[1]   // 返回 "banana"
fruits[2]   // 返回 undefined
fruits[-1]  // 返回 undefined

令人惊讶的是，JavaScript 数组实际上是稀疏的：你可以将一个新元素放在任意索引处，而不仅仅是从 0 开始的连续序列中。 任何未分配的索引都会返回 undefined。 例如：

const arr: Array<string> = [];
arr[2] = "x";
arr[0]    // 返回 undefined
arr[1]    // 返回 undefined
arr[2]    // 返回 "x"
arr[3]    // 返回 undefined

数组稀疏性几乎不被 TypeScript/JavaScript 程序员使用。 除非明确另有说明，类型 Array<T> 表示数组是密集的，具有从 0 开始的连续索引，就像其他语言中的数组和列表一样。

变量声明

从初始化器推断类型

当我们使用初始化器声明一个变量时，我们通常可以省略类型声明，TypeScript 会自动从初始化表达式的类型推断它。 所以我们可以不用：

let x: number = 5;
let name: string = "Frodo";

而可以直接写成：

let x = 5; // 推断出 x: number
let name = "Frodo"; // 推断出 name: string

对于 Array、Set 和 Map 类型，我们可以在声明中或初始化器中写出完整类型，TypeScript 会推断另一个：

// 完整类型在声明中；初始化器类型被推断
let numbers: Array<string> = [];
let map: Map<string, number> = new Map();

// 完整类型在初始化器中；声明类型被推断
let numbers = new Array<string>();
let map = new Map<string, number>();

但是下面的声明是不完整的，并且在某个地方会导致静态类型错误：

let numbers = [];      // 不行：数组的元素类型是什么？
let ages = new Set();  // 不行：集合的元素类型是什么？
let map = new Map();   // 不行：键和值的类型是什么？

let 与 var

正如我们所见，TypeScript 有两种声明局部变量的方法：let 用于可能需要重新赋值的变量，const 用于不可重新赋值的变量。 在较旧的 JavaScript 代码中，你可能还会看到使用 var 来声明变量，像这样：

var x = 5; // 不行：避免使用 var

这些旧式的 var 声明不推荐使用，因为它们的作用域是整个函数（类似于 Python 变量），而 let 变量的作用域只是其外围的大括号。 你可以在 TypeScript 手册中阅读更多关于 let 和 var 之间区别的内容。

对象字面量和对象类型

TypeScript 有一种语法用于创建带有已初始化实例变量的对象：

{ x: 5, y: -2 }

（Python 有类似的语法，但它创建的是字典，而不是对象。）

这个表达式的静态类型是 { x: number, y: number }，它可以用来声明一个变量：

let point: { x: number, y: number } = { x: 5, y: 2 };

现在 point.x 和 point.y 可以用来访问存储在 point 所引用的对象中的 x 和 y 值。

一个仅由命名字段组成的对象类型，没有任何方法或操作，称为记录类型（在 C/C++ 等语言中也称为 struct）。 当我们讨论抽象数据类型时，会看到更好的管理复杂数据的方法。 但像这样的简单记录类型对于临时捆绑相关的数据位很有用，特别是当函数想要返回多个值时，例如：

function integerDivision(a: number, b: number): { quotient: number, remainder: number } {
    return {
        quotient: ...,  // a 除以 b 的结果
        remainder: ..., // a 除以 b 后的余数
    };
}

TypeScript 对对象字面量有许多快捷方式，包括解构赋值：

const { quotient, remainder } = integerDivision(23, 7);

这段代码声明了局部变量 quotient 和 remainder，并用 integerDivision() 返回的对象中相应名称的字段对它们进行初始化。

枚举

有时一个类型有少量、有限个不可变的值，例如：

  • 一年中的月份：January、February、…、November、December
  • 一周中的天：Monday、Tuesday、…、Saturday、Sunday
  • 罗盘点：north、south、east、west
  • 可用颜色：black、gray、red、…

当值的集合小且有限时，将所有值定义为命名常量是有意义的，TypeScript 称之为枚举，用 enum 结构表示。

enum Month {
    JANUARY, FEBRUARY, MARCH, APRIL,
    MAY, JUNE, JULY, AUGUST,
    SEPTEMBER, OCTOBER, NOVEMBER, DECEMBER,
}

enum PenColor {
    BLACK, GRAY, RED, PINK, ORANGE,
    YELLOW, GREEN, CYAN, BLUE, MAGENTA,
}

你可以在变量或方法声明中使用像 PenColor 这样的枚举类型名称：

let drawingColor: PenColor;

并像引用命名常量一样引用枚举的值：

drawingColor = PenColor.RED;

请注意，枚举是一个独特的新类型。 较旧的语言，如 Python 2 或 JavaScript，倾向于使用数字常量或字符串字面量来表示这样的有限值集合。 但枚举更加类型安全，因为它可以捕获类型不匹配等错误：

let month: number = TUESDAY;          // 如果使用数字常量则不会报错
let month: Month = DayOfWeek.TUESDAY; // 如果使用枚举则会产生静态错误

或者拼写错误：

let color: string = "REd";                 // 不会报错，拼写错误没有被捕获
let drawingColor: PenColor = PenColor.REd; // 枚举值拼写错误时产生静态错误

Python 3 也有枚举，类似于 TypeScript 的枚举，但不会进行静态类型检查。

API 文档

本阅读材料的前几节中有许多指向 JavaScript 和 TypeScript API 文档的链接。

API 代表 application programming interface（应用程序编程接口）。 如果你想编写一个与 Facebook 对话的应用程序，Facebook 会发布一个 API（实际上不止一个，针对不同的语言和框架）供你编程使用。

TypeScript 是 JavaScript 的超集，因此它在很大程度上依赖 JavaScript API 来实现功能。 JavaScript 又在两种不同的上下文中运行：在网页浏览器内部，以及在它外部（在 Node.js 中）。 每种上下文都有具有不同功能的不同的 API。

因此，有三个 API 文档来源被广泛用于 TypeScript/JavaScript 编程：

  • MDN JavaScript 参考，用于 JavaScript 的一般特性，以及特定于网页浏览器的 API。
  • Node.js 参考，用于特定于 Node.js 的浏览器外部 API。
  • TypeScript 手册，用于特定于 TypeScript 的特性。

以下是 MDN 提供的一些在每个 TypeScript/JavaScript 上下文中都可用的 API 示例：

  • String 是 TypeScript 称为 string 的类型。我们可以通过使用 "双引号" 或 '单引号' 来创建 String 对象。

  • Array 类似于 Python 列表。

  • Map 类似于 Python 字典。

以下是一些来自 Node.js 的 API，仅对在 Node 中运行的程序可用：

  • os.homedir() 获取用户主目录的路径名。

规范说明

这些详细描述是规范说明。它们允许我们在没有阅读或理解实现代码的情况下使用 Map、String 或 Set 等工具。

阅读、撰写、理解和分析规范说明将是我们 6.102 的首要重要任务之一，从接下来的几节课开始。

请注意，许多 MDN 文档页面还有一个名为“Specifications”的部分，指向 ECMAScript 语言标准中更详细的规范说明。（ECMAScript 是由 Ecma International 标准机构形式化的 JavaScript 语言官方定义，被所有主流网页浏览器和 Node.js 使用。）6.102 不使用标准机构所要求的形式化级别的规范说明，而是使用执业软件工程师所使用的级别，这更好地体现在 MDN 页面的描述中。因此，除非你好奇，否则不需要点进 ECMAScript 规范说明。

编程工具集

在你的 Python 编程中，你可能使用过编程编辑器编写代码，然后使用 python 命令来运行它。（或者你可能使用过像 Spyder 这样的开发环境，或者像 Jupyter 这样的计算笔记本。）

在 TypeScript/JavaScript 世界中，你需要使用的工具集更为复杂。本节简要介绍我们在 6.102 问题集中将使用的每个工具。入门指南页面提供了安装所有这些工具的正确版本的说明。

Visual Studio Code。这是我们将要使用的编程编辑器。它对多种语言的编程都有良好的支持，不仅仅是 TypeScript/JavaScript。

TypeScript 编译器。编译器会静态检查你的 TypeScript 代码，并将其转换为 JavaScript 代码（我们在静态检查阅读材料中看到了一个这样的例子）。Visual Studio Code 内置了一个 TypeScript 编译器，在你输入代码时会显示错误消息。当需要运行代码时，我们将使用 tsc（“TypeScript compiler”的缩写）将 TypeScript 文件转换为磁盘上的 JavaScript 文件。我们不会直接运行 tsc；而是通过 npm 来运行它，这将在下面讨论。

Node.js。Node 是一个 JavaScript 解释器。node 命令运行一个 JavaScript 代码文件，因此它在 Python 世界中扮演着类似于 python 命令的功能。JavaScript 也可以通过网页浏览器运行。在本课程中，我们将主要使用 node 来运行代码，但偶尔也会在网页浏览器中运行一些代码。

npm。NPM 是“Node Package Manager”的缩写，实际上有两个功能。首先，它管理你在程序中使用的外部包库。在使用几乎任何 TypeScript/JavaScript 项目之前，你的第一步很可能是运行 npm install 来安装它依赖的所有库。你会在所有问题集和课堂练习中习惯于运行这个命令。npm 的另一个功能是作为其他编程工具的通用运行器。例如，我们将使用 npm test 来用 TypeScript 编译器编译代码并在其上运行测试套件。

  • npm 从名为 package.json 的文件中获取其配置，你会在我们的所有问题集和课堂练习中看到它。如果你好奇可以查看它，但不要在你的 6.102 作业中修改此文件。
  • 当 npm install 安装库时，它会将它们放入名为 node_modules 的子文件夹中，以便每个项目都有自己的库副本，而不是在你的机器上全局安装它们。如果你从一个刚刚下载的项目中收到奇怪的错误，可能是因为你尚未运行 npm install 来创建你的 node_modules 文件夹。

试验 TypeScript 代码

在 Python 世界中，你可以使用 python 命令（不带文件参数）来获取一个 Python 解释器提示符，在那里你可以尝试编写简短的 Python 代码片段。

这在 TypeScript/JavaScript 世界中稍微复杂一些。虽然不带参数运行 node 确实会给你一个解释器提示符，但它是一个 JavaScript 提示符，而不是 TypeScript 提示符。单独的 node 命令不理解 TypeScript 的额外特性，比如静态检查。

有两种方法可以获取 TypeScript 提示符：

  • 在项目（如 6.102 问题集或课堂练习）中运行 npx ts-node。（如果你收到 Not Found 错误，那么你可能需要 npm install ts-node 来确保它已安装在项目中。）这会给你一个提示符，你可以在其中输入 TypeScript 代码（不仅仅是 JavaScript），你还可以导入项目使用的任何外部库。

  • 在你的网页浏览器中使用 TypeScript Playground。这会给你一个编辑器来编写和运行简短的 TypeScript 代码片段，但请注意，你的代码是在网页浏览器环境中运行的，因此它无法访问 Node 提供的任何库。
