    函数 size

    • size(expression: MemeExpression, library: ImageLibrary): string

      计算图像表情包表达式的大小。

      参数

      • expression: MemeExpression

        要使用的表达式

      • library: ImageLibrary

        命名图像文件的库

      返回 string

      "WxH"（采用与 @ 调整大小运算符对应部分相同的语法），表示该表达式根据 PS3 讲义中的语言定义所生成的图像的宽度 W 和高度 H。

      抛出

      如果大小无法计算，则抛出 Error
