    构造函数

    constructor

    • new ImageLibrary(dirname: "img", ...filenames: string[]): ImageLibrary

      创建一个新的图像库，从文件系统（在 Node.js 中运行）或从 URL（在 Web 浏览器中运行）加载图像。

      参数

      • dirname: "img"

        包含图像的目录，相对于当前文件夹（Node.js）或 URL（Web）；必须为 "img"

      • ...filenames: string[]

        要从目录加载的图像，例如 "boromir.jpg"；名称必须唯一

      返回 ImageLibrary

    方法

    getImage

    • getImage(name: string): Image

      按名称从此库中获取图像。

      参数

      • name: string

        图像基本文件名，例如 "boromir.jpg"

      返回 Image

      完全加载的 Image（因此其尺寸和像素立即可供使用）

      抛出

      如果库中没有该名称的图像，则抛出 Error
