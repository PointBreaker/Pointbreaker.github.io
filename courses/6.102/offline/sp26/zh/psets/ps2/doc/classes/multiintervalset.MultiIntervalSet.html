    Class MultiIntervalSet<Label>

    一个可变的带标签区间集合，其中每个标签关联一个或多个不重叠的半开区间 [start, end)。相同标签或不同标签的区间都不能重叠。

    例如，{ "A"=[[0,10)], "B"=[[20,30)] } 是一个多区间集，其中标签是字符串 "A" 和 "B"。我们可以向该集合添加 "A"=[10,20) 以获得 { "A"=[[0,10),[10,20)], "B"=[[20,30)] }。

    标签可以是任意类型 Label，使用 === 进行相等性比较。不能是 null、undefined 或 NaN。

    PS2 说明：这是一个必需的 ADT。你不能更改规格或添加新方法。

    Methods

    add

    • add(start: bigint, end: bigint, label: Label): void

      将带标签的区间添加到此集合中，前提是不已存在且不与现有区间冲突。

      带标签的区间在以下情况冲突：

      • 它们具有相同的标签但不同的、重叠的区间；或
      • 它们具有不同的标签但重叠的区间。

      例如，如果此集合是 { "A"=[[0,10),[20,30)] }，

      • add("A"=[0,10)) 无效果
      • add("B"=[10,20)) 添加 "B"=[[10,20)]
      • add("C"=[20,30)) 抛出 IntervalConflictError

      Parameters

      • start: bigint

        区间低端，包含

      • end: bigint

        区间高端，不包含，必须大于 start

      • label: Label

        要添加的标签

      Returns void

      Throws

      如果 label 已在此集合中且关联的区间不是 [start,end) 但与 [start,end) 重叠，或者此集合中带有不同标签的区间与 [start,end) 重叠，则抛出 IntervalConflictError

    intervals

    • intervals(label: Label): IntervalSet<number>

      获取此集合中与给定标签关联的所有区间（如果有）。返回的集合具有作为索引的整数标签：标签 0 关联最低区间，1 关联下一个，依此类推，涵盖此集合中具有所提供标签的所有区间。

      例如，如果此集合是 { "A"=[[0,10),[20,30)], "B"=[[10,20)] }，

      • intervals("A") 返回 { 0=[0,10), 1=[20,30) }
