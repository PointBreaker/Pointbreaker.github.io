    Function similarity

    • similarity(
          similarities: LabelSimilarity[],
          setA: MultiIntervalSet<string>,
          setB: MultiIntervalSet<string>,
      ): number

      测量带字符串标签的多区间集之间的相似度。

      使用客户端提供的标签相似度定义，其中 0 表示最不相似，1 表示最相似。

      两个多区间集之间的相似度（至少一个非空）定义为以下比率：
      （集合之间的分段匹配总和）/（集合的跨度）
      其中跨度是包含两个集合中所有区间的最小区间长度，
      对于任意单位区间 [i, i+1)，其分段匹配量为：

      • 如果两个集合在该区间上都没有标签，则为 0
      • 如果只有一个集合在该区间上有标签，则为 0
      • 否则，为客户端定义的标签之间的相似度（下文说明）

      两个空集合的相似度为 0。

      例如，假设你有使用标签 "happy"、"sad" 和 "meh" 的多区间集；
      标签之间的相似度定义为：

      • 如果两者都是 "happy"、都是 "sad" 或都是 "meh"，则为 1
      • 如果一个是 meh，另一个是 "happy" 或 "sad"，则为 0.5
      • 否则为 0
        那么这两个集合的相似度：
        { "happy" = [[0, 1), [2,4)], "sad" = [[1,2)] }
        { "sad" = [[1, 2)], "meh" = [[2,3)], "happy" = [[3,4)] }
        ... 为：(0 + 1 + 0.5 + 1) / (4 - 0) = 0.625

      标签相似度以元组数组形式提供，其中前两个元素给出
      一对标签，第三个元素给出它们之间的相似度，
      介于 0 和 1 之间（含）。
      标签相似度是对称的，因此每个元组中标签的顺序无关紧要，
      且一对标签不能出现超过一次。
      所有其他标签对之间的相似度为：

      • 如果它们是相同的字符串，则为 1
      • 否则为 0

      例如，以下是上面使用的相似度值：
      [ ["happy","meh",0.5], ["meh","sad",0.5] ]

      当各个分段匹配项、集合之间的分段匹配总和
      以及集合的跨度可以高精度表示为 number 值时，
      返回值也将具有类似的精度。否则，精度可能同样较低。

      PS2 说明：这是一个必需的函数。
      你可以加强其规格，但不能削弱它。

      Parameters

      • similarities: LabelSimilarity[]

        上文所述的标签相似度定义

      • setA: MultiIntervalSet<string>

        带字符串标签的多区间集

      • setB: MultiIntervalSet<string>

        带字符串标签的多区间集

      Returns number

      setA 和 setB 之间的相似度（按上文定义）
