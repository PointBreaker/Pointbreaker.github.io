概述

本作业使用 JavaScript 内置数据结构作为构建块，构建自定义数据结构，并用这些 ADT 构建一个小型应用。

区间集（Interval Set）

在 Problem 1–3 中实现区间集抽象类型：一种可变集合，每个标签关联数轴上的一个非重叠区间。

例如，区间集 { A = [0,5), B = [10,30), C = [30,35) }：

" A"      " B"                                " C"
0         10       20       30      35

标签是唯一字符串 "A"、"B"、"C"，每个关联一个 bigint 值区间。所有区间为半开区间（包含起点，不包含终点），故 [0,5) 表示 { x ∈ ℝ | 0 ≤ x < 5 }。

IntervalSet<Label> 是泛型类型，类似 Array<E> 或 <Map<K,V>。本作业将用两种不同表示实现 IntervalSet，练习选择抽象函数与表示不变量并防止表示泄露。实现位于 src/intervalset-impls.ts。

多区间集（Multi-Interval Set）

在 Problem 4 中，使用区间集实现多区间集类型：每个标签可关联一个或多个全局非重叠区间。

例如 { A = [[0,5),[20,25)], B = [[10,20),[25,30)], C = [[30,35)] }：

" A"      " B"      " A" " B"           " C"
0         10       20   25   30         35

多区间集之间的相似度

在 Problem 5 中，实现测量多区间集相似度的函数。相似度定义为两集合跨越范围的比例。

使用二元标签相似度定义（相等=1，不等=0）的示例：

( 5×0 + 5×0 + 10×1 + 5×1 + 5×0 + 5×0 ) ÷ ( 35 - 0 ) = 15 / 35 ≈ 0.42857

若客户端定义 "A" 与 "B" 相似度为 ½：

( 5×0 + 5×0 + 10×1 + 5×1 + 5×0.5 + 5×0 ) ÷ ( 35 - 0 ) = 17.5 / 35 = 0.5
