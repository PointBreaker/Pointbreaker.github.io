海龟绘图与 drawSquare

Logo 是 MIT 创造的编程语言，最初用于控制机器人移动。海龟绘图向屏幕上的"乌龟"发出指令，移动时绘制线条。

本作业使用 TypeScript 的简化版 Logo 子集：

  • forward(units) — 沿当前方向移动 units 像素。乌龟初始朝上。
  • turn(degrees) — 顺时针旋转 degrees 度。

任务步骤

  1. 在 src/turtlesoup.ts 中实现 drawSquare(turtle: Turtle, sideLength: number)，使用 forward 与 turn。
  2. 在 main 函数中取消对 drawSquare 的注释，运行： 
    npm start
    绘图将写入 output.html 并在浏览器中显示。

提交与推送

git diff                # 查看具体改动
git add src/turtlesoup.ts

绘制圆形

限制条件

  • 只需编辑 turtlesoup.ts。
  • 不得修改函数签名，否则该部分计零分。
  • 可自由添加辅助函数和测试，但非必需。
  • 不得修改或新增其他 TypeScript 文件。

任务步骤

  1. 实现 chordLength，仔细阅读规格注释中的弦长公式。
  2. 运行公共测试： 
    npm test
  3. 尝试破坏 chordLength 实现，观察红色错误信息与堆栈跟踪。
  4. 修复实现使其重新通过测试。
  5. 实现 drawApproximateCircle，使用 chordLength 实现。

assertAlmostEqual 函数签名：

function assertAlmostEqual(actual: number, expected: number, delta: number, message?: string): void

断言两个数在给定误差范围内相等。actual 为被测模块返回值；expected 为期望值；delta 为容差（默认 0.001）。

计算距离与路径

  1. 实现 distance，计算 Point 类表示的两点间距离。
  2. 实现 findPath，找到访问给定点列表的路径（转向与移动序列）。
  3. 运行测试： 
    npm test -- -f "findPath"

个人艺术作品

实现 drawPersonalArt，绘制具有一定复杂度和美感的艺术作品。

要求

  • 至少 20 行非重复代码。
  • 使用辅助函数、循环等，而非简单罗列 forward 和 turn 命令。
  • 仅对 drawPersonalArt 可使用 Turtle 的 color 方法更改画笔颜色。

提交说明

  • 务必提交并推送（commit AND push）到 github.mit.edu。评分使用截止日期当天晚上 9:00 的仓库状态。
  • Didit 反馈是尽力而为的，不保证在特定时间内运行。
  • 不要推送无法编译的代码。
  • 通过部分或全部 Didit 公共测试不保证通过完整自动评分测试。

评分构成
