retry客户端重试协议任务 · 提示 · 验收
Handout 完整本土化可离线实施不含参考实现

完整任务

RPC 失败或超时时客户端持续重试同一逻辑请求。每次逻辑操作携带稳定的客户端标识和序列号；重发不能生成新序列号。客户端同一时刻只发一个未完成请求时，可以利用递增序列简化服务端状态。

查看解题提示

区分 transport attempt 与 logical operation。超时不代表服务端未执行。

dedup服务端去重与结果缓存任务 · 提示 · 验收
Handout 完整本土化可离线实施不含参考实现

完整任务

服务端为每个客户端记录最近已执行序列号及其回复。收到重复请求时返回缓存回复，不再修改 KV；收到新请求时在同一锁保护下执行、记录结果并回复。不要只缓存“已执行”布尔值，因为 Append 的旧值回复也必须一致。

查看解题提示

检查状态更新和去重记录是否原子；若先改 KV 再在另一个临界区写缓存，崩溃或并发会产生缝隙。
