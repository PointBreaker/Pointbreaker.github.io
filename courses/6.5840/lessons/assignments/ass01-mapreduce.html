workerWorker 数据路径任务 · 提示 · 验收
Handout 完整本土化可离线实施不含参考实现

完整任务

实现 worker 向 coordinator 请求任务。Map 任务读取指定输入，调用应用 Map，按 ihash(key) % NReduce 分桶，并把每桶 JSON 键值对写入中间文件；Reduce 任务读取属于自身编号的所有 Map 输出，按 key 排序分组，调用 Reduce 并生成 mr-out-X。使用临时文件加原子 rename，避免暴露半成品。

查看解题提示

中间文件名必须让 Reduce 能从 map 编号和 reduce 编号确定找到；编码格式在读写两侧保持一致。

coordinatorCoordinator 状态机任务 · 提示 · 验收
Handout 完整本土化可离线实施不含参考实现

完整任务

维护 Map/Reduce 任务的 idle、in-progress、done 状态。只有全部 Map 完成后才发 Reduce；全部 Reduce 完成后 Done() 返回 true。RPC handler 不应长时间阻塞，任务完成报告必须幂等，以容忍 worker 或回复重复。

查看解题提示

用锁保护阶段与任务表；把“选择任务并标记 in-progress”放在同一个临界区。

failure超时与重派任务 · 提示 · 验收
Handout 完整本土化可离线实施不含参考实现

完整任务

若 worker 领取任务后崩溃，coordinator 应在大约十秒后允许另一 worker 重做。旧 worker 若随后返回，不得破坏已发布结果。Map/Reduce 应是确定性的，输出发布使用 rename；coordinator 以任务身份而不是 worker 身份判断完成。

查看解题提示

可在发任务时记录开始时间，并由后台扫描或请求路径检查超时。不要把整个作业在单个 worker 失败后重启。
