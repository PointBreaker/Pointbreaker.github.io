2aBellman-Ford 性质：最短路径的边数上界题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

回顾 Dijkstra 算法依赖于按距离递增顺序访问顶点这一事实。因此，如果到顶点 \(u\) 的最短路径经过 \(v\)，由于 \(\text{dist}[v] < \text{dist}[u]\)，我们会先访问 \(v\) 再访问 \(u\)。当存在负权边时这不再成立，因为可能出现 \(\text{dist}[v] > \text{dist}[u]\) 的情况。本题研究 Bellman-Ford 算法如何避免这一问题。

设 \(G = (V, E)\) 为带负权可能的加权有向图，其中 \(|V| = n\)，\(|E| = m\)。我们希望找到从固定源点 \(s\) 到 \(V\) 中每个顶点的最短路径。

(a) 假设 \(G\) 没有总权值为负的环。证明：对任意顶点对 \(u, v\)，存在一条最多含 \(n - 1\) 条边的最短路径。

查看解题提示

如果最短路径含有多于 \(n - 1\) 条边，根据鸽巢原理，路径上必有顶点被重复。这意味着什么？重复顶点之间的部分构成一个环，而该环的权值非负。

展开官方参考解答

这是因为，如果路径含有多于 \(n - 1\) 条边，则路径上必有某个顶点被重复访问，即路径包含一个环。然而，由于该环不可能具有负权（题目假设无负权环），我们可以在不增加路径长度的情况下将其移除。

2dBellman-Ford 性质：d_k 的线性时间计算题目 · 提示 · 答案

(d) 对于固定的 \(k > 1\)，假设给定所有 \(v \in V\) 的 \(d_{k-1}[v]\) 值，给出一个在 \(O(n + m)\) 时间内计算所有 \(v\) 的 \(d_k[v]\) 的算法。

查看解题提示

展开官方参考解答

该算法对每条边处理一次，时间复杂度为 \(O(m)\)，加上初始化 \(O(n)\)，总计 \(O(n + m)\)。

查看解题提示

从 \(d_0\) 开始，迭代应用 2(d) 中的算法。尝试用归纳法证明正确性：假设 \(d_{k-1}[\cdot]\) 正确，证明 \(d_k[\cdot]\) 也正确。

3a贪心反例：旅行商问题题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

旅行商问题（Travelling Salesman Problem, TSP）：我们有一个带权无向图 \(G(V, E)\)，包含所有可能的边（即 \(G\) 是完全图）。目标是找到一条访问所有顶点恰好一次且长度最短的环。

一种贪心算法是：从任意起点 \(s\) 开始构建环，已访问顶点集合初始化为 \(\{s\}\)。在每一步，如果当前位于顶点 \(u\) 且环尚未访问所有顶点，则添加从 \(u\) 到某个未访问顶点 \(v\) 的最短边，然后移动到 \(v\) 并标记 \(v\) 为已访问。否则，添加一条从当前顶点到 \(s\) 的边，返回完成的环。

请给出一个反例，说明该贪心算法不能找到最优解。

查看解题提示

思考贪心算法在早期选择低权值边后，是否可能被迫在后期选择高权值边。尝试构造一个含四个顶点的图，使得贪心算法被迫在最后选择一条极贵的边。

展开官方参考解答

一个反例是四个顶点的图，顶点为 \(a, b, c, d\)，其中边 \((a, b), (b, c), (c, d)\) 的权值为 1，边 \((a, d)\) 的权值为 100，其余所有边的权值为 2。如果贪心算法从顶点 \(a\) 出发，它会依次将 \((a, b), (b, c), (c, d)\) 加入环，最后被迫加入权值很高的边 \((a, d)\) 来完成环，总代价为 103。最优环为 \((a, b), (b, d), (d, c), (c, a)\)，代价为 6。

关键思想是，通过使用低权值边构成的路径，我们迫使算法陷入必须选择高权值边才能完成解的境地。

3b贪心反例：最大匹配问题题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

最大匹配问题（Maximum Matching）：我们有一个无向图 \(G(V, E)\)，目标是找到最大的匹配 \(E' \subseteq E\)，即 \(E'\) 是 \(E\) 的一个最大子集，使得 \(E'\) 中没有两条边共享端点。

一种贪心算法是：当存在一条边 \(e = (u, v)\) 使得 \(u\) 和 \(v\) 都不是 \(E'\) 中已有边的端点时，将任意这样的一条边加入 \(E'\)。

请给出一个反例，说明该贪心算法不能找到最优解。（挑战题：能否证明该算法找到的解的大小至少是最优解大小的一半？）

查看解题提示

考虑一条含三条边的路径图。贪心算法可能选中中间的边，而最优解是选两条外侧的边。对于挑战题，思考最优解中的每条边与算法解的关系。

展开官方参考解答

最简单的例子是一条含三条边的路径图。贪心算法可能选中中间的边，而最优解是选两条外侧的边。

为了证明该算法总能找到至少是最优解大小一半的匹配，设算法找到的解大小为 \(m\)。最优解中的任意一条边都与算法解中的某条边共享端点（否则贪心算法本可以将其加入）。最优解中的边不能共享端点，而算法解中的 \(m\) 条边共有 \(2m\) 个端点，因此最优解至多包含 \(2m\) 条边。

4aHorn 公式：求解变量赋值题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

求解下列 Horn 公式的变量赋值： \[(x \land z) \Rightarrow y, \quad z \Rightarrow w, \quad (y \land z) \Rightarrow x, \quad \Rightarrow z, \quad (\bar{z} \lor \bar{x}), \quad (\bar{w} \lor \bar{y} \lor \bar{z})\]

查看解题提示

从单位子句（unit clause）开始。哪些变量必须为真？然后利用蕴含关系传播。最后检查负子句是否满足。

展开官方参考解答

• \(z\) 必须为真，因为有语句 \(\Rightarrow z\)。 • \(w\) 必须为真，因为 \(z \Rightarrow w\)。 • 由负子句 \((\bar{z} \lor \bar{x})\) 可知 \(\bar{x}\) 必须为真，即 \(x = \text{False}\)。 • 由负子句 \((\bar{w} \lor \bar{y} \lor \bar{z})\) 可知 \(\bar{y}\) 必须为真，即 \(y = \text{False}\)。 • 所有蕴含式均已满足，因此满足赋值为：\(z = \text{True}, w = \text{True}, x = \text{False}, y = \text{False}\)。

4bHorn 公式：蕴含 True 的子句题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

证明形如 \((x_i \land x_j \land \cdots) \Rightarrow \text{True}\) 的任意蕴含子句总是可满足的。

6b医生接诊：交换论证（上）题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

考虑与 6(a) 相同的设定。设 \(x_1, x_2, \ldots, x_n\) 表示顾客的一个排序（即我们先接诊顾客 \(x_1\)，然后是 \(x_2\)，依此类推）。证明以下修改，若应用于任意排序，都不会增加平均等待时间： • 如果 \(i < j\) 且 \(t(x_i) \geq t(x_j)\)，则交换顾客 \(i\) 与顾客 \(j\)。

例如，如果顾客排序为 \(3, 1, 4, 2\) 且 \(t(3) \geq t(4)\)，则取 \(i = 1\) 和 \(j = 3\) 应用此规则后得到新排序 \(4, 1, 3, 2\)。

查看解题提示

分析交换对哪些顾客的等待时间有影响。只有 \(i\) 和 \(j\) 之间的顾客（不含 \(i\)，含 \(j\) 之后的顾客？）的等待时间可能变化。计算交换前后这些顾客等待时间的变化量。

展开官方参考解答

首先注意到交换 \(x_i\) 和 \(x_j\) 不影响顾客 \(x_1, x_2, \ldots, x_i\) 和顾客 \(x_{j+1}, x_{j+2}, \ldots, x_n\) 的等待时间（即对于 \(k \leq i\) 或 \(k > j\) 的顾客 \(x_k\)）。因此我们只需处理顾客 \(x_{i+1}, \ldots, x_j\)，即对于 \(i < k \leq j\) 的顾客 \(x_k\)。对于顾客 \(x_k\)，交换前的等待时间为 \[T_k = \sum_{1 \leq l < k} t(x_l),\] 交换后的等待时间为 \[T'_k = \sum_{1 \leq l < i} t(x_l) + t(x_j) + \sum_{i < l < k} t(x_l) = T_k - t(x_i) + t(x_j).\] 由于 \(t(x_i) \geq t(x_j)\)，有 \(T'_k \leq T_k\)，因此顾客 \(x_{i+1}, \ldots, x_j\) 的等待时间从不增加，所有顾客的平均等待时间在交换后也不会增加。
