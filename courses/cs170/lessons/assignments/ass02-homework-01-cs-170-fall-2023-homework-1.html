4数学大杂烩（Math Potpourri）题目 · 提示 · 答案

完整题面

以下各小问将涉及一些在本课程其余部分会用到的数学恒等式、技巧与方法。

(a) 将下列表达式化简为一个对数（即写成 \(\log_a b\) 的形式）：

(i) \(\displaystyle \frac{\ln x}{\ln y}\)

(ii) \(\ln x + \ln y\)

(iii) \(\ln x - \ln y\)

(iv) \(170 \ln x\)

(b) 证明下列恒等式：

(i) \(x^{\log_{1/x} y} = \frac{1}{y}\)

(ii) \(\displaystyle \sum_{i=1}^{n} i = \frac{n(n+1)}{2}\)

(iii) \(\displaystyle \sum_{k=0}^{n} a r^{k} = \begin{cases} a \cdot \frac{1-r^{n+1}}{1-r}, & r \neq 1 \\ a(n+1), & r = 1 \end{cases}\)

查看解题提示

(a) 使用换底公式与对数的运算性质（积、商、幂）。 (b)(i) 把 \(x\) 写成 \(\ln x\) 的幂，或把 \(\log_{1/x} y\) 用自然对数展开；(b)(ii) 考虑正序与倒序配对；(b)(iii) 对 \(S_n\) 与 \(r S_n\) 作错位相减，并单独讨论 \(r=1\)。

展开官方参考解答

(a) (i) \(\log_y x\)。 (ii) \(\ln (xy)\)。 (iii) \(\ln (x/y)\)。 (iv) \(\ln (x^{170})\)。

(b) (i) 由换底公式 \(\log_{1/x} y = \frac{\ln y}{\ln(1/x)} = \frac{\ln y}{-\ln x}\), \[x^{\log_{1/x} y} = x^{\frac{\ln y}{-\ln x}} = \bigl(x^{\frac{\ln y}{\ln x}}\bigr)^{-1}.\] 而 \(x^{\frac{\ln y}{\ln x}} = x^{\log_x y} = y\), 故整体等于 \(y^{-1} = \frac{1}{y}\)。

(ii) 设 \(S = \sum_{i=1}^{n} i = 1 + 2 + \cdots + (n-1) + n\)。将其正序与倒序相加配对： \[S = [1+n] + [2+(n-1)] + [3+(n-2)] + \cdots = \frac{n(n+1)}{2}.\]

(iii) 设 \(S_n = \sum_{k=0}^{n} a r^{k}\)。当 \(r \neq 1\) 时， \[S_n = a + ar + \cdots + ar^{n},\] \[rSn = ar + ar^{2} + \cdots + ar^{n+1}.\] 两式相减得 \((1-r) S_n = a - ar^{n+1}\), 因此 \[S_n = \frac{a - ar^{n+1}}{1-r} = a \cdot \frac{1-r^{n+1}}{1-r}.\] 当 \(r = 1\) 时，\(S_n = a + a + \cdots + a\)（共 \(n+1\) 项），故 \(S_n = a(n+1)\)。

5递推关系（Recurrence Relations）题目 · 提示 · 答案

完整题面

对每一小问，求 \(T(n)\) 的渐近增长阶，即找出一个函数 \(g(n)\) 使得 \(T(n) = \Theta(g(n))\)。请展示你的推理过程，不得直接套用主定理（master theorem）。在所有小问中，你可以忽略因取整（integer）带来的问题。

(a) \(T(n) = 3T(n/4) + 10n\)

(b) \(T(n) = 97T(n/100) + \Theta(n)\)

(c) 算法 A 需要 \(\Theta(n^{2})\) 的时间把输入划分为 5 个大小均为 \(n/5\) 的子问题，然后递归地在其中 3 个子问题上运行自身。试描述算法 A 的运行时间 \(T(n)\) 满足的递推关系，并求其渐近增长阶。

(d) \(T(n) = 3T(n/3) + \Theta(n)\)

(e) \(T(n) = T(3n/5) + T(4n/5)\)（已知 \(T(1) = 1\)）

提示：试着猜一个形如 \(a n^{b}\) 的 \(T(n)\), 再用归纳法论证其正确性。

图表条件 · 递推树示意图：展示每层子问题规模与每层工作量之和，用于理解 (a)(b)(c) 的等比级数与 (d) 的 n log n。

递归树：(a) 规模 n -> 3 个子问题 n/4，每层总工作量 10n * (3/4)^k；(d) 规模 n -> 3 个子问题 n/3，每层总工作量 cn，共 log_3 n 层。

来源：hw01.pdf · 2-3

查看解题提示

(a)(b)(c) 的共同观察：在每一层递归上，子问题总规模相比该层输入都会减少一个常数比例，从而形成收敛的等比级数，总工作量由第一层主导。(d) 每层工作量同为 \(\Theta(n)\)，而层数最多 \(\log n\) 层。(e) 先用 \(T(n) \ge 2T(n/2)\) 与 \(T(n) \le 2T(4n/5)\) 夹出指数范围，再代入 \(T(n)=n^{b}\) 解出 \(b\)。

展开官方参考解答

(a) 将 \(T(n)\) 按递归树展开： \[T(n) = 10n + 3\bigl(10n/4 + 3T(n/16)\bigr) = 10n + 10\cdot\frac{3n}{4} + 10\cdot\frac{9n}{16} + 10\cdot\frac{27n}{64} + \cdots\] 该求和式为 \[T(n) = \sum_{k=0}^{\lfloor \log_{4} n \rfloor} \Bigl(\frac{3}{4}\Bigr)^{k}\cdot 10n \le \sum_{k=0}^{\infty} \Bigl(\frac{3}{4}\Bigr)^{k}\cdot 10n = \frac{1}{1-3/4}\cdot 10n = \Theta(n).\] 直观解释：每一层都有 3 个规模为 \(n/4\) 的递归调用，所以下一层输入总规模为 \(3n/4\)，即每层会"丢掉" \(1/4\) 的输入，形成收敛的等比级数，总工作量与第一层同阶，为 \(\Theta(n)\)。

(b) 答案为 \(\Theta(n)\)。与 (a) 同理：递归调用数（97）小于子问题规模的分母（100），问题规模每次减少一个常数比例（\(3/100\)），运行时间由第一层的工作量 \(\Theta(n)\) 主导，无需主定理。

(c) 递推关系为 \(T(n) = 3T(n/5) + \Theta(n^{2})\)。与 (a)(b) 思路相同，每层都会丢掉输入规模/工作量中的一个常数比例，因此答案为 \(\Theta(n^{2})\)。

(d) 画出递归树，每一层的工作量之和都是 \(\Theta(n)\)，而层数最多为 \(\log n\)，因此整体运行时间为 \(\Theta(n \log n)\)。

(e) 主定理不能直接套用。采用如下两步： 首先给出上下界：由 \(T(n) \ge 2T(n/2)\) 得到 \(T(n) \ge \Omega(n)\)；由 \(T(n) \le 2T(4n/5)\) 得到 \(T(n) \le O\bigl(n^{\log_{5/4} 2}\bigr)\)。由此猜测 \(T(n)\) 形如 \(a n^{b}\)。 由初值 \(T(1) = 1 = a\), 得 \(a = 1\), 即 \(T(n) = n^{b}\)。把它代回递推式： \[n^{b} = T(3n/5) + T(4n/5) = \Bigl(\frac{3}{5}\Bigr)^{b} n^{b} + \Bigl(\frac{4}{5}\Bigr)^{b} n^{b}.\] 两边除以 \(n^{b}\) 得到 \(\bigl(\frac{3}{5}\bigr)^{b} + \bigl(\frac{4}{5}\bigr)^{b} = 1\)。函数 \(f(b) = (3/5)^{b} + (4/5)^{b}\) 对 \(b > 0\) 单调递减，且 \(f(2) = 9/25 + 16/25 = 1\)，故唯一正解为 \(b = 2\)。因此 \(T(n) = n^{2}\)，答案是 \(\Theta(n^{2})\)。

6介于其间的函数（In Between Functions）题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

在本题中，我们要找一个函数 \(f(n)\)，它渐近地比多项式时间差、但仍比指数时间好。也就是说，\(f\) 必须同时满足：

  • 对所有常数 \(k > 0\)，\(f(n) = \Omega(n^{k})\)  (1)

  • 对所有常数 \(c > 0\)，\(f(n) = O(2^{cn})\)  (2)

(a) 试着把 \(f(n)\) 取为一个次数 \(d\) 很大的常数多项式，即 \(f(n) = a_{0} + a_{1}n + a_{2}n^{2} + \cdots + a_{d}n^{d}\)。对哪些 \(k\)（如果有），\(f\) 会不满足 (1)？

(b) 再试着把 \(f(n)\) 取为 \(a^{n}\)，其中 \(a\) 是尽可能小的常数但仍满足 (1)（例如 \(1.000001\)）。对哪些 \(c\)（如果有），\(f\) 会不满足 (2）？

提示：先把 \(a^{n}\) 改写成 \(2^{bn}\)，其中 \(b\) 是依赖于 \(a\) 的常数。

至此我们发现：形如 \(O(n^{d})\)（\(d\) 为常数）的函数增长太慢，而形如 \(O(a^{n})\) 的函数即使 \(a\) 非常小也增长太快。

(c) 找一个函数 \(D(n)\)，使得令 \(f(n) = O\bigl(n^{D(n)}\bigr)\) 同时满足 (1) 与 (2)。并证明你的答案同时满足两者。

提示：请确保 \(D(n)\) 渐近地小于 \(n\)。

查看解题提示

(a)(b) 分别考察多项式与指数在哪些常数下失败。(c) 的关键是让指数本身随 \(n\) 增长，但比线性慢：试试把 \(D(n)\) 取成对数级别。

展开官方参考解答

(a) 当 \(k > d\) 时 \(f\) 不满足 (1)，因为 \(n^{d}\) 的增长严格慢于 \(n^{k}\)。

(b) 当 \(c < \lg a\) 时 \(f\) 不满足 (2)。改写 \(a^{n} = 2^{n \lg a}\) 后可见，只要 \(c\) 小于 \(\lg a\)，\(2^{cn}\) 的增长就会慢于 \(a^{n}\)。

(c) 取 \(D(n) = \lg n\)。则对任意常数 \(k\), \[f(n) = n^{\lg n} = \Omega(n^{k}),\] 因为 \((\lg n)^{2}\) 最终会超过任意常数 \(k \cdot \lg n\)。同时，对任意常数 \(c\), \[n^{\lg n} = 2^{(\lg n)^{2}} = O(2^{cn}),\] 因为 \((\lg n)^{2} = o(n)\)。 更一般地，凡满足 \(D(n) = o(n / \lg n)\) 的函数均可，因为此时 \(n^{D(n)} = 2^{\lg n \cdot D(n)} = 2^{o(n)}\)。

    rhs_bin = decimal_to_binary(rhs)
    power_of_10_bin = decimal_to_binary(power_of_10)

    # reconstruct the original number by multiplying and adding
    return add_binary(mul_binary(lhs_bin, power_of_10_bin), rhs_bin)
