行列式的性质

行列式（determinant）是一个从方阵到实数的函数。Strang 教授从三条基本性质出发，推导出其余所有性质——这是理解行列式最干净、最不易迷路的一条路。

授课：Prof. Gilbert Strang日期：2010-03-22难度：中等

学习目标

  • 叙述行列式三条基本性质（归一性、行交换变号、对单行线性），并由此推导其余性质。
  • 证明 \(|A| = |A^{\mathsf{T}}|\)，从而行性质与列性质等价。
  • 利用性质判断：零行、成比例行、不可逆矩阵的行列式为 0。
  • 理解并运用 \(|AB| = |A|\,|B|\) 与 \(|A^{-1}| = 1/|A|\)。
  • 说明行列式非零与矩阵可逆的等价关系。

三条基本性质

设 \(A\) 为 \(n\times n\) 矩阵，行列式 \(\det A\)（也记作 \(|A|\)）由下列三条性质唯一确定：

性质 1（归一性，normalization）：单位矩阵的行列式为 1。

\[|I| = 1.\]

这给出了尺度：行列式把"单位立方体"的体积定义为 1。

性质 2（行交换变号，row swap）：交换矩阵的两行，行列式变号。

例如对 \(2\times 2\) 矩阵：

\[\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc,\qquad \begin{vmatrix} c & d \\ a & b \end{vmatrix} = cb - ad = -(ad-bc).\]

性质 3（对单行线性，linearity in each row）：行列式对每一行是线性的，其它行保持不变。具体地，若第 \(i\) 行写成 \(\mathbf{r}_i = \mathbf{u} + \mathbf{v}\)，则

\[|[\dots, \mathbf{u}+\mathbf{v}, \dots]| = |[\dots, \mathbf{u}, \dots]| + |[\dots, \mathbf{v}, \dots]|,\] \[|[\dots, c\,\mathbf{r}_i, \dots]| = c\,|[\dots, \mathbf{r}_i, \dots]|.\]

注意：性质 3 是对单行线性，不是对整个矩阵线性。一般 \(\det(A+B) \neq \det A + \det B\)。

由基本性质推导出的重要结论

Strang 强调：一旦承认前三条，下面所有性质都是推论。

性质 4：两行相等则行列式为 0

若第 \(i\) 行与第 \(j\) 行相等，交换这两行，矩阵不变，行列式应不变；但由性质 2 应变号。同时满足"不变"与"变号"的数只有 0。

性质 5：行倍加不改变行列式

把一行的倍数加到另一行（第三种行初等变换）不改变行列式。设把第 \(i\) 行的 \(t\) 倍加到第 \(j\) 行：

\[|[\dots, \mathbf{r}_i, \dots, \mathbf{r}_j + t\mathbf{r}_i, \dots]| = |[\dots, \mathbf{r}_i, \dots, \mathbf{r}_j, \dots]| + t\,|[\dots, \mathbf{r}_i, \dots, \mathbf{r}_i, \dots]|.\]

第二项有两行相等，由性质 4 为 0，故行列式不变。

性质 6：有一行全为 0，则行列式为 0

把零行写成 \(0\cdot \mathbf{r}_i\)，由性质 3b 提出因子 0 即得。

性质 7：上三角矩阵的行列式等于对角元之积

对 \(U\) 做行倍加（性质 5，不改变行列式）消去上三角部分，得到对角阵 \(D\)。再由性质 3b 逐行提取对角元，结合性质 1 得：

\[|U| = |D| = d_{11}\,d_{22}\cdots d_{nn}.\]

性质 8：\(|A|=0\) 当且仅当 \(A\) 奇异（不可逆）

若 \(A\) 可逆，则通过行倍加与行交换可化为 \(I\)，过程中行列式只变号或不变，且 \(|I|=1\)，故 \(|A|\neq 0\)。反之，若 \(A\) 不可逆，则消元后出现零行，由性质 6 得 \(|A|=0\)。

性质 9：\(|A| = |A^{\mathsf{T}}|\)

把 \(A\) 做 LU 分解：\(PA = LU\)。取行列式，利用下面性质 10 与 \(|P| = \pm 1\)、\(|L|=1\)（对角元为 1）、\(|U|=\prod u_{ii}\)。而 \(A^{\mathsf{T}} = U^{\mathsf{T}} L^{\mathsf{T}} P\)，其中 \(U^{\mathsf{T}}\) 是下三角、\(L^{\mathsf{T}}\) 是上三角，对角元相同，故 \(|A|=|A^{\mathsf{T}}|\)。

推论：所有对行成立的性质，对列同样成立。

性质 10：\(|AB| = |A|\,|B|\)

这是行列式最重要的性质之一。固定 \(B\)，把 \(|AB|\) 看作 \(A\) 的函数，验证它满足前三条性质（归一、交换变号、对行线性），而行列式由这三条唯一确定，故 \(|AB| = C(B)\,|A|\)。取 \(A=I\) 得 \(C(B)=|B|\)。

推论：

  • \(|A^{-1}| = 1/|A|\)（只要 \(|A|\neq 0\)）。
  • \(|A^k| = |A|^k\)。
  • 相似变换不改变行列式：\(|B^{-1}AB| = |A|\)。

核心图景：行列式非零 \(\iff\) 矩阵可逆 \(\iff\) 各行线性无关 \(\iff\) 各列线性无关 \(\iff\) 消元得到 \(n\) 个主元。

知识检查

问题 1：把矩阵某一行的 5 倍加到另一行后，行列式如何变化？

问题 2：已知 \(|A|=2\)，\(|B|=5\)，求 \(|B^{-1} A^{-1}|\)。

问题 3：下列哪个条件不能保证方阵 \(A\) 可逆？

问题 4：对任意方阵 \(A\)，必有 \(|A^{\mathsf{T}}| = |A|\)。

本课要点

三条公理

归一、交换变号、对单行线性——这三条唯一确定了行列式，其它性质皆可推出。

行与列等价

\(|A|=|A^{\mathsf{T}}|\)，所以行性质自动成为列性质，讨论时只需记一半。

乘积公式

\(|AB|=|A|\,|B|\) 是行列式最重要的代数性质，贯穿后续特征值与相似变换。

可逆的判据

\(|A|\neq 0 \iff A\) 可逆 \(\iff\) 各行（列）线性无关 \(\iff\) 消元有 \(n\) 个主元。
