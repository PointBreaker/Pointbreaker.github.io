第一次阶段复习

从消元法到四大子空间——第 1–12 课构建了线性代数的核心框架。本课以典型问题串联：秩、零空间、列空间、线性无关，以及 \(A\mathbf{x} = \mathbf{b}\) 解的存在性与唯一性。

授课：Prof. Gilbert Strang日期：2010-04-26难度：中等（复习）

复习目标

  • 运用高斯消元将矩阵化为行阶梯形与行最简形（RREF）
  • 计算矩阵的秩并找到列空间与行空间的基
  • 求解零空间并写出通解形式
  • 判断 \(A\mathbf{x} = \mathbf{b}\) 何时有解、解是否唯一
  • 理解四个基本子空间及其维数关系

核心解题技巧

1. 求秩与基

将 \(A\) 通过行消元化为行阶梯形（echelon form）。主元列数 = 秩。主元列对应的原矩阵列构成列空间的基；非零行构成行空间的基。

2. 求零空间

将 \(A\) 化为 RREF，识别主变量与自由变量。对每个自由变量取 1、其余自由变量取 0，回代求得主变量——得到一个特解。所有特解的线性组合构成零空间。

3. \(A\mathbf{x} = \mathbf{b}\) 可解性

方程有解当且仅当 \(\mathbf{b} \in C(A)\)，即 \(\mathbf{b}\) 与 \(A^T\) 的零空间正交：\(\mathbf{y}^T \mathbf{b} = 0\) 对所有 \(A^T \mathbf{y} = \mathbf{0}\) 成立。

4. 通解结构

若 \(\mathbf{x}_p\) 是一个特解（\(A\mathbf{x}_p = \mathbf{b}\)），则通解为：

\[\mathbf{x} = \mathbf{x}_p + \mathbf{x}_n, \quad \mathbf{x}_n \in N(A)\]

四大子空间维数关系：

  • \(\dim C(A) = \dim C(A^T) = r\)（秩）
  • \(\dim N(A) = n - r\)（零化度）
  • \(\dim N(A^T) = m - r\)（左零化度）
  • \(C(A) \perp N(A^T)\)，\(C(A^T) \perp N(A)\)

典型考题类型

常见陷阱：

  • 行空间的基来自 RREF 的非零行，但列空间的基必须来自原矩阵的对应列
  • 忘记检查 \(\mathbf{b}\) 条件就写通解
  • 把"线性无关"与"生成空间"混淆——基要求两者同时满足
  1. \(3 \times 4\) 矩阵的秩为 2，求四个子空间的维数并给出可能的基。
  2. 判断 \(\mathbf{b} = (1,2,5)^T\) 是否在 \(A\) 的列空间中。
  3. 已知 \(A\) 的零空间基，写出 \(A\mathbf{x} = \mathbf{b}\) 的通解。
  4. 给定图的关联矩阵，求其零空间（物理含义：回路）。

本课要点

消元是基本工具

高斯消元给出秩、主元列、RREF——几乎所有进一步计算的基础。

四大子空间是框架

列空间与零空间在 \(\mathbb{R}^n\) 中互为正交补的类似，行空间与左零空间在 \(\mathbb{R}^m\) 中互为正交补。

可解性 = 正交条件

\(A\mathbf{x}=\mathbf{b}\) 有解当且仅当 \(\mathbf{b}\) 垂直于 \(A^T\) 的零空间——这是贯穿课程的核心判据。

通解 = 特解 + 齐次解

非齐次方程的解集是一个仿射子空间：特解平移零空间。
