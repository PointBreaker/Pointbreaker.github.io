完整知识地图

第一单元：线性方程与矩阵运算（L1–L5）

消元法 → LU 分解 → 矩阵运算 → 转置与置换。核心：行操作不改变行空间，但改变列空间。

第二单元：向量空间与四大子空间（L6–L12）

子空间 → 零空间 → 可解性 → 线性无关/基/维数 → 四大子空间 → 图与网络。核心：\(\dim C(A) = \dim C(A^T) = r\)，\(\dim N(A) = n - r\)。

第三单元：正交性（L13–L16）

正交性 → 投影 → 最小二乘 → Gram-Schmidt/QR。核心：\(P = A(A^T A)^{-1}A^T\)，\(A^T A \hat{\mathbf{x}} = A^T \mathbf{b}\)。

第四单元：行列式（L17–L19）

性质 → 公式 → 应用。核心：\(\det(AB) = \det(A)\det(B)\)，\(\det(A^{-1}) = 1/\det(A)\)。

第五单元：特征值（L20–L26）

特征值/向量 → 对角化 → Markov 矩阵 → 对称/正定 → Fourier/复矩阵 → 相似矩阵 → Jordan 形。核心：\(\sum \lambda_i = \operatorname{tr}(A)\)，\(\prod \lambda_i = \det(A)\)。

第六单元：线性变换与 SVD（L27–L31）

SVD → 线性变换 → 基变换 → 线性规划。核心：\(A = U \Sigma V^T\)，\(\sigma_i = \sqrt{\lambda_i(A^T A)}\)。

核心公式清单

必须熟记

  • 投影矩阵：\(P = A(A^T A)^{-1}A^T\)，\(P^2 = P^T = P\)
  • 正规方程：\(A^T A \hat{\mathbf{x}} = A^T \mathbf{b}\)
  • QR 分解：\(A = QR\)，\(Q^T Q = I\)
  • 特征值：\(\det(A - \lambda I) = 0\)
  • 对角化：\(A = M \Lambda M^{-1}\)，\(A^k = M \Lambda^k M^{-1}\)
  • SVD：\(A = U \Sigma V^T\)，\(A^+ = V \Sigma^+ U^T\)
  • 秩-零化度：\(\operatorname{rank}(A) + \dim N(A) = n\)
  • 行列式：\(\det(A) = \prod_i \lambda_i\)，\(\det(AB) = \det(A)\det(B)\)

常见陷阱

考试中最容易丢分的地方

  1. 列空间基 ≠ RREF 的主元列——必须回到原矩阵取对应列。
  2. 可对角化 ≠ 可逆——零特征值也可能有完整的特征向量。
  3. \(AB = 0\) 不意味着 \(A=0\) 或 \(B=0\)——矩阵乘法有零因子。
  4. \((AB)^T = B^T A^T\)——顺序反转！
  5. 投影矩阵只在 \(A\) 列满秩时有此公式——列不满秩时 \(A^T A\) 不可逆。
  6. \(\det(A+B) \neq \det(A) + \det(B)\)——行列式对加法没有简单公式。

考试策略

  1. 先求秩：秩决定了几乎所有其他问题的答案。
  2. 检查可逆性：\(\det(A) \neq 0\) 等价于 \(n\) 个非零主元。
  3. 对称矩阵优先：实对称矩阵必可对角化，特征值为实数。
  4. 验证答案：把特征向量代回 \(A\mathbf{x} = \lambda\mathbf{x}\)，把解代回 \(A\mathbf{x} = \mathbf{b}\)。
  5. 量纲检查：迹 = 特征值之和，行列式 = 特征值之积。

知识检查

问题 1：下列哪种矩阵分解对任意 \(m \times n\) 矩阵都存在？

问题 2：下列哪项不是矩阵 \(A\) 可逆的等价条件？

问题 3：关于实对称矩阵，下列哪项正确？

问题 4：关于矩阵运算，下列哪项恒成立？

本课要点

六大单元构成完整体系

线性方程 → 向量空间 → 正交性 → 行列式 → 特征值 → 变换与 SVD，层层递进。

公式必须熟练

投影、正规方程、对角化、SVD——这些公式在期末考中出现频率最高。

避开常见陷阱

列空间基取原矩阵、转置顺序反转、行列式对加法无公式——这些细节决定分数。

验证是好习惯

把解代回原方程、检查迹与特征值之和——这几秒钟能挽回很多分。
