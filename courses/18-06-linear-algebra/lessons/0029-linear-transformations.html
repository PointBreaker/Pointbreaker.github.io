线性变换

矩阵背后是变换。线性变换 \(T\) 是保持加法与数乘的映射，选定基后它就对应一个矩阵。核（kernel）即零空间，像（image）即列空间——线性代数的核心概念在此统一。

授课：Prof. Gilbert Strang日期：2010-04-19难度：较难

学习目标

  • 严格定义线性变换并验证给定的 \(T\) 是否线性
  • 建立线性变换与矩阵之间的对应关系
  • 识别核（kernel）与像（image）即四个基本子空间中的两个
  • 计算线性变换的矩阵表示
  • 理解复合变换对应矩阵乘法

线性变换的定义

设 \(V, W\) 是向量空间。映射 \(T: V \to W\) 称为线性变换（linear transformation），如果对所有向量 \(\mathbf{u}, \mathbf{v} \in V\) 和标量 \(c\)：

\[T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}) \quad \text{（保持加法）}\] \[T(c \mathbf{u}) = c\, T(\mathbf{u}) \quad \text{（保持数乘）}\]

两者可以合并为一条：\(T(c\mathbf{u} + d\mathbf{v}) = c\,T(\mathbf{u}) + d\,T(\mathbf{v})\)。

核心直觉：线性变换保持线性结构。如果 \(\mathbf{v}\) 是某些基向量的线性组合，那么 \(T(\mathbf{v})\) 就是这些基像的相同线性组合。知道基像，就知道了整个变换。

常见例子：

  • 旋转：\(T(\mathbf{v}) = R_\theta \mathbf{v}\)
  • 投影：\(T(\mathbf{v}) = P \mathbf{v}\)，其中 \(P^2 = P\)
  • 微分：\(T(f) = f'\)，从多项式空间到多项式空间
  • 零变换：\(T(\mathbf{v}) = \mathbf{0}\)

核与像

线性变换 \(T: V \to W\) 有两个关键子空间：

  • 核（kernel）：\(\ker(T) = \{\mathbf{v} \in V : T(\mathbf{v}) = \mathbf{0}\}\)，即被映到零向量的输入集合
  • 像（image）：\(\operatorname{im}(T) = \{T(\mathbf{v}) : \mathbf{v} \in V\} \subseteq W\)，即所有可能的输出集合

核是 \(V\) 的子空间，像是 \(W\) 的子空间。它们的维数满足秩-零化度定理（rank-nullity theorem）：

\[\dim(\ker(T)) + \dim(\operatorname{im}(T)) = \dim(V)\]

当 \(T\) 由矩阵 \(A\) 给出（\(T(\mathbf{x}) = A\mathbf{x}\)）时：

  • \(\ker(T) = N(A)\)（零空间）
  • \(\operatorname{im}(T) = C(A)\)（列空间）

矩阵表示

选定 \(V\) 的基 \(\{\mathbf{v}_1, \dots, \mathbf{v}_n\}\) 和 \(W\) 的基 \(\{\mathbf{w}_1, \dots, \mathbf{w}_m\}\) 后，线性变换 \(T\) 唯一对应一个 \(m \times n\) 矩阵 \(A\)：

\[T(\mathbf{v}_j) = \sum_{i=1}^{m} a_{ij} \mathbf{w}_i\]

矩阵 \(A\) 的第 \(j\) 列就是 \(T(\mathbf{v}_j)\) 在新基下的坐标。对任意 \(\mathbf{x} = \sum_j x_j \mathbf{v}_j\)：

\[T(\mathbf{x}) = A \mathbf{x}\]

注意：同一个线性变换在不同基下对应不同的矩阵——这些矩阵彼此相似（见第 26 课）。矩阵是变换的"影子"，变换本身才是本质。

复合与乘法

线性变换的复合对应矩阵的乘法。若 \(T_1(\mathbf{x}) = A\mathbf{x}\)，\(T_2(\mathbf{y}) = B\mathbf{y}\)，则：

\[(T_2 \circ T_1)(\mathbf{x}) = T_2(T_1(\mathbf{x})) = B(A\mathbf{x}) = (BA)\mathbf{x}\]

注意顺序：先作用的变换在右边。矩阵乘法不交换，对应变换的复合一般也不交换。

本课要点

线性 = 保持线性组合

\(T(c\mathbf{u}+d\mathbf{v}) = cT(\mathbf{u}) + dT(\mathbf{v})\) 是线性变换的根本性质，由此推出 \(T(\mathbf{0}) = \mathbf{0}\)。

核与像是对偶概念

核测量"信息丢失"（多少输入被映为零），像测量"覆盖范围"（输出空间的维数），两者之和等于输入维数。

矩阵 = 变换 + 基

选定基后，线性变换唯一对应一个矩阵；换基则得到相似矩阵。变换是几何的，矩阵是代数的。

复合 = 乘法

线性变换的复合对应矩阵乘法，这是矩阵乘法最自然的来源——不是为了乘而乘，而是变换组合的必然结果。
