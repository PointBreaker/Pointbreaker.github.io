Problem 7: If A has row 1 + row 2 = row 3, show that A is not invertible: (a) Explain why Ax = (1, 0, 0) cannot have a solution. (b) Which right sides (b1, b2, b3) might allow a solution to Ax = b? (c) What happens to row 3 in elimination? 7

Page 8

Solution (4 points) (a) Suppose A has row vectors A1, A2, A3, and x is a solution to Ax = (1, 0, 0). Then A1 x = 1, A2 x = 0, and A3 x = 0. But A1 + A2 = A3 means that · · · A1 · x + A2 · x = A3 · x and 1 + 0 = 0, a contradiction. (b) If Ax = (b1, b2, b3), then A1 · x = b1, A2 · x = b2, A3 · x = b3. Since A1 + A2 = A3, we deduce b1 + b2 = b3. (c) In the eliminated matrix, the third row will be zero. 8
