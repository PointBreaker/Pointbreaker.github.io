核心解题技巧

1. 投影矩阵

向量 \(\mathbf{b}\) 在 \(A\) 的列空间上的投影为：

\[\mathbf{p} = A \hat{\mathbf{x}} = P \mathbf{b}, \quad P = A(A^T A)^{-1} A^T\]

投影矩阵性质：\(P^2 = P\)，\(P^T = P\)。误差 \(\mathbf{e} = \mathbf{b} - \mathbf{p}\) 垂直于列空间。

2. 最小二乘

当 \(A\mathbf{x} = \mathbf{b}\) 无解时，求最小化 \(\|A\mathbf{x} - \mathbf{b}\|_2\) 的 \(\hat{\mathbf{x}}\)。解正规方程：

\[A^T A \hat{\mathbf{x}} = A^T \mathbf{b}\]

3. Gram-Schmidt

将线性无关向量组 \(\{\mathbf{a}_1, \dots, \mathbf{a}_n\}\) 化为标准正交组 \(\{\mathbf{q}_1, \dots, \mathbf{q}_n\}\)：

\[\mathbf{v}_k = \mathbf{a}_k - \sum_{j=1}^{k-1} (\mathbf{q}_j^T \mathbf{a}_k) \mathbf{q}_j, \quad \mathbf{q}_k = \frac{\mathbf{v}_k}{\|\mathbf{v}_k\|}\]

这给出 \(A = QR\)，其中 \(Q\) 列正交，\(R\) 上三角。

4. 行列式计算

利用三大性质：\(\det(I) = 1\)，行交换变号，对每行线性。实用公式：

  • 上三角矩阵：对角元乘积
  • \(\det(AB) = \det(A)\det(B)\)
  • \(\det(A^{-1}) = 1/\det(A)\)

5. 特征值计算

解特征方程 \(\det(A - \lambda I) = 0\) 得特征值。对每个 \(\lambda\)，求 \(N(A - \lambda I)\) 得特征向量。可对角化当且仅当所有特征值的几何重数等于代数重数。

关键关系：

  • 特征值之和 = 迹：\(\sum \lambda_i = \operatorname{tr}(A)\)
  • 特征值之积 = 行列式：\(\prod \lambda_i = \det(A)\)
  • 实对称矩阵：特征值全为实数，特征向量正交

典型考题类型

常见陷阱：

  • 投影矩阵只在 \(A^T A\) 可逆时才有此公式（\(A\) 列满秩）
  • Gram-Schmidt 中忘记正交化就直接归一化
  • 误以为行列式为零的矩阵一定是零矩阵
  • 可对角化 ≠ 可逆（零特征值也可能有完整的特征向量）
  1. 给定平面上三个点，用最小二乘拟合一条直线 \(y = C + Dt\)。
  2. 对 \(3 \times 2\) 矩阵做 QR 分解。
  3. 计算 \(4 \times 4\) 矩阵的行列式（利用行变换化为上三角）。
  4. 求 \(3 \times 3\) 矩阵的特征值与特征向量，判断是否可对角化。

本课要点

投影 = 最小距离

投影矩阵 \(P\) 给出 \(\mathbf{b}\) 到列空间的最短距离，误差垂直于列空间。

最小二乘 = 正规方程

当方程组不一致时，正规方程 \(A^T A \hat{\mathbf{x}} = A^T\mathbf{b}\) 给出最佳近似解。

Gram-Schmidt = 正交化

逐步减去投影分量，得到标准正交基，对应 \(QR\) 分解。

特征值 = 矩阵的 DNA

特征值决定矩阵的本质行为——振动频率、稳定性、幂的增长速率。
