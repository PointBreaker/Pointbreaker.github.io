第三次测验：对称矩阵、SVD 与线性变换

这份指南帮助你围绕官方真题进行备考复习，梳理重点概念与典型题型。它不包含逐题答案，而是引导你关注核心思路，让你在考场上能独立建模、计算与判断。

覆盖范围：对称/正定矩阵、相似矩阵、SVD、Fourier 与复矩阵、线性变换前置讲义：第 23–31 课建议用时：100 分钟

考试定位

Exam 3 是 18.06 的"高阶结构"考试：对称矩阵的谱定理（spectral theorem）把实特征值与正交特征向量锁定，正定判据给出优化的二阶条件，SVD（singular value decomposition）揭示任意矩阵的四个子空间结构，线性变换把矩阵从"数组"提升为"映射"。官方样卷见 exams/exam3.pdf。

核心主题

1. 对称矩阵与谱定理

实对称矩阵 \(A = A^T\) 有三个核心性质：

  • 所有特征值都是实数
  • 不同特征值对应的特征向量互相正交
  • 可以正交对角化：\(A = Q\Lambda Q^T\)，其中 \(Q^T Q = I\)

考试常让你利用这些性质简化计算，例如不用求特征向量就能判断惯性（正、负、零特征值的个数）。

2. 正定矩阵

对称矩阵 \(A\) 正定当且仅当以下任一条件成立：

  • 所有特征值 \(\lambda_i > 0\)
  • 所有顺序主子式 > 0（Sylvester 判据）
  • \(\xvec^T A \xvec > 0\) 对所有非零 \(\xvec\)
  • \(A = R^T R\) 且 \(R\) 列满秩（Cholesky 型分解）

核心洞察：正定矩阵是"二次型开口向上"的代数对应。在优化中，Hessian 正定意味着局部极小；在线性代数中，正定意味着所有主子式为正，从而可做 Cholesky 分解。

3. 相似矩阵

若存在可逆 \(M\) 使得 \(B = M^{-1}AM\)，则 \(A\) 与 \(B\) 相似。相似矩阵共享：特征值、迹、行列式、秩、Jordan 形。考试常给两个矩阵让你判断是否相似，或让你找一个简单的相似标准形（对角或 Jordan）。

4. 奇异值分解 SVD

任何 \(m \times n\) 矩阵都可以分解为：

\[A = U \Sigma V^T\]

其中 \(U\)（\(m \times m\)）和 \(V\)（\(n \times n\)）是正交矩阵，\(\Sigma\) 对角线上的非负奇异值 \(\sigma_1 \ge \cdots \ge \sigma_r > 0\)。

SVD 的几何意义：把 \(V\) 的列（输入空间的标准正交基）映到 \(U\) 的列（输出空间的标准正交基），并伸缩 \(\sigma_i\) 倍。

考试常要求你通过算 \(A^T A\) 的特征值与特征向量得到 \(V\) 和 \(\Sigma\)，再用 \(\uvec_i = \frac{1}{\sigma_i}A\vvec_i\) 得到 \(U\)。

5. Fourier 与复矩阵

在复数域中，内积变为 \(\langle \xvec, \yvec \rangle = \yvec^* \xvec\)（共轭转置）。酉矩阵（unitary）满足 \(Q^* Q = I\)，是复空间中的"正交矩阵"。Fourier 矩阵 \(F\) 是最常用的酉矩阵，其列是单位圆上的等分点。考试常让你验证酉性或用 Fourier 矩阵做快速变换。

6. 线性变换

线性变换 \(T: V \to W\) 满足 \(T(c_1\vvec_1 + c_2\vvec_2) = c_1 T(\vvec_1) + c_2 T(\vvec_2)\)。选定基后，变换对应一个矩阵；基变换时矩阵按 \(B = M^{-1}AM\) 相似变换。考试常让你在两组基之间转换矩阵，或让你找变换的核（kernel）与像（image）。

常见错误：线性变换的矩阵表示依赖于基的选择。考试若给的是非标准基，务必先写出基向量的像在基下的坐标，再拼成矩阵。

典型题型思路导引

题型 A：正定判定

对 \(2 \times 2\) 对称矩阵 \(\begin{bmatrix} a & b \\ b & c \end{bmatrix}\)，正定等价于 \(a > 0\) 且 \(ac - b^2 > 0\)。更大的矩阵用 Sylvester 判据（所有顺序主子式 > 0）。

题型 B：SVD 计算

步骤：算 \(A^T A\) → 求特征值 \(\lambda_i\) → 奇异值 \(\sigma_i = \sqrt{\lambda_i}\) → 特征向量正交化得 \(V\) → \(\uvec_i = A\vvec_i / \sigma_i\) → 组合成 \(U\Sigma V^T\)。注意重特征值时要正交化。

题型 C：相似与 Jordan 形

判断相似先看特征值与重数，再看几何重数。不可对角化的矩阵需要 Jordan 块——考试常考 \(2 \times 2\) 的单个 Jordan 块 \(J = \begin{bmatrix} \lambda & 1 \\ 0 & \lambda \end{bmatrix}\)。

题型 D：线性变换的矩阵

先确定定义域与值域的基，对每个基向量求变换后的像，再把像写成基的坐标，这些坐标就是矩阵的列。

时间分配提醒：SVD 计算量大，先检查 \(A\) 是否对称（对称时 SVD 与特征分解重合）。正定题多用 Sylvester 判据比求特征值更快。

问题 1：关于实对称矩阵，下列哪项恒成立？

问题 2：在 SVD \(A = U\Sigma V^T\) 中，\(V\) 的列向量是下列哪个矩阵的特征向量？

问题 3：线性变换 \(T\) 在基 \(\mathcal{B}_1\) 下的矩阵为 \(A\)，在基 \(\mathcal{B}_2\) 下的矩阵为 \(B\)。设从 \(\mathcal{B}_1\) 到 \(\mathcal{B}_2\) 的过渡矩阵为 \(M\)，则正确的关系是？

备考要点

对称矩阵 = 实谱 + 正交特征向量

这是整个课程最"友好"的矩阵类：没有复特征值、没有 Jordan 块、SVD 与特征分解重合。遇到对称矩阵，立刻用谱定理。

正定的五种等价判据

特征值、主子式、二次型、Cholesky 分解、惯性指数——考试时选最快的那个。对 \(2 \times 2\) 只需两个不等式。

SVD 是四个子空间的统一视角

\(V\) 的列张成行空间与零空间的正交基，\(U\) 的列张成列空间与左零空间的正交基，奇异值给出伸缩比。

线性变换是矩阵的"意义层"

矩阵只是变换在某组基下的坐标。基变换时矩阵相似变换，但变换本身不变——这是理解相似与对角化的钥匙。
