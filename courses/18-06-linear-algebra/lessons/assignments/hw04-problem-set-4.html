Problem 1 Largest set of independent vectors linear independence · basis · row reduction · pivot columns

(Section 3.5, #2) Find the largest possible number of independent vectors among v1=(1,-1,0,0), v2=(1,0,-1,0), v3=(1,0,0,-1), v4=(0,1,-1,0), v5=(0,1,0,-1), v6=(0,0,1,-1).

公式与已知条件

  • v1=(1,-1,0,0)
  • v2=(1,0,-1,0)
  • v3=(1,0,0,-1)
  • v4=(0,1,-1,0)
  • v5=(0,1,0,-1)
  • v6=(0,0,1,-1)
解题入口

Express later vectors as combinations of earlier ones to find dependencies, then verify independence of the remaining set via row reduction.

完成后检查

  • v4 = v2 − v1, v5 = v3 − v1, v6 = v3 − v2 (dependencies).
  • The matrix [v1 v2 v3] has three pivots, confirming independence.

Problem 2 Basis for a plane, intersection, and perpendicular space basis · nullspace · plane intersection · perpendicular vectors · normal vector

(Section 3.5, #20) Find a basis for the plane x − 2y + 3z = 0 in R^3. Then find a basis for the intersection of that plane with the xy plane. Then find a basis for all vectors perpendicular to the plane.

公式与已知条件

  • Plane: x − 2y + 3z = 0
  • xy plane: z = 0
  • Normal vector: (1, -2, 3)
解题入口

The plane is the nullspace of [1 -2 3]. Find special solutions for the basis. For the intersection, impose z = 0. For perpendicular vectors, use the normal vector.

完成后检查

  • The basis vectors satisfy x − 2y + 3z = 0.
  • The intersection basis lies in both the plane and the xy plane.
  • The perpendicular basis is orthogonal to the plane basis vectors.

Problem 3 Matrices commuting with the shift matrix shift matrix · commuting matrices · subspace dimension · Toeplitz matrices

(Section 3.5, #37) If AS = SA for the shift matrix S, show that A must have the form: A = [a b c; 0 a b; 0 0 a]. (The subspace of matrices that commute with the shift S has dimension ___.)

公式与已知条件

  • S = [0 1 0; 0 0 1; 0 0 0] (shift matrix)
  • AS = SA implies A = [a b c; 0 a b; 0 0 a]
  • Free variables: a, b, c
解题入口

Multiply out AS and SA, equate entries, and solve for the constraints on A.

完成后检查

  • AS = SA holds for the derived form of A.
  • The dimension equals the number of free variables (3).

Problem 4 Permutation matrices as a basis permutation matrices · linear combination · linear independence · basis · subspace of matrices

(Section 3.5, #41) Write a 3 by 3 identity matrix as a combination of the other five permutation matrices. Then show that those five matrices are linearly independent. (Assume a combination gives c1 P1 + ... + c5 P5 = 0, and check entries to prove ci is zero.) The five permutation matrices are a basis for the subspace of 3 by 3 matrices with row and column sums all equal.

公式与已知条件

  • Five permutation matrices: P21, P31, P32, P32P21, P21P32
  • I = P21 + P31 + P32 − P32P21 − P21P32
  • Subspace: 3×3 matrices with all row and column sums equal
解题入口

Express I as a linear combination of the five permutation matrices by matching entries. For independence, set a linear combination to zero and solve for coefficients.

完成后检查

  • The combination equals I by direct computation.
  • Setting the combination to zero yields all ci = 0.

Problem 5 Dimension theorem (rank-nullity) dimension theorem · rank-nullity · column space · nullspace · input dimension

(Section 3.5, #44) dimension of outputs + dimension of nullspace = dimension of inputs. For an m by n matrix of rank r, what are those 3 dimensions? Outputs = column space. This question will be answered in Section 3.6, can you do it now?

公式与已知条件

  • dim(outputs) = dim(column space) = r
  • dim(nullspace) = n − r
  • dim(inputs) = n
  • Relation: (n − r) + r = n
解题入口

Identify the three dimensions: inputs (n), outputs/column space (r), and nullspace (n−r).

完成后检查

  • The three dimensions sum correctly: (n − r) + r = n.
  • Each dimension matches its definition.

Problem 6 Inequalities for m, n, and r rank inequalities · existence of solutions · left nullspace · column space

(Section 3.6, #11) A is an m by n matrix of rank r. Suppose there are right sides b for which Ax = b has no solution. (a) What are all the inequalities (< or ≤) that must be true between m, n, and r? (b) How do you know that A^T y = 0 has solutions other than y = 0?

  1. (a) Inequalities between m, n, and r
  2. (b) A^T y = 0 has nonzero solutions

公式与已知条件

  • r ≤ m and r ≤ n always
  • No solution for some b ⇒ r < m
  • Left nullspace dimension = m − r
解题入口

For (a), use that no solution means the column space is a proper subspace of R^m. For (b), use the dimension of the left nullspace.

完成后检查

  • r < m follows from the existence of b with no solution.
  • m − r > 0 implies nonzero solutions to A^T y = 0.

Problem 7 Solvability of A^T y = d solvability · row space · left nullspace · four fundamental subspaces · uniqueness

(Section 3.6, #24) A^T y = d is solvable when d is in which of the four subspaces? The solution is unique when the ___ contains only the zero vector.

公式与已知条件

  • A^T y = d solvable ⇔ d ∈ row space
  • Unique solution ⇔ left nullspace = {0}
  • Row space = column space of A^T
解题入口

The equation A^T y = d is solvable when d is in the column space of A^T (the row space of A). Uniqueness depends on the left nullspace.

完成后检查

  • d must be in the row space for solvability.
  • Uniqueness requires the left nullspace to be trivial.

Problem 8 Checkerboard and chess matrices rank · row space · left nullspace · nullspace · checkerboard matrix · chess matrix

(Section 3.6, #28) Find the ranks of the 8 by 8 checkerboard matrix B and the chess matrix C. B has alternating 1s and 0s. C has r,n,b,q,k,b,n,r in the first row, p's in the second, zeros in rows 3-6, p's in the seventh, and r,n,b,q,k,b,n,r in the eighth. The numbers r, n, b, k, q, p are all different. Find bases for the rowspace and left nullspace of B and C. Challenge problem: Find a basis for the nullspace of C.

公式与已知条件

  • B: 8×8 alternating 1/0 checkerboard
  • C: 8×8 chess matrix with symbols r,n,b,q,k,p
  • r, n, b, k, q, p are all distinct
  • If p ≠ 0, both B and C have rank 2
解题入口

Use elimination to find the rank. For B (symmetric), the left nullspace equals the nullspace. For C, find special solutions by back-substitution.

完成后检查

  • Rank is determined by the number of pivots after elimination.
  • Bases for row space, left nullspace, and nullspace are verified.
  • The challenge nullspace basis satisfies Cx = 0.

Problem 9 Four fundamental subspaces for a rank-1 matrix four fundamental subspaces · rank-1 matrices · column space · row space · nullspace · left nullspace

(Section 3.6, #30) If A = uv^T is a 2 by 2 matrix of rank 1, redraw Figure 3.5 to show clearly the Four Fundamental Subspaces. If B produces those same four subspaces, what is the exact relation of B to A?

  • A = uv^T (outer product)
  • rank(A) = 1
  • Column space = span{u}
  • Row space = span{v^T}
  • Nullspace = plane perpendicular to v
  • Left nullspace = plane perpendicular to u
解题入口

Identify each subspace for the rank-1 matrix A = uv^T. For B with the same subspaces, compare their column and row spaces.

完成后检查

  • B = u'v'^T with u' a multiple of u and v' a multiple of v, so B is a multiple of A.

Problem 10 Matrix multiplication as a linear map on matrices linear map on matrices · nullspace · column space · dimension theorem · rank

(Section 3.6, #31) M is the space of 3 by 3 matrices. Multiply each matrix X in M by A = [1 0 -1; -1 1 0; 0 -1 1]. Notice: A[1;1;1] = [0;0;0]. (a) Which matrices X lead to AX = 0? (b) Which matrices have the form AX for some matrix X? (a) finds the 'nullspace' of that operation AX and (b) finds the 'column space'. What are the dimensions of those two subspaces of M? Why do the dimensions add to (n − r) + r = 9?

  1. (a) Matrices X with AX = 0 (nullspace)
  2. (b) Matrices of the form AX (column space)
  3. Dimensions of the two subspaces and why they sum to 9

公式与已知条件

  • A = [1 0 -1; -1 1 0; 0 -1 1]
  • A[1;1;1] = [0;0;0]
  • rank(A) = 2
  • dim(nullspace) = 3, dim(column space) = 6
  • 3 + 6 = 9 = dim(M)
解题入口

For (a), AX = 0 when each column of X is in the nullspace of A. For (b), AX has columns in the column space of A. Use the dimension theorem to verify the sum.

完成后检查

  • X in nullspace ⇔ columns of X are multiples of [1;1;1].
  • AX = B ⇔ each column of B sums to 0.
  • Dimensions satisfy (n − r) + r = 9.
