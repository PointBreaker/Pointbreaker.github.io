Problem 1 Parallel plane parametric form parametric vector form · planes · particular solution plus nullspace

The plane x − 3y − z = 12 is parallel to the plane x − 3y − z = 0 in Problem 17. One particular point on this plane is (12, 0, 0). All points on the plane have the form (fill in the first components): [x;y;z] = [0;0;0] + y[1;0;0] + z[0;0;1].

公式与已知条件

  • Plane equation: x − 3y − z = 12
  • Particular point: (12, 0, 0)
  • Direction vectors: (1,0,0) and (0,0,1)
解题入口

Solve the plane equation for x in terms of the free variables y and z, then rewrite in the given parametric form.

完成后检查

  • The particular point (12,0,0) satisfies x − 3y − z = 12.
  • Each direction vector satisfies the homogeneous equation x − 3y − z = 0.

Problem 2 Matrix with given column space and nullspace column space · nullspace · rank constraints · pivot counting

(If possible...) Construct a matrix whose column space contains (1, 1, 0) and (0, 1, 1) and whose nullspace contains (1, 0, 1) and (0, 0, 1).

公式与已知条件

  • Column space must contain (1,1,0) and (0,1,1)
  • Nullspace must contain (1,0,1) and (0,0,1)
解题入口

Count the number of pivots required by the column space dimension versus the number of pivots allowed by the nullspace dimension.

完成后检查

  • The two nullspace vectors are independent, so nullspace dimension ≥ 2.
  • The two column space vectors are independent, so column space dimension ≥ 2.
  • Verify whether both conditions can hold simultaneously for a 3×3 matrix.

Problem 3 Nullspace of a stacked matrix nullspace · stacked matrices · intersection of subspaces

How is the nullspace N(C) related to the spaces N(A) and N(B), if C = [A; B] (A stacked on top of B)?

公式与已知条件

  • C = [A; B]
  • Cx = [Ax; Bx]
解题入口

Cx = 0 requires both Ax = 0 and Bx = 0 simultaneously.

完成后检查

  • Verify that N(C) ⊆ N(A) and N(C) ⊆ N(B).
  • Verify that N(A) ∩ N(B) ⊆ N(C).

Find the four equations Ay = 0 for Kirchhoff's Law at the four nodes. Find three special solutions in the nullspace of A.

Problem 5 Rank from AB = I rank · invertible matrices · matrix inverse

Suppose A and B are n by n matrices, and AB = I. Prove from rank(AB) ≤ rank(A) that the rank of A is n. So A is invertible and B must be its two-sided inverse (Section 2.5). Therefore BA = I (which is not so obvious!).

公式与已知条件

  • AB = I_n
  • rank(AB) ≤ rank(A)
  • A is n×n
解题入口

Use rank(I_n) = n and the inequality rank(AB) ≤ rank(A).

完成后检查

  • rank(I_n) = n.
  • rank(AB) ≤ rank(A) ≤ n.
  • Conclude rank(A) = n.

Problem 6 COL × ROW factorization matrix factorization · column space · row space · reduced row echelon form

Neat fact: Every m by n matrix of rank r reduces to (m by r) times (r by n): A = (pivot columns of A)(first r rows of R) = (COL)(ROW). Write the 3 by 4 matrix A in equation (1) at the start of this section as the product of the 3 by 2 matrix from the pivot columns and the 2 by 4 matrix from R.

公式与已知条件

  • A = (pivot columns of A)(first r rows of R)
  • A is 3×4 of rank 2
  • Factorization: 3×2 times 2×4
解题入口

Identify the pivot columns of A to form COL, and take the first r rows of R to form ROW.

完成后检查

  • The product COL × ROW equals the original matrix A.
  • COL consists of the pivot columns of A.
  • ROW consists of the nonzero rows of the reduced row echelon form.

Problem 7 Block matrix R and its properties block matrices · right-inverse · left-inverse · reduced row echelon form · nullspace · transpose

Suppose R is m by n of rank r, with pivot columns first: R = [I F; 0 0]. (a) What are the shapes of those four blocks? (b) Find a right-inverse B with RB = I if r = m. (c) Find a left-inverse C with CR = I if r = n. (d) What is the reduced row echelon form of R^T (with shapes)? (e) What is the reduced row echelon form of R^T R (with shapes)? Prove that R^T R has the same nullspace as R.

  1. (a) Shapes of the four blocks
  2. (b) Right-inverse B with RB = I when r = m
  3. (c) Left-inverse C with CR = I when r = n
  4. (d) Reduced row echelon form of R^T
  5. (e) Reduced row echelon form of R^T R
  6. Prove R^T R has the same nullspace as R

公式与已知条件

  • R = [I F; 0 0] where I is r×r
  • R is m×n of rank r
  • RB = I when r = m
  • CR = I when r = n
解题入口

For (a), use the rank r to determine block dimensions. For (b) and (c), use the block structure to construct inverses. For (d) and (e), apply row operations to the transposed block forms.

完成后检查

  • Block shapes are consistent with m, n, r.
  • RB = I_m and CR = I_n verify the inverses.
  • N(R^T R) = N(R) by row operation invariance of nullspace.

Problem 10 Explain why false complete solution · particular solution · nullspace · minimum length solution · invertible matrices

Explain why these are all false: (a) The complete solution is any linear combination of xp and xn. (b) A system Ax = b has at most one particular solution. (c) The solution xp with all free variables zero is the shortest solution (minimum length ||x||). Find a 2 by 2 counterexample. (d) If A is invertible there is no solution xn in the nullspace.

  1. (a) Complete solution statement
  2. (b) Uniqueness of particular solution
  3. (c) Shortest solution counterexample (2×2)
  4. (d) Nullspace when A is invertible

公式与已知条件

  • Complete solution: x = xp + xn
  • xp = particular solution, xn ∈ N(A)
  • For (c): find a 2×2 counterexample where xp is not shortest
解题入口

For (a), note the coefficient of xp must be 1. For (b), add any nullspace vector to get another particular solution. For (c), consider a rank-1 system geometrically. For (d), note xn = 0 is always in the nullspace.

完成后检查

  • Each statement is identified as false with a valid counterexample or reasoning.
  • The 2×2 counterexample in (c) has ||xp|| > some other particular solution.

Problem 11 Relations between r, m, and n rank · existence · uniqueness · row rank · column rank

Write down all known relations between r and m and n if Ax = b has (a) no solution for some b (b) infinitely many solutions for every b (c) exactly one solution for some b, no solution for other b (d) exactly one solution for every b.

  1. (a) No solution for some b
  2. (b) Infinitely many solutions for every b
  3. (c) Exactly one solution for some b, no solution for other b
  4. (d) Exactly one solution for every b

公式与已知条件

  • r = rank(A), m = rows, n = columns
  • r ≤ m and r ≤ n always
  • No solution ⇔ r < m (column space ≠ R^m)
  • Unique solution ⇔ r = n (nullspace = {0})
解题入口

Use the relationships between rank, row count, and column count to determine existence and uniqueness.

完成后检查

  • Each case gives consistent inequalities between r, m, and n.
  • Case (d) implies A is invertible (r = m = n).

Apply Gauss-Jordan elimination to Ux = 0 and Ux = c. Reach Rx = 0 and Rx = d, where U0 = [1 2 3 0; 0 0 4 0] and Uc = [1 2 3 5; 0 0 4 8]. Solve Rx = 0 to find xn (its free variable is x2 = 1). Solve Rx = d to find xp (its free variable is x2 = 0).

Problem 14 Same complete solutions implies A = C complete solution · matrix equality · column space · nullspace

Suppose Ax = b and Cx = b have the same (complete) solutions for every b. Is it true that A = C?

公式与已知条件

  • Ax = b and Cx = b have the same complete solutions for every b
  • Complete solution: x = xp + xn
解题入口

To show A = C, show Ay = Cy for all vectors y by choosing b = Ay.

完成后检查

  • For any vector y, set b = Ay.
  • Then y solves Ax = b, so y solves Cx = b, giving Cy = Ay.
  • Since Ay = Cy for all y, A = C.
