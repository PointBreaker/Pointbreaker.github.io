Study guide

作业导读

本习题集围绕线性方程组的解结构与矩阵秩展开，重点训练列空间（column space）、零空间（nullspace）、秩约束、主元计数以及简化行阶梯形（reduced row echelon form）的计算与应用。题目涵盖参数向量形式、基尔霍夫电流定律、COL×ROW 分解、分块矩阵求逆、高斯-若尔当消元以及二阶差分矩阵，强调从几何与代数两个视角理解解空间。

前置知识

  • 矩阵与向量乘法
  • 线性方程组的高斯消元
  • 列空间与零空间的定义
  • 矩阵的秩与主元的概念
  • 子空间的基本运算（交、和）

建议顺序

  • 遇到涉及列空间与零空间共存的问题，先用秩约束（rank + nullity = n）判断可行性。
  • 对于需要构造矩阵的题目，从给定的特解或零空间向量反推矩阵结构。
  • 处理分块矩阵时，先明确各块的维度，再用分块乘法验证。
  • 涉及存在性与唯一性的题目，将条件转化为 r、m、n 之间的不等式关系。
  • 计算类题目先化为简化行阶梯形，再按自由变量赋值求特解与零空间。

易错点

  • 混淆特解与零空间向量的角色：完整解是 xp + xn，不是 xp 与 xn 的任意线性组合。
  • 忽略零空间总是包含零向量，因此可逆矩阵的零空间只有零向量而非不存在。
  • 在构造左右逆时未检查 r = m 或 r = n 的条件，导致维度不匹配。
  • 计算秩不等式时忘记 rank(AB) 同时受 rank(A) 与 rank(B) 的约束。
  • 分块矩阵求逆时混淆左逆与右逆的方向。

题目 1 平行平面的参数向量形式 参数向量形式 · 平面 · 特解加零空间
官方题面翻译可离线作答

平面 \(x - 3y - z = 12\) 与第 17 题中的平面 \(x - 3y - z = 0\) 平行。该平面上一个特解为 \((12, 0, 0)\)。平面上所有点具有以下形式（填写第一个向量）：\[[x;y;z] = [\quad;\quad;\quad] + y[1;0;0] + z[0;0;1]\]。

公式与已知条件

  • 平面方程：\(x - 3y - z = 12\)
  • 特解点：\((12, 0, 0)\)
  • 方向向量：\((1,0,0)\) 与 \((0,0,1)\)
解题入口

将平面方程用自由变量 y 和 z 表示 x，再改写为给定的参数向量形式。

完成后检查

  • 检验特解点 \((12,0,0)\) 是否满足 \(x - 3y - z = 12\)。
  • 检验每个方向向量是否满足齐次方程 \(x - 3y - z = 0\)。

题目 2 给定列空间与零空间的矩阵 列空间 · 零空间 · 秩约束 · 主元计数
官方题面翻译可离线作答

（若可能……）构造一个矩阵，使其列空间包含向量 \((1, 1, 0)\) 与 \((0, 1, 1)\)，且其零空间包含向量 \((1, 0, 1)\) 与 \((0, 0, 1)\)。

公式与已知条件

  • 列空间必须包含 \((1,1,0)\) 与 \((0,1,1)\)
  • 零空间必须包含 \((1,0,1)\) 与 \((0,0,1)\)
解题入口

比较列空间维度所需的主元个数与零空间维度所允许的主元个数。

完成后检查

  • 两个零空间向量线性无关，故零空间维数 \(\ge 2\)。
  • 两个列空间向量线性无关，故列空间维数 \(\ge 2\)。
  • 验证在 3×3 矩阵中两个条件能否同时成立。

题目 3 堆叠矩阵的零空间 零空间 · 堆叠矩阵 · 子空间的交
官方题面翻译可离线作答

若 \(C = [A; B]\)（A 堆叠在 B 上方），零空间 \(N(C)\) 与 \(N(A)\)、\(N(B)\) 有何关系？

公式与已知条件

完成后检查

  • 验证 \(N(A) \cap N(B) \subseteq N(C)\)。

站内等价练习可离线作答

【站内等价练习】如图所示为一含 4 个节点（记为 ①②③④）和 6 条支路的网络，6 条支路电流分别为 \(y_1, y_2, y_3, y_4, y_5, y_6\)（箭头所示为正方向，各 \(y_i\) 可正可负）。各支路连接关系为：\(y_1\) 从节点 ④ 流向节点 ①；\(y_2\) 从节点 ④ 流向节点 ②；\(y_3\) 从节点 ① 流向节点 ②；\(y_4\) 从节点 ① 流向节点 ③；\(y_5\) 从节点 ② 流向节点 ③；\(y_6\) 从节点 ③ 流向节点 ④。在每一节点上应用基尔霍夫电流定律（流入电流之和 = 流出电流之和），列出关于 \(y_1,\dots,y_6\) 的 4 个方程 \(Ay = 0\)，并求出 \(A\) 的零空间中的 3 个特解（special solutions）。

题目 5 由 AB = I 推导秩 秩 · 可逆矩阵 · 矩阵的逆
官方题面翻译可离线作答

设 \(A\) 与 \(B\) 为 \(n \times n\) 矩阵，且 \(AB = I\)。由 \(\operatorname{rank}(AB) \le \operatorname{rank}(A)\) 证明 \(A\) 的秩为 \(n\)，从而 \(A\) 可逆且 \(B\) 必为其双侧逆（2.5 节）。因此 \(BA = I\)（这并不显然！）。

公式与已知条件

  • \(AB = I_n\)
  • \(\operatorname{rank}(AB) \le \operatorname{rank}(A)\)
  • \(A\) 为 \(n \times n\) 矩阵
解题入口

利用 \(\operatorname{rank}(I_n) = n\) 及不等式 \(\operatorname{rank}(AB) \le \operatorname{rank}(A)\)。

完成后检查

  • \(\operatorname{rank}(I_n) = n\)。
  • \(\operatorname{rank}(AB) \le \operatorname{rank}(A) \le n\)。
  • 得出 \(\operatorname{rank}(A) = n\)。

题目 6 COL × ROW 分解 矩阵分解 · 列空间 · 行空间 · 简化行阶梯形

【站内等价练习】已知 3×4 矩阵 \(A = \begin{bmatrix}1&1&2&3\\1&0&1&2\\0&1&1&1\end{bmatrix}\) 的秩为 2。将其分解为 \(A = (COL)(ROW)\)，其中 \(COL\) 是由 \(A\) 的主元列构成的 3×2 矩阵，\(ROW\) 是 \(A\) 的简化行阶梯形 \(R\) 的前 2 行构成的 2×4 矩阵。

  • \(A\) 为 3×4 矩阵，秩为 2
  • 分解为 3×2 矩阵与 2×4 矩阵之积

完成后检查

  • 乘积 \(COL \times ROW\) 等于原矩阵 \(A\)。
  • \(COL\) 由 \(A\) 的主元列组成。
  • \(ROW\) 由简化行阶梯形的非零行组成。

题目 7 分块矩阵 R 及其性质 分块矩阵 · 右逆 · 左逆 · 简化行阶梯形 · 零空间 · 转置
官方题面翻译可离线作答

设 \(R\) 为 \(m \times n\) 矩阵，秩为 \(r\)，主元列在前：\(R = \begin{bmatrix}I&F\\0&0\end{bmatrix}\)。(a) 这四个分块的形状分别是什么？(b) 若 \(r = m\)，求右逆 \(B\) 使得 \(RB = I\)。(c) 若 \(r = n\)，求左逆 \(C\) 使得 \(CR = I\)。(d) \(R^T\) 的简化行阶梯形是什么（含形状）？(e) \(R^T R\) 的简化行阶梯形是什么（含形状）？证明 \(R^T R\) 与 \(R\) 有相同的零空间。

  1. (a) 四个分块的形状
  2. (b) \(r = m\) 时的右逆 \(B\)（\(RB = I\)）
  3. (c) \(r = n\) 时的左逆 \(C\)（\(CR = I\)）
  4. (d) \(R^T\) 的简化行阶梯形
  5. (e) \(R^T R\) 的简化行阶梯形
  6. 证明 \(R^T R\) 与 \(R\) 有相同的零空间

公式与已知条件

  • \(R = \begin{bmatrix}I&F\\0&0\end{bmatrix}\)，其中 \(I\) 为 \(r \times r\)
  • \(R\) 为 \(m \times n\) 矩阵，秩为 \(r\)
  • \(r = m\) 时 \(RB = I\)
  • \(r = n\) 时 \(CR = I\)
解题入口

(a) 由秩 \(r\) 确定各分块维度；(b)(c) 利用分块结构构造逆矩阵；(d)(e) 对转置后的分块形式施行行变换。

完成后检查

  • 分块形状与 \(m\)、\(n\)、\(r\) 一致。
  • \(RB = I_m\) 与 \(CR = I_n\) 验证逆矩阵。
  • 由行变换不改变零空间得 \(N(R^T R) = N(R)\)。

题目 10 说明为何为假 完整解 · 特解 · 零空间 · 最短解 · 可逆矩阵
官方题面翻译可离线作答

说明下列命题为何均为假：(a) 完整解是 \(x_p\) 与 \(x_n\) 的任意线性组合。(b) 方程组 \(Ax = b\) 至多有一个特解。(c) 所有自由变量为零的特解 \(x_p\) 是最短解（最小长度 \(\|x\|\)），找出一个 2×2 反例。(d) 若 \(A\) 可逆，则零空间中不存在解 \(x_n\)。

  3. (c) 最短解反例（2×2）

  • (c) 的 2×2 反例中 \(\|x_p\|\) 大于另一特解的范数。

题目 11 r、m、n 之间的关系 秩 · 存在性 · 唯一性 · 行秩 · 列秩
官方题面翻译可离线作答

写出 \(r\)、\(m\)、\(n\) 之间的全部已知关系，若 \(Ax = b\) 满足：(a) 对某些 \(b\) 无解；(b) 对每个 \(b\) 有无穷多解；(c) 对某些 \(b\) 有唯一解，对其他 \(b\) 无解；(d) 对每个 \(b\) 有唯一解。

  1. (a) 对某些 \(b\) 无解
  2. (b) 对每个 \(b\) 有无穷多解
  3. (c) 对某些 \(b\) 有唯一解，对其他 \(b\) 无解
  4. (d) 对每个 \(b\) 有唯一解

公式与已知条件

  • \(r = \operatorname{rank}(A)\)，\(m\) 为行数，\(n\) 为列数
  • 恒有 \(r \le m\) 且 \(r \le n\)
  • 无解 \(\Leftrightarrow r < m\)（列空间 \(\neq \mathbb{R}^m\)）

解题入口

利用秩、行数、列数之间的关系判断解的存在性与唯一性。

完成后检查

  • 每种情况给出 \(r\)、\(m\)、\(n\) 之间一致的不等式关系。
  • (d) 意味着 \(A\) 可逆（\(r = m = n\)）。

题目 12 高斯-若尔当消元法 高斯-若尔当消元法 · 简化行阶梯形 · 零空间 · 特解
官方题面翻译可离线作答

对 \(Ux = 0\) 与 \(Ux = c\) 施行高斯-若尔当消元，化为 \(Rx = 0\) 与 \(Rx = d\)，其中 \(U_0 = \begin{bmatrix}1&2&3&0\\0&0&4&0\end{bmatrix}\)，\(U_c = \begin{bmatrix}1&2&3&5\\0&0&4&8\end{bmatrix}\)。解 \(Rx = 0\) 求 \(x_n\)（取自由变量 \(x_2 = 1\)），解 \(Rx = d\) 求 \(x_p\)（取自由变量 \(x_2 = 0\)）。

公式与已知条件

  • \(U_0 = \begin{bmatrix}1&2&3&0\\0&0&4&0\end{bmatrix}\)
  • \(U_c = \begin{bmatrix}1&2&3&5\\0&0&4&8\end{bmatrix}\)
  • \(x_n\) 取自由变量 \(x_2 = 1\)
  • \(x_p\) 取自由变量 \(x_2 = 0\)
解题入口

用行变换将 \(U\) 化为 \(R\)（消去主元上方元素），再按给定的自由变量值回代。

完成后检查

  • \(R\) 为简化行阶梯形。
  • \(x_n\) 满足 \(Rx_n = 0\)。
  • \(Rx_p = d\)。

题目 13 二阶差分矩阵 二阶差分矩阵 · 三对角矩阵 · 抛物线型解 · 数值线性代数
官方题面翻译可离线作答

设 \(K\) 为 9×9 二阶差分矩阵（主对角线为 2，上下次对角线为 -1）。解方程 \(Kx = b = (10, 10, \dots, 10)\)。若将 \(x_1,\dots,x_9\) 描在 \(x\) 轴上点 \(1,\dots,9\) 的上方，这九个点落在一条抛物线上。

公式与已知条件

题目 14 相同完整解蕴含 A = C 完整解 · 矩阵相等 · 列空间 · 零空间
官方题面翻译可离线作答

设对每个 \(b\)，\(Ax = b\) 与 \(Cx = b\) 都有相同的（完整）解。是否有 \(A = C\)？

公式与已知条件

  • 对每个 \(b\)，\(Ax = b\) 与 \(Cx = b\) 有相同的完整解
  • 完整解：\(x = x_p + x_n\)
解题入口

取 \(b = Ay\)，证明对任意向量 \(y\) 有 \(Ay = Cy\)。

完成后检查

  • 对任意向量 \(y\)，取 \(b = Ay\)。
  • 则 \(y\) 满足 \(Ax = b\)，故 \(y\) 满足 \(Cx = b\)，即 \(Cy = Ay\)。
  • 由 \(Ay = Cy\) 对所有 \(y\) 成立，得 \(A = C\)。
