Study guide

作业导读

本习题集围绕线性代数前半段的核心概念展开，从向量之间的点积与夹角出发，逐步进入线性相关、马尔可夫过程、奇异系统、矩阵乘法与消元、矩阵逆以及乘法运算量分析。题目强调代数推导与几何直觉的结合，并训练你对矩阵行、列图像的理解。

前置知识

  • 向量的点积、模长与夹角余弦的基本定义
  • 三角恒等式，特别是余弦差角公式
  • 矩阵与向量的乘法、行与列的线性组合
  • 高斯消元的基本操作与行阶梯形

建议顺序

  • 遇到具体数值矩阵（如帕斯卡矩阵、中心差分矩阵）时，先写出矩阵或方程再动手计算。
  • 涉及'奇异/不可逆'的题目，优先寻找行或列之间的线性关系。
  • 马尔可夫矩阵题注意观察迭代过程中分量之和是否保持不变。
  • 矩阵乘法运算量题先代入公式计数，再比较大小。

易错点

  • 不要把'行相关'与'列相关'混为一谈，注意题目问的是行还是列。
  • 消元矩阵 \(E_{21}\) 代表'第 2 行减去第 1 行'，应用两次效果会叠加。
  • 马尔可夫矩阵的稳态向量要求分量之和为 \(1\)，不要忘记归一化。
  • 构造无零元素的奇异矩阵时，行与行之间必须线性相关但不能出现零元。

题目 1.2.23 两个向量夹角的余弦 点积 · 向量夹角 · 余弦和差公式
官方题面翻译可离线作答

设平面内有两个向量 \(v\) 和 \(w\)，它们与 \(x\) 轴的夹角分别为 \(\alpha\) 和 \(\beta\)。已知 \(\cos(\alpha) = v_1/\|v\|\)，\(\sin(\alpha) = v_2/\|v\|\)，其中 \(v = (v_1, v_2)\)。同理，\(\cos(\beta)\) 等于 ___，\(\sin(\beta)\) 等于 ___。记两向量之间的夹角 \(\theta = \beta - \alpha\)。将上述表达式代入三角恒等式 \(\cos(\alpha)\cos(\beta) + \sin(\beta)\sin(\alpha)\)（即 \(\cos(\beta - \alpha)\) 的展开式），推导并得出 \(\cos(\theta) = v \cdot w/(\|v\| \|w\|)\)。

  1. 填写 \(\cos(\beta)\) 与 \(\sin(\beta)\) 的空缺表达式。
  2. 将 \(\cos(\beta-\alpha) = \cos(\alpha)\cos(\beta) + \sin(\beta)\sin(\alpha)\) 中的各量代入，化简得到 \(\cos(\theta) = v \cdot w/(\|v\| \|w\|\)。

公式与已知条件

  • \(\cos(\alpha) = v_1/\|v\|\)，\(\sin(\alpha) = v_2/\|v\|\)，其中 \(v = (v_1, v_2)\)
  • \(\theta = \beta - \alpha\)
  • \(\cos(\beta-\alpha) = \cos(\alpha)\cos(\beta) + \sin(\beta)\sin(\alpha)\)
解题入口

类比 \(v\) 的分量表示，用 \(w = (w_1, w_2)\) 的分量写出 \(\cos(\beta)\) 与 \(\sin(\beta)\)，再代入余弦差角公式。

完成后检查

  • 最终表达式应对 \(v\) 和 \(w\) 是对称的。
  • 在平面情形下应能退化为余弦定理的形式。

本题官方题面翻译。原题引用了一张几何图（向量 \(v\)、\(w\) 与角 \(\alpha\)、\(\beta\)），此处以文字完整描述了几何设定，无需原图即可作答。

题目 1.3.13 中心差分矩阵与相容性条件 奇异矩阵 · 相容性条件 · 中心差分

  1. 写出 \(Cx = b\) 的 5 个方程。
  2. 找出左端的一种线性组合使其为零。
  3. 推出右端项 \(b_i\) 应满足的相应条件。

公式与已知条件

题目 2.4.36 最优乘法顺序 矩阵乘法运算量 · 运算顺序
官方题面翻译可离线作答

设 \(A\) 为 \(m \times n\) 矩阵，\(B\) 为 \(n \times p\) 矩阵，\(C\) 为 \(p \times q\) 矩阵。则 \((AB)C\) 的乘法运算量为 \(mnp + mpq\)，\(A(BC)\) 的乘法运算量为 \(mnq + npq\)。 (a) 若 \(A\) 为 \(2 \times 4\)，\(B\) 为 \(4 \times 7\)，\(C\) 为 \(7 \times 10\)，你更倾向于 \((AB)C\) 还是 \(A(BC)\)？ (b) 对 \(N\) 分量向量，应选 \((u^T v)w^T\) 还是 \(u^T(vw^T)\)？ (c) 两边同除以 \(mnpq\)，证明：当 \(n^{-1} + q^{-1} < m^{-1} + p^{-1}\) 时，\((AB)C\) 更快。

  1. (a) 比较给定规模下的运算量。
  2. (b) 选择运算量更小的向量形式。
  3. (c) 推导不等式。

公式与已知条件

  • \(\operatorname{Cost}(AB)C = mnp + mpq\)

解题入口

将给定规模代入运算量公式；(b) 分别统计每种结合方式的标量乘法次数；(c) 对不等式 \(mnp + mpq < mnq + npq\) 进行变形。

完成后检查

  • 验证 (a) 的数值结果。
  • 验证 (c) 的不等式与运算量比较一致。
