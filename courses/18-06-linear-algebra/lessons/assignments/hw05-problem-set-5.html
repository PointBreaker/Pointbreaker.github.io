Problem 4.1.7 Fredholm's Alternative Fredholm's Alternative · Column space · Left nullspace · Inconsistent systems

Every system with no solution is like the one in problem 6. There are numbers y1,...,ym that multiply the m equations so they add up to 0 = 1. This is called Fredholm's Alternative: Exactly one of these problems has a solution: Ax = b OR A^T y = 0 with y^T b = 1. If b is not in the column space of A it is not orthogonal to the nullspace of A^T. Multiply the equations x1 - x2 = 1, x2 - x3 = 1, and x1 - x3 = 1 by numbers y1, y2, y3 chosen so that the equations add up to 0 = 1.

  1. Choose y1, y2, y3 so that the three equations sum to 0 = 1.

公式与已知条件

  • x1 - x2 = 1
  • x2 - x3 = 1
  • x1 - x3 = 1
解题入口

Find multipliers y1, y2, y3 that cancel all x-variables on the left side while summing the right-hand sides to 1.

完成后检查

  • Left-hand side sums to 0 after combining like terms.
  • Right-hand side sums to 1.

Problem 4.1.9 Nullspace of A^T A Nullspace · Column space · Orthogonality · Fundamental subspaces

If A^T A x = 0 then Ax = 0. Reason: Ax is in the nullspace of A^T and also in the _____ of A and those spaces are _____. Conclusion: A^T A has the same nullspace as A. This key fact is repeated in the next section.

  1. Explain why Ax = 0 follows from A^T A x = 0.
  2. State the conclusion about the nullspace of A^T A.

公式与已知条件

  • A^T A x = 0
解题入口

Note Ax lies in both N(A^T) and C(A); use orthogonality of those subspaces.

完成后检查

  • Ax is in C(A) by definition.
  • A^T(Ax) = 0 puts Ax in N(A^T).
  • Ax must be 0 since the only vector in both is the zero vector.

Problem 4.1.31 null(N') gives the row space Nullspace · Row space · MATLAB null command · Orthogonal complements

The command N = null(A) will produce a basis for the nullspace of A. Then the command B = null(N') will produce a basis for the _____ of A.

  1. Identify what fundamental subspace B spans and explain why.

公式与已知条件

  • N = null(A)
  • B = null(N')
解题入口

A vector in N(N^T) is orthogonal to every nullspace basis vector, hence lies in the row space.

完成后检查

  • Columns of N form a basis for N(A).
  • Vectors in null(N') are orthogonal to N(A).
  • Orthogonal complement of N(A) is C(A^T).

Problem 4.1.32 Four fundamental subspaces from four vectors in R^2 (dim 1) Fundamental subspaces · Orthogonality · Basis conditions · Matrix construction

Suppose I give you four nonzero vectors r, n, c, l in R^2.

  1. a. What are the conditions for those to be bases for the four fundamental subspaces C(A^T), N(A), C(A), N(A^T) of a 2x2 matrix?
  2. b. What is one possible matrix A?

公式与已知条件

  • r, n, c, l in R^2
  • dim = 1 for each subspace
解题入口

Row space and nullspace must be orthogonal; column space and left nullspace must be orthogonal. Dimensions must satisfy rank-nullity.

完成后检查

  • r · n = 0 for row space/nullspace orthogonality.
  • c · l = 0 for column space/left nullspace orthogonality.
  • Dimensions sum correctly (1+1=2).

Problem 4.1.33 Four fundamental subspaces from eight vectors in R^2 (dim 2) Fundamental subspaces · Linear independence · Orthogonality · Full-rank matrix construction

Suppose I give you four nonzero vectors r1, r2, n1, n2, c1, c2, l1, l2 in R^2.

  1. a. What are the conditions for those to be bases for the four fundamental subspaces C(A^T), N(A), C(A), N(A^T) of a 2x2 matrix?
  2. b. What is one possible matrix A?

公式与已知条件

  • r1, r2, n1, n2, c1, c2, l1, l2 in R^2
  • dim = 2 for each subspace
解题入口

Each pair must be linearly independent and span R^2; ri·nj = 0 and ci·lj = 0 for all i,j.

完成后检查

  • {r1,r2}, {n1,n2}, {c1,c2}, {l1,l2} each linearly independent.
  • All ri·nj = 0 and ci·lj = 0.
  • Resulting A has correct row and column spaces.

Problem 4.2.13 Projection onto a coordinate subspace Projection matrix · Column space · Coordinate subspaces

Suppose A is the 4x4 identity matrix with its last column removed. A is 4x3. Project b = (1, 2, 3, 4) onto the column space of A. What shape is the projection matrix P and what is P?

  1. Determine the shape of P.
  2. Compute P.
  3. Compute the projection of b.

公式与已知条件

  • A = 4x4 identity minus last column (4x3)
  • b = (1, 2, 3, 4)
解题入口

The column space is the subspace where the last coordinate is 0; projecting removes that coordinate.

完成后检查

  • P is 4x4.
  • P^2 = P and P^T = P.
  • Projection of b has last coordinate zeroed out.

Problem 4.2.17 Complementary projection matrix Projection matrices · Idempotent matrices · Left nullspace

If P^2 = P show that (I - P)^2 = I - P. When P projects onto the column space of A, I - P projects onto the _____.

  1. Prove (I - P)^2 = I - P.
  2. Identify the subspace I - P projects onto.

公式与已知条件

  • P^2 = P
解题入口

Expand (I-P)^2 using distributive law and substitute P^2 = P.

完成后检查

  • (I-P)^2 = I - 2P + P^2 = I - 2P + P = I - P.
  • I-P projects onto the orthogonal complement of C(A).

Problem 4.2.30 Projecting onto column and row spaces of a rank-1 matrix Projection matrices · Rank-1 matrices · Column space · Row space

Let A = [[3,6,6],[4,8,8]].

  1. a. Find the projection matrix P_C onto the column space of A.
  2. b. Find the 3x3 projection matrix P_R onto the row space of A. Multiply B = P_C A P_R. Your answer B should be a little surprising - can you explain it?

公式与已知条件

  • A = [[3,6,6],[4,8,8]]
解题入口

For rank-1 matrices, use the outer-product form of projection matrices. Then analyze why P_C A = A and A P_R = A.

完成后检查

  • P_C = a(a^T a)^{-1} a^T where a spans C(A).
  • P_R = a(a^T a)^{-1} a^T where a spans C(A^T).
  • P_C A P_R = A.

Problem 4.2.31 Testing whether p is the projection of b Projection test · Span membership · Orthogonality

In R^m, suppose I give you b and p, and n linearly independent vectors a1,...,an. How would you test to see if p is the projection of b onto the subspace spanned by the a's?

  1. Describe the test for p being the projection of b onto span{a1,...,an}.

公式与已知条件

  • b, p in R^m
  • a1,...,an linearly independent in R^m
解题入口

A projection must lie in the subspace and have error orthogonal to it.

完成后检查

  • p is in span{a1,...,an}.
  • b - p is orthogonal to each ai.
  • Both conditions are necessary.

Problem 4.2.34 Invertibility of AB Matrix rank · Invertibility · Independent columns/rows · Rank-nullity

If A has r independent columns and B has r independent rows, AB is invertible. Proof: When A is m by r with independent columns, we know that A^T A is invertible. If B is r by n with independent rows, show that BB^T is invertible (take A = B^T). Now show that AB has rank r.

  1. Show BB^T is invertible.
  2. Show AB has rank r and is therefore invertible.

公式与已知条件

  • A is m x r with independent columns
  • B is r x n with independent rows
解题入口

Use A^T A invertible for full column rank; apply to B^T. Then argue via A^T(AB)B^T having rank r.

完成后检查

  • BB^T = (B^T)^T(B^T) analogue is invertible.
  • A^T(AB)B^T is r x r and invertible.
  • AB is r x r with rank r.

With conductances c1 = c2 = 2 and c3 = c4 = c5 = 3, multiply the matrices A^T C A. Find a solution to A^T C A x = f = (1, 0, 0, -1). Where are these potentials x and currents y = -CAx on the nodes and edges of the square graph?

Problem 8.2.17 Incidence matrix of a 12x9 connected graph Incidence matrix · Rank · Connected graph · Degrees of nodes

Suppose A is a 12 x 9 incidence matrix from a connected (but unknown) graph.

  1. a. How many columns of A are independent?
  2. b. What condition on f makes it possible to solve A^T y = f?
  3. c. The diagonal entries of A^T A give the number of edges into each node. What is the sum of those diagonal entries?

公式与已知条件

  • A is 12 x 9
  • Connected graph (9 nodes, 12 edges)
解题入口

Rank of incidence matrix of connected graph is n-1. For A^T y = f, f must be orthogonal to N(A^T). Sum of degrees equals 2 * number of edges.

完成后检查

  • rank(A) = 8 (tree with 8 edges).
  • Entries of f sum to 0.
  • Sum of diagonal entries = 24.
