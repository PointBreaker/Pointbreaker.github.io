作业导读

本习题集围绕线性代数的四个基本子空间展开，涵盖 Fredholm 择一性、零空间与行空间的正交关系、投影矩阵与最小二乘逼近，以及关联矩阵在网络电位与电流计算中的应用。题目从子空间的正交分解出发，逐步过渡到投影矩阵的构造与性质，最后以图上的电路问题收尾。

前置知识

  • 矩阵的四个基本子空间及其维数关系（秩-零化度定理）
  • 子空间正交性的判断与正交补的概念
  • 投影矩阵的定义、幂等性与对称性
  • 最小二乘问题的法方程推导
  • 关联矩阵与电导矩阵的基本构造

建议顺序

  • 遇到判断解的存在性问题时，优先考虑列空间与左零空间的正交关系。
  • 涉及投影矩阵时，先确认目标子空间，再利用幂等性 P^2 = P 和对称性 P^T = P 进行验证。
  • 处理 A^T A 或 A^T C A 相关问题时，利用对称正定性和零空间关系简化分析。
  • 网络问题中，先明确节点与边的编号，再据此写出关联矩阵和电导矩阵。
  • 证明题注意从定义出发，利用子空间正交补的唯一性得出结论。

易错点

  • 混淆 N(A) 与 N(A^T)，注意行空间与左零空间分别对应 A^T 与 A 的零空间。
  • 投影矩阵的维数容易被忽略，注意 P 是 m×m 而非 m×n。
  • 最小二乘的误差向量必须与列空间正交，而非仅与单个列向量正交。
  • 关联矩阵的零空间维数比节点数少 1，注意连通图 rank = n-1。
  • 验证投影时，仅检查子空间归属或仅检查正交性都不充分，二者缺一不可。

题目 4.1.7 Fredholm 择一性 Fredholm 择一性 · 列空间 · 左零空间 · 不一致方程组
依据本地资料重建可离线作答

每个无解方程组都与第 6 题类似。存在数 \(y_1, \ldots, y_m\)，使得它们分别乘以 m 个方程后相加得到 \(0 = 1\)。这称为 Fredholm 择一性（Fredholm's Alternative）：下列两个问题恰有一个有解：\(Ax = b\)，或 \(A^T y = 0\) 且 \(y^T b = 1\)。若 b 不在 A 的列空间（column space）中，则 b 不与 \(A^T\) 的零空间（nullspace）正交。对以下三个方程 \(x_1 - x_2 = 1\)、\(x_2 - x_3 = 1\)、\(x_1 - x_3 = 1\)，选取数 \(y_1, y_2, y_3\)，使得它们相加后得到 \(0 = 1\)。

  1. 选取 \(y_1, y_2, y_3\)，使得三个方程相加后得到 \(0 = 1\)。

公式与已知条件

  • \(x_1 - x_2 = 1\)
  • \(x_2 - x_3 = 1\)
  • \(x_1 - x_3 = 1\)
解题入口

寻找乘数 \(y_1, y_2, y_3\)，使左侧所有 x 变量相互抵消，同时右侧常数项之和为 1。

完成后检查

  • 合并同类项后左侧之和为 0。
  • 右侧常数项之和为 1。

题目 4.1.9 A^T A 的零空间 零空间 · 列空间 · 正交性 · 四个基本子空间
依据本地资料重建可离线作答

若 \(A^T A x = 0\)，则 \(Ax = 0\)。理由：Ax 既在 \(A^T\) 的零空间中，又在 A 的 _____ 中，而这两个空间是 _____ 的。结论：\(A^T A\) 与 A 有相同的零空间。这一关键结论将在下一节重复出现。

  1. 解释为何由 \(A^T A x = 0\) 可推出 \(Ax = 0\)。
  2. 陈述关于 \(A^T A\) 零空间的结论。

公式与已知条件

  • \(A^T A x = 0\)
解题入口

注意 Ax 同时属于 \(N(A^T)\) 和 \(C(A)\)，利用这两个子空间的正交性。

完成后检查

  • Ax 按定义属于 \(C(A)\)。
  • \(A^T(Ax) = 0\) 表明 Ax 属于 \(N(A^T)\)。
  • 两个子空间的交集只有零向量，故 \(Ax = 0\)。

  • null(N') 中的向量与 \(N(A)\) 正交。
  • \(N(A)\) 的正交补是 \(C(A^T)\)。

题目 4.1.32 R^2 中四个向量对应的四个基本子空间（维数 1） 四个基本子空间 · 正交性 · 基的条件 · 矩阵构造

  1. a. 这四个向量要成为某个 2×2 矩阵 A 的四个基本子空间 \(C(A^T), N(A), C(A), N(A^T)\) 的基，需要满足什么条件？

  • \(c \cdot l = 0\) 保证列空间与左零空间正交。
  • 维数之和正确（1+1=2）。

题目 4.1.33 R^2 中八个向量对应的四个基本子空间（维数 2） 四个基本子空间 · 线性无关性 · 正交性 · 满秩矩阵构造
依据本地资料重建可离线作答

假设给定 \(\mathbb{R}^2\) 中八个非零向量 \(r_1, r_2, n_1, n_2, c_1, c_2, l_1, l_2\)。

  1. a. 这八个向量要成为某个 2×2 矩阵 A 的四个基本子空间 \(C(A^T), N(A), C(A), N(A^T)\) 的基，需要满足什么条件？
  2. b. 给出一个可能的矩阵 A。

  • 所有 \(r_i \cdot n_j = 0\) 且 \(c_i \cdot l_j = 0\)。
  • 所得矩阵 A 具有正确的行空间和列空间。

题目 4.2.17 互补投影矩阵 投影矩阵 · 幂等矩阵 · 左零空间
依据本地资料重建可离线作答

若 \(P^2 = P\)，证明 \((I - P)^2 = I - P\)。当 P 投影到 A 的列空间时，\(I - P\) 投影到 _____。

  1. 证明 \((I - P)^2 = I - P\)。
  2. 指出 \(I - P\) 投影到哪个子空间。

公式与已知条件

  • \(P^2 = P\)
解题入口

利用分配律展开 \((I-P)^2\)，并代入 \(P^2 = P\)。

完成后检查

  • \((I-P)^2 = I - 2P + P^2 = I - 2P + P = I - P\)。
  • \(I-P\) 投影到 \(C(A)\) 的正交补，即 A 的左零空间。

  2. b. 求投影到 A 的行空间的 3×3 投影矩阵 \(P_R\)。计算 \(B = P_C A P_R\)。你的结果 B 可能会有些令人惊讶——能解释一下吗？

题目 4.2.34 AB 的可逆性 矩阵的秩 · 可逆性 · 线性无关列/行 · 秩-零化度定理
依据本地资料重建可离线作答

若 A 有 r 个线性无关列且 B 有 r 个线性无关行，则 AB 可逆。证明：当 A 为 \(m \times r\) 矩阵且列线性无关时，我们知道 \(A^T A\) 可逆。若 B 为 \(r \times n\) 矩阵且行线性无关，证明 \(BB^T\) 可逆（取 \(A = B^T\)）。然后证明 AB 的秩为 r。

  1. 证明 \(BB^T\) 可逆。
  2. 证明 AB 的秩为 r，从而可逆。

公式与已知条件

  • A 为 m×r 矩阵，列线性无关
  • B 为 r×n 矩阵，行线性无关
解题入口

对列满秩矩阵利用 \(A^T A\) 可逆的性质，应用于 \(B^T\)。然后论证 \(A^T(AB)B^T\) 的秩为 r。

完成后检查

  • \(BB^T = (B^T)^T(B^T)\) 的类似形式可逆。
  • \(A^T(AB)B^T\) 为 \(r \times r\) 矩阵且可逆。
  • AB 为 \(r \times r\) 矩阵且秩为 r。
