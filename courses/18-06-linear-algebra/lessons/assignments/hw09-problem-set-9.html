易错点

  • 正定矩阵的乘积不一定对称，特征值为正与矩阵对称是两个独立条件

  • 自由-自由情形 \(A^T C A\) 奇异，解存在需满足力平衡条件
  • 差分格式的前差、后差、中心差对应的离散矩阵不同，注意符号
  • MATLAB 稀疏矩阵求解注意边界条件对矩阵的修改

题目 6.5#25 Cholesky 分解 A = C^T C Cholesky 分解 · LDL^T 分解 · 正定矩阵
依据本地资料重建可离线作答

若 \(D\) 的主元均为正，则分解 \(A = LDL^T\) 可写成 \(L\sqrt{D} \cdot \sqrt{D} L^T\)（其中 \(D\) 的主元开平方给出 \(D = \sqrt{D} \cdot \sqrt{D}\)）。于是 \(C = \sqrt{D} L^T\) 得到 Cholesky 分解 \(A = C^T C\)。已知 \(C = \(\begin{bmatrix}3&1\\0&2\end{bmatrix}\)\)，求 \(A\)；已知 \(A = \(\begin{bmatrix}4&8\\8&25\end{bmatrix}\)\)，求 \(C = \operatorname{chol}(A)\)。

  1. 由已知的 \(C\) 求 \(A\)。
  2. 由已知的 \(A\) 求 \(C\)。

公式与已知条件

  • \(A = LDL^T\)，其中 \(L\) 为单位下三角矩阵，\(D\) 为对角矩阵
  • \(C = \sqrt{D} \cdot L^T\)
  • 已知 \(C = \(\begin{bmatrix}3&1\\0&2\end{bmatrix}\)\)
  • 已知 \(A = \(\begin{bmatrix}4&8\\8&25\end{bmatrix}\)\)
解题入口

利用 \(A = C^T C\) 直接乘法计算。对反向问题，将 \(A = LDL^T\) 分解后取主元平方根构造 \(\sqrt{D}\)，再求 \(C = \sqrt{D} L^T\)。

完成后检查

  • 验证两个方向均有 \(C^T C\) 还原给定矩阵。

题目 6.5#27 LDL^T 与配方法 LDL^T 分解 · 二次型 · 配方法 · 主元
依据本地资料重建可离线作答

对称分解 \(A = LDL^T\) 意味着 \(x^T A x = x^T LDL^T x\)。左边为 \(a x^2 + 2b xy + c y^2\)，右边可配方为 \(a(x + (b/a) y)^2 + (c - b^2/a) y^2\)。第二个主元恰好完成配方！取 \(a = 2\), \(b = 4\), \(c = 10\) 进行验证。

  1. 验证通过 \(LDL^T\) 实现的配方代数恒等式。
  2. 取 \(a = 2\), \(b = 4\), \(c = 10\) 验证该恒等式。

公式与已知条件

  • \(A = \(\begin{bmatrix}a&b\\b&c\end{bmatrix}\)\)
  • \(x^T A x = a x^2 + 2b xy + c y^2\)
  • 配方形式：\(a(x + (b/a) y)^2 + (c - b^2/a) y^2\)
  • 第二个主元 \(= c - b^2/a\)
  • \(a = 2\), \(b = 4\), \(c = 10\)
解题入口

将 \(A\) 分解为 \(LDL^T\)，展开 \(x^T LDL^T x\)，识别配方式。

完成后检查

  • 当 \(a = 2\), \(b = 4\), \(c = 10\) 时，验证 \(2x^2 + 8xy + 10y^2 = 2(x + 2y)^2 + 2y^2\)。

题目 6.5#29 二阶导数（Hessian）矩阵 Hessian 矩阵 · 驻点 · 正定性 · 鞍点 · 凸性
依据本地资料重建可离线作答

设 \(F_1(x,y) = x^4/4 + x^2 + x^2y + y^2\)，\(F_2(x,y) = x^3 + xy - x\)。分别求 \(F_1\) 与 \(F_2\) 的二阶导数矩阵 \(H_1\) 与 \(H_2\)（即 Hessian 矩阵）。\(H_1\) 正定，故 \(F_1\) 为凸函数。求 \(F_1\) 的极小值点与 \(F_2\) 的鞍点（只需考察一阶偏导为零的位置）。

  1. 计算 \(F_1\) 的 Hessian \(H_1\)，并求其极小值点。
  2. 计算 \(F_2\) 的 Hessian \(H_2\)，并求其鞍点。

公式与已知条件

  • \(F_1(x,y) = x^4/4 + x^2 + x^2y + y^2\)
  • \(F_2(x,y) = x^3 + xy - x\)

解题入口

完成后检查

  • 验证 \(F_1\) 的驻点与 \(H_1\) 的正定性。
  • 验证 \(F_2\) 在对应驻点处 Hessian 特征值符号相反。

题目 6.5#33 正定矩阵 A、B 乘积 AB 的特征值 正定矩阵 · 矩阵乘积的特征值 · Rayleigh 商
依据本地资料重建可离线作答
