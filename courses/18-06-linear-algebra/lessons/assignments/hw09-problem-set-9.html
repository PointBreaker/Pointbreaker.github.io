Problem 6.5#25 Cholesky factorization A = C^T C Cholesky factorization · LDL^T decomposition · positive definite matrices

With positive pivots in D, the factorization A = LDL^T becomes L√D √D L^T (square roots of the pivots give D = √D √D). Then C = √D L^T yields the Cholesky factorization A = C^T C. From C = [[3,1],[0,2]] find A. From A = [[4,8],[8,25]] find C = chol(A).

  1. Find A from the given C.
  2. Find C from the given A.

公式与已知条件

  • A = LDL^T; C = √D L^T; C = [[3,1],[0,2]]; A = [[4,8],[8,25]]
解题入口

Compute A = C^T C by direct multiplication. For the reverse direction, diagonalize A to identify L and D, then form C = √D L^T.

完成后检查

  • Verify that C^T C reproduces the given A in both directions.

Problem 6.5#26 Cholesky factorization for two matrices Cholesky factorization · LDL^T decomposition · positive definite matrices

In the Cholesky factorization A = C^T C, with C^T = L√D, the square roots of the pivots are on the diagonal of C. Find C (upper triangular) for A = [[9,0,0],[0,1,2],[0,2,8]] and A = [[1,1,1],[1,2,2],[1,2,7]].

  1. Find C for the first matrix.
  2. Find C for the second matrix.

公式与已知条件

解题入口

Diagonalize each A into LDL^T, take square roots of pivots to form √D, then compute C = √D L^T.

完成后检查

  • Confirm C^T C equals the original A for each matrix.

Problem 6.5#27 LDL^T and completing the square LDL^T decomposition · quadratic forms · completing the square · pivots

The symmetric factorization A = LDL^T means that x^T A x = x^T LDL^T x. The left side is a x^2 + 2b xy + c y^2. The right side is a(x + (b/a) y)^2 + (c - b^2/a) y^2. The second pivot completes the square! Test with a = 2, b = 4, c = 10.

  1. Verify the algebraic identity for completing the square via LDL^T.
  2. Test the identity with a = 2, b = 4, c = 10.

公式与已知条件

  • A = [[a,b],[b,c]]; x^T A x = a x^2 + 2b xy + c y^2; second pivot = c - b^2/a; a=2, b=4, c=10
解题入口

Factor A = LDL^T, expand x^T LDL^T x, and identify the completed-square form.

完成后检查

  • For a=2,b=4,c=10, verify 2x^2+8xy+10y^2 = 2(x+2y)^2 + 2y^2.

Problem 6.5#29 Second-derivative (Hessian) matrices Hessian matrices · stationary points · positive definiteness · saddle points · convexity

For F1(x,y) = x^4/4 + x^2 + x^2 y + y^2 and F2(x,y) = x^3 + xy - x, find the second-derivative matrices H1 and H2 (Hessians). H1 is positive-definite so F1 is convex. Find the minimum point of F1 and the saddle point of F2 (look only where the first derivatives are zero).

  1. Compute the Hessian H1 of F1 and find its minimum point.
  2. Compute the Hessian H2 of F2 and find its saddle point.

公式与已知条件

  • F1 = x^4/4 + x^2 + x^2 y + y^2; F2 = x^3 + xy - x; H = [[F_xx, F_xy],[F_yx, F_yy]]
解题入口

Set first partial derivatives to zero to find critical points. Evaluate the Hessian at those points to classify them via eigenvalues or pivots.

完成后检查

  • For F1 verify (0,0) is the only critical point and H1 is positive definite there. For F2 verify eigenvalues at (0,1) have opposite signs.

Problem 6.5#32 Groups of nonsingular matrices group theory · matrix groups · orthogonal matrices · positive definite matrices · matrix exponential · subgroups

A group of nonsingular matrices includes AB and A^{-1} if it includes A and B. Which of the following are groups? Invent a subgroup of two of these groups (not I by itself). (a) Positive definite symmetric matrices A. (b) Orthogonal matrices Q. (c) All exponentials e^{tA} of a fixed matrix A. (d) Matrices P with positive eigenvalues. (e) Matrices D with determinant 1.

  1. Determine which sets are groups under matrix multiplication.
  2. Invent a subgroup from two of these groups.

公式与已知条件

  • Closure under product and inverse required for a group; example matrices [[1,2],[2,3]] and [[1,2],[2,4]] mentioned in solution
解题入口

Check closure under multiplication and inversion for each set. Intersections of groups yield subgroups.

完成后检查

  • Positive definite symmetric matrices fail closure under multiplication (product need not be symmetric). Orthogonal matrices and det=1 matrices form groups.

Problem 6.5#33 Eigenvalues of AB for positive definite A, B positive definite matrices · eigenvalues of matrix products · Rayleigh quotient

When A and B are symmetric positive definite, AB might not even be symmetric. But its eigenvalues are still positive. Start from ABx = λx and take dot products with Bx. Then prove λ > 0.

  1. Prove that all eigenvalues of AB are positive.

公式与已知条件

  • ABx = λx; A, B symmetric positive definite
解题入口

Take the dot product of ABx = λx with Bx. Use symmetry of A and B to rewrite (ABx)^T Bx = (Bx)^T A (Bx), and λ x^T B x on the other side.

完成后检查

  • Use positive definiteness of B (x^T Bx > 0) and A ((Bx)^T A (Bx) > 0) to conclude λ > 0.

Write down the 5 by 5 sine matrix S from Worked Example 6.5 D, containing the eigenvectors of K when n = 5 and h = 1/6. Multiply K times S to see the five positive eigenvalues. Their sum should equal the trace 10. Their product should be det K = 6.

Problem 6.5#35 Positive definiteness of A^T C A positive definite matrices · full column rank · quadratic forms

If A has full column rank, and C is positive-definite, show that A^T C A is positive definite.

  1. Show A^T C A is positive definite.

公式与已知条件

  • A has full column rank; C positive definite; z^T A^T C A z = (Az)^T C (Az)
解题入口

Rewrite z^T A^T C A z as (Az)^T C (Az). Use that Az ≠ 0 for z ≠ 0 (since N(A)={0}) and that C is positive definite.

完成后检查

  • Confirm N(A) = {0} from full column rank, then (Az)^T C (Az) > 0 for all nonzero z.

Problem 8.1#3 Free-free case: singular A^T C A spring-mass systems · free-free boundary conditions · nullspace · equilibrium equations

In the free-free case when A^T C A in equation (9) is singular, add the three equations A^T C A u = f to show that we need f1 + f2 + f3 = 0. Find a solution to A^T C A u = f when the forces f = (-1, 0, 1) balance themselves. Find all solutions!

Problem 8.1#11 MATLAB: chemical engineering finite differences finite differences · forward/backward/centered differences · differential equations · MATLAB

(MATLAB) Chemical engineering has a first derivative du/dx from fluid velocity as well as d^2u/dx^2 from diffusion. Replace du/dx by a forward difference, then a centered difference, then a backward difference, with Δx = 1/8. Graph your numerical solutions of -d^2u/dx^2 + 10 du/dx = 1 with u(0)=u(1)=0.

  1. Solve using forward difference for du/dx.
  2. Solve using backward difference for du/dx.
  3. Solve using centered difference for du/dx.
  4. Graph all three numerical solutions.

公式与已知条件

  • -u'' + 10 u' = 1; u(0)=u(1)=0; Δx=1/8; grid points n=7
解题入口

Build second-difference K and first-difference D matrices. Form (K+D), (K-D), and (K+D/2-D'/2) for forward, backward, and centered schemes, then solve.

完成后检查

  • Forward and backward solutions should differ noticeably; centered should be more accurate.
