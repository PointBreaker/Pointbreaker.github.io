跨模块联系

从最小二乘到 SVD

最小二乘的解 \(\xhat = (A^T A)^{-1}A^T \bvec\) 在 \(A\) 列不满秩时失效。SVD 给出通解 \(\xhat = V \Sigma^+ U^T \bvec\)，其中 \(\Sigma^+\) 是伪逆（pseudoinverse）。这是课程从"可逆"到"广义可逆"的自然延伸。

从特征值到正定

对称矩阵的特征值全正 ⇔ 正定 ⇔ 二次型开口向上 ⇔ 所有顺序主子式为正。优化、数值代数、统计（协方差矩阵）都依赖这条链。

从投影到 Gram-Schmidt

Gram-Schmidt 的每一步都是投影：\(\vvec_j = \avec_j - \sum_{i < j} \operatorname{proj}_{\qvec_i}(\avec_j)\)。\(Q\) 的列正交意味着 \(A^T A\) 对角化，从而 \(R = Q^T A\) 上三角。

核心洞察：整门课反复使用同一套路——把空间分解为正交子空间，在每个子空间上独立处理，再组合。四个子空间是第一次分解，QR 是第二次，特征分解是第三次，SVD 是最后一次。

常见错误速查

  • 把 \(U\) 的主元列当作列空间的基 → 应取原矩阵 \(A\) 的主元列
  • 认为 \(A^T A\) 总可逆 → 仅当 \(A\) 列满秩时可逆
  • 认为不同特征值只是可对角化的充分条件 → 本质是几何重数 = 代数重数
  • Gram-Schmidt 只减一个投影 → 要减所有前面的投影
  • 混淆相似 \(M^{-1}AM\) 与合同 \(M^T AM\) → 对称矩阵用正交对角化 \(Q^T A Q\)
  • 投影矩阵乘列向量时忘了 \(P\bvec\) 才是投影结果 → \(P\) 作用在向量上，不是 \(A\bvec\)

公式速查

场景公式
投影矩阵\(P = A(A^T A)^{-1}A^T\)，满足 \(P^2 = P^T = P\)
法方程\(A^T A \xhat = A^T \bvec\)
特征多项式（2×2）\(\lambda^2 - \operatorname{tr}(A)\lambda + \det(A) = 0\)
谱分解（对称）\(A = Q\Lambda Q^T = \sum_i \lambda_i \qvec_i \qvec_i^T\)
SVD\(A = U\Sigma V^T\)，\(\sigma_i = \sqrt{\lambda_i(A^T A)}\)
正定判据（2×2）\(a > 0,\; ac - b^2 > 0\)
秩-零化度\(\dim N(A) = n - r\)，\(\dim N(A^T) = m - r\)
行列式与可逆\(\det A \neq 0 \iff A^{-1}\) 存在

考场策略

  1. 通卷分类：先快速浏览，把题目归入"消元/子空间""投影/最小二乘""特征值/对角化""SVD/变换"四类。
  2. 先拿概念分：判断题、选择题、简答往往不需要计算，先拿下。
  3. 消元是通用工具：遇到不确定的矩阵题，先消元到 \(U\) 或 \(R\)，秩与主元会告诉你大部分信息。
  4. 检查对称性：如果矩阵对称，立刻用谱定理——特征值实、特征向量正交、SVD 与特征分解重合。
  5. 最后 5 分钟：检查主元列是否来自原矩阵、投影矩阵是否幂等、特征向量是否归一、行列式符号是否正确。

时间分配提醒：期末考 120 分钟，题量较大。建议每道大题控制在 15 分钟内，留 15 分钟检查。遇到复杂计算先跳过，确保所有题目都有时间作答。

备考要点

一个方程贯穿全课

\(A\xvec = \bvec\) 是 18.06 的主题：从消元的直接解，到最小二乘的近似解，到特征展开的模态解，到 SVD 的广义解——每种解法对应一类矩阵结构。

分解是理解矩阵的钥匙

LU 揭示消元过程，QR 揭示正交化，对角化揭示动力学，SVD 揭示几何结构。每种分解都是一套"语言"。

对称矩阵是"最友好"的矩阵

实谱、正交特征向量、可对角化、正定判据清晰——遇到对称矩阵，所有工具都可用且互相印证。

四个子空间是几何直觉

行空间与零空间、列空间与左零空间——这两对正交补是投影、最小二乘、SVD 的共同几何基础。
