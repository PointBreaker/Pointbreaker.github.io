第一次测验：方程组、消元与四个子空间

这份指南帮助你围绕官方真题进行备考复习，梳理重点概念与典型题型。它不包含逐题答案，而是引导你关注核心思路，让你在考场上能独立建模、计算与判断。

覆盖范围：方程组几何、消元、矩阵运算与逆、LU 分解、转置/置换、向量空间、零空间、四个基本子空间前置讲义：第 1–12 课建议用时：100 分钟

考试定位

Exam 1 考察课程前半段的"语言基础"：你能否把一个线性方程组同时看成行的交点与列的线性组合？能否用消元判断解的存在与唯一性？能否从矩阵的秩读出四个子空间的维数？官方样卷见 exams/exam1.pdf，建议先独立计时做一遍，再对照本指南查漏补缺。

核心主题

1. 行图像与列图像

方程组 \(A\xvec = \bvec\) 有两种几何看法：行图像（row picture，每个方程是一张超平面，解是交点）与列图像（column picture，把 \(A\) 拆成列向量 \(\avec_1, \dots, \avec_n\)，问 \(\bvec\) 能否写成这些列的线性组合）。考试常要求你从一种看法切换到另一种，例如"无解"在行图像中意味着超平面不相交，在列图像中意味着 \(\bvec\) 不在列空间里。

核心洞察：列图像是这门课的主线——四个子空间、最小二乘、特征向量都建立在列图像上。遇到任何方程组，先问自己：列向量张成了哪些方向？\(\bvec\) 是否落在其中？

2. 消元、主元与秩

高斯消元（Gaussian elimination）把 \(A\) 变成上三角 \(U\)（或行最简 \(R\)）。主元的个数就是矩阵的秩 \(r\)。消元不改变行空间，但会改变列空间——这一点常被忽略。

从 \(U\) 或 \(R\) 你能直接读出：

  • 自由变量个数 = \(n - r\)
  • 零空间维数 = \(n - r\)（秩-零化度定理）
  • 解的存在性：若 \(\bvec\) 在消元后出现 \(0 = \text{非零}\)，则无解

常见错误：把 \(U\) 的主元列当作列空间的基。实际上主元列在原矩阵 \(A\) 中的对应列才是列空间的基，而 \(R\) 的非零行才是行空间的基。

3. 矩阵运算与可逆条件

矩阵乘法按列理解：\(A\) 乘以 \(\xvec\) 是列的线性组合；\(A\) 乘以另一矩阵 \(B\) 是对 \(B\) 的每一列做同样的组合。逆矩阵 \(A^{-1}\) 存在当且仅当以下任一条件成立（它们全部等价）：

  • \(A\) 满秩（\(r = m = n\)）
  • \(A\xvec = \zerovec\) 只有零解
  • \(\det(A) \neq 0\)
  • \(A\) 的行最简形是单位矩阵 \(I\)

考试常让你用这些等价条件做快速判断，而不是真的去求逆。

4. LU 分解与置换

当消元不需要换行时，\(A = LU\)：\(L\) 是单位下三角（记录消元系数），\(U\) 是上三角。需要换行时写成 \(PA = LU\)。每次分解的复杂度是 \(O(n^3)\)，但分解一次后可以反复求解不同 \(\bvec\) 的方程组，每次只需 \(O(n^2)\) 的回代。

5. 向量空间与四个基本子空间

这是 Exam 1 最抽象也最关键的部分。对 \(m \times n\) 矩阵 \(A\)（秩 \(r\)）：

子空间所在空间维数如何求基
列空间 \(C(A)\)\(\mathbb{R}^m\)\(r\)\(A\) 的主元列
零空间 \(N(A)\)\(\mathbb{R}^n\)\(n-r\)特解（令自由变量轮流为 1）
行空间 \(C(A^T)\)\(\mathbb{R}^n\)\(r\)\(R\) 的非零行
左零空间 \(N(A^T)\)\(\mathbb{R}^m\)\(m-r\)\(E\) 的最后 \(m-r\) 行（\(EA=R\)）

行空间与零空间在 \(\mathbb{R}^n\) 中互为正交补；列空间与左零空间在 \(\mathbb{R}^m\) 中互为正交补。

6. 解的结构

非齐次方程组 \(A\xvec = \bvec\) 的通解是一个特解加上零空间的任意向量：\(\xvec = \xvec_p + \xvec_n\)。考试常要求你先找特解（自由变量全取 0），再写出零空间的基，最后组合成通解。

典型题型思路导引

题型 A：秩与解的情况判断

给定含参数的矩阵，问参数取何值时方程组有唯一解、无穷解或无解。思路：做消元到 \(U\)，看主元何时为零；再检查 \(\bvec\) 是否与零行相容。

题型 B：求四个子空间的基

先消元到 \(R\)，识别主元列与自由变量。列空间取原矩阵主元列，行空间取 \(R\) 非零行，零空间对每个自由变量求特解，左零空间看消元矩阵 \(E\)。

题型 C：LU 分解

记录每一步消元的乘子，填入 \(L\) 的对应位置。注意：如果某步主元为 0 且无法通过下方行非零来换行，则分解不存在（需要引入置换）。

题型 D：向量空间判定

判断某集合是否为子空间：验证零向量在内、加法封闭、数乘封闭。考试常给一个"看起来像子空间"的集合让你举反例。

时间分配提醒：Exam 1 题量通常不小，先通卷浏览，把"读概念"的题快速拿下，再集中时间在消元与子空间计算上。

备考要点

两种图像随时切换

每个方程组都同时拥有行图像与列图像。练习时，拿一道题分别用两种方式解释"有解 / 无解 / 唯一解"，直到切换成为本能。

秩是信息密度最高的数字

一旦确定 \(r\)，四个子空间的维数、解的结构、可逆性全部确定。消元的目的就是求 \(r\)。

基要来自正确的矩阵

列空间看原矩阵 \(A\) 的主元列，行空间看 \(R\) 的非零行，零空间看特解，左零空间看 \(E\)。不要张冠李戴。

用等价条件做快速判断

"\(A\) 可逆"与"\(R = I\)"、"\(r = n\)"、"\(\det \neq 0\)"、"零空间平凡"等价。考试时选最方便的那条。

题目 1 前向消元与完整解 行最简形 · 消元矩阵 · 完整解 · 特解与零空间
官方题面翻译可离线作答

前向消元法将 \(Ax=b\) 化为行最简形 \(Rx=d\)。已知完整解为 \(x = [4,0,0]^T + c_1 \cdot [2,1,0]^T + c_2 \cdot [5,0,1]^T\)。

  1. (a) (14分) 求 3×3 行最简形矩阵 \(R\) 和向量 \(d\)
  2. (b) (10分) 若消元过程为：从第2行减去3倍第1行，再从第3行减去5倍第1行，求连接 \(R,d\) 与原始 \(A,b\) 的矩阵，并用它求 \(A\) 和 \(b\)

公式与已知条件

  • 特解：\(x_p = [4,0,0]^T\)；零空间基：\(s_1=[2,1,0]^T\)，\(s_2=[5,0,1]^T\)
  • 消元步骤：\(E_{21}(3)\) 从第2行减 3×第1行；\(E_{31}(5)\) 从第3行减 5×第1行
解题入口

从完整解的结构读取特解与零空间基，由此确定 \(R\) 的首行与 \(d\)。

完成后检查

  • \(R\) 必须是行最简形：主元为1，底部两行全零

题目 2 矩阵A的零空间与列空间 零空间 · 特解 · 列空间 · 行最简形 · 分块矩阵
官方题面翻译可离线作答

设 \(A = [0\ 1\ 2\ 2;\ 0\ 3\ 8\ 7;\ 0\ 0\ 4\ 2]\)。

  1. (a) (16分) 求 \(Ax=0\) 的所有特解，并描述 \(A\) 的整个零空间
  2. (b) (10分) 描述该矩阵 \(A\) 的列空间（不能仅回答'四个列的所有组合'）
  3. (c) (10分) 当 \(B\) 为 6×8 分块矩阵 \([A\ A;\ A\ A]\) 时，求 \(R^*=\mathrm{rref}(B)\)

公式与已知条件

  • \(A = [0\ 1\ 2\ 2;\ 0\ 3\ 8\ 7;\ 0\ 0\ 4\ 2]\)
  • \(B = [A\ A;\ A\ A]\) 为 6×8 矩阵
解题入口

对 \(A\) 行化简确定主元列与自由变量，通过回代求零空间特解。

完成后检查

  • \(A\) 的秩为2，零空间维数为2，列空间为 \(\mathbb{R}^3\) 中过原点的平面

题目 4 列空间判定 列空间 · 线性方程组求解
官方题面翻译可离线作答

设 \(A = [2\ 1;\ 6\ 5;\ 2\ 4]\)。

  1. (a) (10分) 解释：如何利用 \(Ax=b\) 的所有解来判断向量 \(b\) 是否在 \(A\) 的列空间中
  2. (b) (14分) 向量 \(b=[8,28,14]^T\) 是否在 \(A\) 的列空间中？

公式与已知条件

  • \(A = [2\ 1;\ 6\ 5;\ 2\ 4]\)
  • \(b = [8,28,14]^T\)
解题入口

\(Ax=b\) 有解当且仅当 \(b\) 在列空间中，对增广矩阵 \([A|b]\) 行化简判断一致性。

完成后检查

  • 增广矩阵行化简后应无矛盾行
