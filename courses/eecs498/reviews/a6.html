阶段 01

VAE 的目标函数

拆开 reconstruction 与 KL，并说清每一项约束谁。

为什么需要它

两项失衡会导致只重建或只贴近 prior。

讲义 14 · 生成建模 →

开始前应该已经会回答

  • 能解释 approximate posterior
  • 会手算 μ=0,logvar=0 的 KL

输入、输出与契约

输入
x, μ, logvar, reconstruction
输出
scalar ELBO loss
不变量
  • reconstruction 与 KL 分项记录
  • batch/reduction convention 一致
不成立的假设
  • 只报告 total loss
  • 把 KL 符号写反

用最小例子检查

单维 μ=0,logvar=0 时手算 KL；再令 μ=1 比较。

如果你看到……

KL 为负

优先检查：公式符号/reduction

KL 很快接近 0 且 decoder 忽略 z

优先检查：posterior collapse

预测 → 实验 → 证据

先预测
增大 KL 权重会更强约束 latent，但可能牺牲 reconstruction。
做实验
固定模型与 batch，比较两个 KL weight 的分项轨迹。
留证据
  • recon
  • KL
  • latent statistics

阶段 02

重参数化

让随机采样保留从 loss 到 μ/logvar 的可微路径。

为什么需要它

直接从参数化分布采样会让普通反向传播无法穿过随机节点。

讲义 14 · 生成建模 →讲义 2 · 反向传播 →

开始前应该已经会回答

  • 能画随机节点计算图
  • 知道 exp(0.5 logvar) 的来源

输入、输出与契约

输入
μ, logvar, ε~N(0,I)
输出
z=μ+σ⊙ε
不变量
  • ε 不需 gradient
  • σ 由 logvar 正确转换
不成立的假设
  • 把 logvar 直接当 σ
  • 在 z 上 detach

用最小例子检查

μ=2,logvar=0,ε=-1 时手算 z，并预测 dz/dμ。

如果你看到……

μ/logvar grad 为 None

优先检查：detach/no_grad

variance 爆炸

优先检查：logvar→std 转换

预测 → 实验 → 证据

先预测
固定 ε 时 z 对 μ 的局部导数为 1；随机性来自多次 ε。
做实验
固定 seed 做 gradient check，再换 seed 看样本变化。
留证据
  • ε
  • z
  • μ/logvar grad

阶段 03

对抗博弈

分开 discriminator 与 generator 的目标、参数和 update。

为什么需要它

GAN 是动态博弈；一个网络的改进会改变另一个网络看到的 objective。

讲义 14 · 生成建模 →

开始前应该已经会回答

  • 能解释 non-saturating G loss
  • 会区分 detach 的位置

输入、输出与契约

输入
real x, noise z
输出
D/G losses + samples
不变量
  • 每步只更新目标网络参数
  • fake 在 D/G step 的 gradient 边界正确
不成立的假设
  • 两个 optimizer 同时更新全部参数
  • 只看一方 loss 判断成功

用最小例子检查

一维参数分别属于 G/D，逐步写出 D step 与 G step 哪个 gradient 应存在。

如果你看到……

G 从不变化

优先检查：fake 是否在 G step 也 detach

D/G 参数同时变化

优先检查：optimizer param list/zero_grad

预测 → 实验 → 证据

先预测
D 太强可能让 G 梯度差；loss 平衡不保证样本多样。
做实验
记录两方 loss、gradient norm 与固定 noise samples。
留证据
  • D/G loss
  • D/G grad norm
  • fixed-noise grid

阶段 04

生成模型的证据

用重建、采样、多样性与失败模式比较 VAE/GAN。

为什么需要它

不同目标没有一个共享的“训练 loss 越低越好”标尺。

讲义 14 · 生成建模 →

开始前应该已经会回答

  • 能解释 blurry reconstruction 与 mode collapse
  • 知道 qualitative evidence 需要固定 protocol

输入、输出与契约

输入
trained models + fixed eval protocol
输出
mechanism-aware comparison
不变量
  • 固定输入/噪声便于纵向比较
  • 同时检查质量与覆盖
不成立的假设
  • 用 VAE loss 与 GAN loss 数值直接比较
  • 只挑最好样本

用最小例子检查

为 VAE 固定输入重建，为 GAN 固定 noise，写出各自最可能暴露的失败。

如果你看到……

样本漂亮但高度重复

优先检查：mode collapse/coverage

重建模糊但 latent 平滑

优先检查：像素 likelihood 与目标取舍

预测 → 实验 → 证据

先预测
VAE 通常有可解释 objective 与覆盖倾向；GAN 可能更锐利但训练/覆盖更难。
做实验
用固定网格、latent interpolation 与最近邻检查建立证据包。
留证据
  • 固定协议
  • 失败样本而非只放最好
  • 目标边界解释
