Why Did We Need This?

同一个正确 gradient，步子太小会停滞，太大会越过谷底；层数增加后，activation/gradient 尺度还可能逐层放大或衰减。训练失败常不是“模型不会”，而是优化路径失去可用信号。

优化器决定如何在 loss landscape 上走；初始化与 normalization 决定这张地形和梯度信号是否处在能走的尺度。

Mechanism · 从 SGD 到 Adam

SGD:       θ ← θ − ηg
Momentum:  v ← μv − ηg; θ ← θ + v
Adam:      m ← β₁m+(1−β₁)g
           v ← β₂v+(1−β₂)g²
           θ ← θ − η m̂/(√v̂+ε)

m 平滑方向，v 估计每个坐标近期的平方尺度；bias correction 处理训练初期两个状态从零开始的偏差。

Normalization is about coordinates

BatchNorm 用 batch statistics 校准 channel；后来的 Transformer 更常用 LayerNorm，在每个 token 的 feature 维内校准。二者不是可互换 API：它们选择了不同的归一化轴，也就选择了哪些样本/位置互相影响。

Why This Design?

  • 没有合适 initialization：深层 ReLU 的 variance 会漂移。
  • 没有 regularization：训练 accuracy 可继续升，验证集却可能停滞。
  • 没有 optimizer state：狭长谷底中 SGD 容易来回震荡。

Common misconception：Adam 不是“永远更好的 SGD”，BatchNorm 也不只是让数字落进固定范围。它们改变训练动力学与隐式偏好，仍需和 learning rate、batch、architecture 一起看。

Then vs Now

现代 LLM 常见 AdamW、warmup、cosine decay、gradient clipping 与 LayerNorm/RMSNorm；但账本仍是：gradient → optimizer state → parameter update。你当年写的 Adam 状态就是今天大模型训练中昂贵 optimizer memory 的来源。

Concept Checks

参数 θ=[128,64]，Adam 的 m 与 v 是什么 shape？

都为 [128,64]。它们为每个参数坐标保存一阶、二阶历史，因此 optimizer state 通常是参数量的倍数。

若把 learning rate 放大 1000 倍，gradient 方向仍正确，为什么训练仍会坏？

一阶局部近似只在小邻域可信；大步会跨过低 loss 区域并让 activation/gradient 爆炸。

BatchNorm 与 LayerNorm 最关键的 shape 区别是什么？

BatchNorm 对同一 channel 汇总 batch/空间样本；LayerNorm 对单个样本或 token 的 feature 维汇总，不依赖其他 batch item。
