Encoder, Decoder, and Cross Attention

Self-attention 让一组 representations 内部交流；cross-attention 让 decoder 带着“我现在需要什么”的 query，去 encoder 的整组输出里检索。

Why Did We Need This?

问题与答案是两组不同角色的 sequence。Encoder 可以双向理解完整 expression；decoder 的每一步既要读已生成的 answer prefix，又要查询 expression 中与当前输出相关的位置。

One View, Two Sources

Self-attention · 我内部交流

Q = same sequence
K = same sequence
V = same sequence

expression 内各 token 互相 contextualize；或 answer prefix 内部交流。

Cross-attention · 我向另一组查询

Q = decoder states
K = encoder states
V = encoder states

answer position 根据当前需求读取问题 representations。

Mental model

Encoder 把输入改写成可被检索的 contextual memory；decoder 一边维护答案上下文，一边用 cross-attention 动态查询这份 memory。

Block Data Flow

Encoder block
x [N,Kq,M] → self-attention → residual+norm → MLP → residual+norm → [N,Kq,M]

Decoder block
answer [N,Ka,M] → masked self-attention
                    ↓
encoder [N,Kq,M] → cross-attention(Q=answer, K/V=encoder)
                    ↓
                  MLP → [N,Ka,M]

MLP 对每个位置独立地改写 feature channels；attention 在位置之间搬运信息。两者分别负责 token mixing 与 channel mixing。

Causal Mask · 为什么不能看未来

decoder input prefix     prediction target
BOS                      POSITIVE
BOS POSITIVE             0
BOS POSITIVE 0           4
BOS POSITIVE 0 4         EOS

训练时整条 target 已在 tensor 中；若位置 i 能 attention 到 i 之后的 token，就直接看到了答案，产生 label leakage。你的 get_subsequent_mask 构造上三角 True，在 softmax 前把未来 scores 设为极小值。

Why Residual + Norm?

Attention/MLP 学的是对当前 representation 的更新，residual 保留原表示并提供直接 gradient path；normalization 控制每个 token 的 feature scale。没有 residual，深层 block 必须每次完整重建表示。

Historical implementation note：Notebook 的 DecoderBlock saved checks 为 0.5016 / 0.4971，并留下 “I think the bug is with the skeleton”。本课基于源码解释实际 data flow，不把该 check 写成通过，也不替历史仓库静默修复。

Common misconceptions：Cross-attention 不是 encoder/decoder concat；encoder output 也不是一个单一向量。K/V 保留 Kq 个位置，decoder 的每个 query row 都可采用不同读取分布。

Concept Checks

decoder length Ka=4，encoder length Kq=9，cross-attention matrix shape？

每个 batch/head 为 [4,9]：4 个 decoder queries，各对 9 个 encoder keys 分配读取权重。

Self-attention 中第 3 个 answer token 能看到第 5 个吗？encoder 中呢？

decoder causal self-attention 不能；encoder self-attention 通常可以双向看完整输入。

Cross-attention 中为什么 K=V=encoder，却仍要两份 projection？

来源 tensor 相同，但 K projection 产出可匹配地址特征，V projection 产出被读取的内容特征。

如果 causal mask 在 softmax 后才乘 0，会有什么问题？

剩余权重行不再归一化；更重要的是未来位置先参与了 softmax denominator。标准做法在 softmax 前屏蔽 score。
