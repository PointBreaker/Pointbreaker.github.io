Problem · 一组 representations 不够

题目和答案扮演不同角色。题目是完整可见的 source；答案是在生成中的 target。若把它们无条件拼成一组双向 self-attention，答案位置可能直接读取未来 label。若完全隔开，decoder 又无法根据题目作答。需要一条有方向的桥。

Encoder memory每个 question position 的 contextual representation
Decoder state每个 answer position 对 prefix 的理解
Cross-attentiondecoder state 作为 Q，encoder memory 作为 K/V

Stage 1 · Encoder self-attention

question tokens shape [N,Kq] 经 embedding+position 变成 [N,Kq,M]。encoder self-attention 的 Q/K/V 都来自这组 states，所有 question positions 可互相读取。

Conceptual walkthrough（不是对 checkpoint attention pattern 的事实声明）：

position: subtract
query:    当前 operator 需要理解哪些 operands/signs？
keys:     所有 question positions 提供可匹配特征
values:   NEGATIVE, 3, 0, NEGATIVE, 3, 4 ... 的可传递内容

new subtract state may combine:
operator identity + sign 1 + operand 1 + sign 2 + operand 2

encoder output 不是一个 answer，也不是一条压缩成单 vector 的 summary。它仍是 Kq 个 contextual states：[N,Kq,M]，可供 decoder 按需读取。

Mental model · Encoder

把 source sequence 变成一排“已经相互沟通过、仍保留位置”的 memory slots。

Stage 2 · Decoder masked self-attention

假设当前训练/生成前缀是 BOS POSITIVE 0。decoder 首先要回答“我已经输出了什么？”因此 Q/K/V 都来自 answer prefix，但位置 i 不能读取 i 之后的答案。

reader \ source   BOS   POSITIVE   0   4   EOS
BOS               ✓       ✕       ✕   ✕    ✕
POSITIVE          ✓       ✓       ✕   ✕    ✕
0                 ✓       ✓       ✓   ✕    ✕
4                 ✓       ✓       ✓   ✓    ✕
EOS               ✓       ✓       ✓   ✓    ✓

mask 把非法 score 设为近似 -∞，再做 softmax。于是未来位置得到 0 probability，剩余合法位置重新归一化。

为什么不能 softmax 后再把未来 weights 清零？

未来 scores 已参与 denominator，合法位置的 weights 被压低；清零后 row sum 也不再是 1。mask 必须改变 normalization 的候选集合。

Stage 3 · Cross-attention

masked self-attention 之后，decoder state 已表示 answer-so-far。接着它问：“基于我已经生成的内容，现在该从题目哪里取信息？”

Q = decoder states             [N,Ka,M]
K = encoder contextual states [N,Kq,M]
V = encoder contextual states [N,Kq,M]

scores / A                    [N,Ka,Kq]
cross-attention output        [N,Ka,M]

row i    = answer/query position i
column j = question/memory position j

对于 answer prefix BOS POSITIVE 0，最后一个 query 可以按当前需要读取题目中的操作符、符号或个位数字。它不必每一步读取同样位置：A 是随 decoder state 和 source 内容动态计算的。

因此 cross-attention 后的 decoder state 同时包含：

answer-so-far information
+
selected question information

反向思想实验 · 如果 Q 来自 encoder 呢？

设 Q=encoder、K,V=decoder。数学上完全可算，matrix shape 变为 [N,Kq,Ka]，语义变成“每个 question position 去查询 answer representations”。但当前生成任务需要更新 decoder states 以预测下一个答案 token；反向连接更新的是 source-side queries，信息流方向不合目标。

为什么还需要 Residual、Norm、MLP？

  1. Attention 在 positions 间搬运 information。
  2. Residual 把原状态与新读取结果相加，保留 identity path。
  3. LayerNorm 稳定每个 token 的 feature scale（历史代码采用相应 block ordering）。
  4. Position-wise MLP 对每个 token 的 features 做 nonlinear transformation。
没有 residual 会怎样？

每层必须完全用当前 attention/MLP 重写状态，缺少直接保留旧 representation 与 gradient 的路径。模型仍可能训练，但深层优化与信息保留更困难。

Misconception diagnosis

“Self-attention 是自己看自己”太模糊。准确说：一组 states 同时提供 Q/K/V，因此每个位置从同一组 positions读取。Cross-attention 则是 query group 与 memory group 不同。

End-of-Lesson Deep Checks

Decoder 的两次 attention 各回答什么问题？

Masked self：我已经生成了什么？Cross：基于当前 answer state，我该从 source memory 读取什么？

为什么 encoder states 同时作为 K 和 V，但仍承担不同角色？

进入 attention head 后分别经过 WK/WV；同一 source activation 被投影为寻址 feature 与 payload feature。

若完全删除 cross-attention，模型还能条件于 question 吗？

按当前架构不能；decoder 只见 answer prefix，问题信息没有计算路径进入 logits。

causal mask 与 padding mask 是否同一目的？

不是。causal mask 阻止未来 label leakage；padding mask 阻止读取非内容 positions。二者都作用于 score，但屏蔽理由不同。
