Attention as Dynamic Information Routing

Attention 的核心不是一条公式，而是一个可计算的问题：当前位置想找什么、其他位置凭什么被找到、找到后实际读回什么。

Concrete Problem First

看一句 The animal slept。处理 slept 时，它需要知道“谁 slept”。RNN 让信息沿相邻 time steps 传过来；attention 允许 slept 直接对所有位置提出查询。

Q · Query

当前 token 想找什么？例如谓词在找可能的主语特征。

K · Key

每个候选 token 可以用什么特征被匹配？

V · Value

如果候选被关注，它实际提供哪份信息？

Weights

当前 query 对所有 keys 的归一化读取比例。

Data / Shape Flow

Q, K, V[N,K,D]
QKᵀ[N,K,K]
softmax weights A[N,K,K]
AV[N,K,D]

第一个 K 轴是谁在读取（query position i）；第二个 K 轴是从谁读取（key/value position j）。因此 A[i,j] 很大表示：新的第 i 个 representation 大量读取第 j 个 value。

Mental model

Attention 是由内容动态决定路由权重的信息读取机制；A 不是旁观的可视化，而是实际参与计算的 token-to-token routing matrix。

Mechanism · 公式终于出现

score(i,j) = q_i · k_j / √D
A_i = softmax(score(i,:))
Y_i = Σ_j A_ij V_j

QKᵀ: matching scores
softmax: reading weights (each query row sums to 1)
×V: information aggregation

Y_i 数学上就是其他位置 values 的加权和。“token 交换信息”不是比喻。

Why Separate Q, K, V?

若匹配特征与被传递内容必须相同，模型受限。独立 projections 允许一个 token 用语法特征被找到，却把语义/数值特征送出去。Q 与 K 决定地址，V 决定 payload。

Multi-head: several routing spaces

你为每个 head 创建独立 SelfAttention，拼接各 head 输出，再投影回 dim_in。每个 head 都能学习不同的 matching subspace；不是把同一 attention matrix 复制多次。

input[N,K,M]
H headsH × [N,K,Dh]
concat[N,K,H·Dh]
project[N,K,M]

Why Scale by √D?

若 q/k 分量方差相近，dot product 的 variance 随 D 增长；不缩放会让 softmax 过早饱和，只有极少数位置拿到权重，gradient 变弱。

Common misconceptions：Attention 不等于单纯 similarity visualization；self-attention 不等于每个 token 广播自己；[K,K] 也不是 feature covariance，而是 query-position × key-position。

Then vs Now

FlashAttention 改变的是精确 attention 的计算与内存调度，不改变 softmax(QKᵀ)V 的结果语义。MQA/GQA 共享部分 K/V 以降低 cache；“query 找地址，value 提供内容”的 mental model 仍成立。

Concept Checks

A[i,j] 很大，究竟是谁从谁读取？

输出位置 i（query i）从输入/value 位置 j 大量读取。读者是行，来源是列。

Q=[32,9,16]，K=[32,9,16]，QKᵀ 与 attention output shape？

scores/weights [32,9,9]；若 V=[32,9,16]，output 是 [32,9,16]。

如果所有 keys 对某个 query 得分完全相同，softmax 后怎样？

该行是均匀的 1/K，输出是所有 values 的平均；没有内容选择性。

为什么 Y_i 不只是“知道 j 很相关”，而是真的含有 j 的信息？

因为计算直接执行 Σ_j A_ij V_j；只要 A_ij 非零，V_j 的分量就在 Y_i 中。
