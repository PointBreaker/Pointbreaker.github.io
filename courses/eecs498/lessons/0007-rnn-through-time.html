Why Did We Need This?

CNN 擅长局部空间结构，但 caption 是有序符号：dog bites man 与 man bites dog token 相同、关系不同。RNN 让第 t 步 representation 显式依赖第 t−1 步。

Mental model

RNN 用固定宽度的 hidden state 作为滚动摘要：每一步把当前输入与过去摘要混合，产生新的过去。

Mechanism · recurrent data flow

a_t = x_t Wₓ + h_{t−1} Wₕ + b     [N,H]
h_t = tanh(a_t)                     [N,H]
scores_t = h_t W_vocab + b_vocab    [N,V]

Wₓ 与 Wₕ 跨所有 time steps 共享，所以模型能处理不同长度 sequence；代价是 h_t 必须等 h_{t−1}。

Backpropagation Through Time

展开 T 步后，这是一个深度为 T、但重复使用同一参数的计算图。Wₕ 的 gradient 是所有 time steps 贡献之和；而早期 signal 必须反复乘局部 Jacobian，导致 vanishing/exploding gradients。

Why This Design?

固定 hidden state 比保留所有过去便宜，天然支持 streaming；但它制造了两种瓶颈：信息必须挤进 H 维，计算必须沿时间串行。Attention 稍后会允许直接读取多个过去位置。

Common misconception：hidden state 不是“上一 token 的 embedding”。它是模型结合截至当前所有已处理信息后得到的 contextual state。

Then vs Now

现代 state-space models 仍保留 recurrence/streaming 的吸引力；Transformer 则选择保存每个 token representation，并用 attention 直接访问，换来更强并行训练与更长的直接依赖路径。

Concept Checks

x=[32,15,128]，hidden size=256，h 的 shape？

[32,15,256]；每个样本、每个时间步都有一个 256 维 contextual hidden state。

为什么训练可对多个 t 同时算 vocabulary loss，但 h 仍须顺序产生？

得到全部 h 后 projection/loss 可批量计算；但 h_t 的值依赖 h_{t−1}，主 recurrence 仍有 sequential dependency。

从 t=50 的 loss 回到 t=1，梯度为何容易消失？

需要穿过约 49 次 recurrent Jacobian；若其有效 singular values 多数小于 1，连乘会指数衰减。
