Why Did We Need This?

Vanilla RNN 每一步都把旧状态整体通过 tanh 重写；长期 signal 必须反复穿过同一种非线性。LSTM 让 cell state 可以通过近似加法路径保留，并用 gates 控制更新。

xₜ[N,D]
four gates[N,4H] → 4×[N,H]
cell cₜ[N,H]
hidden hₜ[N,H]

Mental model

Cell state 是可选择保留的长期通道；gates 是由当前输入和旧 hidden state 动态算出的写入、遗忘与读出开关。

Mechanism · 不背 gate equation，读 data flow

[i,f,o,g] ← split(xₜWₓ + hₜ₋₁Wₕ + b)
cₜ = sigmoid(f) ⊙ cₜ₋₁ + sigmoid(i) ⊙ tanh(g)
hₜ = sigmoid(o) ⊙ tanh(cₜ)

关键是 cₜ 的加法：旧 memory 与新 candidate 分开加权，而不是全部塞回一次 tanh。

What LSTM Did Not Solve

  • Sequential compute：cₜ/hₜ 仍等上一步。
  • Fixed recurrent path：远处信息仍沿所有中间 steps 传递。
  • Compression：hidden/cell 仍是固定宽度摘要。

Common misconception：LSTM “有 memory”不代表它能无损保存任意长历史；gates 是软数值决策，容量与训练信号仍有限。

Concept Checks

hidden size=256，合并 activation a 的最后一维多大？

4H=1024，随后切成四个 [N,256] gate/candidate blocks。

若 forget gate≈1 且 input gate≈0，cell state 怎么变？

c_t≈c_{t−1}，旧 memory 沿加法通道保留；这也是长期 gradient 更容易通过的情形。

LSTM 已改善长期记忆，为什么还会走向 attention-first 模型？

它没消除串行 dependency，也没让当前位置一步直达任意历史位置；attention 提供动态 direct access。
