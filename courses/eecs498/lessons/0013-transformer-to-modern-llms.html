现代 LLM 不是把 Transformer 原理换掉，而是把 decoder-style next-token prediction 扩展到更大的 vocabulary、context、data、parameters 与 distributed systems。

How Decoder-only Re-expresses the Task

EECS498 encoder-decoder:
encode(expression) → cross-attend while generating answer

Decoder-only:
[BOS expression SEP answer-prefix]
  causal self-attention over everything to the left
  → predict next answer token

Prompt tokens 充当条件，answer tokens 只读左侧。没有显式 cross-attention，但 answer query 仍可通过 causal self-attention 读取 earlier prompt representations。

What Scale Changed

  • Tokenizer engineering：coverage、compression、multilingual behavior 直接改变有效 context 与 compute。
  • Attention systems：K² score matrix 推动 FlashAttention、KV cache、GQA、long-context methods。
  • Training memory：parameters、gradients、Adam states 与 activations 需要 mixed precision、sharding、parallelism。
  • Data/objective：从 supervised pairs 扩展到 pretraining、instruction tuning 与 preference/RL objectives。

A Bridge to CS336, Not a Duplicate

EECS498 负责恢复机制脉络：为什么有 Q/K/V、mask 与 representation flow。CS336 继续追问这些组件怎样被高效实现、训练和扩展。复习时可用下面映射：

Common misconception：“Decoder-only”不表示模型没有内部 encoder-like representation building。它表示拓扑没有独立 encoder/cross-attention；每层 causal block 仍持续把 prompt 与 prefix 改写成 contextual representations。

Concept Checks

为什么 GPT 不需要 cross-attention 也能根据 prompt 回答？

Prompt 位于同一 causal sequence 的左侧；answer positions 用 self-attention 直接读取 prompt tokens。

把 vocab 从 16 扩到 100k，最直接变大的两个参数块？

Input embedding table [V,M] 与 output vocabulary projection [M,V]（若 weight tying，可共享权重但 logits 计算仍依赖 V）。

KV cache 缓存什么，为什么不缓存 Q？

缓存过去 tokens 各层的 K/V，未来 query 会重复读取它们；当前 step 的 Q 只用来发起本次读取，不被未来作为历史地址/内容。

FlashAttention 是否改变 A[i,j] 的语义？

不改变精确算法的结果语义；它通过分块与在线 softmax 避免把完整 A 写回慢速显存。
