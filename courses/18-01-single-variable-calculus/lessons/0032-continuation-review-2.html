积分技术决策树

拿到一道积分题，按以下顺序判断：

  1. 根号下是二次式？→ 三角反代换或配方（第 27 课）。
  2. 有理函数 P/Q？→ 先长除，再部分分式（第 28 课）。
  3. 两类函数乘积？（xⁿ 乘 eˣ/ln/sin/反三角）→ 分部积分（第 29 课）。
  4. 三角函数的乘方？→ 半角公式或递推（第 25 课）。
  5. 根号下是完全平方？→ 可能配方后直接看出（第 27 课例 5）。

例 1：识别技术

∫ x·eˣ dx → 分部积分（代数 × 指数）。

∫ 1/(x²+4x+13) dx → 配方 → 反正切。

∫ √(x²+1) dx → 三角反代换 x = tan u。

∫ x²/(x²−1) dx → 长除 → 1 + 1/(x²−1) → 部分分式。

∫ eˣ sin x dx → 分部积分（循环型）。

例 2：部分分式 + 配方 + 三角代换

∫ 1/((x²+1)(x−1)) dx。分母已是一次 × 不可约二次，设：

\[\frac{1}{(x^2+1)(x-1)} = \frac{A}{x-1} + \frac{Bx+C}{x^2+1}.\]

覆盖法求 A：乘 \(x-1\)，令 \(x=1\)：\(A = 1/2\)。

令 x=0：\(1/(-1) = A/(-1) + C/1\) → \(−1 = −A + C\) → \(C = A − 1 = −1/2\)。

比较 x² 系数：0 = A + B → B = −A = −1/2。

积分：

\[\int\!\left(\frac{1/2}{x-1} + \frac{-x/2-1/2}{x^2+1}\right)dx = \frac12\ln|x-1| - \frac14\ln(x^2+1) - \frac12\tan^{-1}x + c.\]

例 3：分部积分 + 代换

∫ x³ e^{x²} dx。先用代换 \(w=x²\)，\(dw=2x dx\)：

\[\int x^3 e^{x^2}\,dx = \frac12\int w e^w\,dw.\]

再分部积分：\(u=w\)，\(dv=e^w dw\) → \(\frac12(w e^w - e^w)+c\)。回代 w=x²：

\[\frac12 e^{x^2}(x^2-1) + c.\]

例 4：弧长综合

求摆线一拱（x = a(t−sin t), y = a(1−cos t), t∈[0,2π]）的弧长。

dx/dt = a(1−cos t)，dy/dt = a sin t。利用 \(1-\cos t = 2\sin^2(t/2)\)，\(\sin t = 2\sin(t/2)\cos(t/2)\)：

\[ds = \sqrt{a^2(1-\cos t)^2 + a^2\sin^2 t}\,dt = a\sqrt{2-2\cos t}\,dt = 2a|\sin(t/2)|\,dt.\]

t∈[0,2π] 时 sin(t/2) ≥ 0：

\[L = \int_0^{2\pi} 2a\sin(t/2)\,dt = 2a\!\left[-2\cos(t/2)\right]_0^{2\pi} = 2a(2+2) = 8a.\]

常见误区与边界情况

1. 该长除没长除。假分式直接拆部分分式是期中 4 最常扣分的错误。看到 deg(P) ≥ deg(Q) 立刻长除。

2. 部分分式漏项。重因式 \((x-a)^m\) 要写 m 项，不可约二次的分子必须是一次式。

3. 分部积分选错 u/dv。用 LIATE 快速判断；如果一次分部后更复杂，多半选反了。

4. 组合题分步拿分。期中 4 的综合题按步骤给分：即使最后答案错，部分分式拆对、代换写对、上下限代对都能拿分。不要跳步。

本课要点

决策顺序

根号 → 三角代换/配方；有理式 → 部分分式；乘积 → 分部积分

长除优先

假分式必须先长除再拆部分分式

组合拳

一道题可能需要多种技术依次使用

公式表范围

三角公式印发，其余公式（递推、极坐标面积等）需熟记

分步拿分

综合题按步骤给分，不要跳步
