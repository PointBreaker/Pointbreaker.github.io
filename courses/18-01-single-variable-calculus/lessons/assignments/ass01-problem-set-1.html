从偶函数/奇函数的分解出发，经过测量灵敏度、相关变化率、抛物面镜，到平均与瞬时变化率、三角极限与乘积法则的归纳证明——这份作业把第 1–4 课的定义、法则和第一次真实应用串成一条线。

学习目标

  • 能把函数分解成一个偶函数与一个奇函数之和，并据此分析图像对称性。
  • 用差商 \(\Delta f/\Delta x\) 与线性近似 \(|\Delta L|\le C|\Delta h|\) 量化「测量灵敏度」。

Part II 主题梳理与示例

1. 偶函数与奇函数的分解

要把 \(\displaystyle f(x)=\frac{x-1}{x+1}\) 写成一个偶函数与一个奇函数之和。标准做法是利用恒等式：

\[f(x)=\frac{f(x)+f(-x)}{2}+\frac{f(x)-f(-x)}{2}\]

第一项是偶函数，第二项是奇函数。代入并通分化简即可。这类分解是后续讨论函数对称性与导数奇偶性的基础（可导偶函数的导数是奇函数，反之亦然）。

2. 测量灵敏度（GPS 距离）

卫星距地面高度 \(20000\) km，斜距为 \(h\)，地面距离为 \(L\)。几何关系：

\[L^2+20000^2=h^2\quad\Longrightarrow\quad L=\sqrt{h^2-20000^2}\]

问题要求你在 \(h_0=25000\) 与 \(h_0=20001\) 两点，用差商 \(\Delta L/\Delta h\) 估算 \(|\Delta L|\le C|\Delta h|\)，取对所有 \(\Delta h\in\{1,10^{-1},10^{-2}\}\) 都成立的最简常数 \(C\)。

核心思想：当 \(h_0\) 远大于高度（\(25000\)）时，同样的 \(|\Delta h|\) 对 \(L\) 影响较小；当 \(h_0\) 接近最低点（\(20001\)）时，灵敏度急剧放大——这是「除以接近零的数」在几何中的体现。

后续 Problem Set 3 会用隐式微分重访此题，给出精确的 \(dL/dh\)。

3. 抛物面镜与切线（几何应用）

第 3 题（视线与塔）和第 4 题（抛物面镜）都依赖「切线的几何意义」。抛物面镜问题（Simmons 3.1/21）的关键事实：从焦点发出的光线经抛物面反射后平行于轴射出，反过来也成立。解题时通常设曲线为 \(y=x^2/(4f)\)，用隐式或显式求导得到切线斜率，再利用入射角等于反射角。

5. 平均变化率 vs. 瞬时变化率

水箱在 \(t\) 分钟时的体积 \(V(t)=(10-t)^2/5\) 升。

  • 平均（前 5 分钟）：\(\displaystyle \frac{V(5)-V(0)}{5-0}\)。
  • 瞬时（\(t=5\)）：\(V'(5)\)，其中 \(V'(t)=2(10-t)(-1)/5=-2(10-t)/5\)。

注意区分这两个概念：平均变化率是差商，瞬时变化率是差商的极限。

6. 三角极限综合

这一组（Simmons 2.5/19d,f,g; 20c,g; 22a,b）反复使用两个标准极限：

\[\lim_{h\to 0}\frac{\sin h}{h}=1,\qquad \lim_{h\to 0}\frac{\cos h-1}{h}=0\]

19d 提示「令 \(u=1/x\)」，把 \(x\to\infty\) 的极限转化为 \(u\to 0\)，是处理无穷远处极限的常用技巧。

7. 乘积法则的归纳证明

先对三个函数验证：

\[D(uvw)=u'vw+uv'w+uvw'\]

再猜测 \(n\) 个函数的情形：

\[D(u_1u_2\cdots u_n)=\sum_{i=1}^n u_1\cdots u_i'\cdots u_n\]

用数学归纳法证明：假设对 \(n\) 成立，把 \(u_1\cdots u_{n+1}\) 看成 \((u_1\cdots u_n)\cdot u_{n+1}\)，用两点乘积法则拆开，再代入归纳假设即可。这是训练「从特例到一般、再到严格证明」的经典练习。

题目 1 偶函数与奇函数的分解 偶函数与奇函数 · 函数分解
官方题面翻译可离线作答

将 \(\frac{x-1}{x+1}\) 表示为一个偶函数与一个奇函数之和。尽可能化简。（周三，3 分）

公式与已知条件

  • 给定函数：\(f(x) = \frac{x-1}{x+1}\)
  • 偶部公式：\(f_e(x) = \frac{f(x) + f(-x)}{2}\)
  • 奇部公式：\(f_o(x) = \frac{f(x) - f(-x)}{2}\)
解题入口

分别计算 \(f(-x)\) 并代入偶部与奇部公式，再化简。

完成后检查

  • 验证 \(f_e\) 为偶函数：\(f_e(-x) = f_e(x)\)
  • 验证 \(f_o\) 为奇函数：\(f_o(-x) = -f_o(x)\)
  • 验证 \(f_e(x) + f_o(x) = \frac{x-1}{x+1}\)

题目 2 测量的灵敏度 灵敏度 · 变化率 · 数值近似
官方题面翻译可离线作答

设 \(f\) 是 \(x\) 的函数。若 \(x = x_0 + \Delta x\)，则 \(\Delta f = f(x) - f(x_0)\)，比值 \(\Delta f/\Delta x\) 衡量 \(x\) 的变化对 \(f\) 的影响。Quirk 星球是平的。GPS 卫星悬停在 \(20\,000\ \text{km}\) 的高空。已知卫星到地表某点的距离 \(h\)（\(h\) 为斜边），估算卫星正下方地面点与该点之间的距离 \(L\)。（周四，6 分）

  1. a) 用计算器计算 \(h = h_0 \pm \Delta h = 25\,000 \pm \Delta h\)（其中 \(\Delta h = 1,\,10^{-1},\,10^{-2}\)）时的 \(\Delta L/\Delta h\)。写出一个估计式 \(|L - L_0| = |\Delta L| \le C|\Delta h|\)，选取对所有三种情况都成立的最简单整数 \(C\)。
  2. b) 对 \(h = 20\,001 \pm \Delta h\)（\(\Delta h = 1,\,10^{-1},\,10^{-2}\)）重复上述计算。与 (a) 相比，\(L\) 的估计是更精确还是更不精确？

公式与已知条件

  • 卫星高度：\(20\,000\ \text{km}\)
  • 勾股关系：\(h^2 = L^2 + 20\,000^2\)，即 \(L = \sqrt{h^2 - 20\,000^2}\)
  • (a) 中心值：\(h_0 = 25\,000\)
  • (b) 中心值：\(h_0 = 20\,001\)
  • 扰动取值：\(\Delta h = 1,\,10^{-1},\,10^{-2}\)
解题入口

由 \(L = \sqrt{h^2 - 20\,000^2}\) 对每个 \(\Delta h\) 数值计算 \(\Delta L/\Delta h\)，再找出对所有情况都适用的统一常数 \(C\)。

完成后检查

  • (a) 中的 \(C\) 对三种 \(\Delta h\) 均成立
  • (a) 与 (b) 的精度比较给出了合理解释

题目 4 抛物面镜 抛物面镜 · 反射 · 导数应用
站内等价练习可离线作答

（站内等价练习）抛物面镜的重要光学性质是：从焦点发出的光线经镜面反射后平行于对称轴射出，该性质被用于卫星天线与聚光器。考虑抛物线 \(y = x^2/4\)，其焦点为 \(F(0,\,1)\)。 a) 证明：从焦点 \(F\) 发出的任意光线经抛物线上任一点 \(P(x,\,x^2/4)\) 反射后，反射光线平行于 \(y\) 轴（即平行于抛物线的对称轴）。 b) 利用 (a) 的结论，解释为何卫星天线要把接收器放在焦点位置。

公式与已知条件

  2. b) 求排水开始 5 分钟后水的排出速率。

  • (b) 使用了 \(t = 5\) 处的导数

题目 6 极限计算 极限 · 连续性 · 极限计算技巧
站内等价练习可离线作答

（站内等价练习）计算下列极限，需要写出过程的题目请写出完整推导。这些题目训练极限计算技巧，包括重要极限、等价无穷小、有理化和夹挤定理。

  1. a) \(\displaystyle \lim_{x \to 0} \frac{\sin(x)}{x}\)
  2. b) \(\displaystyle \lim_{x \to 0} \frac{\tan(3x)}{\tan(5x)}\)
  3. c) \(\displaystyle \lim_{x \to 0} \frac{x - \sin(x)}{x^3}\)（提示：利用泰勒展开或多次应用洛必达法则）
  4. d) \(\displaystyle \lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4}\)（提示：令 \(u = \sqrt{x}\)）
  5. e) \(\displaystyle \lim_{x \to \infty} \bigl(\sqrt{x^2 + 1} - x\bigr)\)（需写出过程）
  6. f) \(\displaystyle \lim_{x \to 0^{+}} x \sin\bigl(\frac{1}{x}\bigr)\)（可使用计算器观察趋势）
  7. g) 设函数 \(f\) 在 \(x = a\) 处可导，证明 \(f\) 在 \(x = a\) 处连续

公式与已知条件

  • 重要极限：\(\displaystyle \lim_{x \to 0} \frac{\sin(x)}{x} = 1\)
  • 等价无穷小：当 \(x \to 0\) 时，\(\sin(x) \sim x\)，\(\tan(x) \sim x\)
  • 夹挤定理：若 \(g(x) \le f(x) \le h(x)\) 且 \(\lim g = \lim h = L\)，则 \(\lim f = L\)
  • 可导必连续：若 \(f'(a)\) 存在，则 \(\lim_{x \to a} f(x) = f(a)\)
解题入口

  • 第 (f) 题利用了夹挤定理或数值观察

题目 7 乘积法则的推广 乘积法则 · 数学归纳法 · 广义乘积法则
官方题面翻译可离线作答

多个函数的乘积的乘积法则。（周二，6 分）

  1. a) 若 \(u\)、\(v\)、\(w\) 均为可微函数，求它们的乘积的导数公式 \(D(uvw)\)。
  2. b) 将 (a) 的工作推广：猜想 \(n\) 个可微函数乘积的导数公式 \(D(u_1 u_2 \cdots u_n)\)，并用数学归纳法证明你的公式（假设公式对 \(n\) 个函数成立，证明对 \(n+1\) 个函数成立）。

公式与已知条件

  • 两函数乘积法则：\(D(uv) = u'v + uv'\)
  • 三函数乘积公式：\(D(uvw) = u'vw + uv'w + uvw'\)
  • 一般公式：\(D(u_1 \cdots u_n) = \sum_{i=1}^{n} (u_1 \cdots u_i' \cdots u_n)\)
解题入口

(a) 两次应用乘积法则：\(D(uvw) = D((uv)w)\)。(b) 归纳时把前 \(n\) 个函数视为整体，再与第 \(n+1\) 个函数应用乘积法则。

完成后检查

  • (a) 公式为三项的对称和
  • (b) 基础情形与归纳步骤均已给出
  • 归纳假设表述清晰
