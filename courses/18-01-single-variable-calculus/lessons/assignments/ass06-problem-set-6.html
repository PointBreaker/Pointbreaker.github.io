主题梳理与示例

2. 交流电 RMS（Part II/2）

电压 \(V(t)=C\sin(120\pi t)\)，周期 \(T=1/60\) 秒。均方根：

\[V_{\text{RMS}}^2=\frac{1}{T}\int_0^T C^2\sin^2(120\pi t)\,dt=\frac{C^2}{T}\cdot\frac{T}{2}=\frac{C^2}{2}\]

用了 \(\sin^2\) 在一个周期内的平均值为 \(1/2\)。所以 \(V_{\text{RMS}}=C/\sqrt{2}\approx 0.707C\)。家庭用电标称 120V 就是 RMS 值，峰值约为 \(\pm 170\)V。

3. 放射性衰变概率（Part II/3）

「整体」反常积分：

\[W=\int_0^\infty e^{-at}\,dt=\lim_{N\to\infty}\frac{1-e^{-aN}}{a}=\frac1a\]

衰变发生在 \([0,T]\) 的概率为：

\[P([0,T])=\frac{1}{W}\int_0^T e^{-at}\,dt=\frac{1-e^{-aT}}{1}=1-e^{-aT}\]

半衰期 \(T_{1/2}\) 满足 \(P=1/2\)：\(1-e^{-aT_{1/2}}=1/2\)，解得 \(T_{1/2}=\frac{\ln 2}{a}\)。若 \(T_{1/2}=1\) 秒，则 \(a=\ln 2\)。

这里把「概率 = 部分/整体」与反常积分结合，是 18.01 把微积分应用于概率的标准范例。

4. Simpson 法则的证明（Part II/4）

取区间 \([x_0,x_2]\)，中点 \(x_1=(x_0+x_2)/2\)，半长 \(h=(x_2-x_0)/2\)。由对称性设 \(x_0=-h\)、\(x_1=0\)、\(x_2=h\)。设过 \((x_i,y_i)\) 的抛物线 \(y=Ax^2+Bx+C\)：

  • 由 \(x=\pm h\) 数据相减消去，可得 \(A\)；由 \(x=0\) 得 \(C=y_1\)。
  • 积分 \(\displaystyle\int_{-h}^{h}(Ax^2+Bx+C)\,dx=\frac{2Ah^3}{3}+2Ch\)。
  • 由 \(y_0=Ah^2-Bh+C\)、\(y_2=Ah^2+Bh+C\)，相加消去 \(B\)：\(y_0+y_2=2Ah^2+2C\)。
  • 整理得面积 \(=\frac{h}{3}(y_0+4y_1+y_2)\)。

5. Fresnel 积分的数值近似（Part II/5）

用 Simpson 法则（\(n=4\) 与 \(n=8\)）估算 \(\int_0^{\pi/2}\cos(t^2)\,dt\)。精确值（5 位小数）为 1.22505。Simpson 法则对三次以下多项式精确，这里被积函数不是多项式，但 \(n=8\) 时误差已经很小。

常见坑

  • RMS 与峰值混淆：RMS = 峰值/\(\sqrt{2}\)，不是峰值的一半。
  • 反常积分忘记取极限：\(\int_0^\infty e^{-at}dt\) 必须写成 \(\lim_{N\to\infty}\int_0^N\)。
  • Simpson 法则系数记错：是 \(h/3\) 乘 \((y_0+4y_1+y_2)\)，中点系数是 4 不是 2。
  • 半衰期公式：\(T_{1/2}=\ln 2/a\)，不是 \(1/a\)。

知识检查

问题 1：交流电压 \(V(t)=C\sin(120\pi t)\) 的 RMS 是？

问题 2：衰变概率 \(P=1-e^{-at}\) 的半衰期是？

问题 3：Simpson 法则在区间 \([x_0,x_2]\)（中点 \(x_1\)）的公式是？

自测小结

RMS

峰值/\(\sqrt{2}\)，来自 \(\sin^2\) 周期平均。

概率模型

反常积分归一化，半衰期 \(T_{1/2}=\ln 2/a\)。

Simpson 法则

\(h/3\) 乘 \((1,4,1)\) 权重，对三次以下精确。

数值近似

\(n\) 越大越精确，与精确值 1.22505 比较。

题目 I.3 第 24 讲作业：数值积分 Numerical integration
站内等价练习可离线作答

以下是一组站内等价练习，用于替代原教材习题，覆盖梯形法则与 Simpson 法则近似计算定积分的核心内容。

  1. 练习 1：用梯形法则（\(n = 4\)）近似计算 \(\int_{0}^{1} e^x \, dx\)。
  2. 练习 2：用 Simpson 法则（\(n = 4\)）近似计算 \(\int_{0}^{1} e^x \, dx\)。
  3. 练习 3：用 Simpson 法则（\(n = 4\)）近似计算 \(\int_{0}^{\pi} \sin(x) \, dx\)，并估计使误差小于 \(0.001\) 所需的最少子区间数 \(n\)（\(n\) 为偶数）。

公式与已知条件

  • 梯形法则：\(\int_{a}^{b} f(x) \, dx \approx \frac{\Delta x}{2}[f(x_0) + 2f(x_1) + \cdots + 2f(x_{n-1}) + f(x_n)]\)
  • Simpson 法则：\(\int_{a}^{b} f(x) \, dx \approx \frac{\Delta x}{3}[f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 4f(x_{n-1}) + f(x_n)]\)
  • \(\Delta x = (b - a)/n\)，Simpson 法则要求 \(n\) 为偶数
解题入口

先计算子区间宽度 \(\Delta x\) 与各节点处的函数值，再按对应法则的权重系数求加权和。

完成后检查

  • 梯形法则权重为 1-2-2-...-2-1；Simpson 法则权重为 1-4-2-4-...-4-1
  • Simpson 法则的 \(n\) 必须为偶数
  • \(n\) 增大时近似值应更接近精确值

题目 2 家用交流电的 RMS 电压 Average value · RMS voltage · Periodic functions
官方题面翻译可离线作答

家用交流电的电压 \(V(t) = C \sin(120\pi t)\)，其中 \(t\) 的单位为秒，\(C\) 为常数振幅。\(V(t)\) 在一个周期（即一个完整循环）上 \(V^2\) 的平均值的平方根称为均方根电压（root-mean-square voltage，简称 RMS）。家用电压表所显示的正是该值。对于家用交流电，试用常数 \(C\) 表示其 RMS 电压。（送至家庭的峰值电压为 \(\pm C\)。\(V^2\) 的单位为平方伏特；取平均值后再开方，单位恢复为伏特。）

公式与已知条件

  • \(V(t) = C \sin(120\pi t)\)
  • 峰值电压 = \(\pm C\)
  • 角频率 = \(120\pi \, \text{rad/s}\)，周期 \(T = \frac{2\pi}{120\pi} = \frac{1}{60} \, \text{s}\)
  • \(\text{RMS} = \sqrt{\text{一个周期上 } V^2 \text{ 的平均值}}\)
  • 函数平均值：\(f_{\text{avg}} = \frac{1}{T} \int_{0}^{T} f(t) \, dt\)
解题入口

先写出 \(V^2 = C^2 \sin^2(120\pi t)\)，在一个周期上求其平均值，再开方。利用三角恒等式化简 \(\sin^2\)。

完成后检查

  • RMS 的量纲应为伏特（V）
  • 结果应以 \(C\) 表示

题目 3 概率与广义积分 Probability · Improper integrals · Half-life · Radioactive decay
官方题面翻译可离线作答

本题涉及几何概型（面积比）与广义积分。

  1. （1 分）在单位正方形 \(0 \le x \le 1\)、\(0 \le y \le 1\) 内随机取一点（概率等于面积），求 \(x^2 < y\) 的概率。
  2. （2 分）在正方形 \(0 \le x \le 2\)、\(0 \le y \le 2\) 内随机取一点（概率与面积成正比），求 \(x^2 < y\) 的概率。
  3. （1 分）计算 \(W = \int_{0}^{\infty} e^{-at} \, dt = \lim_{N\to\infty} \int_{0}^{N} e^{-at} \, dt\)。这是一个表示无界区域面积的广义积分。\(P([0,\infty)) = 1 = 100\%\)。
  4. （2 分）半衰期是使 \(P([0,T]) = 1/2\) 的时间 \(T\)。求使半衰期为 \(T = 1\) 的 \(a\) 与 \(W\) 的值。设一放射性粒子的半衰期为 1 秒，求它存活至 \(t = 1\)、但在 \(1 \le t \le 2\) 期间发生衰变的概率。（给出积分公式，并用计算器算出近似数值答案。）

公式与已知条件

  • 单位正方形：\(0 \le x \le 1\)，\(0 \le y \le 1\)
  • 正方形：\(0 \le x \le 2\)，\(0 \le y \le 2\)
  • \(W = \int_{0}^{\infty} e^{-at} \, dt = \lim_{N\to\infty} \int_{0}^{N} e^{-at} \, dt\)
  • \(P([0,T]) = \frac{1}{W} \int_{0}^{T} e^{-at} \, dt\)
  • \(P([0,\infty)) = 1\)
  • 半衰期条件：\(P([0,T]) = 1/2\)，\(T = 1\)
解题入口

对 (a)(b)，先画出区域并求满足不等式的面积，再除以总面积；对 (c) 计算广义积分；对 (d) 由半衰期条件建立方程求参数。

完成后检查

  • \(W\) 的积分在 \(a > 0\) 时收敛
  • 概率归一性：\(P([0,\infty)) = 1\)
  • 半衰期条件应给出 \(P([0,1]) = 1/2\)

题目 4 Simpson 法则的证明 Simpson's rule · Numerical integration · Quadratic interpolation · Symmetry in integration
官方题面翻译可离线作答

Simpson 法则的基础是如下公式。设 \(x_1\) 为区间 \([x_0, x_2]\) 的中点，记其长度为 \(2h\)。任取三点 \((x_0, y_0)\)、\((x_1, y_1)\)、\((x_2, y_2)\)，存在唯一的二次函数（抛物线）\(y = Ax^2 + Bx + C\) 的图像经过这三点。Simpson 法则断言：该抛物线在 \([x_0, x_2]\) 上的面积为 \(\frac{h}{3}(y_0 + 4y_1 + y_2)\)。本题证明该公式，并展示如何通过对称性与前瞻简化计算。由于平移不改变面积，可设 \(x_0 = -h\)，\(x_1 = 0\)，\(x_2 = h\)。

  1. 画出示意图，并确定 \(C\) 的值。
  2. 通过积分说明：为求面积，只需确定 \(A\)（或更简便地，确定 \(2Ah^2\)）。
  3. 利用已知数据确定 \(2Ah^2\)。
  4. 综合上述结果，推导出面积公式 \(\frac{h}{3}(y_0 + 4y_1 + y_2)\)。

公式与已知条件

  • \(x_0 = -h\)，\(x_1 = 0\)，\(x_2 = h\)
  • 抛物线：\(y = Ax^2 + Bx + C\)
  • Simpson 法则面积公式：面积 = \(\frac{h}{3}(y_0 + 4y_1 + y_2)\)
解题入口

利用对称性：奇函数部分 \(Bx\) 在 \([-h, h]\) 上的积分为零，因此面积仅与 \(A\) 和 \(C\) 有关。先由数据确定 \(C\)，再求 \(2Ah^2\)，最后合并。

完成后检查

  • \(x_1 = 0\) 时，\(C = y_1\)
  • 面积公式对任意二次函数均精确成立
  • 可验证 \(2Ah^2\) 与 \(\frac{h}{3}(y_0 + 4y_1 + y_2)\) 中来自 \(C\) 的贡献之间的关系

题目 5 利用 Simpson 法则近似计算 Fresnel 积分 Fresnel integrals · Simpson's rule · Numerical integration
官方题面翻译可离线作答

使用计算器列出被积函数值表，并分别用 Simpson 法则在四个子区间和八个子区间下近似 Fresnel 积分 \(\int_{0}^{\pi/2} \cos(t^2) \, dt\)。（精确答案保留五位小数为 \(1.22505\)。请将近似值保留六位小数以便比较。）

  1. 用 Simpson 法则（四个子区间）计算近似值。
  2. 用 Simpson 法则（八个子区间）计算近似值。
  3. 将两个近似值保留六位小数，并与精确值 \(1.22505\) 进行比较。

公式与已知条件

  • Fresnel 积分：\(\int_{0}^{\pi/2} \cos(t^2) \, dt\)
  • Simpson 法则：\(\int_{a}^{b} f(t) \, dt \approx \frac{\Delta t}{3}[f(t_0) + 4f(t_1) + 2f(t_2) + 4f(t_3) + \cdots + 4f(t_{n-1}) + f(t_n)]\)
  • 精确答案（五位小数）：\(1.22505\)
解题入口

在 \([0, \pi/2]\) 上分别取 \(n = 4\) 和 \(n = 8\)，计算各节点处 \(\cos(t^2)\) 的值，按 Simpson 法则权重求加权和。

完成后检查

  • 八个子区间的近似值应比四个子区间更接近 \(1.22505\)
  • Simpson 法则的 \(n\) 必须为偶数
