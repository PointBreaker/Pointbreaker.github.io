主题梳理与示例

2. 交流电 RMS（Part II/2）

电压 \(V(t)=C\sin(120\pi t)\)，周期 \(T=1/60\) 秒。均方根：

\[V_{\text{RMS}}^2=\frac{1}{T}\int_0^T C^2\sin^2(120\pi t)\,dt=\frac{C^2}{T}\cdot\frac{T}{2}=\frac{C^2}{2}\]

用了 \(\sin^2\) 在一个周期内的平均值为 \(1/2\)。所以 \(V_{\text{RMS}}=C/\sqrt{2}\approx 0.707C\)。家庭用电标称 120V 就是 RMS 值，峰值约为 \(\pm 170\)V。

3. 放射性衰变概率（Part II/3）

「整体」反常积分：

\[W=\int_0^\infty e^{-at}\,dt=\lim_{N\to\infty}\frac{1-e^{-aN}}{a}=\frac1a\]

衰变发生在 \([0,T]\) 的概率为：

\[P([0,T])=\frac{1}{W}\int_0^T e^{-at}\,dt=\frac{1-e^{-aT}}{1}=1-e^{-aT}\]

半衰期 \(T_{1/2}\) 满足 \(P=1/2\)：\(1-e^{-aT_{1/2}}=1/2\)，解得 \(T_{1/2}=\frac{\ln 2}{a}\)。若 \(T_{1/2}=1\) 秒，则 \(a=\ln 2\)。

这里把「概率 = 部分/整体」与反常积分结合，是 18.01 把微积分应用于概率的标准范例。

4. Simpson 法则的证明（Part II/4）

取区间 \([x_0,x_2]\)，中点 \(x_1=(x_0+x_2)/2\)，半长 \(h=(x_2-x_0)/2\)。由对称性设 \(x_0=-h\)、\(x_1=0\)、\(x_2=h\)。设过 \((x_i,y_i)\) 的抛物线 \(y=Ax^2+Bx+C\)：

  • 由 \(x=\pm h\) 数据相减消去，可得 \(A\)；由 \(x=0\) 得 \(C=y_1\)。
  • 积分 \(\displaystyle\int_{-h}^{h}(Ax^2+Bx+C)\,dx=\frac{2Ah^3}{3}+2Ch\)。
  • 由 \(y_0=Ah^2-Bh+C\)、\(y_2=Ah^2+Bh+C\)，相加消去 \(B\)：\(y_0+y_2=2Ah^2+2C\)。
  • 整理得面积 \(=\frac{h}{3}(y_0+4y_1+y_2)\)。

5. Fresnel 积分的数值近似（Part II/5）

用 Simpson 法则（\(n=4\) 与 \(n=8\)）估算 \(\int_0^{\pi/2}\cos(t^2)\,dt\)。精确值（5 位小数）为 1.22505。Simpson 法则对三次以下多项式精确，这里被积函数不是多项式，但 \(n=8\) 时误差已经很小。

常见坑

  • RMS 与峰值混淆：RMS = 峰值/\(\sqrt{2}\)，不是峰值的一半。
  • 反常积分忘记取极限：\(\int_0^\infty e^{-at}dt\) 必须写成 \(\lim_{N\to\infty}\int_0^N\)。
  • Simpson 法则系数记错：是 \(h/3\) 乘 \((y_0+4y_1+y_2)\)，中点系数是 4 不是 2。
  • 半衰期公式：\(T_{1/2}=\ln 2/a\)，不是 \(1/a\)。

知识检查

问题 2：衰变概率 \(P=1-e^{-at}\) 的半衰期是？

自测小结

RMS

峰值/\(\sqrt{2}\)，来自 \(\sin^2\) 周期平均。

概率模型

反常积分归一化，半衰期 \(T_{1/2}=\ln 2/a\)。

Simpson 法则

\(h/3\) 乘 \((1,4,1)\) 权重，对三次以下精确。

数值近似

\(n\) 越大越精确，与精确值 1.22505 比较。

Problem 2 RMS voltage of house current Average value · RMS voltage · Periodic functions

The voltage V of house current is given by V(t) = C sin(120πt), where t is time in seconds and C is a constant amplitude. The square root of the average value of V² over one period of V(t) (or cycle) is called the root-mean-square voltage, abbreviated RMS. This is what the voltage meter on a house records. For house current, find the RMS in terms of the constant C. (The peak voltage delivered to the house is ±C. The units of V² are square volts; when we take the square root again after averaging, the units become volts again.)

公式与已知条件

  • V(t) = C sin(120πt)
  • RMS = sqrt(average value of V² over one period)
  • Peak voltage = ±C
  • Angular frequency = 120π rad/s
解题入口

Compute the average value of V² = C² sin²(120πt) over one period, then take the square root. Use the fact that the average of sin² over a full period is 1/2.

完成后检查

  • RMS should simplify to C/√2
  • Units: V² averaged then square-rooted gives volts

Problem 3 Probability and improper integrals Probability · Improper integrals · Half-life · Radioactive decay

  1. (1 pt) What is the probability that x² < y if (x,y) is chosen from the unit square 0 ≤ x ≤ 1, 0 ≤ y ≤ 1 with probability equal to the area.
  2. (2 pts) What is the probability that x² < y if (x,y) is chosen from the square 0 ≤ x ≤ 2, 0 ≤ y ≤ 2 with probability proportional to the area. (Probability = Part/Whole.)
  3. (1 pt) Evaluate W = ∫₀^∞ e^(-at) dt = lim_{N→∞} ∫₀^N e^(-at) dt. This is an improper integral representing the area of an unbounded region. (We use the letter W to signify 'whole'.) Note that P([0,∞)) = 1 = 100%.
  4. (2 pts) The half-life is the time T for which P([0,T]) = 1/2. Find the value of a and W for which the half-life is T=1. Suppose a radioactive particle has a half-life of 1 second. What is the probability that it survives to time t=1, but decays some time during the interval 1 ≤ t ≤ 2? (Give an integral formula, and use a calculator to get an approximate numerical answer.)

公式与已知条件

  • Unit square: 0 ≤ x ≤ 1, 0 ≤ y ≤ 1
  • Square: 0 ≤ x ≤ 2, 0 ≤ y ≤ 2
  • W = ∫₀^∞ e^(-at) dt = lim_{N→∞} ∫₀^N e^(-at) dt
  • P([0,T]) = (1/W) ∫₀ᵀ e^(-at) dt = PART/WHOLE
  • P([0,∞)) = 1
  • Half-life: P([0,T]) = 1/2, T = 1
解题入口

For (a) and (b), compute area of region where x² < y within the given square, then divide by total area. For (c), evaluate the improper integral. For (d), use the half-life condition to find a, then compute the conditional probability.

完成后检查

  • W = 1/a for a > 0
  • P([0,∞)) = 1 (normalization)
  • Half-life condition gives a = ln(2) when T=1
  • Probability in (d) should be P([1,2]) = e^(-a) - e^(-2a)

Problem 4 Proof of Simpson's rule Simpson's rule · Numerical integration · Quadratic interpolation · Symmetry in integration

The basis for Simpson's rule is the following formula. Let x₁ be the midpoint of the interval [x₀, x₂], and denote its length by 2h. Consider any three points (x₀,y₀), (x₁,y₁), (x₂,y₂). There is a unique quadratic function (parabola) y = Ax² + Bx + C whose graph passes through the three points. Simpson's rule says that the area under the parabola above [x₀, x₂] is (h/3)(y₀ + 4y₁ + y₂). This problem proves this formula, illustrating how calculations can be simplified by using symmetry and looking ahead. Since the area is the same if the parabola is translated, assume x₀ = -h, x₁ = 0, and x₂ = h.

  1. Make a sketch and determine C.
  2. Show, by integrating, that to find the area we need only determine A (or better, 2Ah²).
  3. Determine 2Ah² using the data.
  4. Put the results together to establish the formula for area: (h/3)(y₀ + 4y₁ + y₂).

公式与已知条件

  • x₀ = -h, x₁ = 0, x₂ = h
  • Parabola: y = Ax² + Bx + C
  • Simpson's rule area = (h/3)(y₀ + 4y₁ + y₂)
解题入口

Use symmetry: the integral of the odd part (Bx) over [-h,h] vanishes, so only A and C matter. Determine C from the data, then find 2Ah², and combine.

完成后检查

  • C = y₁ (since x₁=0)
  • The area formula should be exact for any quadratic
  • Verify 2Ah² = (h/3)(y₀ + 4y₁ + y₂) - 2Ch (the contribution from C)

Problem 5 Fresnel integral approximation via Simpson's rule Fresnel integrals · Simpson's rule · Numerical integration

Use a calculator to make a table of values of the integrand and find approximations to the Fresnel integral ∫₀^(π/2) cos(t²) dt using Simpson's rule with four and eight intervals. (The exact answer to five decimal places is 1.22505. Record your approximations to six decimal places to compare.)

  1. Compute approximation using Simpson's rule with four intervals.
  2. Compute approximation using Simpson's rule with eight intervals.
  3. Record both approximations to six decimal places and compare with the exact value 1.22505.

公式与已知条件

  • Fresnel integral: ∫₀^(π/2) cos(t²) dt
  • Simpson's rule with 4 and 8 intervals
  • Exact answer to 5 decimal places: 1.22505
解题入口

Apply Simpson's rule on [0, π/2] with n=4 and n=8 subintervals. Compute cos(t²) at the required points, apply the Simpson's rule weights, and record to six decimal places.

完成后检查

  • 8-interval approximation should be closer to 1.22505 than 4-interval
  • Both approximations should bracket or approach the exact value
