Problem Set 3：相关变化率、中值定理与微分方程

本作业把导数的三大应用——相关变化率、中值定理、牛顿法——集中在一张 PS 里，并第一次系统涉及微分方程与不等式的证明。GPS 灵敏度问题在 PS1 首次登场后，在这里用隐式微分给出精确答案。

类型：Problem Set 3（Part I + Part II） 截止：2006-10-06 13:55 覆盖：Lecture 12, 13, 14, 16

学习目标

  • 用隐式微分处理相关变化率问题，并解释线性近似 \(\Delta L/\Delta h \le dL/dh\) 的几何含义。
  • 掌握牛顿法 \(x_{n+1}=x_n-f(x_n)/f'(x_n)\) 的迭代格式、收敛判断与误差估计。
  • 用中值定理（MVT）证明不等式，并求极值问题的端点最值。
  • 用相关变化率推导星形线（hypocycloid）的切线包络。

前置知识

  • 第 11 课：极值问题——第 1 题的梯子/围墙极值。
  • 第 12 课：相关变化率——隐式微分的使用场景。
  • 第 13 课：牛顿法——第 5 题的迭代格式。
  • 第 14 课：中值定理与不等式——MVT 的不等式推论。

结构说明

  • Part I（10 分）：极值、相关变化率、牛顿法的配套短练习。
  • Part II（31 分 + 8 额外）：6 道大题，涵盖极值、星形线切线长度、GPS 灵敏度精确化、抛物面镜、牛顿法综合、星形线包络推导。

主题梳理与示例

1. 极值问题（Part II/1）

梯子靠墙问题（4.3/28）：设梯子脚距墙 \(x\)，列出到达高度关于 \(x\) 的函数，求最小值并检查端点。这类问题容易忽略定义域端点——18.01 反复强调「极值可能出现在端点」。

3. 测量灵敏度精确化（Part II/3）

PS1 中的 GPS 关系 \(L^2+20000^2=h^2\)。隐式微分：

\[2L\frac{dL}{dh}=2h\quad\Longrightarrow\quad \frac{dL}{dh}=\frac{h}{L}=\frac{h}{\sqrt{h^2-20000^2}}\]

与 PS1 的差商 \(\Delta L/\Delta h\) 比较：当 \(\Delta h>0\) 且导数在左端点取值时，\(\Delta L/\Delta h\le dL/dh\)，这是因为 \(dL/dh\) 随 \(h\) 增大而增大（上凸函数）。

一维情形（一维行星 + 两卫星）：由两个观测联立求解位置，并讨论 \(x_1x_1\) 两种顺序。

这类「反问题」是工程中的常见模式：通过多个含噪声的观测推断未知量，并用导数估计误差传播。

4. 抛物面镜与角度灵敏度（Part II/4）

抛物线 \(y=-\frac14+x^2\)，焦点在原点。光线沿 \(x=a\) 竖直入射点 \((a,b)\)，反射到原点，反射光线与 \(x\) 轴夹角 \(\theta\)：

\[\tan\theta=\frac{b}{a}=\frac{-1/4+a^2}{a}\]

隐式微分求 \(d\theta/da\)，再利用 \(\theta=-\pi/6\)、测量精度 \(10^{-3}\) 弧度反推 \(a\) 的不确定度。

5. 牛顿法求 \(9^{1/3}\)（Part II/5）

求 \(x^3=9\) 的正根，迭代函数 \(f(x)=x^3-9\)，牛顿格式：

\[x_{n+1}=x_n-\frac{x_n^3-9}{3x_n^2}=\frac{2x_n^3+9}{3x_n^2}\]

取 \(x_0=2\)，迭代直到稳定到 6 位有效数字。注意每一步 \(x_k\) 都大于精确值 \(9^{1/3}\)（因为牛顿法对凸函数从左侧逼近），且序列单调递减。

第 (c) 小题用 \(9=8(1+1/8)\) 与二次逼近 \((1+x)^{1/3}\approx 1+x/3-x^2/9\) 估算 \(9^{1/3}=2(1+1/8)^{1/3}\)。

6. 星形线的包络（Part II/6，额外学分）

长度为 1 的梯子从竖直滑到水平，包络线即所有位置的「公共切线」形成的曲线。设两位置 \((0,y_1)\to(x_1,0)\) 与 \((0,y_2)\to(x_2,0)\)，交点：

\[x_3=\frac{x_1y_2-x_2y_1}{y_2-y_1+x_1-x_2}\quad\text{（对称式）}\]

令 \(x_2\to x_1\)、用 \(x_1^2+y_1^2=1\) 的隐式微分求极限 \((X,Y)\)，最终得到 \(X^{2/3}+Y^{2/3}=1\)。这是一道极具综合性的难题，把相关变化率、极限、隐式微分融为一体。

常见坑

  • 极值漏检端点：梯子问题中 \(x\) 的定义域是闭区间，端点可能给出最值。
  • 牛顿法收敛判断不清：要明确写出「何时达到计算器精度」，并列出每步数值。
  • 隐式微分后忘记用原方程化简：第 3 题 \(dL/dh=h/L\)，而 \(L\) 要代回 \(\sqrt{h^2-20000^2}\)。
  • 相关变化率中符号与单位：注意 \(\Delta h>0\) 与 \(\Delta h<0\) 对应的不等式方向不同。

自测小结

相关变化率

隐式微分 + 原方程化简，注意几何/物理意义。

牛顿法

\(x_{n+1}=x_n-f/f'\)，凸函数时单调递减地从右侧逼近。

中值定理

用 MVT 把函数值差转化为导数乘积，证明不等式。

包络

曲线族的公共切线形成包络，取交点极限可得方程。
