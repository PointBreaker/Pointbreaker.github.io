Problem Set 3：相关变化率、牛顿法与星形线

本次作业把极值、隐函数求导、误差传播与牛顿迭代连接起来，并用滑动梯子的包络问题综合训练极限与相关变化率。导读只提供方法入口，不给出官方题目的最终结论。

覆盖：Lecture 11–14中文自包含可离线作答

目标

  • 在闭区间极值问题中同时检查临界点与端点。
  • 从几何约束建立方程，再用隐函数求导处理相关变化率和测量灵敏度。
  • 使用牛顿法迭代求根，并从函数几何性质判断迭代行为。
  • 通过相邻曲线或线段交点的极限理解包络线的形成机制。
  • 用量纲、对称性与极端情形检查推导是否合理。

核心知识要点

先建模，再求导

相关变化率题的关键不是立刻写导数，而是先明确哪些量随时间或测量值变化、哪些量保持不变，并写出始终成立的约束。之后对同一个自变量求导，最后才代入指定状态。

牛顿法是切线迭代

一般迭代式为 \(x_{n+1}=x_n-f(x_n)/f'(x_n)\)。数值结果之外，还应结合凸凹性、切线位置和前几步迭代判断收敛方向，避免把起始点与后续点混为一谈。

包络来自相邻成员的极限交点

对一族连续变化的直线，先求两条相邻直线的交点，再让两组参数趋于一致。所得极限点沿参数移动形成包络边界；推导中应同时检查交换坐标后的对称性。

典型题型与解题策略

1

约束型最值

明确变量范围，把目标量化为单变量函数；求临界点后必须回到闭区间检查端点，并说明为什么候选点给出绝对最值。

2

相关变化率与灵敏度

先写几何或物理约束，再对测量变量求导。比较导数与有限差商时，要结合导数在区间上的增减性判断不等式方向。

3

迭代与包络

牛顿法先计算少量迭代观察模式，再用函数几何证明；包络问题先做交点代数，再取相邻位置的极限，最后用对称性和原约束化简。

常见错误

只检查导数为零的点，却遗漏定义域端点。

在相关变化率题中先代入数值，导致变量关系和符号信息丢失。

把有限差商与某一点的导数直接视为相等，没有检查导数在区间上的变化。

根据一两步牛顿迭代就断言整个序列单调，未结合凸凹性证明。

包络交点公式未做交换 \(x,y\) 的对称性或尺度检查。

题目 3 测量灵敏度（续） 隐函数求导 · 测量灵敏度 · 线性近似 · 误差传播 · 卫星测距几何
官方题面翻译可离线作答

利用习题集 1 第 II 部分第 2 题的关系，通过隐函数求导研究测量灵敏度。

  1. a) 设 \(L^2+20{,}000^2=h^2\)，即 \(L=\sqrt{h^2-20{,}000^2}\)。先在中心值 \(h_0=25{,}000\) 与 \(h_0=20{,}001\) 处，分别取 \(\Delta h=1,10^{-1},10^{-2}\)，自行计算 \(\Delta L/\Delta h=[L(h_0+\Delta h)-L(h_0)]/\Delta h\)。再用隐函数求导计算 \(dL/dh\)，比较有限差商与线性近似。解释当导数在不确定区间的左端点处取值时（\(\Delta h>0\)），为何 \(\Delta L/\Delta h\le dL/dh\)。\(h\) 在什么取值范围内有 \(|\Delta L|\le2|\Delta h|\)？
  2. b) 假设 Quirk 星球不仅是平的，而且是一维的（一条直线）。若干卫星位于 20,000 千米高度。卫星 1 位于 \(x_1 \pm 10^{-10}\) 正上方，距离 \(h_1 = 21{,}000 \pm 10^{-2}\)；卫星 2 位于 \(x_2 \pm 10^{-10}\) 正上方，距离 \(h_2 = 52{,}000 \pm 10^{-2}\)。你在何处，精度如何？提示：分别考虑 \(x_1 < x_2\) 和 \(x_1 > x_2\) 两种情形。
  3. c) 用从地面观察者到卫星的视线与水平方向的夹角 \(\theta\) 表示 \(\frac{dL}{dh}\)。（用视线夹角表达后，该公式对地球这样的弯曲星球同样适用。）

公式与已知条件

  • \(L^2 + 20{,}000^2 = h^2\)
  • 比较用中心值：\(h_0=25{,}000\) 与 \(h_0=20{,}001\)
  • 扰动取值：\(\Delta h=1,10^{-1},10^{-2}\)
  • \(h_1 = 21{,}000 \pm 10^{-2}\)
  • \(h_2 = 52{,}000 \pm 10^{-2}\)
  • 位置不确定度：\(\pm 10^{-10}\)
解题入口

对勾股关系隐式求导；(b) 利用两距离方程求解位置并传播误差；(c) 用直角三角形三角函数。

完成后检查

  • (a) 验证不等式方向及 \(h\) 范围。
  • (b) 检查 \(x_1\) 与 \(x_2\) 的两种排序。
  • (c) 确认公式退化为平直情形并可推广到弯曲几何。

题目 4 测量灵敏度（续）：抛物面镜 隐函数求导 · 相关变化率 · 抛物面镜 / 焦点几何 · 误差估计
官方题面翻译可离线作答

考虑抛物面镜 \(y = -\frac{1}{4} + x^2\)，焦点在原点。一束光线沿 \(x = a\) 垂直向下传播，在镜面上点 \((a, b)\) 处反射，其中 \(b = -\frac{1}{4} + a^2\)，然后沿与正 x 轴夹角为 \(\theta\) 的射线射向原点。

  1. a) 求 \(\tan\theta\) 关于 \(a\) 和 \(b\) 的表达式，并用隐函数求导计算 \(\frac{d\theta}{da}\)。答案用 \(a\) 和 \(\theta\) 表示。
  2. b) 若望远镜记录一颗恒星位于 \(\theta = -\frac{\pi}{6}\)，测量精度为 \(10^{-3}\) 弧度，利用 (a) 估计该恒星在变量 \(a\) 中的位置。
  3. c)（选做，不计分）将 \(a\) 单独表示为 \(\theta\) 的函数，并复核 (a)(b) 的答案。

公式与已知条件

  • 抛物面镜方程：\(y = -\frac{1}{4} + x^2\)
  • 入射点：\((a, b)\)，其中 \(b = -\frac{1}{4} + a^2\)
  • 焦点在原点
  • \(\theta = -\frac{\pi}{6}\)，精度 \(\pm 10^{-3}\) 弧度
解题入口

将 \(\theta\) 与从 \((a, b)\) 到原点的射线斜率关联；隐式求导；(b) 利用 \(\Delta\theta \approx \frac{d\theta}{da}\Delta a\)。

完成后检查

  • (a) 验证量纲与符号约定。
  • (b) 确认估计的 \(a\) 与 \(\theta = -\frac{\pi}{6}\) 一致。

题目 5 牛顿法 牛顿法 · 迭代近似 · 二次近似 / 泰勒展开
官方题面翻译可离线作答

用牛顿法计算 9 的立方根。

  1. a) 用牛顿法将 \(9^{1/3}\) 计算到 6 位有效数字。给出通项公式，从 \(x_0 = 2\) 开始列出各次迭代值。第几次迭代 \(k\) 的精度超过你的计算器或计算机？答案按计算器或计算机的精度呈现。
  2. b) 对每一步 \(x_k\)（\(k = 0, 1, \ldots\)），判断：i) 该值大于还是小于 \(9^{1/3}\)；ii) 该值大于还是小于前一步 \(x_{k-1}\)。在 \(f(x) = x^3 - 9\) 的图像上说明原因。
  3. c) 求 \(9^{1/3}\) 的二次近似，并估计二次近似与精确值的差。提示：利用 \(9 = 8(1 + \frac{1}{8})\)。

公式与已知条件

  • 目标：\(9^{1/3}\)
  • 初值：\(x_0 = 2\)
  • 改写：\(9 = 8(1 + \frac{1}{8})\)
解题入口

对 \(f(x) = x^3 - 9\) 应用牛顿法；(c) 将 \(9^{1/3} = 2(1 + \frac{1}{8})^{1/3}\) 用二项式/泰勒展开。

完成后检查

  • (a) 确认收敛到 6 位有效数字。
  • (c) 验证二次近似的误差估计合理。

题目 6 星形线（续）（附加分） 星形线 · 直线交点 · 隐函数求导 · 相关变化率 · 扫掠区域边界的极限
官方题面翻译可离线作答

直接从扫掠性质推导第 2 题星形线的方程。将第一象限建模为以墙面为正 y 轴、地面为正 x 轴的区域。一架单位长度的梯子初始时垂直靠墙，滑动至水平过程中顶端被拖向原点，扫出一片区域。

  1. a) 设 \(L_1\) 为从 \((0, y_1)\) 到 \((x_1, 0)\) 的线段，\(L_2\) 为从 \((0, y_2)\) 到 \((x_2, 0)\) 的线段。求两线段交点 \((x_3, y_3)\) 关于参数 \(x_1, x_2, y_1, y_2\) 的表达式，并尽量化简。可选自检：i) 若 \(y_2 = 0\) 则 \(x_3 = x_1\)；ii) 交换 \(x\) 与 \(y\) 的对称性；iii) 分母为零对应两直线平行；iv) 所有变量同乘 \(c\) 时，交点坐标也应同乘 \(c\)，即公式为一次齐次。
  2. b) 写出含 \(x_2\) 和 \(y_2\) 的方程，表达梯子 \(L_2\) 长度为 1 的约束。固定 \(L_1\)，令 \(L_2\) 趋近 \(L_1\)：\(x_2 = x_1 + \Delta x\), \(y_2 = y_1 + \Delta y\)。用隐函数求导（相关变化率）求 \(\lim_{\Delta x \to 0}\frac{\Delta y}{\Delta x}\) 作为 \(x_1, y_1\) 的函数。
  3. c) 将 \(x_2 = x_1 + \Delta x\), \(y_2 = y_1 + \Delta y\) 代入 (a) 的 \(x_3\) 表达式，利用 (b) 计算 \(X = \lim_{x_2 \to x_1} x_3 = \lim_{\Delta x \to 0} x_3\)。化简，并由对称性推出 \(Y = \lim_{x_2 \to x_1} y_3\)。
  4. d) 证明 \(X^{2/3} + Y^{2/3} = 1\)。

公式与已知条件

  • 梯子长度 = 1
  • \(L_1\)：从 \((0, y_1)\) 到 \((x_1, 0)\) 的线段
  • \(L_2\)：从 \((0, y_2)\) 到 \((x_2, 0)\) 的线段
  • \(x_2 = x_1 + \Delta x\), \(y_2 = y_1 + \Delta y\)
解题入口

(a) 由两直线方程推导交点；(b) 对长度约束求导；(c) 利用相关变化率斜率取极限；(d) 合并参数表达式。

完成后检查

  • (a) 验证四条可选自检。
  • (d) 验证所得关系恰为星形线方程。
