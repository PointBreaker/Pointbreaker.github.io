Problem Set 8：极坐标、洛必达、级数与泰勒级数

课程的最后一次常规作业，分 8A（Lecture 30–31：参数方程、弧长、极坐标面积、悬链线）与 8B（Lecture 34–37：洛必达、反常积分、级数收敛、Gamma 函数递推、球面帽优化）。内容跨度大，是期末总复习的绝佳素材。

类型：Problem Set 8（8A + 8B） 截止：2006-12-08 13:55 覆盖：Lecture 31, 34, 35, 36, 37（8A 含 Lecture 30）

学习目标

  • 把参数曲线 \(x=a\cos^k t,\ y=a\sin^k t\) 化为直角坐标方程，并计算弧长。
  • 用极坐标面积公式 \(\frac12\int r^2\,d\theta\) 计算区域面积，并与直角坐标结果对照。
  • 用洛必达法则判断 \(\int_0^\infty x^n e^{-x}\,dx\) 的收敛性，并用分部积分推导 Gamma 递推 \(A(n+1)=nA(n)\)。
  • 结合球冠体积与表面积，优化肥皂泡形状（最小表面积问题）。

主题梳理与示例

1. 参数曲线 \(x=a\cos^k t,\ y=a\sin^k t\)（8A/1）

取 \(k=1\)：\(x=a\cos t,\ y=a\sin t\)，满足 \(x^2+y^2=a^2\)（圆），弧长 \(=a\cdot\pi/2\)。

取 \(k=2\)：\(x=a\cos^2 t=a(1+\cos 2t)/2\)，\(y=a\sin^2 t=a(1-\cos 2t)/2\)，满足 \(x+y=a\)，且参数描出从 \((a,0)\) 到 \((0,a)\) 的整条线段；弧长由两端点距离得 \(a\sqrt{2}\)。

一般 \(k\)：弧长积分 \(\displaystyle L=\int_0^{\pi/2}\sqrt{(dx/dt)^2+(dy/dt)^2}\,dt\)，代入求值并与 \(k=1,2\) 的几何结果对照。

2. 悬链线与悬链面（8A/2）

双曲函数定义 \(\cosh x=\frac{e^x+e^{-x}}{2}\)，\(\sinh x=\frac{e^x-e^{-x}}{2}\)。基本性质：\((\sinh x)'=\cosh x\)，\((\cosh x)'=\sinh x\)，\(\cosh^2 x-\sinh^2 x=1\)。

参数曲线 \(x=\cosh t,\ y=\sinh t\) 满足 \(x^2-y^2=1\)（双曲线）。悬链线 \(y=\cosh x\) 的弧长：

\[s=\int_0^{x_1}\sqrt{1+\sinh^2 x}\,dx=\int_0^{x_1}\cosh x\,dx=\sinh x_1\]

悬链面（绕 \(x\) 轴旋转）的表面积：

\[A=\int 2\pi y\,ds=\int_0^{x_1}2\pi\cosh x\cdot\cosh x\,dx=2\pi\int_0^{x_1}\cosh^2 x\,dx\]

悬链面是连接两个圆盘的「最小表面积」形状——肥皂膜实验的经典结果，与最速降线、等周问题同为变分法起源。

3. 极坐标面积（8A/3）

极坐标面积公式：\(\displaystyle A=\frac12\int_{\theta_1}^{\theta_2}r^2\,d\theta\)。

曲线 \(r=1/(1+\sin\theta)\) 化为直角坐标：\(r+r\sin\theta=1\)，即 \(\sqrt{x^2+y^2}+y=1\)，整理得 \(x^2=1-2y\)（开口向下的抛物线）。

区域 \(0\le r\le 1/(1+\sin\theta)\)，\(0\le\theta\le\pi\) 的面积：

\[A=\frac12\int_0^\pi\frac{1}{(1+\sin\theta)^2}\,d\theta\]

令 \(u=\theta-\pi/2\)，用 \(1+\cos u=2\cos^2(u/2)\) 化简。这个例子说明：极坐标面积公式在处理「绕焦点扫过的面积」时比直角坐标方便（开普勒定律的背景）。

4. Gamma 函数与反常积分（8B/1）

用洛必达法则：\(\displaystyle\lim_{x\to\infty}x^m e^{-x}=0\)（指数衰减比任何幂增长快）。由此用比较判别法证明 \(\int_0^\infty x^n e^{-x}\,dx\) 对 \(n\ge 0\) 收敛。

记 \(A(n)=\int_0^\infty x^n e^{-x}\,dx\)。分部积分：

\[A(n+1)=\int_0^\infty x^{n+1}e^{-x}\,dx=\left[-x^{n+1}e^{-x}\right]_0^\infty+(n+1)\int_0^\infty x^n e^{-x}\,dx=(n+1)A(n)\]

边界项在 \(\infty\) 处为 0 正是用了洛必达的结果。又 \(A(0)=1\)，所以 \(A(n)=n!\)。

5. 肥皂泡形状优化（8B/2）

球冠体积 \(V=\pi(rh^2-h^3/3)\)，其中 \(r\) 是球半径，\(h\) 是冠高。球冠表面积（只算曲面）：

\[S=2\pi rh\]

在体积 \(V\) 固定下最小化 \(S\)：由 \(V\) 的公式把 \(r\) 表为 \(h\) 的函数，代入 \(S\)，对 \(h\) 求导令为零，得到 \(h/r=1\)，即半球。所以最优肥皂泡是半球。

常见坑

  • 参数曲线弧长积分限：\(t\) 从 \(0\) 到 \(\pi/2\) 只描出第一象限部分。
  • 极坐标面积漏乘 \(1/2\)：面积元是 \(\frac12 r^2\,d\theta\)，不是 \(r^2\,d\theta\)。
  • 洛必达使用条件：必须是不定式 \(0/0\) 或 \(\infty/\infty\)，且导数极限存在。
  • 分部积分边界项：\(\left[-x^{n+1}e^{-x}\right]_0^\infty\) 在 \(\infty\) 处为 0 需要洛必达保证。

\(\frac12\int r^2\,d\theta\)，注意 \(\theta\) 范围避免重复计数。

题目 1 参数曲线 \(x = a \cos^k t, y = a \sin^k t\) 参数方程 · 弧长
官方题面翻译可离线作答

分析参数曲线 \(x = a \cos^k t\)，\(y = a \sin^k t\)，其中 \(a > 0\)，\(k > 0\) 为常数。

  1. a) 求该曲线的关于 \(x\) 与 \(y\) 的代数方程。在 \(k = 1\)、\(k = 2\)、\(k = 3\) 三种情况下，画出 \(0 \le t \le \pi/2\) 对应的那段曲线。
  2. b) 不通过计算，求 \(k = 1\) 和 \(k = 2\) 两种情况下的弧长。
  3. c) 对一般情形 \(k\)，建立曲线弧长的定积分表达式，并分别计算 \(k = 1\)、\(k = 2\)、\(k = 3\) 时的积分值。（前两种情况的结果应与 (b) 一致，但计算过程会更耗时。）

公式与已知条件

  • 参数方程：\(x = a \cos^k t\)，\(y = a \sin^k t\)
  • 弧长微分：\(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\,dt\)
解题入口

(a) 部分利用 \(\cos^2 t + \sin^2 t = 1\) 消去参数 \(t\)；(c) 部分计算 \(ds\) 再积分。

完成后检查

  • (c) 中 k=1、k=2 的计算结果应与 (b) 一致。

题目 2 双曲函数与悬链线 双曲函数 · 参数方程 · 弧长 · 旋转曲面面积
官方题面翻译可离线作答

双曲正弦（\(\sinh\)）、双曲余弦（\(\cosh\)）、悬链线与悬链面。

  1. a) 证明：i) \(\frac{d}{dx} \sinh x = \cosh x\)，\(\frac{d}{dx} \cosh x = \sinh x\)；ii) \(\cosh^2 x = 1 + \sinh^2 x\)；iii) \(\cosh^2 x = \frac{1 + \cosh 2x}{2}\)。
  2. b) 参数方程 \(x = \cosh t\)，\(y = \sinh t\) 表示什么曲线？（给出方程与名称。）
  3. c) 曲线 \(y = \cosh x\) 称为悬链线（catenary）。i) 画出其大致图像。ii) 求从最低点 \((0,1)\) 到点 \((x_1, \cosh x_1)\) 的弧长，其中 \(x_1 > 0\) 固定。
  4. d) 将 (c) 中的曲线段绕 \(x\) 轴旋转，求生成的旋转曲面面积。该曲面称为悬链面（catenoid）。

公式与已知条件

  • \(\cosh x = \frac{e^x + e^{-x}}{2}\)
  • \(\sinh x = \frac{e^x - e^{-x}}{2}\)
  • \(\frac{d}{dx} \sinh x = \cosh x\)
  • \(\frac{d}{dx} \cosh x = \sinh x\)
  • \(\cosh^2 x = 1 + \sinh^2 x\)
  • \(\cosh^2 x = \frac{1 + \cosh 2x}{2}\)
解题入口

利用指数定义推导；弧长与旋转曲面面积使用标准公式。

完成后检查

  • 导数结果与恒等式一致；弧长与面积为正值。

题目 3 极坐标下的面积 极坐标 · 极坐标下的面积 · 坐标转换

用极坐标与直角坐标计算面积。

  2. b) 将曲线 \(r = \frac{1}{1 + \sin \theta}\) 转化为 \((x,y)\) 直角坐标方程，并画出其图像。

  • 三角恒等式：\(1 + \cos u = 2 \cos^2(u/2)\)

题目 1 洛必达法则与反常积分 洛必达法则 · 反常积分 · 比较判别法 · 分部积分 · Gamma 函数
官方题面翻译可离线作答

利用洛必达法则与比较判别法分析反常积分的收敛性，并推导 \(A(n)\) 的递推关系。

  1. a) 用洛必达法则求 \(\lim_{x \to \infty} x^m e^{-x}\)。
  2. b) 利用 (a) 及比较判别法证明：反常积分 \(\int_0^{\infty} x^n e^{-x}\,dx\) 对任意 \(n \ge 0\) 收敛。（不得使用分部积分。）
  3. c) 记 \(A(n) = \int_0^{\infty} x^n e^{-x}\,dx\)。用分部积分求常数 \(c_n\)，使得 \(A(n+1) = c_n A(n)\)。（利用 (a) 说明无穷远处的极限行为。）
  4. d) 求 \(A(0)\)，并由 (c) 推导出 \(A(n)\) 在 \(n = 0, 1, 2, \dots\) 时的表达式。
  5. e)（选做；额外 5 分）证明表示 \(A(-1/2)\) 的反常积分收敛，并用换元法求其值。

公式与已知条件

  • \(A(n) = \int_0^{\infty} x^n e^{-x}\,dx\)
  • 递推目标：\(A(n+1) = c_n A(n)\)
解题入口

(a) 改写为 \(x^m/e^x\) 再用洛必达法则；(c) 取 \(u = x^{n+1}\) 进行分部积分。

完成后检查

  • 递推关系应给出整数 \(n\) 时 \(A(n) = n!\)。

题目 2 球冠与肥皂泡 旋转体 · 球冠 · 表面积 · 优化
官方题面翻译可离线作答

求球冠的体积与表面积，并确定在体积固定时使表面积最小的肥皂泡形状。

  1. a) 证明：由半径为 \(r\)、高度为 \(h\) 的球冠（顶部）与水平平面（底部）所围成的旋转体体积为 \(V = \pi(rh^2 - h^3/3)\)。画出图形，并在 \(h = 0\)、\(h = r\)、\(h = 2r\) 三种情形下检验结果。设 \(0 \le h \le 2r\)。
  2. b) 证明：该球冠的曲面面积为 \(S = 2\pi rh\)。画出图形，并在 \(h = 0\)、\(h = r\)、\(h = 2r\) 三种情形下检验结果。
  3. c) 一个肥皂泡由上述球冠与底部水平圆盘组成。在体积 \(V\) 固定的条件下，求使总表面积最小的 \(r\) 与 \(h\) 的比值，并说明此时肥皂泡的形状。

公式与已知条件

  • 体积公式：\(V = \pi(rh^2 - h^3/3)\)
  • 高度范围：\(0 \le h \le 2r\)
解题入口

(a)(b) 由相应圆弧旋转得到；(c) 在体积约束下最小化表面积。

完成后检查

  • 体积与面积公式在 \(h=0\)、\(h=r\)、\(h=2r\) 时均能正确退化。
