考试范围

  • 逼近：线性逼近 \(L(x)=f(a)+f'(a)(x-a)\)、二次逼近 \(Q(x)=L(x)+\frac{f''(a)}{2}(x-a)^2\)。
  • 曲线绘图：用一阶导数判单调性、二阶导数判凹凸性，找出极值、拐点、渐近线。
  • 极值优化：列函数 → 求导找临界点 → 用二阶导数或端点检验确认最小/最大。
  • 相关变化率：隐式微分 + 几何/物理关系（梯子、影子、圆锥、探照灯）。
  • 中值定理：MVT 证明单调性、不等式（\(\ln(1+x)1+x\)）。
  • 微分方程：分离变量解初值问题（冷却定律、逻辑斯蒂型）。

核心公式与定理

中值定理（MVT）

若 \(f\) 在 \([a,b]\) 连续、在 \((a,b)\) 可导，则存在 \(c\in(a,b)\) 使得：

\[f'(c)=\frac{f(b)-f(a)}{b-a}\]

推论：若 \(f'(x)>0\) 对所有 \(x\) 成立，则 \(f\) 严格递增。

极值检验

  • 临界点：\(f'(x)=0\) 或 \(f'(x)\) 不存在。
  • 二阶导数检验：\(f'(x_0)=0\) 时，\(f''(x_0)>0\) → 极小，\(f''(x_0)<0\) → 极大。
  • 闭区间最值：比较临界点与端点的函数值。

牛顿法

\(\displaystyle x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\)，用于求方程 \(f(x)=0\) 的近似根。

冷却定律（牛顿冷却）

\(\displaystyle \frac{dT}{dt}=k(T_e-T)\)，解为 \(T(t)=T_e+(T_0-T_e)e^{-kt}\)。

代表性练习（来自 pre-exam 材料）

类型 A：曲线绘图（prexam2a/1, prexam2b/1）

对 \(f(x)=3x^5-5x^3+1\) 或 \(f(x)=2x^3+3x^2-12x+1\)，要求：

  • 求 \(f'(x)\)、\(f''(x)\)，找出临界点与拐点。
  • 列表判号：\(f'\) 正负 → 增减区间；\(f''\) 正负 → 凹凸区间。
  • 在坐标轴上描点绘图，标注极值与拐点坐标。

注意：不同坐标轴尺度（prexam2b 明确提示两轴比例不同），要按所给网格标注。

类型 B：极值优化（prexam2a/3, prexam2b/2）

「过点 \((1,2)\) 的负斜率直线在第一象限截出三角形，何时面积最小？」设斜率 \(m<0\)，直线 \(y-2=m(x-1)\)，与坐标轴交点：

\[x_{\text{int}}=1-\frac{2}{m},\qquad y_{\text{int}}=2-m\]

面积 \(A(m)=\frac12\cdot x_{\text{int}}\cdot y_{\text{int}}\)（取绝对值）。对 \(m\) 求导找临界点，用二阶导数或端点检验确认是最小值。

「NoKarb PopKorn 罐头体积固定 \(64\pi\)，何时用金属最少？」：设半径 \(r\)、高 \(h\)，体积 \(=\pi r^2 h=64\pi\)，表面积 \(=\pi r^2+2\pi r h\)（只有一个底面），消去 \(h\) 后对 \(r\) 求导。

优化题必须写「这是最小值」的论证：二阶导数正、或端点值比较、或函数只有一个临界点且问题本身存在最值。

类型 C：相关变化率（prexam2a/5, prexam2b/4）

「200 英尺树倒下，与水平成 30° 时影子伸长 50 ft/s，角度变化速率？」设树长 \(L=200\)，顶高 \(h=L\sin\theta\)，影长 \(x=L\cos\theta\)。

注意：\(\frac{dx}{dt}=L(-\sin\theta)\frac{d\theta}{dt}\)，代入 \(\theta=30^\circ\)、\(dx/dt=50\) 求 \(d\theta/dt\)。

「探照灯距墙 100 m，每 8 分钟转一圈，60° 角时囚犯跑多快？」角速度 \(\omega=2\pi/8=\pi/4\) rad/min，\(x=100\tan\theta\)，\(\frac{dx}{dt}=100\sec^2\theta\cdot\omega\)。

类型 D：MVT 不等式（prexam2a/8, prexam2b/6a）

「用 MVT 证 \(e^x>1+x\)（\(x>0\)）」：设 \(f(t)=e^t\)，在 \([0,x]\) 上 MVT 给出 \(\frac{e^x-1}{x}=e^c\)（\(c\in(0,x)\)）。因为 \(e^c>1\)，所以 \(e^x-1>x\)。

类型 E：微分方程（prexam2a/10,11, prexam2b/5b）

「解 \(\frac{dy}{dx}=xy+x\)，\(y(0)=1\)」：分离变量 \(\frac{dy}{y+1}=x\,dx\)，积分得 \(\ln|y+1|=\frac{x^2}{2}+C\)，由初值定 \(C\)。

「鱼从 20°C 放入 100°C 水，5 分钟后 30°C，何时到 60°C？」设 \(T(t)\) 满足冷却定律，\(T_e=100\)，\(T(0)=20\)，\(T(5)=30\)，先求 \(k\) 再解 \(T(t)=60\)。

类型 F：逼近（prexam2a/7, prexam2b/5a）

「选 \(\varepsilon\) 使 \(f(x)=\frac{e^{-x}}{1+2\sin x}\) 在 \(x\approx 0\) 时尽量接近 1」：在 \(x=0\) 处展开，\(f(0)=1\)，要求 \(f'(0)=0\) 以消除一阶偏差，解出 \(\varepsilon\)。然后用该值估计 \(f(0.1)\)。

常见陷阱

  • 优化题漏写「这是最值」论证：Exam 2 明确要求「show it is a minimum」。
  • 相关变化率符号：树高减少时 \(dh/dt<0\)，注意链式法则中的负号。
  • MVT 不等式方向：\(\frac{f(b)-f(a)}{b-a}=f'(c)\) 中，若 \(f'>0\) 则 \(f(b)>f(a)\)。
  • 冷却定律环境温度 vs. 初值：\(T_e=100\)、\(T_0=20\)，不要代反。
  • 探照灯角速度单位：每 8 分钟一圈 = \(\pi/4\) rad/min，不是 1/8。

自测小结

绘图

\(f'\) 判增减，\(f''\) 判凹凸，列表系统化。

优化

列函数 → 求导 → 临界点 → 论证最值。

相关变化率

隐式微分 + 几何关系，注意符号。

MVT

MVT 把函数差转为导数，用于不等式。

题目 3 优化问题：三角形围栏 优化（Optimization） · 面积最大化（Maximizing area） · 极大值的导数检验
官方题面翻译可离线作答

一位建筑师计划建造一个三角形围栏，两条栅栏边共用一个顶点，该顶点恰好位于第三边（借用一堵墙）的正对面，且这两条栅栏边的长度均固定为 \(L\)。设第三边的长度为 \(x\)（\(0 < x < 2L\)）。 1. 将围成的区域面积 \(A\) 表示为 \(x\) 的函数； 2. 求使面积最大的第三边长度 \(x\)； 3. 给出论证，说明你的答案确实给出最大面积（例如利用二阶导数符号或端点比较）。

公式与已知条件

  • 两条栅栏边长度均为 \(L\)
  • 第三边（墙）长度为 \(x\)
  • 由几何关系可得高 \(h = \sqrt{L^2 - \left(\frac{x}{2}\right)^2}\)
  • 面积 \(A(x) = \frac{1}{2} x \sqrt{L^2 - \frac{x^2}{4}}\)
  • 定义域 \(0 < x < 2L\)
解题入口

将面积表示为单一变量的函数，利用微积分求其最大值。

完成后检查

  • 需给出论证说明所得答案给出最大面积（如二阶导数符号或端点比较）。

题目 6 拉格朗日中值定理估计 拉格朗日中值定理（Mean Value Theorem, MVT） · 函数的界（Bounds on functions）
官方题面翻译可离线作答

设 \(f'(x) = e^{x^2}\)，且 \(f(0) = 10\)。根据拉格朗日中值定理（Mean Value Theorem, MVT），可以得出 \(A < f(1) < B\)。求 \(A\) 和 \(B\) 的值。

公式与已知条件

  • \(f'(x) = e^{x^2}\)
  • \(f(0) = 10\)
  • \(\text{MVT: } f(1) - f(0) = f'(c)(1 - 0)\)，其中 \(c \in (0, 1)\)
解题入口

在区间 \([0, 1]\) 上应用拉格朗日中值定理，利用 \(e^{x^2}\) 的单调性给出 \(f'(c)\) 的上下界。

完成后检查

  • \(e^{x^2}\) 在 \([0, 1]\) 上单调递增。
