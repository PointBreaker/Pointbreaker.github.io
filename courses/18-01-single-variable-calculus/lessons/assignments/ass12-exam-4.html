考试范围

Exam 4 是积分技巧的专考。随卷公式表给出基本三角恒等式与少数积分公式，但不会告诉你「该用什么技巧」——技巧选择仍是考点。

  • 三角换元：\(\sqrt{a^2-x^2}\to x=a\sin u\)，\(\sqrt{a^2+x^2}\to x=a\tan u\)，\(\sqrt{x^2-a^2}\to x=a\sec u\)。
  • 三角积分：\(\int\sin^m x\cos^n x\,dx\)、\(\int\tan^n x\,dx\) 递推、\(\int\sec x\,dx\)。
  • 部分分式：有理函数 \(P/Q\) 系统积分——先长除（若 \(\deg P\ge\deg Q\)），再分解，逐项积分。
  • 分部积分：\(\int u\,dv=uv-\int v\,du\)，选 \(u\) 的 LIATE 原则。
  • 弧长与面积：\(ds=\sqrt{1+(dy/dx)^2}\,dx\)，旋转面 \(2\pi y\,ds\)（绕 \(x\) 轴）。
  • 极坐标面积：\(\frac12\int r^2\,d\theta\)，注意 \(\theta\) 范围避免重复计数。

技巧决策与示例

三角换元后的「回代」

做完三角换元得到 \(\int f(\theta)\,d\theta\) 后，必须用直角三角形把 \(\theta\) 函数换回 \(x\)。例如 \(x=a\sin u\) 时，对边 \(=x\)、斜边 \(=a\)、邻边 \(=\sqrt{a^2-x^2}\)，所以 \(\sin u=x/a\)、\(\cos u=\sqrt{a^2-x^2}/a\)。

有理函数积分系统流程

例：\(\displaystyle\int\frac{x^3}{x^2-2x+1}\,dx\)。

  1. 长除：\(\deg P=3\ge\deg Q=2\)，做除法：\(\displaystyle\frac{x^3}{x^2-2x+1}=x+2+\frac{3x-2}{(x-1)^2}\)。
  2. 部分分式：\(\displaystyle\frac{3x-2}{(x-1)^2}=\frac{3}{x-1}+\frac{1}{(x-1)^2}\)。
  3. 逐项积分：\(\displaystyle\int(x+2)\,dx+\int\frac{3}{x-1}\,dx+\int\frac{1}{(x-1)^2}\,dx\)。

对于分母含不可约二次因子（如 \(x^2+9\)），部分分式项 \(\frac{Cx+D}{x^2+9}\) 的积分仍需三角换元 \(x=3\tan u\)。

分部积分的 LIATE 原则

选 \(u\) 的优先级：Logarithmic（对数）→ Inverse trig（反三角）→ Algebraic（代数）→ Trig（三角）→ Exponential（指数）。例如 \(\int x^2 e^x\,dx\)：\(u=x^2\)（代数），\(dv=e^x\,dx\)。

弧长与旋转面面积

参数曲线 \(x=x(t),\ y=y(t)\) 的弧长：

\[s=\int_{t_0}^{t_1}\sqrt{(dx/dt)^2+(dy/dt)^2}\,dt\]

绕 \(x\) 轴旋转的表面积：\(A=\int 2\pi y\,ds\)。绕 \(y\) 轴则 \(2\pi x\,ds\)。注意：公式要求你已知 \(y=y(x)\) 或 \(x=x(y)\) 的形式，否则要调整。

极坐标面积的范围陷阱

求 \(\frac12\int r^2\,d\theta\) 时，\(\theta\) 的范围必须使曲线恰好扫过区域一次。例如 \(r=\cos\theta\) 的圆在 \(\theta\in[-\pi/2,\pi/2]\) 扫过一次；若取 \([0,2\pi]\) 会重复计数。

常见陷阱

  • 三角换元后忘回代：最终答案必须是 \(x\) 的函数，不能停留在 \(\theta\)。
  • 有理函数不先长除：\(\deg P\ge\deg Q\) 时直接部分分式会出错。
  • 部分分式漏项：\((x-1)^2\) 要拆成 \(\frac{A}{x-1}+\frac{B}{(x-1)^2}\)，不能只写一项。
  • 分部积分选错 \(u\)：\(\int x\ln x\,dx\) 选 \(u=\ln x\)（对数优先），不是 \(u=x\)。
  • 极坐标面积 \(\theta\) 范围：画图确认扫过区域，避免重复或遗漏。

题目 1 三角换元与三角积分 三角换元 · 三角积分 · 直角三角形回代
官方题面翻译可离线作答

通过三角换元进行积分，计算三角积分后借助直角三角形（即 \(\text{trig}(\text{trig}^{-1})\) 的关系）回代到原变量。

  1. a) 对形如 \(\sqrt{a^2 - x^2}\) 的根式，令 \(x = a \sin u,\; dx = a \cos u\, du\)。
  2. b) 对形如 \(\sqrt{a^2 + x^2}\) 的根式，令 \(x = a \tan u,\; dx = a \sec^2 u\, du\)。
  3. c) 对形如 \(\sqrt{x^2 - a^2}\) 的根式，令 \(x = a \sec u,\; dx = a \sec u \tan u\, du\)。

公式与已知条件

  • 对 \(a^2 - x^2\) 型使用 \(x = a \sin u\)
  • 对 \(a^2 + x^2\) 型使用 \(x = a \tan u\)
  • 对 \(x^2 - a^2\) 型使用 \(x = a \sec u\)
  • 公式表：\(\sin^2 x + \cos^2 x = 1\)；\(\sec^2 x = \tan^2 x + 1\)
  • 公式表：\(\sin^2 x = \tfrac{1}{2}(1 - \cos 2x)\)；\(\cos^2 x = \tfrac{1}{2}(1 + \cos 2x)\)
  • 公式表：\(\cos 2x = \cos^2 x - \sin^2 x\)；\(\sin 2x = 2 \sin x \cos x\)
解题入口

根据根式形式选取对应的换元。在 \(u\) 积分完成后，画一个直角三角形把结果换回 \(x\)。

完成后检查

  • 确认每种根式形式配对了正确的换元方式
  • 通过三角形验证回代是否正确

本题为官方题面翻译，公式与换元形式均按原资料呈现。

题目 2 部分分式（有理函数） 部分分式 · 多项式长除法 · 配方法 · 有理函数积分
官方题面翻译可离线作答

用部分分式法积分有理函数 \(P/Q\)。若 \(\deg(P) \ge \deg(Q)\)，先做长除法。把分母 \(Q\) 完全分解为一次因子与二次不可约因子，再拆分为部分分式之和。

  1. 示例形式：\(\frac{3x^2 + 1}{(x - 1)(x + 2)^2(x^2 + 9)} = \frac{A}{x - 1} + \frac{B_1}{x + 2} + \frac{B_2}{(x + 2)^2} + \frac{Cx + D}{x^2 + 9}\)
  2. 形如 \(\frac{D}{x^2 + 9}\) 的项可通过三角换元 \(x = 3 \tan u\) 积分。

公式与已知条件

  • 一次因子对应 \(\frac{A}{(x - a)^k}\)，不可约二次因子对应 \(\frac{ax + b}{(\text{二次式})^k}\)
  • 配方：\(x^2 + 4x + 13 = (x + 2)^2 + 9 = u^2 + a^2\)，其中 \(u = x + 2,\; a = 3\)
  • 当 \(\deg(P) \ge \deg(Q)\) 时作长除法：\(P/Q = P_1 + R/Q\)，且 \(\deg(R) < \deg(Q)\)
解题入口

先比较分子与分母的次数，必要时作长除法；再分解分母，设出部分分式形式，求系数（可用覆盖法）。逐项积分即可。

完成后检查

  • 长除法后确认 \(\deg(R) < \deg(Q)\)
  • 代回原式验证各系数满足分解

题目 3 分部积分 分部积分
官方题面翻译可离线作答

应用分部积分公式：\(\int u\, dv = uv - \int v\, du\)；定积分形式为 \(\int_a^b u\, dv = [uv]_a^b - \int_a^b v\, du\)。当 \(\int v\, du\) 比 \(\int u\, dv\) 更简（常因 \(du\) 比 \(u\) 更简）时使用。

公式与已知条件

  • \(\int u\, dv = uv - \int v\, du\)
  • 定积分形式：\(\int_a^b u\, dv = [uv]_a^b - \int_a^b v\, du\)
解题入口

把求导后会简化的部分（如 \(\ln x\)、多项式、反三角函数）取为 \(u\)；把容易积分的剩余部分取为 \(dv\)。

完成后检查

  • 确认新积分 \(\int v\, du\) 比原积分更简单

本题为官方题面翻译。

题目 4 弧长与旋转曲面面积 弧长 · 旋转曲面面积
官方题面翻译可离线作答

利用相应的弧长微分 \(ds\) 计算平面曲线的弧长与旋转曲面面积。

  1. 弧长：\(ds = \sqrt{dx^2 + dy^2}\)；\(ds = \sqrt{1 + (dy/dx)^2}\, dx\)；\(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\, dt\)；\(ds = \sqrt{(dx/dy)^2 + 1}\, dy\)
  2. 绕 \(x\) 轴旋转的曲面面积：\(2\pi y\, ds = 2\pi y \sqrt{1 + (dy/dx)^2}\, dx\)（需已知 \(y = y(x)\)）
  3. 绕 \(y\) 轴旋转的曲面面积：\(2\pi x\, ds = 2\pi x \sqrt{(dx/dy)^2 + 1}\, dy\)（需已知 \(x = x(y)\)）

公式与已知条件

  • \(ds = \sqrt{1 + (dy/dx)^2}\, dx\)
  • \(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\, dt\)
  • 绕 \(x\) 轴：\(S_x = 2\pi \int y \sqrt{1 + (dy/dx)^2}\, dx\)
  • 绕 \(y\) 轴：\(S_y = 2\pi \int x \sqrt{(dx/dy)^2 + 1}\, dy\)
解题入口

先确定积分变量并选取对应的 \(ds\) 公式；计算曲面面积时再乘以 \(2\pi\) 倍的半径（即垂直于旋转轴的坐标）。

完成后检查

  • 确认半径项正确（绕 \(x\) 轴用 \(y\)，绕 \(y\) 轴用 \(x\)）
  • 确认 \(ds\) 与积分变量匹配

本题为官方题面翻译。

题目 5 极坐标 极坐标 · 坐标转换 · 极坐标曲线描绘
官方题面翻译可离线作答

运用极坐标：\(x = r \cos \theta,\; y = r \sin \theta\)（以及 \(r = \sqrt{x^2 + y^2},\; \theta = \tan^{-1}(y/x)\)）。通过代换把直角坐标方程化为极坐标方程，并能描绘极坐标曲线。

  1. a) 把已知直角坐标方程的曲线通过代换化为极坐标方程。
  2. b) 描绘给定极坐标方程的曲线，并确定合适的 \(\theta\) 取值范围（常为积分做准备）。

公式与已知条件

  • \(x = r \cos \theta\)
  • \(y = r \sin \theta\)
  • \(r = \sqrt{x^2 + y^2}\)
  • \(\theta = \tan^{-1}(y/x)\)
解题入口

把 \(x = r \cos \theta\) 与 \(y = r \sin \theta\) 代入直角坐标方程得到极坐标形式；描绘曲线时考虑对称性以及能恰好描出一次曲线的 \(\theta\) 范围。

完成后检查

  • 代换后确认得到合法的极坐标方程
  • 确认 \(\theta\) 范围不重复计数也不遗漏区域

本题为官方题面翻译。

题目 6 极坐标下的面积 极坐标面积积分
官方题面翻译可离线作答

利用 \(A = \int_{\theta_1}^{\theta_2} \tfrac{1}{2} r^2\, d\theta\) 计算极坐标曲线所围成的面积。注意 \(\theta\) 的取值范围，避免重复计数或遗漏区域。

公式与已知条件

  • \(A = \int_{\theta_1}^{\theta_2} \tfrac{1}{2} r^2\, d\theta\)
解题入口

确定恰好描出该区域一次的 \(\theta\) 区间，再在该区间上积分 \(\tfrac{1}{2} r(\theta)^2\)。

完成后检查

  • 确认上下限描出该区域一次且无重叠

题目 7 参数方程（弧长） 参数方程 · 参数形式弧长
依据本地资料重建可离线作答

关于参数方程需要掌握：使用 \(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\, dt\) 计算弧长。重建例题：已知 \(x(t) = t^4,\; y(t) = 1 + t\)，求该参数曲线在给定区间上的弧长 \(s\)（具体上下限在具体题目中给出）。

  1. 示例：\(x(t) = t^4,\; y(t) = 1 + t\)，则 \(dx/dt = 4t^3,\; dy/dt = 1\)，从而 \(ds = \sqrt{(4t^3)^2 + 1^2}\, dt\)，再对 \(t\) 积分。

公式与已知条件

  • \(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\, dt\)
  • 示例导数：\(dx/dt = 4t^3,\; dy/dt = 1\)
解题入口

先求出 \(dx/dt\) 与 \(dy/dt\)，写出 \(ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\, dt\)，再在给定的 \(t\) 区间上积分。

完成后检查

  • 确认导数计算正确
  • 验证 \(ds\) 表达式无误
