Problem Set 5：面积与体积

温度冷却模型、 Fresnel 积分 \(\int\cos(t^2)dt\) 的图像分析、以及一个由不等式 \(\frac{z^2}{2}

类型：Problem Set 5（Part I + Part II） 截止：2006-10-27 13:55 覆盖：Lecture 21, 22（Part I 含 Lecture 19–20）

学习目标

  • 用分离变量解指数增长/冷却模型，用定积分表示「冷却度日数 (cooling degree days)」。
  • 分析无法用初等函数表达的积分 \(\int\cos(t^2)dt\)（Fresnel 积分），用 FTC 判断极值、拐点、奇偶性。
  • 熟练运用柱壳法（shells）与圆盘法（disks）计算旋转体体积。
  • 通过换元把反常积分与 Fresnel 积分相互转化。

  • 第 20 课：第二基本定理——FTC2、\(\ln x\) 定义。
  • 第 21 课：面积与切片体积——面积、旋转体体积。
  • 第 22 课：圆盘与柱壳——两种体积方法的选择。

  • Part II（30 分 + 5 额外）：3 道大题——温度模型、Fresnel 积分、不等式区域体积。

主题梳理与示例

1. 温度模型与冷却度日数（Part II/1）

Boston 温度满足 \(y'(t)=y(t)/100\)，初值 \(y(0)=65\)°F。分离变量：

\[\frac{dy}{y}=\frac{dt}{100}\quad\Longrightarrow\quad \ln y=\frac{t}{100}+C\]

由 \(y(0)=65\) 得 \(y(t)=65e^{t/100}\)。连续平均值定义：\(\frac{1}{b-a}\int_a^b y\,dt\)。冷却度日数 = 每日平均温度减去 65 的总和，用面积表示为：

\[\text{CDD}=65\cdot 50-\int_0^{50}y(t)\,dt=3250-\int_0^{50}65e^{t/100}\,dt\]

第 (c) 小题（额外学分）要求用黎曼和直接算这个积分，与 PS4 的 \(e^x\) 黎曼和做法类似，再次凸显 FTC 的威力。

2. Fresnel 积分 \(\displaystyle f(x)=\int_0^x\cos(t^2)\,dt\)（Part II/2）

这是无法用初等函数表达的积分。关键问题：

  • 奇偶性：\(\cos(t^2)\) 是偶函数，所以 \(f(x)\) 是奇函数。
  • 临界点：由 FTC2，\(f'(x)=\cos(x^2)\)，零点在 \(x^2=\pi/2+k\pi\)，即 \(x=\pm\sqrt{\pi/2},\,\pm\sqrt{3\pi/2},\dots\)。
  • 极值/拐点：\(f''(x)=-2x\sin(x^2)\)，符号变化给出拐点位置。
  • 估值：\(f(0.1)\approx\int_0^{0.1}(1-t^2/2+t^4/24-\cdots)\,dt\approx 0.1-0.001/6\)。

第 (e) 小题用换元把 \(f\) 与标准 Fresnel 积分 \(g(x)=\int_0^x\cos(\frac{\pi}{2}u^2)\,du\) 以及反常积分 \(\int_0^x\frac{\cos v}{\sqrt{v}}\,dv\) 联系起来：

\[f(x)=c_1\,g(c_2x),\qquad f(x)=c\,h(x^2)\]

Fresnel 积分是「积分存在但原函数非初等」的典型例子，在光学（衍射）中有重要应用。

3. 不等式区域体积（Part II/3）

区域 \(x>0,y>0,z>0\)，满足 \(\frac{z^2}{2}0\)、\(y>0\)、\(\frac{z^2}{2} \[A(z)=\frac12 z^2-\frac12\left(\frac{z^2}{2}\right)^2\quad\text{（需确认边界交点）}\]

体积 \(V=\int_0^2 A(z)\,dz\)（\(z\) 的范围由 \(x+yz^2/2\) 的相容性决定）。

常见坑

  • 冷却度日数符号：是「平均温度 - 65」的总和，65 减去积分对应面积差。
  • Fresnel 积分奇偶性：被积函数偶 → 积分奇，不要搞反。
  • 体积方法选择：绕 \(y\) 轴旋转时，若函数是 \(y=f(x)\)，通常柱壳（\(dx\)）更方便；绕 \(x\) 轴则圆盘（\(dy\)）。
  • 反常积分收敛：\(\int_0^1\frac{\cos v}{\sqrt{v}}\,dv\) 在 0 处被积函数无界，但积分收敛（比较 \(1/\sqrt{v}\)）。

知识检查

问题 2：\(f(x)=\int_0^x\cos(t^2)\,dt\) 的第一个正临界点是？

问题 3：\(f(x)=\int_0^x\cos(t^2)\,dt\) 的奇偶性是？

自测小结

指数模型

\(y'=ky\) → \(y=y_0e^{kt}\)，冷却度日数用面积差表示。

Fresnel 积分

非初等原函数，用 FTC 分析极值/拐点/奇偶。

体积方法

圆盘 vs. 柱壳：由旋转轴与函数形式决定。

反常积分

\(\int\frac{\cos v}{\sqrt{v}}\,dv\) 在 0 无界但收敛。
