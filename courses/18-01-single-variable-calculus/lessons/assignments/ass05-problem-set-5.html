主题梳理与示例

1. 温度模型与冷却度日数（Part II/1）

Boston 温度满足 \(y'(t)=y(t)/100\)，初值 \(y(0)=65\)°F。分离变量：

\[\frac{dy}{y}=\frac{dt}{100}\quad\Longrightarrow\quad \ln y=\frac{t}{100}+C\]

由 \(y(0)=65\) 得 \(y(t)=65e^{t/100}\)。连续平均值定义：\(\frac{1}{b-a}\int_a^b y\,dt\)。冷却度日数 = 每日平均温度减去 65 的总和，用面积表示为：

\[\text{CDD}=\int_0^{50}y(t)\,dt-65\cdot 50=\int_0^{50}65e^{t/100}\,dt-3250\]

第 (c) 小题（额外学分）要求用黎曼和直接算这个积分，与 PS4 的 \(e^x\) 黎曼和做法类似，再次凸显 FTC 的威力。

2. Fresnel 积分 \(\displaystyle f(x)=\int_0^x\cos(t^2)\,dt\)（Part II/2）

这是无法用初等函数表达的积分。关键问题：

  • 奇偶性：\(\cos(t^2)\) 是偶函数，所以 \(f(x)\) 是奇函数。
  • 临界点：由 FTC2，\(f'(x)=\cos(x^2)\)，零点在 \(x^2=\pi/2+k\pi\)，即 \(x=\pm\sqrt{\pi/2},\,\pm\sqrt{3\pi/2},\dots\)。
  • 极值/拐点：\(f''(x)=-2x\sin(x^2)\)，符号变化给出拐点位置。
  • 估值：\(f(0.1)\approx\int_0^{0.1}(1-t^2/2+t^4/24-\cdots)\,dt\approx 0.1-0.001/6\)。

第 (e) 小题用换元把 \(f\) 与标准 Fresnel 积分 \(g(x)=\int_0^x\cos(\frac{\pi}{2}u^2)\,du\) 以及反常积分 \(\int_0^x\frac{\cos v}{\sqrt{v}}\,dv\) 联系起来：

\[f(x)=c_1\,g(c_2x),\qquad f(x)=c\,h(x^2)\]

Fresnel 积分是「积分存在但原函数非初等」的典型例子，在光学（衍射）中有重要应用。

3. 不等式区域体积（Part II/3）

区域 \(x>0,y>0,z>0\)，满足 \(\frac{z^2}{2}0\)、\(y>0\)、\(\frac{z^2}{2} \[A(z)=\frac12 z^2-\frac12\left(\frac{z^2}{2}\right)^2\quad\text{（需确认边界交点）}\]

体积 \(V=\int_0^2 A(z)\,dz\)（\(z\) 的范围由 \(x+yz^2/2\) 的相容性决定）。

常见坑

  • 冷却度日数符号：是「平均温度 - 65」的总和，因此应由温度曲线下的积分减去 (65\cdot 50)。
  • Fresnel 积分奇偶性：被积函数偶 → 积分奇，不要搞反。
  • 体积方法选择：绕 \(y\) 轴旋转时，若函数是 \(y=f(x)\)，通常柱壳（\(dx\)）更方便；绕 \(x\) 轴则圆盘（\(dy\)）。
  • 反常积分收敛：\(\int_0^1\frac{\cos v}{\sqrt{v}}\,dv\) 在 0 处被积函数无界，但积分收敛（比较 \(1/\sqrt{v}\)）。

以下为一组关于微积分第一基本定理与积分性质的站内等价练习。

  1. （等价练习 A）设 \(f(x) = \int_{0}^{x} (3t^{2} + 2t)\,dt\)。利用微积分第一基本定理求 \(f'(x)\)，并计算 \(f(1)\)。
  2. （等价练习 B）设 \(g(x) = \int_{0}^{x} \sin(t^{2})\,dt\)。求 \(g'(x)\) 以及 \(g'(\sqrt{\pi})\) 的值。
  3. （等价练习 C）计算定积分 \(\int_{0}^{1} (3x^{2} + 2x)\,dx\)，并求函数 \(h(x) = 3x^{2} + 2x\) 在区间 \([0,2]\) 上的平均值。
  4. （等价练习 D）利用换元法计算 \(\int_{1}^{2} 2x\,e^{x^{2}}\,dx\)。

公式与已知条件

  • 第一基本定理：若 \(f\) 连续，则 \(\frac{d}{dx}\int_{a}^{x} f(t)\,dt = f(x)\)。
  • 函数在 \([a,b]\) 上的平均值：\(\frac{1}{b-a}\int_{a}^{b} f(x)\,dx\)。
  • 定积分的线性性质：\(\int_{a}^{b} (\alpha f + \beta g) = \alpha\int_{a}^{b} f + \beta\int_{a}^{b} g\)。
解题入口

对练习 A、B 直接使用第一基本定理；对练习 C 先用幂函数积分公式再用平均值定义；对练习 D 令 \(u = x^{2}\)。

完成后检查

  • 练习 A：用幂函数积分直接求 \(f(x)\) 再求导，与定理结果对照。
  • 练习 D：代换后核对微分关系 \(du = 2x\,dx\) 与积分上下限。
  • 练习 C：检查平均值是否落在 \(h\) 于 \([0,2]\) 上的最小值与最大值之间。

  1. （等价练习 A）设 \(f(x) = \int_{1}^{x} \frac{1}{t}\,dt\)（\(x > 0\)）。利用第二基本定理求 \(f'(x)\)，并说明 \(f(x)\) 为何恰好是自然对数 \(\ln x\)。

  3. （等价练习 C）利用第二基本定理求 \(\frac{d}{dx}\ln(x^{2} + 1)\)，并求函数 \(\ln(x^{2} + 1)\) 在区间 \([0, e-1]\) 上的平均值。

  • 练习 C：检查平均值是否介于 \(\ln(x^{2} + 1)\) 在 \([0, e-1]\) 上的最小值与最大值之间。

  • 等价练习 (a)：区域 \(x > 0\)、\(y > 0\)、\(0 < x + y < 1\)，顶面 \(z = 1 - (x + y)\)。
  • 区域 (b)：\(x > 0\)、\(y > 0\)、\(z > 0\)，且 \(\frac{z^{2}}{2} < x + y < z\)。
  • 截面法体积：\(V = \int \text{截面面积}(z)\,dz\)。
解题入口

先求水平截面的面积，再对 \(z\) 积分。

完成后检查

  • 验证 (b) 中 \(z\) 的取值范围是否合理（由 \(\frac{z^{2}}{2} < z\) 得 \(0 < z < 2\)）。
  • 通过积分截面面积核对体积计算。
