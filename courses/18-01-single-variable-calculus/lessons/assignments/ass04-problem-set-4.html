Problem Set 4：定积分与基本定理

从平均值定理推导 \(\ln(1+x)\) 的逐阶不等式，到不定积分的多样表达、微分方程初值问题，再到用黎曼和直接算出 \(\int_0^1 e^x dx\)——本作业横跨 Lecture 14–20，把中值定理、微积分基本定理（FTC）与定积分定义第一次放在一起使用。

主题梳理与示例

1. MVT 证明 \(\ln(1+x)\) 不等式（Part II/1）

已知 \(f(0)=0\)、\(f'(x)\ge 0\)，由 MVT：对 \(x>0\) 存在 \(c\in(0,x)\) 使得：

\[f(x)=f(0)+f'(c)x=f'(c)x\ge 0\]

取 \(f(x)=x-\ln(1+x)\)，则 \(f'(x)=1-1/(1+x)=x/(1+x)\ge 0\)（\(x\ge 0\)），于是 \(\ln(1+x)\le x\)。

第 (c) 小题逐阶推进：\(\ln(1+x)\ge x-x^2/2\)、\(\ln(1+x)\le x-x^2/2+x^3/3\)，用 \(f(x)=\ln(1+x)-(x-x^2/2)\) 等函数。第 (d) 要求归纳出一般规律——交错级数：

\[\ln(1+x)=\sum_{n=1}^\infty(-1)^{n-1}\frac{x^n}{n},\qquad 0

这是 MVT 证明不等式的标准套路：构造辅助函数 → 求导判号 → 由 \(f(0)\) 确定符号方向。

2. 不定积分的多样表达（Part II/2）

验证 \(\displaystyle\int\tan x\sec^2 x\,dx=\frac12\tan^2 x\) 与 \(\displaystyle=\frac12\sec^2 x\) 都正确。关键恒等式：\(\sec^2 x=1+\tan^2 x\)，所以两个原函数只差常数 \(1/2\)。这说明不定积分的「正确形式」不唯一。

5. 黎曼和算 \(\int_0^1 e^x dx\)（Part II/5）

把 \([0,1]\) 分成 \(n\) 等份，\(\Delta x=1/n\)，取下黎曼和：

\[L_n=\sum_{k=0}^{n-1} e^{k/n}\cdot\frac1n=\frac1n\sum_{k=0}^{n-1}(e^{1/n})^k=\frac1n\cdot\frac{e-1}{e^{1/n}-1}\]

取极限 \(n\to\infty\)，需要：

\[\lim_{n\to\infty}n(e^{1/n}-1)=\lim_{h\to 0}\frac{e^h-1}{h}=1\]

于是：

\[\int_0^1 e^x dx=\lim_{n\to L_n}=e-1\]

这道题让你亲手感受「没有 FTC 时算积分有多麻烦」——从而体会基本定理的价值。

6. 星形线的微分方程（Part II/6，额外学分）

设切线在第一象限的线段长为 \(L\)。切线过 \((x_0,y_0)\)、斜率 \(m_0=y'\)，与坐标轴交点给出的线段长平方：

\[L^2=\left(x_0-\frac{y_0}{m_0}\right)^2+(y_0-m_0x_0)^2=(x_0-y_0/y')^2+(y_0-y'x_0)^2\]

化简后令 \(y''\) 因子分解，得到 \((xy'-y)y''=0\)。解 \(xy'-y=0\) 得直线 \(y=Cx\)（退化）；解 \(y''=0\) 也得直线；真正非平凡解来自约束，最终可验证 \(x^{2/3}+y^{2/3}=L^{2/3}\) 满足方程。

常见坑

  • MVT 不等式方向：\(f'(x)\ge 0\) 给出 \(f(x)\ge f(0)\)，注意是「\(\ge\)」不是「\(\le\)」。
  • 不定积分忘加常数或误判唯一：\(\frac12\tan^2x\) 与 \(\frac12\sec^2x\) 只差常数，都对。
  • 黎曼和几何级数求和出错：\(\sum_{k=0}^{n-1} r^k=(r^n-1)/(r-1)\)，注意项数是 \(n\) 不是 \(n-1\)。
  • 极限 \(n(e^{1/n}-1)\)：令 \(h=1/n\)，用标准极限 \((e^h-1)/h\to 1\)。

知识检查

问题 1：若 \(f(0)=0\)、\(f'(x)\ge 0\)（\(x\ge 0\)），则 MVT 直接推出？

问题 2：\(\frac12\tan^2x\) 与 \(\frac12\sec^2x\) 都是 \(\tan x\sec^2x\) 的原函数，原因是？

问题 3：用黎曼和算 \(\int_0^1 e^x dx\) 的极限结果是？

自测小结

MVT 不等式

辅助函数 + 判导符号 + 用 \(f(0)\) 定方向。

反导数族

原函数不唯一，差常数即都对。

黎曼和

几何级数求和 + 标准指数极限。

FTC 价值

没有基本定理时，算一个 \(e^x\) 积分都很费劲。

题目 1 中值定理与不等式 中值定理 · 不等式 · \(\ln(1+x)\) 的泰勒/级数估计
官方题面翻译可离线作答

利用中值性质与单调性证明关于 \(\ln(1+x)\) 的不等式。

  1. a) 利用中值性质证明：若 \(f(0)=0\) 且 \(f'(x) \ge 0\)，则对所有 \(x \ge 0\) 都有 \(f(x) \ge 0\)。
  2. b) 由 (a) 推出：当 \(x \ge 0\) 时，\(\ln(1+x) \le x\)。提示：取 \(f(x)=x-\ln(1+x)\)。
  3. c) 采用与 (b) 相同的方法，证明当 \(x \ge 0\) 时，\(\ln(1+x) \ge x - x^2/2\) 且 \(\ln(1+x) \le x - x^2/2 + x^3/3\)。
  4. d) 观察 (b) 与 (c) 中的规律，提出一般猜想。
  5. e) 证明当 \(-1 < x \le 0\) 时，\(\ln(1+x) \le x\)。使用换元 \(u = -x\)。

公式与已知条件

  • \(f(0)=0\)，\(f'(x) \ge 0\)
  • 当 \(x \ge 0\) 时，\(\ln(1+x) \le x\)
  • 当 \(x \ge 0\) 时，\(\ln(1+x) \ge x - x^2/2\)
  • 当 \(x \ge 0\) 时，\(\ln(1+x) \le x - x^2/2 + x^3/3\)
  • 换元 \(u = -x\)
解题入口

构造辅助函数，利用中值定理判断导数符号以得到单调性，再代入端点值。对 (e) 把负 \(x\) 情形转化为正 \(x\) 情形。

完成后检查

  • (a) 检查单调性论证是否成立。
  • (b)–(c) 确认每个不等式方向与导数符号分析一致。
  • (d) 识别交错级数的规律。
  • (e) 确认换元处理定义域 \(-1 < x \le 0\) 无误。

题目 5 用下黎曼和计算定积分 定积分 · 黎曼和 · 几何级数 · 数列极限 · \(e^x\) 的线性近似
官方题面翻译可离线作答

利用下黎曼和计算 \(\int_0^1 e^x \,dx\)。先将黎曼和化为几何级数的形式，再利用指数函数的标准线性近似，求极限 \(\lim_{n\to\infty} n(e^{1/n} - 1)\)。

公式与已知条件

  • 积分：\(\int_0^1 e^x \,dx\)
  • 待求极限：\(\lim_{n\to\infty} n(e^{1/n} - 1)\)
  • \(e^x\) 在 0 附近的线性近似
解题入口

完成后检查

  • 取极限前先核对黎曼和表达式。
  • 确认极限计算得到预期值 \(e - 1\)。

题目 6 内摆线进一步讨论（附加分） 微分方程 · 切线段长度 · 内摆线 · 曲线族
官方题面翻译可离线作答

利用微分方程求如下曲线：其在第一象限内的切线段长度保持为定值。

  1. a) 设过点 \((x_0, y_0)\) 的直线斜率为 \(m_0\)，且该点位于第一象限。记 \(L\) 为该直线在第一象限内的长度。将 \(L^2\) 用 \(x_0\)、\(y_0\) 与 \(m_0\) 表示，不要展开或化简。
  2. b) 设 \(y = f(x)\) 是定义在 \(0 \le x \le L\) 上的曲线，满足 \(f(0) = L\)、\(f(L) = 0\)，且曲线上任一点的切线在第一象限内的长度均为 \(L\)。求 \(f\) 所满足的微分方程，用 \(L\)、\(x\)、\(y\) 与 \(y' = dy/dx\) 表示。不取平方根，使用 \(L^2\)；不要展开或化简。
  3. c) 将 (b) 中的方程对 \(x\) 求导，化简并写成（某式）\((x y' - y) y'' = 0\) 的形式。
  4. d) 证明 \(x^{2/3} + y^{2/3} = L^{2/3}\) 是 (c) 中方程的一组解。另外两组解 \(y'' = 0\) 与 \(x y' - y = 0\) 分别对应什么曲线？

公式与已知条件

  • 边界条件：\(f(0) = L\)，\(f(L) = 0\)
  • 切线长度 = \(L\)
  • 目标曲线：\(x^{2/3} + y^{2/3} = L^{2/3}\)
  • 微分形式：（某式）\((x y' - y) y'' = 0\)
解题入口

(a) 求切线截距后再算平方距离；(b) 在曲线上施加 \(L^2\) 为常数；(c) 求导并因式分解；(d) 逐因子讨论。

完成后检查

  • (a) 确认 \(L^2\) 表达式正确且未展开。
  • (b) 确认微分方程使用了 \(L^2\) 与给定变量。
  • (c) 确认因式分解与化简无误。
  • (d) 验证 \(x^{2/3} + y^{2/3} = L^{2/3}\) 满足方程，并对另外两类解族分类。
