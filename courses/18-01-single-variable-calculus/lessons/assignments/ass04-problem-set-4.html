主题梳理与示例

1. MVT 证明 \(\ln(1+x)\) 不等式（Part II/1）

已知 \(f(0)=0\)、\(f'(x)\ge 0\)，由 MVT：对 \(x>0\) 存在 \(c\in(0,x)\) 使得：

\[f(x)=f(0)+f'(c)x=f'(c)x\ge 0\]

取 \(f(x)=x-\ln(1+x)\)，则 \(f'(x)=1-1/(1+x)=x/(1+x)\ge 0\)（\(x\ge 0\)），于是 \(\ln(1+x)\le x\)。

第 (c) 小题逐阶推进：\(\ln(1+x)\ge x-x^2/2\)、\(\ln(1+x)\le x-x^2/2+x^3/3\)，用 \(f(x)=\ln(1+x)-(x-x^2/2)\) 等函数。第 (d) 要求归纳出一般规律——交错级数：

\[\ln(1+x)=\sum_{n=1}^\infty(-1)^{n-1}\frac{x^n}{n},\qquad 0

这是 MVT 证明不等式的标准套路：构造辅助函数 → 求导判号 → 由 \(f(0)\) 确定符号方向。

2. 不定积分的多样表达（Part II/2）

验证 \(\displaystyle\int\tan x\sec^2 x\,dx=\frac12\tan^2 x\) 与 \(\displaystyle=\frac12\sec^2 x\) 都正确。关键恒等式：\(\sec^2 x=1+\tan^2 x\)，所以两个原函数只差常数 \(1/2\)。这说明不定积分的「正确形式」不唯一。

5. 黎曼和算 \(\int_0^1 e^x dx\)（Part II/5）

把 \([0,1]\) 分成 \(n\) 等份，\(\Delta x=1/n\)，取下黎曼和：

\[L_n=\sum_{k=0}^{n-1} e^{k/n}\cdot\frac1n=\frac1n\sum_{k=0}^{n-1}(e^{1/n})^k=\frac1n\cdot\frac{e-1}{e^{1/n}-1}\]

取极限 \(n\to\infty\)，需要：

\[\lim_{n\to\infty}n(e^{1/n}-1)=\lim_{h\to 0}\frac{e^h-1}{h}=1\]

于是：

\[\int_0^1 e^x dx=\lim_{n\to L_n}=e-1\]

这道题让你亲手感受「没有 FTC 时算积分有多麻烦」——从而体会基本定理的价值。

6. 星形线的微分方程（Part II/6，额外学分）

设切线在第一象限的线段长为 \(L\)。切线过 \((x_0,y_0)\)、斜率 \(m_0=y'\)，与坐标轴交点给出的线段长平方：

\[L^2=\left(x_0-\frac{y_0}{m_0}\right)^2+(y_0-m_0x_0)^2=(x_0-y_0/y')^2+(y_0-y'x_0)^2\]

化简后令 \(y''\) 因子分解，得到 \((xy'-y)y''=0\)。解 \(xy'-y=0\) 得直线 \(y=Cx\)（退化）；解 \(y''=0\) 也得直线；真正非平凡解来自约束，最终可验证 \(x^{2/3}+y^{2/3}=L^{2/3}\) 满足方程。

常见坑

  • MVT 不等式方向：\(f'(x)\ge 0\) 给出 \(f(x)\ge f(0)\)，注意是「\(\ge\)」不是「\(\le\)」。
  • 不定积分忘加常数或误判唯一：\(\frac12\tan^2x\) 与 \(\frac12\sec^2x\) 只差常数，都对。
  • 黎曼和几何级数求和出错：\(\sum_{k=0}^{n-1} r^k=(r^n-1)/(r-1)\)，注意项数是 \(n\) 不是 \(n-1\)。
  • 极限 \(n(e^{1/n}-1)\)：令 \(h=1/n\)，用标准极限 \((e^h-1)/h\to 1\)。

知识检查

自测小结

MVT 不等式

辅助函数 + 判导符号 + 用 \(f(0)\) 定方向。

反导数族

原函数不唯一，差常数即都对。

黎曼和

几何级数求和 + 标准指数极限。

FTC 价值

没有基本定理时，算一个 \(e^x\) 积分都很费劲。

Problem 1 Mean-value theorem and inequalities Mean-value theorem · Inequalities · Taylor / series bounds for ln(1+x)

Use the mean value property and monotonicity arguments to prove inequalities for ln(1+x).

  1. a) Use the mean value property to show that if f(0) = 0 and f'(x) ≥ 0, then f(x) ≥ 0 for all x ≥ 0.
  2. b) Deduce from part (a) that ln(1 + x) ≤ x for x ≥ 0. Hint: use f(x) = x - ln(1 + x).
  3. c) Use the same method as in (b) to show ln(1 + x) ≥ x - x^2/2 and ln(1 + x) ≤ x - x^2/2 + x^3/3 for x ≥ 0.
  4. d) Find the pattern in (b) and (c) and make a general conjecture.
  5. e) Show that ln(1 + x) ≤ x for -1 < x ≤ 0. Use the change of variable u = -x.

公式与已知条件

  • f(0) = 0, f'(x) ≥ 0
  • ln(1 + x) ≤ x for x ≥ 0
  • ln(1 + x) ≥ x - x^2/2
  • ln(1 + x) ≤ x - x^2/2 + x^3/3
  • Change of variable u = -x
解题入口

Define an auxiliary function, check its derivative's sign via the mean value theorem to establish monotonicity, then evaluate at the boundary. For (e) transform the negative-x case to the positive case.

完成后检查

  • For (a), verify the monotonicity argument is valid.
  • For (b)-(c), confirm each inequality direction matches the derivative sign analysis.
  • For (d), identify the alternating-series pattern.
  • For (e), check the substitution handles the domain -1 < x ≤ 0 correctly.

Problem 5 Definite integral via lower Riemann sums Definite integrals · Riemann sums · Geometric series · Limit of a sequence · Linear approximation of e^x

Calculate ∫_0^1 e^x dx using lower Riemann sums. Sum a geometric series to get a usable formula for the Riemann sum. To take the limit, evaluate lim_(n→∞) n(e^(1/n) - 1) using the standard linear approximation to the exponential function.

公式与已知条件

  • Integral: ∫_0^1 e^x dx
  • Limit needed: lim_(n→∞) n(e^(1/n) - 1)
  • Linear approximation of e^x near 0
解题入口

Partition [0,1] into n equal subintervals, use left endpoints (lower sums since e^x is increasing), sum the resulting geometric series, then take n→∞ using the linear approximation e^(1/n) ≈ 1 + 1/n.

完成后检查

  • Confirm the Riemann sum formula is correct before taking the limit.
  • Verify the limit evaluation yields the expected value e - 1.

Problem 6 More about the hypocycloid (extra credit) Differential equations · Tangent line segment length · Hypocycloid · Curve families

Use differential equations to find the curve with the property that the portion of its tangent line in the first quadrant has fixed length.

  1. a) Suppose a line through (x0, y0) has slope m0 and the point is in the first quadrant. Let L denote the length of the portion of the line in the first quadrant. Calculate L^2 in terms of x0, y0 and m0. Do not expand or simplify.
  2. b) Suppose y = f(x) is a graph on 0 ≤ x ≤ L satisfying f(0) = L and f(L) = 0, such that the portion of each tangent line to the graph in the first quadrant has the same length L. Find the differential equation that f satisfies, in terms of L, x, y and y' = dy/dx. Don't take square roots; use L^2. Don't expand or simplify.
  3. c) Differentiate the equation in part (b) with respect to x. Simplify and write in the form (something)(x y' - y) y'' = 0.
  4. d) Show that one solution to the equation in part (c) is x^(2/3) + y^(2/3) = L^(2/3). What about the two other possibilities, namely those solving y'' = 0 and x y' - y = 0?

公式与已知条件

  • Boundary conditions: f(0) = L, f(L) = 0
  • Tangent length = L
  • Target curve: x^(2/3) + y^(2/3) = L^(2/3)
  • Differential form: (something)(x y' - y) y'' = 0
解题入口

For (a) compute intercepts of the tangent line and the squared distance; for (b) impose constant L^2 along the curve; for (c) differentiate and factor; for (d) test each factor.

完成后检查

  • For (a), confirm L^2 is correct without expanding.
  • For (b), verify the DE uses L^2 and the given variables.
  • For (c), confirm the factorization and simplification.
  • For (d), verify x^(2/3) + y^(2/3) = L^(2/3) satisfies the DE and classify the other solution families.
