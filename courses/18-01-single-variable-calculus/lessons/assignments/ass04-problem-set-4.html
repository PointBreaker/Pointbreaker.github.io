主题梳理与示例

1. MVT 证明 \(\ln(1+x)\) 不等式（Part II/1）

已知 \(f(0)=0\)、\(f'(x)\ge 0\)，由 MVT：对 \(x>0\) 存在 \(c\in(0,x)\) 使得：

\[f(x)=f(0)+f'(c)x=f'(c)x\ge 0\]

取 \(f(x)=x-\ln(1+x)\)，则 \(f'(x)=1-1/(1+x)=x/(1+x)\ge 0\)（\(x\ge 0\)），于是 \(\ln(1+x)\le x\)。

第 (c) 小题逐阶推进：\(\ln(1+x)\ge x-x^2/2\)、\(\ln(1+x)\le x-x^2/2+x^3/3\)，用 \(f(x)=\ln(1+x)-(x-x^2/2)\) 等函数。第 (d) 要求归纳出一般规律——交错级数：

\[\ln(1+x)=\sum_{n=1}^\infty(-1)^{n-1}\frac{x^n}{n},\qquad 0

这是 MVT 证明不等式的标准套路：构造辅助函数 → 求导判号 → 由 \(f(0)\) 确定符号方向。

2. 不定积分的多样表达（Part II/2）

验证 \(\displaystyle\int\tan x\sec^2 x\,dx=\frac12\tan^2 x\) 与 \(\displaystyle=\frac12\sec^2 x\) 都正确。关键恒等式：\(\sec^2 x=1+\tan^2 x\)，所以两个原函数只差常数 \(1/2\)。这说明不定积分的「正确形式」不唯一。

5. 黎曼和算 \(\int_0^1 e^x dx\)（Part II/5）

把 \([0,1]\) 分成 \(n\) 等份，\(\Delta x=1/n\)，取下黎曼和：

\[L_n=\sum_{k=0}^{n-1} e^{k/n}\cdot\frac1n=\frac1n\sum_{k=0}^{n-1}(e^{1/n})^k=\frac1n\cdot\frac{e-1}{e^{1/n}-1}\]

取极限 \(n\to\infty\)，需要：

\[\lim_{n\to\infty}n(e^{1/n}-1)=\lim_{h\to 0}\frac{e^h-1}{h}=1\]

于是：

\[\int_0^1 e^x dx=\lim_{n\to L_n}=e-1\]

这道题让你亲手感受「没有 FTC 时算积分有多麻烦」——从而体会基本定理的价值。

6. 星形线的微分方程（Part II/6，额外学分）

设切线在第一象限的线段长为 \(L\)。切线过 \((x_0,y_0)\)、斜率 \(m_0=y'\)，与坐标轴交点给出的线段长平方：

\[L^2=\left(x_0-\frac{y_0}{m_0}\right)^2+(y_0-m_0x_0)^2=(x_0-y_0/y')^2+(y_0-y'x_0)^2\]

化简后令 \(y''\) 因子分解，得到 \((xy'-y)y''=0\)。解 \(xy'-y=0\) 得直线 \(y=Cx\)（退化）；解 \(y''=0\) 也得直线；真正非平凡解来自约束，最终可验证 \(x^{2/3}+y^{2/3}=L^{2/3}\) 满足方程。

常见坑

  • MVT 不等式方向：\(f'(x)\ge 0\) 给出 \(f(x)\ge f(0)\)，注意是「\(\ge\)」不是「\(\le\)」。
  • 不定积分忘加常数或误判唯一：\(\frac12\tan^2x\) 与 \(\frac12\sec^2x\) 只差常数，都对。
  • 黎曼和几何级数求和出错：\(\sum_{k=0}^{n-1} r^k=(r^n-1)/(r-1)\)，注意项数是 \(n\) 不是 \(n-1\)。
  • 极限 \(n(e^{1/n}-1)\)：令 \(h=1/n\)，用标准极限 \((e^h-1)/h\to 1\)。

知识检查

问题 1：若 \(f(0)=0\)、\(f'(x)\ge 0\)（\(x\ge 0\)），则 MVT 直接推出？

问题 2：\(\frac12\tan^2x\) 与 \(\frac12\sec^2x\) 都是 \(\tan x\sec^2x\) 的原函数，原因是？

问题 3：用黎曼和算 \(\int_0^1 e^x dx\) 的极限结果是？

自测小结

MVT 不等式

辅助函数 + 判导符号 + 用 \(f(0)\) 定方向。

反导数族

原函数不唯一，差常数即都对。

黎曼和

几何级数求和 + 标准指数极限。

FTC 价值

没有基本定理时，算一个 \(e^x\) 积分都很费劲。
