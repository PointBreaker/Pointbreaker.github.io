功、平均值与概率

定积分最强大的地方在于它不只能算面积——任何「连续累积」的量都可以用积分表达。这一课把积分应用到三个新场景：变力做功、函数的平均值、以及连续概率，展示同一个数学工具跨越不同领域的统一力量。

授课：Prof. David Jerison 日期：2006-10-31 难度：中等

这一课在课程中的位置

前面几课把积分落到几何（面积、体积）。这一课跳出几何，把积分作为「连续求和」的一般工具：力沿位移累积成功、温度在时间上累积成平均气温、概率密度在区间上累积成概率。这些应用的数学结构完全相同——都是 \(\int f(x)\,dx\) 的实例。

功 (work)

恒力 \(F\) 沿直线移动距离 \(d\)，功 \(W = Fd\)。若力随位置变化，\(F=F(x)\)，则把位移分成小段：在每段 \(\Delta x\) 上力近似恒力 \(F(x_i)\)，元功 \(dW = F(x)\,dx\)，故

\[ W = \int_a^b F(x)\,dx. \]

例 1：弹簧

胡克定律：伸长 \(x\) 的弹簧需力 \(F(x)=kx\)（\(k\) 为弹簧常数）。把弹簧从自然长度再拉长 \(L\) 所做的功：

\[ W = \int_0^L kx\,dx = \frac12 kL^2. \]

例 2：单摆（Exam 3 Review 原题）

摆长 \(L\)、质量 \(m\) 的单摆在重力下从角度 \(\theta_0\) 摆到最低点。沿摆动路径的切向力 \(F = mg\sin\theta\)，元位移 \(ds = L\,d\theta\)，故

\[ W = \int_0^{\theta_0} mg\sin\theta\cdot L\,d\theta = mgL\Bigl[-\cos\theta\Bigr]_0^{\theta_0} = mgL(1-\cos\theta_0). \]

这恰好等于重力势能的减少量 \(mgh\)，其中 \(h = L(1-\cos\theta_0)\) 是摆球下降的竖直高度——功只取决于初末位置，与路径无关，这正是重力是保守力的体现。

功的积分本质：力沿位移的累积。只要能把力表达为位置的函数，积分就给出总功。

函数的平均值

离散平均：\(\displaystyle \frac{1}{n}\sum_{i=1}^n f(x_i)\)。连续版本：把 \([a,b]\) 分成 \(n\) 等份，\(\Delta x=(b-a)/n\)，取点 \(x_i\)，令 \(n\to\infty\)：

\[ f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx. \]

几何意义：\(f_{\text{avg}}\) 是这样一个常数函数——它在 \([a,b]\) 上的面积与 \(f(x)\) 下的面积相等。即 \(f_{\text{avg}}\cdot(b-a) = \int_a^b f(x)\,dx\)。

例 3：交流电压的平均值

电压 \(V(t)=120\sin(120\pi t)\)，周期 \(T=1/60\) 秒。平均电压：

\[ V_{\text{avg}} = \frac{1}{T}\int_0^T 120\sin(120\pi t)\,dt = 60\cdot 120\Bigl[\frac{-\cos(120\pi t)}{120\pi}\Bigr]_0^T = 0. \]

正负抵消，平均为零。所以电力公司用均方根 (RMS) 电压：

\[ V_{\text{RMS}} = \sqrt{\frac{1}{T}\int_0^T V(t)^2\,dt}. \]

（PS6 第 2 题正是要推导 \(V_{\text{RMS}} = C/\sqrt{2}\)，其中 \(C\) 是峰值。）

例 4：单位圆上的平均弦长

(a) 在 \([-1,1]\) 上随机取点 \(P\)，过 \(P\) 作单位圆的竖直弦，弦长 \(=2\sqrt{1-x^2}\)。平均弦长：

\[ \frac{1}{2}\int_{-1}^1 2\sqrt{1-x^2}\,dx = \int_{-1}^1 \sqrt{1-x^2}\,dx = \frac{\pi}{2} \approx 1.57. \]

(b) 若 \(P\) 在圆周上随机取，设其幅角 \(\theta\in[0,\pi]\)，弦长 \(=2\sin\theta\)，平均值为

\[ \frac{1}{\pi}\int_0^\pi 2\sin\theta\,d\theta = \frac{2}{\pi}\Bigl[-\cos\theta\Bigr]_0^\pi = \frac{4}{\pi} \approx 1.27. \]

两种「随机」定义给出不同答案——这是著名的「贝特朗悖论」的雏形，提醒我们「随机取点」必须明确定义概率测度。

连续概率

若随机变量 \(X\) 落在区间 \([a,b]\) 内的概率由概率密度函数 \(p(x)\ge 0\) 给出，则

\[ P(a\le X\le b) = \int_a^b p(x)\,dx, \qquad\text{且}\qquad \int_{-\infty}^\infty p(x)\,dx = 1. \]

例 5：放射性衰变（PS6 第 3 题）

设粒子在时间 \(t\) 衰变的概率密度为 \(ae^{-at}\)（\(a>0\)）。则

\[ P(0\le T\le t) = \int_0^t a e^{-a\tau}\,d\tau = 1-e^{-at}. \]

半衰期 \(T_{1/2}\) 满足 \(P(0\le T\le T_{1/2})=1/2\)：

\[ 1-e^{-aT_{1/2}} = \frac12 \;\Longrightarrow\; T_{1/2} = \frac{\ln 2}{a}. \]

若半衰期为 1 秒，则 \(a=\ln 2\)，粒子活过 \(t=1\) 但在 \(t=1\) 到 \(t=2\) 之间衰变的概率：

\[ P(1\le T\le 2) = e^{-a\cdot 1} - e^{-a\cdot 2} = \frac12 - \frac14 = \frac14. \]

例 6：几何概率

从单位正方形 \(0\le x,y\le 1\) 中等可能取点 \((x,y)\)，概率 = 面积。则

\[ P(x^2 < y) = \int_0^1 \int_{x^2}^1 dy\,dx = \int_0^1 (1-x^2)\,dx = \Bigl[x-\frac{x^3}{3}\Bigr]_0^1 = \frac23. \]

积分即概率：连续情形下，概率是概率密度函数下的面积，与「面积 = 积分」一脉相承。

常见误区与边界情况

平均值 ≠ 中点值：\(f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx\) 是积分平均，不是 \(f\!\left(\frac{a+b}{2}\right)\)。

  • 功的符号：力与位移同向做正功，反向做负功。积分自动处理方向。
  • 概率密度 ≠ 概率：\(p(x)\) 可以大于 1；只有积分 \(\int p(x)\,dx\) 给出概率（≤1）。
  • 概率密度归一化：\(\int_{-\infty}^\infty p(x)\,dx\) 必须等于 1。
  • RMS 与平均值的区别：交流电压平均值为 0，但 RMS 非零——物理上对应实际发热功率。
  • 「随机」要定义清楚：例 4 显示，不同的随机化方式给出不同概率。
