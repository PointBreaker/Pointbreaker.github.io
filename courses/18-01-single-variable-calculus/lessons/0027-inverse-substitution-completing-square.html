反代换与配方

当被积函数里出现根式 √(a²−x²)、√(a²+x²) 或 √(x²−a²) 时，直接下手往往很难。这一课引入三角反代换 (trigonometric substitution)——用三角恒等式把根号“消掉”——以及把一般二次式化成标准形的配方法 (completing the square)，它们是处理含根式积分的两把核心钥匙。

授课：Prof. David Jerison 日期：2006-11-09 难度：中等

这一课在课程中的位置

在此之前，你已经掌握了直接代换 (u-substitution)、三角函数的积分，以及两次期中覆盖的微分工具。第 25–26 课的三角积分为本课的三角反代换打下恒等式基础；本课完成后，将在后续 lecture 中组合部分分式、分部积分，最终在第 33 课的期中 4 上综合考察。本课的目标是：见到根号下的二次式，能立刻判断该用哪种三角代换或配方，并能正确地回到原变量。

三角反代换：三类标准形

三角反代换的思路：利用 sin²u + cos²u = 1、sec²u = tan²u + 1 这类恒等式，把根号内的平方项吸收掉。三种情形对应三种代换：

根号内的形式代换恒等式效果dx
\(a^2 - x^2\)\(x = a\sin u\)\(\sqrt{a^2-x^2}=a\cos u\)\(dx = a\cos u\,du\)
\(a^2 + x^2\)\(x = a\tan u\)\(\sqrt{a^2+x^2}=a\sec u\)\(dx = a\sec^2 u\,du\)
\(x^2 - a^2\)\(x = a\sec u\)\(\sqrt{x^2-a^2}=a\tan u\)\(dx = a\sec u\tan u\,du\)

核心思想：三角反代换不是“凑巧”，而是用参数 u 把代数式重新参数化为三角式。积分做完后，再用同一个 u 的直角三角形把答案改写成 x 的函数。

例 1：∫ dx / √(a²−x²)

令 \(x = a\sin u\)，则 \(dx = a\cos u\,du\)，且 \(\sqrt{a^2-x^2}=a\cos u\)（这里取 \(\cos u\ge 0\)，对应 \(-\pi/2\le u\le\pi/2\)）：

\[\int \frac{dx}{\sqrt{a^2-x^2}} = \int \frac{a\cos u}{a\cos u}\,du = \int du = u + c.\]

回到原变量：\(u = \sin^{-1}(x/a)\)。于是得到一个基本公式：

\[\boxed{\int \frac{dx}{\sqrt{a^2-x^2}} = \sin^{-1}\!\left(\frac{x}{a}\right) + c.}\]

例 2：∫ √(a²−x²) dx （用三角形回代）

同样令 \(x=a\sin u\)。被积函数变为：

\[\int \sqrt{a^2-x^2}\,dx = \int (a\cos u)(a\cos u\,du) = a^2\int \cos^2 u\,du.\]

用半角公式 \(\cos^2 u = \frac{1+\cos 2u}{2}\)：

\[a^2\int \frac{1+\cos 2u}{2}\,du = \frac{a^2}{2}\!\left(u + \frac{\sin 2u}{2}\right)+c = \frac{a^2}{2}(u+\sin u\cos u)+c.\]

现在回代。由 \(x=a\sin u\) 作直角三角形：对边 \(x\)、斜边 \(a\)、邻边 \(\sqrt{a^2-x^2}\)。于是 \(\sin u = x/a\)，\(\cos u = \sqrt{a^2-x^2}/a\)，\(u=\sin^{-1}(x/a)\)：

\[\boxed{\int \sqrt{a^2-x^2}\,dx = \frac{a^2}{2}\sin^{-1}\!\left(\frac{x}{a}\right) + \frac{x\sqrt{a^2-x^2}}{2} + c.}\]

例 3：∫ dx / (x²√(x²−a²)) （第三类代换）

这里出现 \(x^2-a^2\)，用 \(x=a\sec u\)，\(dx=a\sec u\tan u\,du\)，\(\sqrt{x^2-a^2}=a\tan u\)：

\[\int \frac{dx}{x^2\sqrt{x^2-a^2}} = \int \frac{a\sec u\tan u}{a^2\sec^2 u \cdot a\tan u}\,du = \int \frac{1}{a^2}\cos u\,du = \frac{\sin u}{a^2}+c.\]

回代：由 \(x=a\sec u\)，\(\sec u = x/a\)，画三角形得 \(\sin u = \sqrt{x^2-a^2}/x\)，所以：

\[\int \frac{dx}{x^2\sqrt{x^2-a^2}} = \frac{\sqrt{x^2-a^2}}{a^2 x} + c.\]

回代是易错环节：积分做完后，答案必须写成 x 的函数，不能留着 u。标准流程是：(1) 写出 \(\sin u = x/a\) 这类关系；(2) 画一个直角三角形标出三边；(3) 从三角形读出其他三角比的 x 表达式。

配方法：把一般二次式化成标准形

当被积函数的分母是 \(x^2+Bx+C\) 这种一般二次式时，先配方把它写成 \((x-p)^2 + q^2\)（或差/和形式），就能套用上面的三角代换或基本积分公式。

配方公式：

\[Ax^2+Bx+C = A\!\left(x-\frac{B}{2A}\right)^{\!2} + \left(C-\frac{B^2}{4A}\right).\]

令 \(u = x - B/(2A)\)，就得到 \(u^2 + k^2\)、\(u^2-k^2\) 或 \(k^2-u^2\) 之一。

配方实例

分母 \(x^2+4x+13\)：

\[x^2+4x+13 = (x+2)^2 - 4 + 13 = (x+2)^2 + 9 = u^2 + 3^2,\quad u=x+2.\]

这正是第 33 课公式表上标注的情形：\(u^2+a^2\)，接下来可令 \(u=3\tan\theta\)。

例 4：∫ dx / (x²+4x+13)

配方：\(x^2+4x+13=(x+2)^2+9\)。令 \(u=x+2\)，\(du=dx\)：

\[\int \frac{dx}{x^2+4x+13} = \int \frac{du}{u^2+9} = \frac{1}{3}\tan^{-1}\!\left(\frac{u}{3}\right)+c = \frac{1}{3}\tan^{-1}\!\left(\frac{x+2}{3}\right)+c.\]

例 5：∫ dx / √(−x²+6x−5) （根号下是负二次）

先对根号内配方：\(-x^2+6x-5 = -(x^2-6x)-5 = -(x-3)^2+9-5 = 4-(x-3)^2\)。于是：

\[\int \frac{dx}{\sqrt{4-(x-3)^2}}.\]

这是 \(\sqrt{a^2-u^2}\) 形，令 \(x-3=2\sin u\)：

\[\int \frac{2\cos u}{\sqrt{4-4\sin^2 u}}\,du = \int du = u + c = \sin^{-1}\!\left(\frac{x-3}{2}\right)+c.\]

递推公式：tanⁿ x 的积分

三角反代换常把积分化为 ∫ tanⁿ u du 或 ∫ secⁿ u du 的形式。这类积分有系统的递推公式 (reduction formula)，每次都把指数降 2，直到落到基本情形。

tanⁿ x 递推公式（n ≥ 2）

利用恒等式 \(\tan^2 x = \sec^2 x - 1\)：

\[\int \tan^{n+2}x\,dx = \int \tan^n x(\sec^2 x - 1)\,dx = \int \tan^n x\sec^2 x\,dx - \int \tan^n x\,dx.\]

第一项用代换 \(w=\tan x\)，\(dw=\sec^2 x\,dx\)：

\[\int \tan^n x\sec^2 x\,dx = \int w^n\,dw = \frac{w^{n+1}}{n+1} = \frac{\tan^{n+1}x}{n+1}.\]

于是得到递推公式：

\[\boxed{\int \tan^{n+2}x\,dx = \frac{\tan^{n+1}x}{n+1} - \int \tan^n x\,dx.}\]

用递推算 ∫ tan⁴ x dx

取 n=2：

\[\int \tan^4 x\,dx = \frac{\tan^3 x}{3} - \int \tan^2 x\,dx.\]

而 \(\int \tan^2 x\,dx = \int(\sec^2 x - 1)\,dx = \tan x - x + c\)。代入：

\[\boxed{\int \tan^4 x\,dx = \frac{\tan^3 x}{3} - \tan x + x + c.}\]

常见误区与边界情况

1. 根号开出来要取绝对值吗？在三角反代换中，我们人为限定 u 的区间来保证三角比为正。例如 \(x=a\sin u\) 取 \(u\in[-\pi/2,\pi/2]\)，此时 \(\cos u\ge 0\)，于是 \(\sqrt{a^2-x^2}=a\cos u\) 而不是 \(a|\cos u|\)。不写清区间是扣分重灾区。

2. 忘记回到原变量。积分做完后答案里不能再出现 u。务必画直角三角形完成回代；常见模式：\(x=a\sin u\) → 对边 x、斜边 a、邻边 \(\sqrt{a^2-x^2}\)。

3. 配方时常数项算错。\(x^2+Bx+C = (x+B/2)^2 + C - B^2/4\)，注意常数是 \(C-B^2/4\)，不是 \(C+B^2/4\)。建议代一个具体 x 值验算。

本课要点

三类三角代换

a²−x² → x=a sin u；a²+x² → x=a tan u；x²−a² → x=a sec u

配方标准化

Ax²+Bx+C = A(x−B/2A)² + (C−B²/4A)，化为 u²±k² 再代换

画图回代

积分做完必须用直角三角形把 u 的三角式改写回 x

递推公式

∫tanⁿ⁺²x dx = tanⁿ⁺¹x/(n+1) − ∫tanⁿx dx，逐次降指数
