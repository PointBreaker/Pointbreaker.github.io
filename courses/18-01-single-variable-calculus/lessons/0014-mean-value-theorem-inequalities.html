中值定理与不等式

整条曲线的平均变化率，必等于某个中间瞬间的瞬时变化率——这就是中值定理 (Mean Value Theorem)。它把"导数的信息"和"函数值的信息"桥接起来，是证明不等式的利器，也是反导数思想的萌芽。

授课：Prof. David Jerison 日期：2006-10-06 难度：中等

这一课在课程中的位置

你已经会用导数判断升降与凹凸（第 10 课），但那些都是"导数→局部形状"。中值定理反向一步：从导数的信息得到函数值的整体估计。讲义 Notes MVT 把中值定理称为"穷人的积分替代"——在还没学积分时，它是联系 f′ 与 f 的最强工具。

中值定理的两种形式

假设 f 在闭区间上连续、开区间内可导，端点为 a 和 b（或 a 和 x）。

形式一（斜率形式）

\[\frac{f(b)-f(a)}{b-a}=f'(c)\quad\text{对某个 } c\in(a,b).\]

几何意义：曲线上至少有一点的切线平行于两端点的割线。

形式二（函数值形式）

\[f(x)=f(a)+f'(c)(x-a)\quad\text{对某个 } c\text{ 介于 }a\text{ 与 }x\text{ 之间}.\]

这是形式一乘以 \(b-a\) 并改记 b 为 x 得到的。它告诉我们：只要知道 f 在一点的值，以及 f′ 在区间上的大小，就能估计 f 在另一点的值。

罗尔定理（Rolle's theorem）

中值定理的特殊情形：若 \(f(a)=f(b)\)，则存在 \(c\in(a,b)\) 使得 \(f'(c)=0\)。几何上，起点终点同高的曲线上必有水平切线。罗尔定理其实是证明中值定理的垫脚石。

用中值定理证明不等式

中值定理的核心用途之一：从导数的不等式推出函数的不等式。

例 1：导数正 ⇒ 函数递增

（复习题 8a）设 f 可导且 \(f'(x)>0\) 对所有 x 成立。任取 \(x>a\)，由形式二：

\[f(x)-f(a)=f'(c)(x-a),\quad c\in(a,x).\]

因为 \(f'(c)>0\) 且 \(x-a>0\)，所以 \(f(x)-f(a)>0\)，即 \(f(x)>f(a)\)。故 f 严格递增。

同理：\(f'<0\) 处处成立 ⇒ f 严格递减；\(f'=0\) 处处成立 ⇒ f 为常数。

例 2：证明 \(e^x > 1+x\)（\(x>0\)）

（复习题 8b）令 \(f(x)=e^x-1-x\)，则 \(f(0)=0\)，\(f'(x)=e^x-1\)。当 \(x>0\) 时，对区间 \([0,x]\) 用中值定理：

\[f(x)-f(0)=f'(c)\cdot x=(e^c-1)x,\quad c\in(0,x).\]

因为 \(c>0\) 时 \(e^c>1\)，所以 \(f'(c)>0\)，从而 \(f(x)>f(0)=0\)，即 \(e^x>1+x\)。

例 3：\(\ln(1+x) < x\)（\(x>0\)）

（复习题 6a）令 \(f(x)=x-\ln(1+x)\)，\(f(0)=0\)，\(f'(x)=1-\frac{1}{1+x}=\frac{x}{1+x}>0\)（\(x>0\)）。由例 1 的论证，\(f(x)>0\)，即 \(\ln(1+x)<x\)。

中值定理与零点唯一性

（复习题 6b）设 \(f(x)=x^3+x+c\)。若能有两个不同的零点 \(r_1<r_2\)，则由罗尔定理，其间必有 c 使 \(f'(c)=0\)。但

\[f'(x)=3x^2+1\ge 1>0\quad\text{处处成立},\;\text{无零点}.\]

矛盾！故 \(f\) 不可能有两个零点。导数恒正 ⇒ 函数至多一个零点——这是中值定理的一个重要推论。

常见误区与边界情况

  • 忘记验证条件：中值定理要求函数在闭区间连续、开区间可导。有尖点或间断时不能直接用。
  • 把 c 当已知：定理只保证 c 存在，不告诉你它在哪里。证明时不要试图算出 c。
  • 形式一与形式二混淆：形式一是斜率等式，形式二等号右边是 \(f'(c)(x-a)\) 不是 \(f'(c)(b-a)\)。注意区分。
  • 不等式方向搞反：用中值定理证不等式时，关键看 \(f'(c)\) 的符号与 \((x-a)\) 的符号是否匹配。
  • 罗尔定理条件：\(f(a)=f(b)\) 是前提，没有它就不能得出 \(f'(c)=0\)。

知识检查

问题 1：中值定理（斜率形式）的结论是什么？

问题 2：若 f 可导且 \(f'(x)>0\) 对所有 x 成立，则 f 是？

问题 3：当 \(f(a)=f(b)\) 时，中值定理会退化成什么定理？

问题 4：若 \(f'(x)>0\) 处处成立，f 最多能有几个零点？

本课要点

两种形式

斜率形式与函数值形式等价，后者用于估计

罗尔定理

\(f(a)=f(b)\) 时得到 \(f'(c)=0\)

导数→函数

从 f′ 的不等式推出 f 的不等式

递增判据

\(f'>0\) 处处成立 ⇒ f 严格递增

零点唯一

\(f'>0\) 处处成立 ⇒ f 至多一个零点
