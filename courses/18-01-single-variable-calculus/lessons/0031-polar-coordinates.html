极坐标与极坐标下的面积

圆、玫瑰线、心形线……这些以“绕原点旋转”为特征的曲线，用直角坐标写出的方程往往复杂，但在极坐标 (r, θ) 下却极其简洁。这一课把面积和弧长的积分搬到极坐标系：面积微元是 \(\frac12 r^2 d\theta\)，它是弧长公式的又一个特例。

授课：Prof. David Jerison 日期：2006-11-21 难度：中等

这一课在课程中的位置

极坐标是参数方程的又一个特例（参数 θ 同时决定 r 和角度），所以第 30 课的 ds 框架直接适用。极坐标面积公式是期中 4 最后一个考点。掌握它之后，第 32–33 课将对 lecture 25–32 的全部积分技术做总复习与测试。

极坐标基础

极坐标用“到原点的距离 r”和“与极轴的夹角 θ”来确定一点：

\[x = r\cos\theta,\qquad y = r\sin\theta.\]

反解（注意象限）：\(r = \sqrt{x^2+y^2}\)，\(\theta = \tan^{-1}(y/x)\)。

常见极坐标曲线

曲线极坐标方程说明
圆心在原点、半径 a\(r = a\)r 为常数
过原点的直线\(\theta = \alpha\)θ 为常数
玫瑰线\(r = a\cos(n\theta)\)n 瓣（n 奇）或 2n 瓣（n 偶）
心形线\(r = a(1+\cos\theta)\)cardioid
阿基米德螺线\(r = a\theta\)等间距缠绕
圆锥曲线（焦点在原点）\(r = \dfrac{ed}{1+e\cos\theta}\)e 为离心率

从极坐标到直角坐标

例：\(r = 1/(1+\sin\theta)\)。两边乘 \(1+\sin\theta\)：\(r + r\sin\theta = 1\)，即 \(r = 1 - y\)。再平方：\(x^2+y^2 = (1-y)^2 = 1 - 2y + y^2\)，消去 y² 得：

\[x^2 = 1 - 2y \quad\Longrightarrow\quad y = \frac{1-x^2}{2}.\]

这是一条开口向下的抛物线——一个分式极坐标方程对应抛物线，离心率 e=1。

极坐标下的面积

极坐标下的面积微元：把 dθ 扫过的窄扇形近似为三角形，面积 ≈ \(\frac12 r^2 d\theta\)。积分得：

\[\boxed{A = \frac12\int_{\theta_1}^{\theta_2} r(\theta)^2\,d\theta.}\]

核心：极坐标面积就是“对 θ 积分 r²/2”。关键是确定 θ 的上下限，使曲线恰好扫过目标区域一次，不重复不遗漏。

例 1：圆的面积

\(r=a\)，θ 从 0 到 2π：

\[A = \frac12\int_0^{2\pi} a^2\,d\theta = \frac{a^2}{2}\cdot 2\pi = \pi a^2.\]

例 2：心形线 r = a(1+cos θ) 的面积

θ 从 0 到 2π 刚好描完一圈：

\[A = \frac12\int_0^{2\pi} a^2(1+\cos\theta)^2\,d\theta = \frac{a^2}{2}\int_0^{2\pi}(1+2\cos\theta+\cos^2\theta)\,d\theta.\]

其中 \(\int_0^{2\pi}\cos\theta\,d\theta = 0\)，用 \(\cos^2\theta = \frac{1+\cos 2\theta}{2}\)：

\[A = \frac{a^2}{2}\!\left(2\pi + 0 + \pi\right) = \frac{3\pi a^2}{2}.\]

例 3：用两种方法算同一区域（第 8A 课问题 3）

区域 \(0\le r \le \frac{1}{1+\sin\theta},\ 0\le\theta\le\pi\)。

方法 A（直角坐标）：上面已化得 \(y=(1-x^2)/2\)，区域是抛物线下方、x 从 −1 到 1：

\[A = \int_{-1}^{1}\frac{1-x^2}{2}\,dx = \frac12\!\left[x - \frac{x^3}{3}\right]_{-1}^{1} = \frac12\!\left(\frac{4}{3} - \left(-\frac{4}{3}\right)\right) = \frac{4}{3}.\]

方法 B（极坐标）：令 \(u = \theta - \pi/2\)，用半角公式 \(1+\cos u = 2\cos^2(u/2)\)：

\[A = \frac12\int_0^{\pi}\frac{1}{(1+\sin\theta)^2}\,d\theta = \frac12\int_{-\pi/2}^{\pi/2}\frac{1}{(1+\cos u)^2}\,du = \frac12\int_{-\pi/2}^{\pi/2}\frac{du}{4\cos^4(u/2)}.\]

两种方法都得到同一答案，验证了极坐标面积公式的正确性。极坐标的价值在于：它给出任意扇形的面积，这对开普勒定律（行星扫过面积）至关重要。

区间陷阱：对 \(r=a\cos(n\theta)\)（玫瑰线），完整一瓣的 θ 跨度是 \(\pi/n\)，不是 2π。要画图确认曲线何时“回到原点”，再定上下限。

极坐标下的弧长

把极坐标看成参数方程 \(x(\theta)=r(\theta)\cos\theta,\ y(\theta)=r(\theta)\sin\theta\)，代入 ds 公式并化简：

\[ds = \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^{\!2}}\,d\theta,\] \[\boxed{L = \int_{\theta_1}^{\theta_2} \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^{\!2}}\,d\theta.}\]

例 4：圆的极坐标弧长

\(r=a\)，dr/dθ = 0：\(ds = \sqrt{a^2+0}\,d\theta = a\,d\theta\)，与参数法一致。

常见误区与边界情况

1. θ 区间取错导致重复计数。画图是必须的。比如 \(r=\cos(2\theta)\) 的四叶玫瑰，一叶是 θ∈[−π/4,π/4]，整花要乘 4，而不是直接积 0 到 2π（会算成 4 倍）。

2. 忘记 1/2。极坐标面积微元是 \(\frac12 r^2 d\theta\)，不是 \(r^2 d\theta\)。它是扇形面积 \(\frac12 r^2 d\theta\) 的直接推广。

3. r 为负值的处理。极坐标允许 r < 0，此时点画在反向延长线上。若曲线出现 r< 0 的部分，要确认它是否描出新区域，避免重复或遗漏。

4. 极坐标弧长公式里的 r²。ds = √(r²+(dr/dθ)²) dθ，不要漏掉 r² 项——它来自 x 和 y 对 θ 的导数中的 cos²+sin² 贡献。

本课要点

极坐标转换

x = r cos θ, y = r sin θ

极坐标面积

A = (1/2)∫r² dθ，注意 θ 区间不重复不遗漏

极坐标弧长

ds = √(r²+(dr/dθ)²) dθ

画图优先

先画曲线、确认上下限再积分

两种方法互验

同一区域用直角坐标和极坐标各算一次
