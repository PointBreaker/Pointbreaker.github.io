部分分式

有理函数（多项式之商）看起来千变万化，但部分分式分解 (partial fraction decomposition) 告诉我们：任何有理函数都能拆成 A/(x−a)、A/(x−a)ⁿ 和 (Cx+D)/(x²+bx+c)ⁿ 这三类“积木”之和。每一块都能直接积分——于是积分有理函数就变成了一次系统性的代数拆分。

授课：Prof. David Jerison 日期：2006-11-14 难度：中等

这一课在课程中的位置

你已经会做多项式长除法、会处理不可约二次项的配方与三角代换（第 27 课）。本课把“有理函数”这一大类统一处理：先用长除法把假分式化为真分式，再按分母的因式分解写出部分分式形状，最后定出系数。这是期中 4（第 33 课）的核心考点之一，也是后续处理 ∫sec x dx 等三角积分的代数基础。

部分分式分解的策略

设被积函数为 \(P(x)/Q(x)\)，其中 P、Q 为多项式。

三步流程：

  1. 检查次数：若 deg(P) ≥ deg(Q)，先做长除法，写成 \(P/Q = P_1 + R/Q\)，其中 deg(R) < deg(Q)。
  2. 分解分母 Q：在实数域内分解为一次因式 \((x-a)^m\) 和不可约二次因式 \((x^2+bx+c)^n\)。
  3. 写出形状、定系数：按规则写出部分分式之和，用待定系数法（覆盖法、比较系数、代入特殊值）求出所有常数。

每类因式对应的“积木”

分母中的因式对应的部分分式项
一次因式 \((x-a)\)\(\dfrac{A}{x-a}\)
重一次因式 \((x-a)^m\)\(\dfrac{A_1}{x-a}+\dfrac{A_2}{(x-a)^2}+\cdots+\dfrac{A_m}{(x-a)^m}\)
不可约二次 \((x^2+bx+c)\)\(\dfrac{Cx+D}{x^2+bx+c}\)
重二次 \((x^2+bx+c)^n\)\(\dfrac{C_1x+D_1}{x^2+bx+c}+\cdots+\dfrac{C_nx+D_n}{(x^2+bx+c)^n}\)

覆盖法 (cover-up method) 与系数确定

对于单一次因式 \((x-a)\)，系数 A 有一个极快的求法：在等式两边乘 \((x-a)\)，再令 \(x=a\)，左边剩下的就是 A。这就是覆盖法。

例 1：单一次因式

分解 \(\dfrac{3x+1}{(x-1)(x+2)}\)。设：

\[\frac{3x+1}{(x-1)(x+2)} = \frac{A}{x-1} + \frac{B}{x+2}.\]

乘 \((x-1)\) 后令 \(x=1\)：\(A = \dfrac{3(1)+1}{1+2} = \dfrac{4}{3}\)。

乘 \((x+2)\) 后令 \(x=-2\)：\(B = \dfrac{3(-2)+1}{-2-1} = \dfrac{-5}{-3} = \dfrac{5}{3}\)。

所以：

\[\frac{3x+1}{(x-1)(x+2)} = \frac{4/3}{x-1} + \frac{5/3}{x+2}.\]

例 2：重因式（来自 Exam 4 复习）

分解 \(\dfrac{x^2+x+1}{(x-1)^2(x+2)}\)。形状为：

\[\frac{x^2+x+1}{(x-1)^2(x+2)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{x+2}.\]

覆盖法可直接求出最高次重因式的系数：

  • 乘 \((x-1)^2\)，令 \(x=1\)：\(B = \dfrac{1+1+1}{1+2} = \dfrac{3}{3} = 1\)。
  • 乘 \((x+2)\)，令 \(x=-2\)：\(C = \dfrac{4-2+1}{(-2-1)^2} = \dfrac{3}{9} = \dfrac{1}{3}\)。

A 用覆盖法不方便（因为 \((x-1)\) 还出现一次），代入一个方便的值，比如 \(x=0\)：

\[\frac{1}{(-1)^2(2)} = \frac{A}{-1} + \frac{1}{(-1)^2} + \frac{1/3}{2} \;\Longrightarrow\; \frac{1}{2} = -A + 1 + \frac{1}{6}.\]

解得 \(-A = \frac{1}{2}-1-\frac{1}{6} = -\frac{2}{3}\)，即 \(A=\frac{2}{3}\)。

技巧：覆盖法只能直接求“最高次重因式”和“单一次因式”的系数；其余系数用代入特殊值（优先选 x=0、x=−1 这类计算简单的）或比较系数法。

逐块积分

拆分后每一块的积分都是基本公式：

\[\int \frac{A}{(x-a)^n}\,dx = \begin{cases} A\ln|x-a|+c, & n=1,\\ \quad \dfrac{A(1-n)^{-1}}{(x-a)^{n-1}}+c, & n\ge 2.\end{cases}\]

二次项 \(\dfrac{Cx+D}{x^2+bx+c}\) 则先配方，再拆成“代换 w=u²+k²”和“反正切”两部分。

例 3：完整积分

用上题结果积分：

\[\int \frac{x^2+x+1}{(x-1)^2(x+2)}\,dx = \int\!\left(\frac{2/3}{x-1} + \frac{1}{(x-1)^2} + \frac{1/3}{x+2}\right)dx.\]

逐项积分：

\[= \frac{2}{3}\ln|x-1| - \frac{1}{x-1} + \frac{1}{3}\ln|x+2| + c.\]

例 4：含不可约二次项

积分 \(\displaystyle\int\frac{2x+1}{x^2+4x+13}\,dx\)。分母配方：\(x^2+4x+13=(x+2)^2+9\)。令 \(u=x+2\)，则 \(x=u-2\)，分子 \(2x+1=2u-3\)：

\[\int \frac{2u-3}{u^2+9}\,du = \int \frac{2u}{u^2+9}\,du - \int \frac{3}{u^2+9}\,du.\]

第一项代换 \(w=u^2+9\)：\(\ln(u^2+9)\)；第二项：\(\tan^{-1}(u/3)\)。回代：

\[= \ln(x^2+4x+13) - \tan^{-1}\!\left(\frac{x+2}{3}\right) + c.\]

应用：推导 ∫ sec x dx

一个经典技巧：把正割写成 \(\sec x = \dfrac{\cos x}{1-\sin^2 x}\)，再令 \(u=\sin x\)，得到一个有理函数积分，用部分分式完成：

\[\int \sec x\,dx = \int \frac{\cos x}{1-\sin^2 x}\,dx = \int \frac{du}{1-u^2} = \int \frac{du}{(1-u)(1+u)}.\]

部分分式：\(\dfrac{1}{(1-u)(1+u)} = \dfrac{1/2}{1-u} + \dfrac{1/2}{1+u}\)。积分：

\[= -\frac{1}{2}\ln|1-u| + \frac{1}{2}\ln|1+u| + c = \frac{1}{2}\ln\left|\frac{1+\sin x}{1-\sin x}\right| + c.\]

分子分母同乘 \(1+\sin x\)，利用 \(1-\sin^2 x=\cos^2 x\)，就得到更常见的形式：

\[\boxed{\int \sec x\,dx = \ln|\sec x + \tan x| + c.}\]

常见误区与边界情况

1. 没做长除法就拆分。若 deg(P) ≥ deg(Q)，必须先长除。例如 \(\dfrac{x^3}{x^2-2x+1}\) 应先写成 \(x+2 + \dfrac{3x-2}{x^2-2x+1}\)，再对真分式部分做部分分式。

2. 重因式漏项。\((x-a)^m\) 必须写出从 1 次到 m 次的所有项，不能只写最高次那一项。

3. 二次项分子写成常数。不可约二次因式 \((x^2+bx+c)^n\) 对应的分子必须是一次式 \(Cx+D\)，不能只写常数。

4. 分解在实数域内做。18.01 要求分母分解为实系数的一次和不可约二次因式。例如 \(x^2+9\) 在实数域不可约，保留为二次项，用 \(x=3\tan\theta\) 或配方处理。

本课要点

三步流程

长除法 → 分解分母 → 写形状定系数

积木类型

A/(x−a)、A/(x−a)ⁿ、(Cx+D)/(x²+bx+c)ⁿ

覆盖法

乘 (x−a) 再令 x=a，快速求单/最高次重因式系数

逐块积分

一次项得对数，二次项配方后得对数或反正切

sec x 积分

sec x = cos x/(1−sin²x) → 部分分式 → ln|sec x+tan x|
