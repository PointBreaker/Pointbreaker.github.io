曲线作图

仅凭一支笔和函数 f 及其前两阶导数的信息，就能把一条曲线的形状完整画出来——哪里上升、哪里下降、哪里弯折、在哪里逼近哪条直线。这是微分学最综合的应用之一，也是后续优化问题的绘图基础。

授课：Prof. David Jerison 日期：2006-09-28 难度：入门 → 中等

这一课在课程中的位置

你已经掌握了求导法则（积、商、链式）、隐函数求导，以及一阶/二阶导数的含义。这一课把所有工具整合成一个系统流程：用 f 找截距与定义域，用 f′ 找单调区间与极值，用 f″ 找凹凸区间与拐点，再加上渐近线，就能可靠地徒手画出函数的图像。它是第 11 课（最大值与最小值问题）和第 17 课（第二次期中考试）的核心技能。

三个函数：f、f′、f″ 各告诉我们什么

核心思路：导数就是图像的"形状语言"。

f′(x) 的符号决定 f 的升降；f″(x) 的符号决定 f 的凹凸（弯曲方向）。

观察到的符号f 的几何含义
\(f'(x) > 0\)f 在 x 处上升（图像从左下到右上）
\(f'(x) < 0\)f 在 x 处下降（图像从左上到右下）
\(f'(x) = 0\) 或不存在可能的临界点(critical point)——局部极值的候选
\(f''(x) > 0\)f 在 x 处上凹/凸向上(concave up)——像碗口朝上
\(f''(x) < 0\)f 在 x 处下凹/凸向下(concave down)——像帽子朝下
\(f''(x) = 0\) 且变号可能的拐点(inflection point)——凹凸性改变的点

临界点与局部极值

满足 \(f'(x) = 0\) 或 \(f'(x)\) 不存在的点称为临界点。临界点不一定是极值（例如 \(f(x)=x^3\) 在 \(x=0\) 处），需要用下面的检验法判定。

一阶导数检验（first derivative test）

看 f′ 在临界点两侧的符号变化：

  • f′ 由正变负 → 局部极大值；
  • f′ 由负变正 → 局部极小值；
  • f′ 不变号 → 不是极值（可能是鞍点/驻点）。

二阶导数检验（second derivative test）

若 \(f'(c) = 0\) 且 f″ 在 c 处连续：

  • \(f''(c) > 0\) → 局部极小值（图像在该处上凹）；
  • \(f''(c) < 0\) → 局部极大值（图像在该处下凹）；
  • \(f''(c) = 0\) → 无法判定，退回一阶导数检验。

注意：\(f''(c)=0\) 并不保证 c 是拐点，必须 f″ 在 c 两侧变号才算。例如 \(f(x)=x^4\)，\(f''(0)=0\)，但 x=0 两侧 f″ 都为正，不是拐点，而是极小值点。

渐近线：函数在"无穷远处"和"奇点附近"的行为

垂直渐近线（vertical asymptote）

若在 \(x = a\) 处 \(\displaystyle\lim_{x\to a^+} f(x)\) 或 \(\displaystyle\lim_{x\to a^-} f(x)\) 为 \(\pm\infty\)，则直线 \(x=a\) 是垂直渐近线。对有理函数，这通常出现在分母为零而分子不为零的点。

水平渐近线（horizontal asymptote）

若 \(\displaystyle\lim_{x\to\infty} f(x) = L\) 或 \(\displaystyle\lim_{x\to -\infty} f(x) = L\)（L 为有限数），则 \(y=L\) 是水平渐近线。

斜渐近线（slant/oblique asymptote）：当 x→∞ 时，若 \(f(x) - (mx+b) \to 0\)（其中 \(m = \lim f(x)/x \neq 0\)，\(b=\lim (f(x)-mx)\)），则 \(y=mx+b\) 是斜渐近线。18.01 期中重点考察垂直与水平两种。

完整作图流程

一个被验证有效的七步法：

  1. 定义域与截距：找出 f 的定义域；算 \(f(0)\)（y 截距）和 \(f(x)=0\) 的根（x 截距）。
  2. 渐近线：求垂直渐近线（分母零点）和水平渐近线（\(x\to\pm\infty\) 的极限）。
  3. 一阶导数：求 f′，找临界点（\(f'=0\) 或不存在）；用符号表列出 f′ 在各区间的符号，确定升降区间和局部极值。
  4. 二阶导数：求 f″，找拐点候选（\(f''=0\) 或不存在）；用符号表列出 f″ 符号，确定凹凸区间和拐点。
  5. 特殊点：把极值点和拐点的坐标算出来标在图上。
  6. 奇偶/周期：检查 f 是否为偶函数、奇函数或周期性函数，减少工作量。
  7. 连线：用升降与凹凸信息，结合渐近线，光滑地连出整条曲线。

完整例题：徒手画出 \(f(x) = \dfrac{1}{1+x^2}\)

这个函数（与作业 2B 第 2 题同类）是练习 f / f′ / f″ 作图的经典例子。

第 1–2 步：定义域、截距、渐近线

定义域为全体实数（分母 \(1+x^2\) 永不为零），故没有垂直渐近线。\(f(0)=1\)。分子恒为 1 故无 x 截距。

\[\lim_{x\to\pm\infty}\frac{1}{1+x^2} = 0,\]

所以 \(y=0\) 是双侧水平渐近线。又 \(f(-x)=f(x)\)，是偶函数，只需画 \(x\ge 0\) 再对称过去。

第 3 步：一阶导数

\[f'(x) = -\frac{2x}{(1+x^2)^2}.\]

临界点：\(x=0\)。当 \(x>0\) 时 \(f'<0\)（下降），\(x<0\) 时 \(f'>0\)（上升）。由一阶导数检验，\(x=0\) 是局部（也是全局）极大值，极大值为 \(f(0)=1\)。

第 4 步：二阶导数

对 f′ 再求导：

\[f''(x) = \frac{6x^2-2}{(1+x^2)^3} = \frac{2(3x^2-1)}{(1+x^2)^3}.\]

令 \(f''(x)=0\) 得 \(x=\pm 1/\sqrt{3}\)。分母恒正，符号由分子 \(3x^2-1\) 决定：

  • \(|x| > 1/\sqrt{3}\) 时 \(f''>0\)：上凹；
  • \(|x| < 1/\sqrt{3}\) 时 \(f''<0\)：下凹。

在 \(x=\pm 1/\sqrt{3}\) 处 f″ 变号，故这两点是拐点，纵坐标 \(f(\pm 1/\sqrt{3}) = 3/4\)。

第 5–7 步：描图

综合以上：图像关于 y 轴对称；在 \(x=0\) 取极大值 1；在 \(x=\pm 1/\sqrt{3}\approx \pm 0.577\) 处穿过拐点，凹凸性翻转；向左右两侧以 \(y=0\) 为水平渐近线趋于 0。这是一条光滑的"钟形"曲线（柯西分布核）。

例题（多项式）：\(f(x) = 3x^5 - 5x^3 + 1\)

（期中复习题风格）

\[f'(x) = 15x^4 - 15x^2 = 15x^2(x^2-1),\qquad f''(x) = 60x^3 - 30x = 30x(2x^2-1).\]

临界点：\(x=0,\pm 1\)。f″ 零点：\(x=0,\pm 1/\sqrt{2}\)。列表讨论符号可得：\(x=-1\) 为局部极小，\(x=1\) 为局部极小，\(x=0\) 不是极值（f′ 不变号）；拐点在 \(x=0,\pm 1/\sqrt{2}\)。无渐近线（多项式）。据此可完整画图。

常见误区与边界情况

  • 把临界点当极值：\(f'(c)=0\) 只是候选。必须用一阶或二阶导数检验确认。
  • 把 \(f''(c)=0\) 当拐点：必须 f″ 在该点两侧变号；\(x^4\) 在 0 处是反例。
  • 忘记导数不存在的点：尖点（如 \(|x|\) 在 0 处）也可能是极值，但 f′ 不存在，二阶导数检验用不了。
  • 漏掉渐近线：有理函数一定要先检查分母零点（垂直）和无穷极限（水平）。
  • 混淆凹凸与升降：f′ 管升降，f″ 管凹凸，两者独立。可以同时上升且上凹（如 \(e^x\)），或上升且下凹。

本课要点

形状语言

f′ 管升降，f″ 管凹凸

临界点

\(f'=0\) 或不存在，只是极值候选

两种检验

一阶导数检验看符号变化，二阶导数检验看 f″(c) 符号

拐点

f″ 变号，不是 f″=0

渐近线

垂直看分母零点，水平看无穷极限

七步流程

定义域→截距→渐近线→f′→f″→特值点→连线
