无穷级数与收敛判别法

无穷多个数相加，结果可以是有限值，也可以是无穷，甚至不存在。无穷级数 (infinite series) 的敛散性由部分和的极限决定。这一课建立级数收敛的概念，并给出从易到难的一整套审敛法 (convergence tests)：发散判别法、比较判别法、积分判别法、交错级数审敛法、比值审敛法。

授课：Prof. David Jerison 日期：2006-12-07 难度：中等 → 较难

这一课在课程中的位置

这是课程最后三大主题的第二块。广义积分（第 35 课）是级数审敛法（积分判别法、比较判别法）的工具；本课建立的级数理论是下节课泰勒级数（第 37 课）的前提。期末考会直接考级数敛散性判断（practice final 第 16–17 题）。

级数基础：部分和与收敛

级数 \(\displaystyle\sum_{n=1}^\infty a_n\) 定义为部分和数列的极限：

\[S_N = \sum_{n=1}^N a_n,\qquad \sum_{n=1}^\infty a_n = \lim_{N\to\infty} S_N.\]

若极限存在且有限，级数收敛 (converges)；否则发散 (diverges)。

几何级数（核心基准）

\[\sum_{n=0}^\infty ar^n = \frac{a}{1-r},\quad |r|<1;\qquad\text{若 }|r|\ge 1\text{ 则发散}.\]

例：\(\displaystyle\sum_{n=0}^\infty \frac{1}{2^n} = \dfrac{1}{1-1/2} = 2\)。

调和级数（经典发散例）

\[\sum_{n=1}^\infty \frac{1}{n} = \infty.\]

虽然通项 1/n → 0，但级数仍然发散——通项趋于零不是收敛的充分条件。

基本事实：级数收敛 ⇒ 通项 aₙ → 0（逆否命题就是下面的发散判别法）。但 aₙ → 0 ⇏ 级数收敛（调和级数反例）。

收敛判别法一览

1. 发散判别法 (Divergence Test / nth-term test)

若 \(\displaystyle\lim_{n\to\infty} a_n \neq 0\)（或极限不存在），则 \(\sum a_n\) 发散。

注意：只能用来判断发散，不能判断收敛（极限为 0 时级数可能收敛也可能发散）。

2. 积分判别法 (Integral Test)

设 f 在 [1,∞) 上连续、正、递减，\(a_n = f(n)\)。则

\[\sum_{n=1}^\infty a_n \text{ 收敛} \iff \int_1^\infty f(x)\,dx \text{ 收敛}.\]

例：p-级数

\(\displaystyle\sum_{n=1}^\infty \frac{1}{n^p}\) 收敛 ⇔ p > 1（对应 p-积分的结论）。调和级数 p=1 是发散的临界情形。

3. 比较判别法 (Comparison Test)

设 \(0\le a_n \le b_n\)：

  • 若 \(\sum b_n\) 收敛，则 \(\sum a_n\) 收敛。
  • 若 \(\sum a_n\) 发散，则 \(\sum b_n\) 发散。

例：∑ 1/(n²+1)

\(\dfrac{1}{n^2+1} \le \dfrac{1}{n^2}\)，而 \(\sum 1/n^2\) 收敛（p=2>1），所以原级数收敛。

4. 极限比较判别法 (Limit Comparison Test)

设 aₙ, bₙ > 0 且 \(\displaystyle\lim_{n\to\infty}\frac{a_n}{b_n}=L\)，0<L<∞，则 \(\sum a_n\) 与 \(\sum b_n\) 同敛散。

例：∑ 1/(2n²−n−1)

与 \(b_n=1/n^2\) 做极限比较：\(\lim a_n/b_n = 1/2\)，所以与 ∑1/n² 同敛散，故收敛。

5. 交错级数审敛法 (Alternating Series Test)

若级数形如 \(\displaystyle\sum_{n=1}^\infty (-1)^{n-1}b_n\)（或 \((-1)^n b_n\)），其中 \(b_n>0\)，且满足：

  1. \(b_{n+1}\le b_n\)（单调递减），
  2. \(\displaystyle\lim_{n\to\infty} b_n = 0\)，

则级数收敛。

例：交错调和级数

\[\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n} = 1 - \frac12 + \frac13 - \frac14 + \cdots\]

\(b_n=1/n\) 递减趋于 0，所以收敛！注意：它收敛但不是绝对收敛（取绝对值后是调和级数，发散），这种情况称为条件收敛 (conditionally convergent)。

6. 比值判别法 (Ratio Test)

设 \(\displaystyle L = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|\)：

  • L < 1 ⇒ 绝对收敛。
  • L > 1（或 ∞）⇒ 发散。
  • L = 1 ⇒ 判别法失效，需用其他方法。

例：∑ n/2ⁿ

\(\displaystyle\left|\frac{a_{n+1}}{a_n}\right| = \frac{n+1}{2^{n+1}}\cdot\frac{2^n}{n} = \frac{n+1}{2n} \to \frac12 < 1\)，所以绝对收敛。

判别法选择顺序（经验）：

  1. 先算 \(\lim a_n\)。非零 → 发散（结束）。
  2. 识别几何/ p-级数 → 直接下结论。
  3. 通项像已知级数的变体 → 比较 / 极限比较。
  4. 含阶乘或指数 aⁿ、nⁿ → 比值判别法。
  5. 交错 → 交错级数审敛法 + 检查绝对/条件收敛。

绝对收敛与条件收敛

若 \(\sum |a_n|\) 收敛，则 \(\sum a_n\) 绝对收敛 (absolutely convergent)，此时原级数必收敛。

若 \(\sum a_n\) 收敛但 \(\sum |a_n|\) 发散，则为条件收敛。

例：交错调和级数条件收敛；\(\sum (-1)^n/n^2\) 绝对收敛（因为 ∑1/n² 收敛）。

重要：绝对收敛的级数可以任意重排而不改变和；条件收敛的级数重排后可能收敛到任意值（黎曼重排定理，18.01 不考证明但要知道结论）。

常见误区与边界情况

1. 把“通项→0”当作收敛的充分条件。调和级数是经典反例。通项→0 只是必要条件。

2. 比较判别法方向搞反。要证收敛，需要“小的 ≤ 大的且大的收敛”；要证发散，需要“大的 ≥ 小的且小的发散”。

3. 比值判别法 L=1 时随便下结论。L=1 时判别法失效，必须换其他方法。例如 ∑1/n 和 ∑1/n² 用比值判别法都得 L=1，但前者发散、后者收敛。

4. 积分判别法的前提。f 必须连续、正、递减。不满足递减就不能用（比如通项先增后减的级数）。

本课要点

部分和定义

∑aₙ = lim Sₙ，极限存在则收敛

基准级数

几何级数（|r|<1 收敛）；p-级数（p>1 收敛）

发散判别法

aₙ ↛ 0 ⇒ 发散（非充分条件）

比较与积分

比较法、极限比较法、积分判别法

交错与比值

莱布尼茨判别法；比值法 L=1 失效
