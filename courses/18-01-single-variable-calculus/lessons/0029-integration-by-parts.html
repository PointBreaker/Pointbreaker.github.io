分部积分与递推公式

乘积的积分一般不等于积分的乘积。分部积分 (integration by parts) 是乘积法则的逆运算：把 ∫u dv 转化成 uv − ∫v du。选对 u 和 dv，就能让新积分比原来更简单；反复使用，就得到把指数逐步降低的递推公式 (reduction formula)。

授课：Prof. David Jerison 日期：2006-11-16 难度：中等

这一课在课程中的位置

你已经掌握了代换、三角代换和部分分式。分部积分是处理“两类不同函数乘积”（比如 xⁿ 乘 eˣ、ln x、sin x）的核心工具，也是期中 4 的重点。它与递推公式结合，能系统解决 ∫xⁿeˣ、∫sinⁿx、∫secⁿx 等一整族积分。

分部积分公式

由乘积法则 \((uv)' = u'v + uv'\) 两边积分并移项：

\[\boxed{\int u\,dv = uv - \int v\,du.}\]

定积分形式（期中常考）：

\[\int_a^b u\,dv = \bigl[uv\bigr]_a^b - \int_a^b v\,du.\]

核心判断：选 u 和 dv，使得 v du 比 u dv 更容易积分。经验上，u 通常选“求导后会变简单”的部分（比如 xⁿ 求导降次，ln x 求导变成 1/x）。

LIATE 选 u 法则（经验排序）

当被积函数是两类函数的乘积时，按以下优先级选 u（越靠前越优先当 u）：

字母函数类型例子
L对数 Logarithmic\(\ln x\)
I反三角 Inverse trig\(\tan^{-1}x,\ \sin^{-1}x\)
A代数 Algebraic（多项式）\(x^n\)
T三角 Trigonometric\(\sin x,\ \cos x\)
E指数 Exponential\(e^x\)

LIATE 不是定理，而是经验法则；但它在 18.01 范围内几乎总是有效。

典型例题

例 1：∫ x eˣ dx

按 LIATE，代数 x 优先于指数 eˣ 当 u。取 \(u=x\)，\(dv=e^x dx\)，则 \(du=dx\)，\(v=e^x\)：

\[\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + c = e^x(x-1)+c.\]

例 2：∫ x² sin x dx （用两次）

取 \(u=x^2\)，\(dv=\sin x\,dx\)，则 \(du=2x\,dx\)，\(v=-\cos x\)：

\[\int x^2\sin x\,dx = -x^2\cos x + \int 2x\cos x\,dx.\]

对 ∫2x cos x dx 再做一次：\(u=2x\)，\(dv=\cos x\,dx\)，\(du=2dx\)，\(v=\sin x\)：

\[\int 2x\cos x\,dx = 2x\sin x - \int 2\sin x\,dx = 2x\sin x + 2\cos x.\]

代回：

\[\boxed{\int x^2\sin x\,dx = -x^2\cos x + 2x\sin x + 2\cos x + c.}\]

例 3：∫ ln x dx （“藏起来的”乘积）

把 \(\ln x\) 看成 \(1\cdot\ln x\)。按 LIATE，ln x 当 u，1 dx 当 dv：\(u=\ln x\)，\(dv=dx\)，\(du=dx/x\)，\(v=x\)：

\[\int \ln x\,dx = x\ln x - \int x\cdot\frac{1}{x}\,dx = x\ln x - x + c.\]

例 4：∫ eˣ sin x dx （循环型）

取 \(u=\sin x\)，\(dv=e^x dx\)，则：

\[I = \int e^x\sin x\,dx = e^x\sin x - \int e^x\cos x\,dx.\]

对 ∫eˣ cos x dx 再做一次分部（u=cos x，dv=eˣdx）：

\[\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I.\]

代回：

\[I = e^x\sin x - (e^x\cos x + I) = e^x(\sin x - \cos x) - I.\]

把 −I 移到左边：\(2I = e^x(\sin x - \cos x)\)，所以：

\[\boxed{\int e^x\sin x\,dx = \frac{e^x(\sin x - \cos x)}{2} + c.}\]

循环型要点：两次分部后出现原积分 I，把它当作未知数解方程即可。注意不要每次都换 u/dv 的选法，否则会回到原点。

递推公式

当被积函数带有参数 n（比如 ∫xⁿeˣ、∫sinⁿx、∫secⁿx），分部积分能把 n 降到 n−2 或 n−1，得到一个关于 n 的递推公式。

例 5：∫ xⁿ eˣ dx 的递推

取 \(u=x^n\)，\(dv=e^x dx\)，则 \(du=n x^{n-1}dx\)，\(v=e^x\)：

\[\boxed{I_n = \int x^n e^x\,dx = x^n e^x - n\int x^{n-1}e^x\,dx = x^n e^x - n I_{n-1}.}\]

不断递推，直到 \(I_0 = \int e^x dx = e^x\)。例如：

\[I_2 = x^2 e^x - 2I_1 = x^2 e^x - 2(x e^x - I_0) = e^x(x^2 - 2x + 2) + c.\]

例 6：∫ secⁿ x dx 的递推（n ≥ 2）

写 \(\sec^n x = \sec^{n-2}x \cdot \sec^2 x\)，取 \(u=\sec^{n-2}x\)，\(dv=\sec^2 x\,dx\)：

\[du = (n-2)\sec^{n-2}x\tan x\,dx,\quad v=\tan x.\]

于是：

\[I_n = \sec^{n-2}x\tan x - (n-2)\int \sec^{n-2}x\tan^2 x\,dx.\]

用 \(\tan^2 x = \sec^2 x - 1\)：

\[I_n = \sec^{n-2}x\tan x - (n-2)\int \sec^n x\,dx + (n-2)\int \sec^{n-2}x\,dx.\]

注意到 \(\int \sec^n x\,dx = I_n\) 出现在等式两边，移项解出：

\[\boxed{\int \sec^n x\,dx = \frac{\sec^{n-2}x\tan x}{n-1} + \frac{n-2}{n-1}\int \sec^{n-2}x\,dx.}\]

基础情形：\(\int \sec x\,dx = \ln|\sec x+\tan x|+c\)，\(\int \sec^2 x\,dx = \tan x + c\)。

应用：旋转体体积与分部积分

第 33 课习题：求 \(y=\cos x\) 第一个拱形绕 y 轴旋转的体积（圆柱壳法）。

第一个拱形对应 \(x\in[0,\pi/2]\)。壳法公式 \(V = 2\pi\int_a^b x\cdot y\,dx\)：

\[V = 2\pi\int_0^{\pi/2} x\cos x\,dx.\]

用分部积分，\(u=x\)，\(dv=\cos x\,dx\)，\(du=dx\)，\(v=\sin x\)：

\[\int_0^{\pi/2} x\cos x\,dx = \bigl[x\sin x\bigr]_0^{\pi/2} - \int_0^{\pi/2}\sin x\,dx = \frac{\pi}{2} - \bigl[-\cos x\bigr]_0^{\pi/2} = \frac{\pi}{2} - 1.\]

所以：

\[\boxed{V = 2\pi\!\left(\frac{\pi}{2} - 1\right) = \pi^2 - 2\pi.}\]

常见误区与边界情况

1. dv 必须能积分。选 dv 时一定要确保你能（在合理步骤内）写出 v。比如 ∫x eˣ² dx 里若错选 u=eˣ²，dv=x dx，则 v du 会变得更复杂；这里其实应该用代换 w=x²。

2. 定积分忘代上下限。用 \(\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du\) 时，uv 必须代入上下限，不能只写 uv 不取值。

3. 循环型漏掉移项。∫eˣ sin x dx 类问题，两次分部后得到 I = ... − I，必须把 −I 移到左边合并成 2I，不能直接约掉。

4. 分部积分和代换可以组合。有时先用一次代换简化，再分部；或者先分部，剩下的 ∫v du 里再做代换。期中 4 的难题常是组合拳。
