最大值与最小值问题

微积分最直接的"现实世界"用途之一：在一切可能的方案里，找到最优的那一个——用料最少、面积最大、距离最短。本课把"求最值"转化为"找临界点并检验"，核心工具就是上一课的导数检验法。

授课：Prof. David Jerison 日期：2006-09-29 难度：入门 → 中等

这一课在课程中的位置

第 10 课建立了用 f′ 和 f″ 分析函数形状的工具。这一课把这些工具指向一个具体目标：求函数在某个区间上的绝对最大值与最小值（global extrema），以及在约束条件下做优化。它是应用微积分建模的起点，也是期中考试里"列方程—求导—判断最值"的标准题型的直接来源。

闭区间上的绝对最值：闭区间法

若 f 在闭区间 \([a,b]\) 上连续，则 f 在 \([a,b]\) 上必能取到最大值与最小值（极值定理）。求法如下：

  1. 求 f 在开区间 \((a,b)\) 内的所有临界点（\(f'(x)=0\) 或 \(f'\) 不存在的点）；
  2. 计算 f 在这些临界点以及两端点 \(x=a,\;x=b\) 处的函数值；
  3. 比较这些函数值：最大者即全局最大值，最小者即全局最小值。

为什么不能忘掉端点？最值可能出现在端点，而端点处导数未必为零。只要题目给了闭区间，端点必须代入。作业 3 第 1a 题特别提醒："Check endpoints"。

例题：在 \([-2,2]\) 上求 \(f(x)=x^3-3x\) 的最值

\(f'(x)=3x^2-3=3(x^2-1)\)，临界点 \(x=\pm 1\)，都在区间内。算四点的值：

\[f(-2)=-2,\; f(-1)=2,\; f(1)=-2,\; f(2)=2.\]

全局最大值 2（在 \(x=-1\) 和 \(x=2\) 处取得），全局最小值 \(-2\)（在 \(x=-2\) 和 \(x=1\) 处取得）。

应用优化：从文字到方程

应用题的一般策略：

  1. 读题画图，定义变量：把未知量设为自变量 x，把几何/物理关系写成等式。
  2. 写出目标函数：把要"最大"或"最小"的那个量写成 x 的函数 \(f(x)\)，并确定 x 的可行区间（定义域）。
  3. 求导找临界点：\(f'(x)=0\) 解出临界点。
  4. 判断并回答：用一阶或二阶导数检验确认最值，或比较端点值。务必回答题目问的是什么。

常见坑：忘记确定定义域！"第一象限内""长度为正值"等条件决定 x 的取值范围，直接影响端点和临界点是否合法。

例题（作业 3 第 1a 题型）：梯子问题

设梯子长 \(L\)，底端离墙距离为 x，顶端高度为 y，则约束为 \(x^2+y^2=L^2\)。若要求某个关于 x 的量的极值，就把 y 用 \(\sqrt{L^2-x^2}\) 代入目标函数，再对 x 求导。记得检查端点——x 不能为 0 或 L。

例题：第一象限内接三角形的极值面积

（与复习题 3 同类）过点 \((1,2)\) 作一条负斜率直线，与正 x 轴、正 y 轴围成三角形。设斜率为 \(m<0\)，则直线方程 \(y-2=m(x-1)\)，x 截距 \(x_0=1-2/m\)，y 截距 \(y_0=2-m\)。面积

\[A(m)=\frac{1}{2}x_0 y_0=\frac{1}{2}(1-2/m)(2-m).\]

对 m 求导并令 \(A'(m)=0\)，结合 \(m<0\) 筛选合法临界点，再用二阶导数或端点比较确认最小值（或最大值）。

用导数检验判断最值

求出临界点后，要证明它确实是最值（而不仅是候选）：

  • 二阶导数检验：若 \(f'(c)=0,\;f''(c)>0\) 则 c 为局部极小；\(f''(c)<0\) 则局部极大。若区间内只有一个临界点且问题是"求最值"，则局部最值就是全局最值。
  • 一阶导数检验：看 f′ 在 c 两侧的符号；适用于 f″ 不存在或为零的情形。
  • 闭区间比较法：把临界点与端点处的函数值全部列出比较——这是最可靠、考试中最推荐的做法。

实用技巧：如果题目情境决定了"最值必然存在"，而你在区间内部只找到一个临界点，那么无需二阶检验，该临界点就是所求的最值点——这是 18.01 优化题常用的"唯一临界点即最值"论证。

常见误区与边界情况

  • 忘记端点：闭区间上的最值可能在端点，必须代入。
  • 忘记定义域：应用题中变量有实际范围（长度为正、在第一象限等），临界点可能落在定义域外，应舍去。
  • 没有"证明"是最值：只算出 \(f'(x)=0\) 的根还不够，需要用一阶/二阶检验或端点比较说明它确实是最值。作业明确要求 "Show that you get a minimum"。
  • 把局部最值当全局最值：除非题目保证存在性或你比较了所有候选，否则不能直接认定。
  • 变量选得不好：导致目标函数复杂。多画图、多试几种设法，选让导数最简洁的那个。

知识检查

问题 1：求连续函数在闭区间 \([a,b]\) 上的绝对最值，必须比较哪些点？

问题 2：解应用优化问题的第一步应该做什么？

问题 3：在某个区间内只找到一个临界点，且由实际背景知最值存在，则能得出什么结论？

问题 4：求出一个临界点后，应用题中下一步必须做什么？

本课要点

闭区间法

临界点 + 两端点，比较函数值

应用建模

定义变量→目标函数→求导→检验

定义域

实际约束决定哪些临界点合法

证明最值

一阶/二阶检验或端点比较，不能只解 f′=0

唯一临界点

最值存在且临界点唯一 → 它就是答案
