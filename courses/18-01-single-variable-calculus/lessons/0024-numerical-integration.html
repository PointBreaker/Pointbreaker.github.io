数值积分

许多定积分找不到初等闭形（如 \(\int_0^{\pi/2}\cos(t^2)\,dt\)），但工程上仍需要数值答案。这一课介绍两种经典近似方案——梯形法则 (Trapezoidal rule) 与辛普森法则 (Simpson's rule)——并给出它们的误差估计，这是 Exam 3 的收官考点。

授课：Prof. David Jerison 日期：2006-11-02 难度：中等

这一课在课程中的位置

前几课教了用 FTC 1 算精确积分的方法，但被积函数 \(\cos(t^2)\)、\(e^{-x^2}\) 等没有初等反导数。这一课转向数值近似：把积分区间等分，用折线或抛物线代替曲线，再求和。Exam 3 会要求你手算梯形 / 辛普森近似值并估算误差。

梯形法则 (Trapezoidal rule)

把 \([a,b]\) 分成 \(n\) 等份，步长 \(h=(b-a)/n\)，节点 \(x_i=a+ih\)，\(y_i=f(x_i)\)。在每个子区间 \([x_{i-1},x_i]\) 上用梯形代替曲边：

\[ \int_{x_{i-1}}^{x_i} f(x)\,dx \approx \frac{h}{2}(y_{i-1}+y_i). \]

求和得复合梯形公式：

\[ T_n = \frac{h}{2}\Bigl(y_0 + 2y_1 + 2y_2 + \dots + 2y_{n-1} + y_n\Bigr). \]

误差估计

若 \(f''\) 在 \([a,b]\) 上连续，记 \(M_2 = \max_{[a,b]}|f''(x)|\)，则梯形误差满足

\[ |E_T| \le \frac{(b-a)^3}{12n^2}\,M_2 = \frac{(b-a)h^2}{12}\,M_2. \]

误差按 \(O(h^2)\) 衰减——步长减半，误差约减为四分之一。

例 1：\(\int_0^{\pi/2}\sin^6 x\,dx\)，\(n=2\)

节点：\(x_0=0\)，\(x_1=\pi/4\)，\(x_2=\pi/2\)，\(h=\pi/4\)。

\(y_0=\sin^6 0=0\)，\(y_1=\sin^6(\pi/4)=(\sqrt2/2)^6=1/8\)，\(y_2=\sin^6(\pi/2)=1\)。

\[ T_2 = \frac{\pi/4}{2}\Bigl(0 + 2\cdot\tfrac18 + 1\Bigr) = \frac{\pi}{8}\cdot\frac54 = \frac{5\pi}{32} \approx 0.4909. \]

辛普森法则 (Simpson's rule)

梯形用直线近似，辛普森用抛物线近似——每两个子区间（三个点）拟合一条二次曲线。设区间 \([x_0,x_2]\) 长 \(2h\)，中点 \(x_1=x_0+h\)，抛物线过 \((x_0,y_0)\)、\((x_1,y_1)\)、\((x_2,y_2)\)，其下面积为

\[ \frac{h}{3}(y_0+4y_1+y_2). \]

辛普森公式的关键：系数模式是 \(1,4,2,4,2,\dots,4,1\)。必须要求偶数个子区间（奇数个节点）。

复合辛普森公式（\(n\) 为偶数）：

\[ S_n = \frac{h}{3}\Bigl(y_0 + 4y_1 + 2y_2 + 4y_3 + \dots + 4y_{n-1} + y_n\Bigr). \]

误差估计

若 \(f^{(4)}\) 连续，记 \(M_4=\max|f^{(4)}(x)|\)，则

\[ |E_S| \le \frac{(b-a)^5}{180n^4}\,M_4 = \frac{(b-a)h^4}{180}\,M_4. \]

误差按 \(O(h^4)\) 衰减——步长减半，误差约减为十六分之一，比梯形快得多。

例 2：同例 1，辛普森法则 \(n=2\)

\[ S_2 = \frac{\pi/4}{3}\Bigl(0 + 4\cdot\tfrac18 + 1\Bigr) = \frac{\pi}{12}\cdot\frac32 = \frac{\pi}{8} \approx 0.3927. \]

辛普森公式的证明思路（PS6 第 4 题）

平移区间使 \(x_0=-h\)，\(x_1=0\)，\(x_2=h\)。设过三点的抛物线 \(y=Ax^2+Bx+C\)：

  • 由 \(y(-h)=y_0\)、\(y(0)=y_1\)、\(y(h)=y_2\) 解得 \(C=y_1\)，\(A=\frac{y_0-2y_1+y_2}{2h^2}\)，\(B=\frac{y_2-y_0}{2h}\)。
  • 积分 \(\int_{-h}^h (Ax^2+Bx+C)\,dx = \frac{2Ah^3}{3}+2Ch\)。
  • 代入 \(A,C\)：\(\frac{h}{3}(y_0+4y_1+y_2)\)。

例 3：菲涅尔积分近似（PS6 第 5 题）

精确到五位小数，\(\displaystyle\int_0^{\pi/2}\cos(t^2)\,dt \approx 1.22505\)。用辛普森 \(n=4\) 与 \(n=8\) 做近似，可以观察到误差随 \(n\) 增大迅速缩小。

两种方法对比

方法每段近似误差阶要求
梯形直线\(O(h^2)\)任意 \(n\)
辛普森抛物线\(O(h^4)\)\(n\) 为偶数

辛普森精度远高于梯形（同 \(n\) 下），但要求偶数段且被积函数四阶导数连续。

常见误区与边界情况

辛普森法则要求偶数个子区间：\(n\) 必须是偶数，否则系数模式 \(1,4,2,4,\dots\) 对不上。

  • 系数别记错：梯形是 \(1,2,2,\dots,2,1\)；辛普森是 \(1,4,2,4,\dots,4,1\)。
  • 步长 \(h\) 的定义：\(h=(b-a)/n\)，辛普森中每段跨 \(2h\)（两个子区间）。
  • 误差界要算导数：误差公式需要 \(\max|f''|\) 或 \(\max|f^{(4)}|\)，考试会给或要求你估算。
  • 近似 ≠ 精确：数值方法给出近似值，能算精确时仍应用 FTC。
  • 被积函数要光滑：若 \(f\) 有尖点或间断，误差估计可能失效。
