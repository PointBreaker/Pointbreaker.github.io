考试范围与题型

  1. 计算定积分：换元法、FTC 1。
  2. FTC 2 应用：\(\displaystyle F(x)=\int_a^x f(t)\,dt\) 的导数、图像、换元。

  4. 面积与体积：曲线间面积、旋转体体积（圆盘/垫圈/壳层）、一般切片。

核心公式速查表

定积分基本性质

\[ \int_a^b f = -\int_b^a f,\quad \int_a^c f = \int_a^b f + \int_b^c f,\quad \int_a^b cf = c\int_a^b f,\quad \Bigl|\int_a^b f\Bigr|\le\int_a^b |f|. \]

两个基本定理

\[ \text{FTC 1: }\int_a^b f(x)\,dx = F(b)-F(a),\quad F'(x)=f(x). \] \[ \text{FTC 2: }\frac{d}{dx}\int_a^x f(t)\,dt = f(x). \]

面积与体积

\[ A = \int_a^b (\text{上}-\text{下})\,dx. \] \[ V_{\text{圆盘}} = \int_a^b \pi R(x)^2\,dx,\quad V_{\text{垫圈}} = \int_a^b \pi\bigl(R^2-r^2\bigr)\,dx,\quad V_{\text{壳层}} = \int_a^b 2\pi x\,h(x)\,dx. \]

累积量

\[ f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx,\quad W = \int_a^b F(x)\,dx,\quad P = \int_a^b p(x)\,dx. \]

数值积分（\(n\) 等份，\(h=(b-a)/n\)）

\[ T_n = \frac{h}{2}(y_0+2y_1+\dots+2y_{n-1}+y_n),\quad |E_T|\le\frac{(b-a)h^2}{12}M_2. \] \[ S_n = \frac{h}{3}(y_0+4y_1+2y_2+\dots+4y_{n-1}+y_n),\quad |E_S|\le\frac{(b-a)h^4}{180}M_4. \]

对数定义

\[ \ln x = \int_1^x \frac{dt}{t},\quad \ln(ab)=\ln a+\ln b. \]

代表性习题精练

以下题目改编自 prexam 3 复习题（Notes Exam 3 Review），覆盖五大题型。先尝试独立完成，再看提示。

A 类：计算定积分

A1：\(\displaystyle \int_0^1 \frac{dx}{1+3x}\)。

提示：令 \(u=1+3x\)，\(du=3dx\)，\(x=0,1\) 对应 \(u=1,4\)。答案：\(\frac13\ln 4 = \frac23\ln 2\)。

A2：\(\displaystyle \int_0^{\pi/2} \cos x\sin 2x\,dx\)。

提示：\(\sin 2x = 2\sin x\cos x\)，被积函数 \(=2\sin x\cos^2 x\)，凑 \(u=\cos x\)。答案：\(2/3\)。

B 类：FTC 2 与变限积分

B1：设 \(\displaystyle F(x)=\int_0^x (3+\sin t)\,dt\)。

  • (a) 不求显式公式，证明 \(F(1)\ge 2\)。
  • (b) 判断 \(F(x)\) 在 \(0<x<1\) 上是凹 (concave up) 还是凸 (concave down)。
  • (c) 把 \(\displaystyle \int_1^2 (3+\sin 2t)\,dt\) 用 \(F\) 的值表示。

解答：

  • (a) 在 \([0,1]\) 上 \(\sin t\ge -1\)，故 \(3+\sin t\ge 2\)，积分 \(\ge 2\cdot 1 = 2\)。
  • (b) \(F'(x)=3+\sin x\)，\(F''(x)=\cos x\)。在 \(0<x<1\)（弧度）内 \(\cos x>0\)，故 \(F''>0\)，图像凹 (concave up)。
  • (c) 令 \(u=2t\)，则 \(\int_1^2 (3+\sin 2t)\,dt = \frac12\int_2^4 (3+\sin u)\,du = \frac12\bigl(F(4)-F(2)\bigr)\)。

B2：若 \(\displaystyle \int_0^x f(t)\,dt = e^{2x}\cos x + c\)，求 \(f(t)\) 与常数 \(c\)。

解答：两边对 \(x\) 求导：\(f(x) = 2e^{2x}\cos x - e^{2x}\sin x\)，故 \(f(t)=e^{2t}(2\cos t-\sin t)\)。令 \(x=0\)：左边 \(=0\)，右边 \(=1+c\)，故 \(c=-1\)。

C 类：体积

C1：玻璃花瓶由 \(y=\sqrt{x}\) 在第一象限绕 \(y\) 轴旋转而成（\(0\le x\le a\)）。用水平切片求体积。

解答：水平切片是半径 \(x=y^2\) 的圆盘（\(0\le y\le\sqrt a\)）：

\[ V = \int_0^{\sqrt a} \pi (y^2)^2\,dy = \pi\int_0^{\sqrt a} y^4\,dy = \frac{\pi (\sqrt a)^5}{5} = \frac{\pi a^{5/2}}{5}. \]

C2：冰淇淋筒（prexam 3 第 7 题）：圆锥高 5、底半径 1，顶点在原点、轴沿正 \(y\) 轴；顶部覆盖由 \(y=6-x^2\) 绕 \(y\) 轴旋转的抛物面。用壳层法求冰淇淋体积。

提示：圆锥母线方程 \(x = y/5\)（半径与高度成正比）。在 \(x\) 处壳层高度 = 抛物面 \(y=6-x^2\) 减去圆锥顶 \(y=5x\)（改写为 \(y\) 关于 \(x\)）。求两曲线交点定积分限，用壳层公式 \(2\pi x\cdot h(x)\) 积分。

D 类：平均值与概率

D1：矩形内接于半径为 \(a\) 的四分之一圆（\(x\in[0,a]\)），\(x\) 在 \([0,a]\) 上均匀随机选取，求矩形平均面积。

解答：矩形宽 \(x\)、高 \(\sqrt{a^2-x^2}\)，面积 \(A(x)=x\sqrt{a^2-x^2}\)。平均值：

\[ \frac{1}{a}\int_0^a x\sqrt{a^2-x^2}\,dx \overset{u=a^2-x^2}{=} \frac{1}{a}\cdot\frac12\int_0^{a^2} u^{1/2}\,du = \frac{1}{3a}a^3 = \frac{a^2}{3}. \]

E 类：数值积分

E1：用梯形法则和辛普森法则（均取 \(n=2\)）近似 \(\displaystyle \int_0^{\pi/2}\sin^6 x\,dx\)。

解答：节点 \(0,\pi/4,\pi/2\)，\(y_0=0,y_1=1/8,y_2=1\)。

  • 梯形：\(T_2=\frac{\pi/4}{2}(0+2\cdot 1/8+1)=\frac{5\pi}{32}\approx 0.4909\)。
  • 辛普森：\(S_2=\frac{\pi/4}{3}(0+4\cdot 1/8+1)=\frac{\pi}{8}\approx 0.3927\)。

考前提醒：高频失分点

壳层 vs 圆盘选错：绕 \(y\) 轴旋转时，若竖条高度表达式简单，优先用壳层法；若水平截面半径简单，用垫圈法。

  • 换元忘换限：换元后立即改上下限，或代回原变量再代原限——两种都对，混用必错。
  • 垫圈法「外减内」要平方：\(\pi(R^2-r^2)\)，不是 \(\pi(R-r)^2\)。
  • 辛普森要求偶数段：\(n\) 必须是偶数。
  • 有向面积 vs 总面积：题目问面积时，若曲线交叉必须分段取绝对值。
  • FTC 2 链式法则：\(\frac{d}{dx}\int_a^{g(x)} f = f(g(x))\,g'(x)\)。
  • 数值近似的系数：梯形 \(1,2,\dots,2,1\)；辛普森 \(1,4,2,4,\dots,4,1\)。
