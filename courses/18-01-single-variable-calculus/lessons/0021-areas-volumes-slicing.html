曲线之间面积，切片法求体积

定积分的力量在于它能把「不规则形状」的度量变成积分运算。这一课把面积从「曲线下方」推广到「两条曲线之间」，再用切片法 (slicing) 求一般三维立体的体积——这是微积分走向几何应用的第一次飞跃。

授课：Prof. David Jerison 日期：2006-10-26 难度：中等

这一课在课程中的位置

第 18–20 课建立了定积分与基本定理的理论框架，第 15–16 课给出了实际物理意义（位移、速度）。这一课把抽象的积分落到几何上：面积与体积。下一课的圆盘法与壳层法会把「切片」技巧专门化到旋转体，而这里学到的「先截面、再积分」思路是处理一切累积量问题的通用模板。

两条曲线之间的面积

设 \(f(x) \ge g(x)\) 对所有 \(x\in[a,b]\) 成立，由曲线 \(y=f(x)\)、\(y=g(x)\)、直线 \(x=a\)、\(x=b\) 所围区域的面积为

\[ A = \int_a^b \bigl(f(x)-g(x)\bigr)\,dx. \]

「外减内」原理：竖条的高度是 \(f(x)-g(x)\)，宽度是 \(dx\)，面积微元 \(dA = (f-g)\,dx\)。积分即把这些竖条从 \(a\) 累加到 \(b\)。

例 1：抛物线与直线

求由 \(y=x^2\) 与 \(y=x\) 所围区域的面积。

先求交点：\(x^2=x\) 得 \(x=0,1\)。在 \([0,1]\) 上 \(x \ge x^2\)，故

\[ A = \int_0^1 (x-x^2)\,dx = \Bigl[\frac{x^2}{2}-\frac{x^3}{3}\Bigr]_0^1 = \frac12-\frac13 = \frac16. \]

例 2：曲线相交、上下翻转

求 \(y=\sin x\) 与 \(y=\cos x\) 在 \([0,\pi/2]\) 上所围面积。

交点：\(\sin x=\cos x\) 得 \(x=\pi/4\)。在 \([0,\pi/4]\) 上 \(\cos x\ge\sin x\)，在 \([\pi/4,\pi/2]\) 上 \(\sin x\ge\cos x\)。因此

\[ A = \int_0^{\pi/4}(\cos x-\sin x)\,dx + \int_{\pi/4}^{\pi/2}(\sin x-\cos x)\,dx. \]

第一段：\([\sin x+\cos x]_0^{\pi/4} = (\frac{\sqrt2}{2}+\frac{\sqrt2}{2})-(0+1) = \sqrt2-1\)。第二段：\([-\cos x-\sin x]_{\pi/4}^{\pi/2} = (0-1)-(-\frac{\sqrt2}{2}-\frac{\sqrt2}{2}) = \sqrt2-1\)。总面积 \(=2\sqrt2-2\)。

必须找到交点：若区间内 \(f-g\) 会变号，必须分段积分，否则正负会抵消，得到错误面积。

用水平条（对 y 积分）

有时对 \(y\) 积分更方便：若 \(x_{\text{right}}(y) \ge x_{\text{left}}(y)\)，则

\[ A = \int_c^d \bigl(x_{\text{right}}(y)-x_{\text{left}}(y)\bigr)\,dy. \]

例：由 \(y=x^2\) 与 \(y=x\) 所围面积，改写为 \(x=y\) 与 \(x=\sqrt{y}\)，对 \(y\) 从 0 到 1 积分：

\[ A = \int_0^1 (y-\sqrt{y})\,dy = \Bigl[\frac{y^2}{2}-\frac{2}{3}y^{3/2}\Bigr]_0^1 = \frac12-\frac23 = \frac16. \]

切片法求体积

设三维立体位于 \(x=a\) 与 \(x=b\) 之间，过点 \(x\) 作垂直于 \(x\) 轴的截面，截面面积为 \(A(x)\)。体积微元是厚度 \(dx\)、底面 \(A(x)\) 的薄片，因此

\[ V = \int_a^b A(x)\,dx. \]

「切片法」的核心：只要能用 \(x\) 表达截面积 \(A(x)\)，体积就等于 \(\int A(x)\,dx\)。

例 3：正方锥体

底面是边长为 \(a\) 的正方形、高为 \(h\) 的正方锥。在高度 \(x\) 处（从顶点起算），截面是边长为 \(s(x)=a\cdot x/h\) 的正方形，面积 \(A(x) = a^2 x^2/h^2\)。于是

\[ V = \int_0^h \frac{a^2 x^2}{h^2}\,dx = \frac{a^2}{h^2}\cdot\frac{h^3}{3} = \frac{a^2 h}{3}, \]

即「底乘高除以 3」。

例 4：一般锥体

任何底面积为 \(B\)、高为 \(h\) 的锥体，在高度 \(x\) 处截面面积按相似比 \(x/h\) 缩小：\(A(x) = B(x/h)^2\)。故

\[ V = \int_0^h B\frac{x^2}{h^2}\,dx = \frac{B}{h^2}\cdot\frac{h^3}{3} = \frac{Bh}{3}. \]

这说明所有锥体（不论底面形状）体积都是 \(\frac13 Bh\)。

例 5：PS5 第 3b 题思路

求由 \(x,y,z>0\) 与 \(z/2 < x+y < z\) 所围区域的体积。

思路：先固定 \(z\)，水平截面是 \(x,y>0\) 上满足 \(z/2 < x+y < z\) 的区域，这是一个等腰直角三角形之间的「环带」。求出截面面积 \(A(z)\)（它是 \(z\) 的二次函数），再对 \(z\) 积分。

例 6：旋转体的预备——圆盘

把区域 \(0\le y\le f(x)\)，\(a\le x\le b\) 绕 \(x\) 轴旋转，截面是半径 \(R(x)=f(x)\) 的圆盘，面积 \(A(x)=\pi f(x)^2\)，故

\[ V = \int_a^b \pi f(x)^2\,dx. \]

这是下一课圆盘法 (disk method) 的特例。

常见误区与边界情况

面积必须是非负的：算面积时若 \(f-g\) 变号却没分段，积分会给出有向面积而非几何面积。

  • 选对积分变量：对 \(x\) 积分用竖条，对 \(y\) 积分用水平条。选错变量可能让反函数很复杂。
  • 截面面积表达式：切片法要求 \(A(x)\) 能写出显式。如果截面形状随 \(x\) 变化，要仔细找出规律。
  • 旋转轴：绕 \(x\) 轴用 \(dx\)、绕 \(y\) 轴用 \(dy\)。轴选错会让半径表达式错乱。
  • 单位一致性：面积是长度平方，体积是长度立方，截面面积表达式里不要漏平方。
