考试印发公式表（必须会用）

以下公式会随试卷印发，但你必须在考前就熟记用法，不能靠现场查：

三角恒等式

\[\sin^2 x + \cos^2 x = 1,\qquad \sec^2 x = \tan^2 x + 1.\] \[\sin^2 x = \frac{1-\cos 2x}{2},\qquad \cos^2 x = \frac{1+\cos 2x}{2}.\] \[\cos 2x = \cos^2 x - \sin^2 x,\qquad \sin 2x = 2\sin x\cos x.\]

导数公式

\[\frac{d}{dx}\tan x = \sec^2 x,\quad \frac{d}{dx}\sec x = \sec x\tan x,\quad \frac{d}{dx}\tan^{-1}x = \frac{1}{1+x^2},\quad \frac{d}{dx}\sin^{-1}x = \frac{1}{\sqrt{1-x^2}}.\]

积分公式

\[\int \tan x\,dx = -\ln(\cos x) + c,\qquad \int \sec x\,dx = \ln(\sec x + \tan x) + c.\]

公式表不包含的内容（必须自己背）：部分分式形状、分部积分公式、递推公式、弧长/面积公式、极坐标面积公式、配方模式。

核心公式清单（需熟记）

1. 三角反代换

  • \(a^2-x^2\)：令 \(x=a\sin u\)，\(dx=a\cos u\,du\)，\(\sqrt{a^2-x^2}=a\cos u\)
  • \(a^2+x^2\)：令 \(x=a\tan u\)，\(dx=a\sec^2 u\,du\)，\(\sqrt{a^2+x^2}=a\sec u\)
  • \(x^2-a^2\)：令 \(x=a\sec u\)，\(dx=a\sec u\tan u\,du\)，\(\sqrt{x^2-a^2}=a\tan u\)

做完后画直角三角形回代。

2. 部分分式（系统流程）

对 \(P/Q\)，若 deg(P) ≥ deg(Q) → 长除。把 Q 分解为一次和不可约二次因式，按以下形状拆分：

\[\frac{3x^2+1}{(x-1)(x+2)^2(x^2+9)} = \frac{A}{x-1}+\frac{B_1}{x+2}+\frac{B_2}{(x+2)^2}+\frac{Cx+D}{x^2+9}.\]

系数用覆盖法（单/最高次重因式）+ 代入特殊值（常取 x=0）确定。

3. 分部积分

\[\int_a^b u\,dv = \bigl[uv\bigr]_a^b - \int_a^b v\,du.\]

选 u 的经验顺序：LIATE（对数 > 反三角 > 代数 > 三角 > 指数）。

4. 弧长

\[ds = \sqrt{dx^2+dy^2} = \sqrt{1+(dy/dx)^2}\,dx = \sqrt{(dx/dt)^2+(dy/dt)^2}\,dt = \sqrt{(dx/dy)^2+1}\,dy.\]

5. 旋转面面积

  • 绕 x 轴：\(2\pi y\,ds = 2\pi y\sqrt{1+(dy/dx)^2}\,dx\)（需要 y=y(x)）
  • 绕 y 轴：\(2\pi x\,ds = 2\pi x\sqrt{(dx/dy)^2+1}\,dy\)（需要 x=x(y)）

6. 极坐标

\(x=r\cos\theta,\ y=r\sin\theta\)。面积：\(A = \frac12\int_{\theta_1}^{\theta_2} r^2\,d\theta\)。注意 θ 区间不重复不遗漏。

代表性题型

题型 A：含根号的积分（三角代换 + 配方）

例 A1：∫ dx/√(x²+4x+13)。配方 → (x+2)²+9，令 x+2=3 tan u → (1/3)tan⁻¹((x+2)/3)+c。

例 A2：∫ √(a²−x²) dx。令 x=a sin u，用半角公式，画图回代。

题型 B：有理函数积分（长除 + 部分分式）

例 B1：∫ x³/(x²−2x+1) dx。长除得 x+2+(3x−2)/(x²−2x+1)，余项拆部分分式（分母 (x−1)²）。

例 B2：∫ (x²+x+1)/((x−1)²(x+2)) dx。形状 A/(x−1)+B/(x−1)²+C/(x+2)，覆盖法求 B、C，代入 x=0 求 A。

题型 C：乘积积分（分部积分）

例 C1：∫ x² eˣ dx → 两次分部。

例 C2：∫ eˣ sin x dx → 循环型，解方程。

题型 D：弧长与旋转面面积

例 D1：求 y=x²/2 一段的弧长 → ds = √(1+x²) dx，可能需三角代换。

例 D2：把 y=√x 绕 x 轴旋转的表面积 → 2π∫y ds。

题型 E：极坐标面积

例 E1：求 r=2cos θ 内部面积 → (1/2)∫₋π/2^{π/2} 4cos²θ dθ = π。

高频失分点

1. 假分式没长除。这是 lecture 32 复习讲义专门强调的第一条。看到 deg(P) ≥ deg(Q)，立刻长除。

2. 部分分式漏项。(x−a)ᵐ 要写 m 项；不可约二次的分子必须是一次式 Cx+D。

3. 分部积分后忘记 ±∫v du。公式是 ∫u dv = uv − ∫v du，负号和 v du 都不能丢。

4. 极坐标面积忘乘 1/2。A = (1/2)∫r² dθ，不是 ∫r² dθ。

5. 旋转面面积半径写反。绕 x 轴半径是 y，绕 y 轴半径是 x。

6. 三角回代不画图。不画直角三角形就回代，极易把邻边对边搞反。
