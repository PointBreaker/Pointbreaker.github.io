参数方程、弧长与表面积

很多曲线无法写成 y=f(x) 或 x=g(y) 的形式——圆、摆线、椭圆都更适合用参数 (x(t), y(t)) 描述。这一课把积分从“沿着 x 轴”推广到“沿着曲线”：用参数 t 写出弧长微元 ds，进而求弧长 (arc length) 和旋转面面积 (surface area)。

授课：Prof. David Jerison 日期：2006-11-17 难度：中等

这一课在课程中的位置

你已经会算面积和体积（沿着 x 或 y 轴积分）。本课引入参数方程，把“沿曲线”的积分统一表达。弧长是定积分的一个直接应用，而旋转面面积是期中 4 的重点公式之一。下一课（极坐标）会再给出一套参数化 (r(θ), θ)，本课的 ds 推导是它的基础。

参数方程入门

若曲线上每一点的坐标由同一个参数 t 决定：

\[x = x(t),\qquad y = y(t),\quad t_0\le t\le t_1,\]

则 t 变化时点 (x(t),y(t)) 就描出整条曲线。

例：圆和椭圆

圆 \(x^2+y^2=a^2\) 的参数方程：\(x=a\cos t,\ y=a\sin t,\ 0\le t\le 2\pi\)。

椭圆 \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\)：\(x=a\cos t,\ y=b\sin t\)。

从参数式消去 t

有时需要把参数方程代回直角坐标。例如 \(x=a\cos^3 t,\ y=a\sin^3 t\)（星形线）：

\[x^{2/3}+y^{2/3} = a^{2/3}(\cos^2 t+\sin^2 t) = a^{2/3}.\]

弧长公式

把一小段弧长 ds 近似为直角三角形的斜边：\(ds^2 = dx^2 + dy^2\)。两边除以 dt² 再开方：

\[ds = \sqrt{\left(\frac{dx}{dt}\right)^{\!2} + \left(\frac{dy}{dt}\right)^{\!2}}\,dt.\]

从 t₀ 到 t₁ 积分，得到弧长：

\[\boxed{L = \int_{t_0}^{t_1} \sqrt{\left(\frac{dx}{dt}\right)^{\!2} + \left(\frac{dy}{dt}\right)^{\!2}}\,dt.}\]

三种等价形式：根据选哪个变量作积分元，弧长可写成

\[ds = \sqrt{1+\left(\frac{dy}{dx}\right)^{\!2}}\,dx = \sqrt{\left(\frac{dx}{dt}\right)^{\!2}+\left(\frac{dy}{dt}\right)^{\!2}}\,dt = \sqrt{\left(\frac{dx}{dy}\right)^{\!2}+1}\,dy.\]

例 1：圆的弧长（参数式）

\(x=a\cos t,\ y=a\sin t\)，dx/dt = −a sin t，dy/dt = a cos t：

\[ds = \sqrt{a^2\sin^2 t + a^2\cos^2 t}\,dt = a\,dt.\]

一圈 \(t\in[0,2\pi]\)：\(L = \int_0^{2\pi} a\,dt = 2\pi a\)，与常识一致。

例 2：星形线的弧长

\(x=a\cos^3 t,\ y=a\sin^3 t\)，则 dx/dt = −3a cos²t sin t，dy/dt = 3a sin²t cos t：

\[ds = \sqrt{9a^2\cos^4 t\sin^2 t + 9a^2\sin^4 t\cos^2 t}\,dt = 3a|\sin t\cos t|\,dt.\]

利用对称性，算第一象限（t∈[0,π/2]，sin t, cos t ≥ 0）再乘 4：

\[L = 4\int_0^{\pi/2} 3a\sin t\cos t\,dt = 12a\int_0^{\pi/2}\sin t\cos t\,dt = 12a\cdot\frac{1}{2} = 6a.\]

期中提示：弧长积分往往根号下是一个完全平方，先化简根号再积分；对称性可以大幅减少计算量。

旋转面面积

把一段弧 ds 绕轴旋转，它扫出一个“细带”，面积 ≈ 周长 × 带宽 = \(2\pi(\text{半径})\cdot ds\)。

旋转轴半径面积微元 dA
绕 x 轴\(y\)（竖直距离）\(dA = 2\pi y\,ds\)
绕 y 轴\(x\)（水平距离）\(dA = 2\pi x\,ds\)

代入 ds 的三种形式：

\[\text{绕 x 轴： } A = \int 2\pi y\,\sqrt{1+(dy/dx)^2}\,dx.\] \[\text{绕 y 轴： } A = \int 2\pi x\,\sqrt{(dx/dy)^2+1}\,dy.\]

例 3：球面面积（绕 x 轴旋转半圆）

上半圆 \(y=\sqrt{a^2-x^2}\)，\(x\in[-a,a]\)。dy/dx = −x/y，所以：

\[1+\left(\frac{dy}{dx}\right)^2 = 1+\frac{x^2}{y^2} = \frac{x^2+y^2}{y^2} = \frac{a^2}{y^2}.\] \[dA = 2\pi y\cdot\frac{a}{y}\,dx = 2\pi a\,dx.\]

积分：\(A = \int_{-a}^{a} 2\pi a\,dx = 4\pi a^2\)。

应用：悬链线与悬链面

第 8A 课问题 2 引入了双曲函数：

\[\cosh x = \frac{e^x+e^{-x}}{2},\qquad \sinh x = \frac{e^x-e^{-x}}{2}.\]

它们满足 \(\dfrac{d}{dx}\sinh x = \cosh x\)，\(\dfrac{d}{dx}\cosh x = \sinh x\)，以及恒等式 \(\cosh^2 x = 1+\sinh^2 x\)。

悬链线的参数化

曲线 \(x=\cosh t,\ y=\sinh t\) 满足 \(y^2-x^2 = -1\)，即 \(x^2-y^2=1\)——这是一条等轴双曲线。

悬链线 y=cosh x 的弧长

这里 y 直接是 x 的函数，用 x 作参数：dy/dx = sinh x。

\[\sqrt{1+\sinh^2 x} = \sqrt{\cosh^2 x} = \cosh x.\]

从最低点 (0,1) 到点 (x₁, cosh x₁) 的弧长：

\[L = \int_0^{x_1} \cosh x\,dx = \sinh x_1.\]

一个漂亮的结果：悬链线一段的弧长恰好等于该点的 sinh 值。

悬链面（catenoid）的表面积

把上面这段绕 x 轴旋转，dA = 2πy ds = 2π cosh x · cosh x dx = 2π cosh²x dx：

\[A = \int_0^{x_1} 2\pi\cosh^2 x\,dx.\]

用恒等式 \(\cosh^2 x = \dfrac{1+\cosh 2x}{2}\)：

\[A = 2\pi\int_0^{x_1}\frac{1+\cosh 2x}{2}\,dx = \pi\!\left[x + \frac{\sinh 2x}{2}\right]_0^{x_1} = \pi\!\left(x_1 + \sinh x_1\cosh x_1\right).\]

这个“最小曲面”正是肥皂膜在两个圆环之间自然张成的形状。

常见误区与边界情况

1. 旋转轴和半径搞混。绕 x 轴旋转时，半径是 |y|（到 x 轴的竖直距离）；绕 y 轴旋转时，半径是 |x|。写反是最常见的丢分。

2. 弧长积分忘记开方。ds = √(dx²+dy²)，不是 dx²+dy² 本身。根号下的式子要仔细化简。

3. 参数区间取错。参数 t 的上下限必须对应曲线的起止点。比如圆 x=a cos t, y=a sin t，t∈[0,π] 只是上半圆，不是整圆。

4. 绝对值。当根号化简得到 |sin t cos t| 这类形式时，要根据 t 的区间判断正负，必要时分段或利用对称性。

本课要点

参数方程

x=x(t), y=y(t)，消去 t 可得直角坐标方程

弧长公式

ds = √((dx/dt)²+(dy/dt)²) dt = √(1+(dy/dx)²) dx

旋转面面积

绕 x 轴：2πy ds；绕 y 轴：2πx ds

双曲函数

cosh²x − sinh²x = 1，求导互逆

对称性

弧长和表面积常可利用对称区间化简
