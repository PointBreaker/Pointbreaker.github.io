未定式与洛必达法则

\(\frac{0}{0}\)、\(\frac{\infty}{\infty}\)、\(0\cdot\infty\)、\(\infty-\infty\)、\(1^\infty\)、\(0^0\)、\(\infty^0\)——这些“未定式”不能直接代入求极限。洛必达法则 (L'Hôpital's rule) 把 \(\frac{0}{0}\) 和 \(\frac{\infty}{\infty}\) 的极限转化为导数之比的极限；其他五种形式则通过取对数或通分化归为前两种。

授课：Prof. David Jerison 日期：2006-12-01 难度：中等

这一课在课程中的位置

这是期中 4 之后的第一课，开启课程的最后一章：从“积分技术”转向“极限的进阶技巧 + 无穷”。洛必达法则是计算未定式极限的利器，也是后续广义积分（第 35 课）和级数审敛（第 36 课）中反复用到的工具。期末考会直接考洛必达（见 practice final 第 15 题）。

七种未定式

直接代入极限点会得到一个无意义或不确定的表达式，称为未定式 (indeterminate form)：

形式为什么“未定”化归目标
\(\frac{0}{0}\)洛必达直接适用——
\(\frac{\infty}{\infty}\)洛必达直接适用——
\(0\cdot\infty\)改写为 \(\frac{0}{1/\infty}\) 或 \(\frac{\infty}{1/0}\)\(\frac{0}{0}\) 或 \(\frac{\infty}{\infty}\)
\(\infty-\infty\)通分、有理化、提公因式\(\frac{0}{0}\) 或 \(\frac{\infty}{\infty}\)
\(1^\infty\)取对数：\(\ln L = \lim \ln f\)\(0\cdot\infty\) → 继续化归
\(0^0\)取对数\(0\cdot\infty\)
\(\infty^0\)取对数\(0\cdot\infty\)

核心策略：只有 \(\frac{0}{0}\) 和 \(\frac{\infty}{\infty}\) 能直接用洛必达；其他五种都要先代数变形，化归成这两种之一。

洛必达法则

设 f、g 可导，\(g'(x)\neq 0\)，且满足以下两种情形之一：

  • \(\displaystyle\lim_{x\to a}f(x)=0\) 且 \(\displaystyle\lim_{x\to a}g(x)=0\)（\(\frac{0}{0}\) 型），或
  • \(\displaystyle\lim_{x\to a}|f(x)|=\infty\) 且 \(\displaystyle\lim_{x\to a}|g(x)|=\infty\)（\(\frac{\infty}{\infty}\) 型），

且 \(\displaystyle\lim_{x\to a}\frac{f'(x)}{g'(x)}\) 存在（或为 ±∞），则：

\[\boxed{\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}.}\]

法则对 \(x\to a^+,\ x\to a^-,\ x\to\infty,\ x\to-\infty\) 同样成立。

例 1：\(\frac{0}{0}\) 型

\(\displaystyle\lim_{x\to 0}\frac{\sin x}{x}\)。代入得 0/0，用洛必达：

\[\lim_{x\to 0}\frac{\sin x}{x} = \lim_{x\to 0}\frac{\cos x}{1} = 1.\]

例 2：\(\frac{\infty}{\infty}\) 型

\(\displaystyle\lim_{x\to\infty}\frac{x^n}{e^x}\)（n ≥ 0）。连续用 n 次洛必达，每次分子降一次幂，分母始终是 eˣ：

\[\lim_{x\to\infty}\frac{x^n}{e^x} = \lim_{x\to\infty}\frac{n x^{n-1}}{e^x} = \cdots = \lim_{x\to\infty}\frac{n!}{e^x} = 0.\]

结论：指数函数增长快于任何幂函数——这一事实在广义积分敛散性判断中会用到。

例 3：\(\frac{\infty}{\infty}\) 型（多项式之比）

\(\displaystyle\lim_{x\to\infty}\frac{3x^2+2x+1}{5x^2-x+7}\)。用一次洛必达：\(\lim \frac{6x+2}{10x-1}\)，仍是 ∞/∞，再用一次：\(\lim \frac{6}{10} = \frac{3}{5}\)。当然更简单的做法是分子分母同除 x²。

其他五种未定式的化归

\(0\cdot\infty\) 型

\(\displaystyle\lim_{x\to 0^+} x\ln x\)。改写为 \(\frac{\ln x}{1/x}\)（∞/∞ 型）：

\[\lim_{x\to 0^+}\frac{\ln x}{1/x} = \lim_{x\to 0^+}\frac{1/x}{-1/x^2} = \lim_{x\to 0^+}(-x) = 0.\]

\(\infty-\infty\) 型

\(\displaystyle\lim_{x\to 0}\left(\frac{1}{\sin x} - \frac{1}{x}\right)\)。通分：

\[\lim_{x\to 0}\frac{x-\sin x}{x\sin x}\quad(\tfrac{0}{0}).\]

洛必达一次：\(\lim\frac{1-\cos x}{\sin x + x\cos x}\)（仍 0/0），再来一次：

\[\lim_{x\to 0}\frac{\sin x}{\cos x + \cos x - x\sin x} = \frac{0}{2} = 0.\]

\(1^\infty\) 型（重要！）

\(\displaystyle\lim_{x\to \infty}\left(1+\frac{1}{x}\right)^x = e\)。设 \(L\) 为该极限，取对数：

\[\ln L = \lim_{x\to\infty} x\ln\!\left(1+\frac{1}{x}\right) = \lim_{x\to\infty}\frac{\ln(1+1/x)}{1/x}\quad(\tfrac{0}{0}).\]

洛必达：

\[\lim_{x\to\infty}\frac{\frac{1}{1+1/x}\cdot(-1/x^2)}{-1/x^2} = \lim_{x\to\infty}\frac{1}{1+1/x} = 1.\]

所以 \(\ln L = 1\)，\(L = e\)。

\(0^0\) 与 \(\infty^0\) 型

\(\displaystyle\lim_{x\to 0^+} x^x\)（0⁰ 型）。取对数：\(\ln L = \lim_{x\to 0^+} x\ln x = 0\)（见例 3），所以 \(L = 1\)。

函数增长阶的比较

反复用洛必达可得以下增长阶由慢到快（x→∞）：

\[\ln x \ll x^p\ (p>0) \ll e^x \ll e^{x^p}\ (p>1) \ll \cdots\]

即：对数 < 幂 < 指数。这个顺序在判断广义积分和级数敛散时非常有用。

常见误区与边界情况

1. 对非未定式用洛必达。洛必达只适用于 0/0 或 ∞/∞。若代入得 1/0、5/∞ 等非未定式，直接得结论（无穷或 0），用洛必达反而会出错。

2. 洛必达失效≠极限不存在。若 \(\lim f'/g'\) 振荡或无极限，不能断定原极限不存在，应换用其他方法（泰勒展开、夹挤等）。

3. \(1^\infty\) 型忘记取对数。直接写“1 的任何次幂是 1”是错误的；必须先取对数化为 0·∞，再继续化归。

4. 洛必达可重复使用。一次洛必达后若仍是 0/0 或 ∞/∞，可以继续用，直到不再是未定式或得到确定结果。

本课要点

七种未定式

0/0、∞/∞、0·∞、∞−∞、1^∞、0^0、∞^0

洛必达法则

lim f/g = lim f'/g'，仅限 0/0 或 ∞/∞

化归策略

非 0/0、∞/∞ 的未定式先变形（取对数、通分）再洛必达

增长阶

对数 ≪ 幂 ≪ 指数

验证前提

用洛必达前先确认是未定式，且导数之比极限存在
