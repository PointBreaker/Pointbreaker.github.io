广义积分

定积分 \(\int_a^b f(x)\,dx\) 要求区间有限、被积函数有界。当区间无穷或被积函数在某点爆破时，普通的黎曼积分无法定义——这时需要广义积分 (improper integral)，用极限来推广积分的概念。一个广义积分可能收敛到一个有限值，也可能发散到无穷或根本没有极限。

授课：Prof. David Jerison 日期：2006-12-05 难度：中等 → 较难

这一课在课程中的位置

期中 4 之后进入课程最后三大主题：洛必达（第 34 课）、广义积分（本课）、无穷级数（第 36–37 课）。广义积分是连接积分与级数的桥梁——积分审敛法（第 36 课）会把级数的敛散性转化为广义积分来判断。期末考会直接考广义积分的计算与敛散性。

两类广义积分

Type I：无穷区间

区间一端或两端是无穷。定义为极限：

\[\int_a^\infty f(x)\,dx = \lim_{N\to\infty}\int_a^N f(x)\,dx.\] \[\int_{-\infty}^b f(x)\,dx = \lim_{M\to -\infty}\int_M^b f(x)\,dx.\] \[\int_{-\infty}^\infty f(x)\,dx = \int_{-\infty}^c f(x)\,dx + \int_c^\infty f(x)\,dx,\]

右端两个极限都存在时，左端才收敛。

Type II：无界被积函数

被积函数在积分区间的某端点（或内点）趋于无穷。若 f 在 x=b 处爆破：

\[\int_a^b f(x)\,dx = \lim_{t\to b^-}\int_a^t f(x)\,dx.\]

若爆破点在内部 c∈(a,b)，则拆成两段极限之和。

统一思想：广义积分 = 常义积分 + 取极限。先算常义积分（得到含参数 N 或 t 的表达式），再让参数趋于边界。

计算例题

例 1：∫₁^∞ dx/xᵖ （p-积分，核心基准）

\[\int_1^\infty \frac{dx}{x^p} = \lim_{N\to\infty}\int_1^N x^{-p}\,dx = \lim_{N\to\infty} \begin{cases} \dfrac{N^{1-p}-1}{1-p}, & p\neq 1,\\ \quad \ln N, & p = 1.\end{cases}\]

当 \(p>1\) 时 \(N^{1-p}\to 0\)，极限为 \(\dfrac{1}{p-1}\)（收敛）；当 \(p\le 1\) 时极限为 ∞（发散）。

\[\boxed{\int_1^\infty \frac{dx}{x^p}\text{ 收敛} \iff p>1.}\]

同样，\(\displaystyle\int_0^1 \frac{dx}{x^p}\) 收敛当且仅当 \(p<1\)。

例 2：∫₀^∞ e⁻ˣ dx

\[\int_0^\infty e^{-x}\,dx = \lim_{N\to\infty}\int_0^N e^{-x}\,dx = \lim_{N\to\infty}(1-e^{-N}) = 1.\]

这是一个收敛的广义积分，值为 1——它也是概率论中指数分布的归一化常数。

例 3：∫₀^1 dx/√x （Type II）

被积函数在 x=0 处爆破：

\[\int_0^1 \frac{dx}{\sqrt{x}} = \lim_{t\to 0^+}\int_t^1 x^{-1/2}\,dx = \lim_{t\to 0^+}[2\sqrt{x}]_t^1 = 2.\]

收敛，值为 2。

例 4：∫₀^∞ xⁿ e⁻ˣ dx 的收敛性（第 8B 课问题 1）

记 \(A(n)=\int_0^\infty x^n e^{-x}\,dx\)。在 ∞ 处，e⁻ˣ 的衰减压倒任何幂函数（由洛必达，\(\lim_{x\to\infty}x^n e^{-x}=0\)），所以 ∞ 端没问题；在 0 处被积函数连续（n≥0）。因此对任意 n≥0 收敛。

用分部积分可得递推：\(A(n+1) = (n+1)A(n)\)，而 \(A(0)=1\)，于是 \(A(n) = n!\)——这是 Gamma 函数在整数点的取值。

比较判别法

当广义积分难以直接计算时，可以通过与已知敛散性的积分比较来判断。

比较判别法（Comparison Test）

设 \(0\le f(x)\le g(x)\) 对充分大的 x 成立：

  • 若 \(\int g\) 收敛，则 \(\int f\) 收敛（大的收敛 → 小的也收敛）。
  • 若 \(\int f\) 发散，则 \(\int g\) 发散（小的发散 → 大的也发散）。

极限比较判别法（Limit Comparison Test）

设 f, g 非负且 \(\displaystyle\lim_{x\to\infty}\frac{f(x)}{g(x)} = L\)，0 < L < ∞，则 \(\int f\) 与 \(\int g\) 同敛散。

例 5：∫₁^∞ dx/√(x⁴+1) 的敛散性

当 x→∞ 时，\(\dfrac{1}{\sqrt{x^4+1}} \sim \dfrac{1}{x^2}\)。与 p=2>1 的 p-积分做极限比较：

\[\lim_{x\to\infty}\frac{1/\sqrt{x^4+1}}{1/x^2} = \lim_{x\to\infty}\frac{x^2}{\sqrt{x^4+1}} = 1.\]

L=1∈(0,∞)，而 \(\int_1^\infty dx/x^2\) 收敛（p=2>1），所以原积分收敛——无需算出具体值。

例 6：∫₁^∞ (x+1)/(x³+2x) dx

当 x→∞，被积函数 ~ 1/x²。与 1/x² 极限比较得收敛。

选比较函数的经验：抓“首项”——x→∞ 时只看分子分母的最高次项，忽略低阶项和常数。

常见误区与边界情况

1. 不检查敛散性就写“= 某值”。必须先取极限，确认极限存在（有限），才能说积分收敛。若极限为 ∞ 或不存在，要说“发散”。

2. 内部爆破点没拆开。若被积分函数在区间内部 c 点爆破，必须拆成 \(\int_a^c + \int_c^b\) 两段极限，两段都收敛才算收敛。

3. 比较判别法方向搞反。“大的收敛 → 小的收敛”正确；“小的收敛 → 大的收敛”错误。方向感：收敛是“好事”，只能从大到小传递。

4. p-积分是基准。\(\int_1^\infty dx/x^p\) 收敛 ⇔ p>1；\(\int_0^1 dx/x^p\) 收敛 ⇔ p<1。几乎所有比较判别都拿它当参照。

本课要点

Type I

无穷区间，用 lim N→∞ ∫ₐᴺ 定义

Type II

被积函数无界，用 lim t→爆破点 定义

p-积分基准

∫₁^∞ dx/xᵖ 收敛 ⇔ p>1；∫₀^¹ 收敛 ⇔ p<1

比较判别法

0≤f≤g：大的收敛→小的收敛；小的发散→大的发散

极限比较

lim f/g = L∈(0,∞) 则同敛散
