三角函数的积分

三角函数的幂次积分是积分技巧的第一座高峰。这一课系统处理 \(\int \sin^m x\cos^n x\,dx\) 与 \(\int \tan^m x\sec^n x\,dx\) 的分类策略，并引入三角换元 (trigonometric substitution) 的雏形——这些技巧将在后续课程中反复出现。

授课：Prof. David Jerison 日期：2006-11-03 难度：中等 → 较难

这一课在课程中的位置

前几课建立了积分的理论与几何应用，这一课转入积分技巧——面对的被积函数不再是多项式或简单指数，而是三角函数的各种组合。掌握这些技巧需要识别模式并选择正确的化简路径，下一课的三角换元是这里的自然延伸。

\(\int \sin^m x\cos^n x\,dx\) 的分类策略

处理 \(\sin^m x\cos^n x\) 的关键是利用恒等式 \(\sin^2 x+\cos^2 x=1\)，把偶次幂降次，把奇次幂拆开一个因子凑微分。

情形 1：\(\sin x\) 的幂次 \(m\) 为奇数

拆出一个 \(\sin x\) 凑 \(d(\cos x)\)：

\[ \sin^m x\cos^n x = \sin^{m-1}x\cdot \sin x\cdot\cos^n x = (1-\cos^2 x)^{(m-1)/2}\cos^n x\cdot\sin x. \]

令 \(u=\cos x\)，\(du=-\sin x\,dx\)，积分化为关于 \(u\) 的多项式积分。

例 1：\(\displaystyle\int \sin^3 x\,dx = \int (1-\cos^2 x)\sin x\,dx\)。令 \(u=\cos x\)：

\[ -\int (1-u^2)\,du = -u+\frac{u^3}{3}+C = -\cos x+\frac{\cos^3 x}{3}+C. \]

情形 2：\(\cos x\) 的幂次 \(n\) 为奇数

拆出一个 \(\cos x\) 凑 \(d(\sin x)\)：\(\cos^{n}x\,dx = \cos^{n-1}x\,\cos x\,dx = (1-\sin^2 x)^{(n-1)/2}\,d(\sin x)\)。令 \(u=\sin x\)。

情形 3：\(m,n\) 均为偶数

用半角公式降次：

\[ \sin^2 x = \frac{1-\cos 2x}{2},\qquad \cos^2 x = \frac{1+\cos 2x}{2},\qquad \sin x\cos x = \frac{\sin 2x}{2}. \]

例 2：\(\displaystyle\int \sin^2 x\cos^2 x\,dx = \int \frac{\sin^2 2x}{4}\,dx = \int \frac{1-\cos 4x}{8}\,dx = \frac{x}{8}-\frac{\sin 4x}{32}+C.\)

\(\int \tan^m x\sec^n x\,dx\) 的分类策略

利用恒等式 \(\sec^2 x = 1+\tan^2 x\) 与微分关系 \(d(\tan x)=\sec^2 x\,dx\)、\(d(\sec x)=\sec x\tan x\,dx\)。

情形 1：\(\sec x\) 的幂次 \(n\) 为偶数

拆出 \(\sec^2 x\) 凑 \(d(\tan x)\)：\(\sec^{n}x = \sec^{n-2}x\cdot\sec^2 x = (1+\tan^2 x)^{(n-2)/2}\sec^2 x\)。令 \(u=\tan x\)。

例 3：\(\displaystyle\int \tan^2 x\sec^4 x\,dx = \int \tan^2 x(1+\tan^2 x)\sec^2 x\,dx\)。令 \(u=\tan x\)：

\[ \int u^2(1+u^2)\,du = \frac{u^3}{3}+\frac{u^5}{5}+C = \frac{\tan^3 x}{3}+\frac{\tan^5 x}{5}+C. \]

情形 2：\(\tan x\) 的幂次 \(m\) 为奇数

拆出 \(\sec x\tan x\) 凑 \(d(\sec x)\)：\(\tan^m x\sec^{n}x = \tan^{m-1}x\sec^{n-1}x\cdot(\sec x\tan x)\)，其中 \(\tan^{m-1}x = (\sec^2 x-1)^{(m-1)/2}\)。令 \(u=\sec x\)。

例 4：\(\displaystyle\int \tan^5 x\sec^3 x\,dx\)。拆出 \(\sec x\tan x\)，四次方 \(\tan^4 x=(\sec^2 x-1)^2\)，令 \(u=\sec x\)，化为多项式积分。

基本积分公式

\[ \int \tan x\,dx = -\ln|\cos x|+C = \ln|\sec x|+C. \] \[ \int \sec x\,dx = \ln|\sec x+\tan x|+C. \]

后者是 18.01 最著名的「凑微分」积分之一：分子分母同乘 \(\sec x+\tan x\) 即可推出。

三角换元 (trigonometric substitution) 预览

当被积函数含 \(\sqrt{a^2-x^2}\)、\(\sqrt{a^2+x^2}\)、\(\sqrt{x^2-a^2}\) 时，可用三角换元把根号去掉：

根号形式换元利用恒等式
\(\sqrt{a^2-x^2}\)\(x=a\sin\theta\)\(1-\sin^2\theta=\cos^2\theta\)
\(\sqrt{a^2+x^2}\)\(x=a\tan\theta\)\(1+\tan^2\theta=\sec^2\theta\)
\(\sqrt{x^2-a^2}\)\(x=a\sec\theta\)\(\sec^2\theta-1=\tan^2\theta\)

例 5：\(\displaystyle\int \frac{dx}{\sqrt{a^2-x^2}}\)。令 \(x=a\sin\theta\)，\(dx=a\cos\theta\,d\theta\)：

\[ \int \frac{a\cos\theta\,d\theta}{\sqrt{a^2-a^2\sin^2\theta}} = \int d\theta = \theta+C = \arcsin\frac{x}{a}+C. \]

三角换元的本质：利用三角恒等式把代数根号转化为三角函数的绝对值，从而去掉根号。

常见误区与边界情况

符号与绝对值：\(\int \tan x\,dx = -\ln|\cos x|+C\)，绝对值不能丢，否则在 \(\cos x<0\) 的区间会出错。

  • 先看幂次奇偶：\(\sin^m\cos^n\) 先看 \(m,n\) 哪个是奇数，决定凑哪个微分。
  • 半角公式降次会倍增计算量：偶次幂情形往往比奇次幂繁琐，耐心展开。
  • \(\int \sec x\,dx\) 不要硬记：分子分母同乘 \(\sec x+\tan x\)，凑 \(d(\sec x+\tan x)\) 即可。
  • 三角换元后要画三角形回代：用 \(\theta\) 表示出 \(\sin\theta\)、\(\tan\theta\) 等，再换回 \(x\)。
  • 定义域：\(\sec x\)、\(\tan x\) 在 \(\cos x=0\) 处无定义，积分要避开这些点。
