定积分

把曲线下方的面积定义为矩形面积和的极限——这就是定积分 (definite integral)。这一课建立 \(\int_a^b f(x)\,dx\) 的严格定义，并推导它的基本性质，为后面微积分基本定理的「神之一手」做好铺垫。

授课：Prof. David Jerison 日期：2006-10-19 难度：入门 → 中等

这一课在课程中的位置

此前我们掌握了求导与反导数（不定积分）的操作，但一直缺少一个严格的「面积」定义。这一课把积分从「反导数」提升为「黎曼和的极限」，定积分从此拥有自己的独立含义。下一课的微积分基本定理再把这含义与反导数重新缝合——那是整个课程的枢纽时刻。

黎曼和：从矩形到极限

设 \(f(x)\) 在 \([a,b]\) 上有界。把区间分成 \(n\) 份，分点

\[ a = x_0 < x_1 < x_2 < \dots < x_n = b \]

第 \(i\) 个子区间长度 \(\Delta x_i = x_i - x_{i-1}\)，在其中任取一点 \(x_i^* \in [x_{i-1}, x_i]\)。黎曼和 (Riemann sum) 定义为

\[ S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x_i \]

如果当最大子区间长度 \(\max \Delta x_i \to 0\)（同时 \(n\to\infty\)）时，\(S_n\) 趋于一个与取点方式无关的极限 \(I\)，则称 \(f\) 在 \([a,b]\) 上黎曼可积，记

\[ \int_a^b f(x)\,dx = I = \lim_{\max\Delta x_i \to 0}\sum_{i=1}^{n} f(x_i^*)\,\Delta x_i. \]

几何意义：当 \(f(x)\ge 0\)，\(\int_a^b f(x)\,dx\) 就是曲线 \(y=f(x)\) 与 \(x\) 轴、直线 \(x=a\)、\(x=b\) 所围区域的面积。

用等宽子区间计算一个经典例子

取 \(f(x)=x\) 在 \([0,1]\) 上，用 \(n\) 等份、右端点 \(x_i^* = i/n\)，\(\Delta x = 1/n\)：

\[ \sum_{i=1}^{n} f\!\left(\frac{i}{n}\right)\frac{1}{n} = \sum_{i=1}^{n}\frac{i}{n}\cdot\frac{1}{n} = \frac{1}{n^2}\sum_{i=1}^{n} i = \frac{1}{n^2}\cdot\frac{n(n+1)}{2} = \frac{n+1}{2n}. \]

令 \(n\to\infty\) 得极限 \(1/2\)，因此

\[ \int_0^1 x\,dx = \frac{1}{2}, \]

恰好等于底为 1、高为 1 的三角形面积。

不是所有函数都可积：若 \(f\) 在 \([a,b]\) 上连续，则必定黎曼可积。但若间断点「太多」（如狄利克雷函数），极限会依赖取点方式，积分不存在。18.01 几乎只处理连续函数，所以可积性一般不成问题。

符号里的 \(dx\) 是什么？

记号 \(\int_a^b f(x)\,dx\) 里的 \(dx\) 来自 \(\Delta x_i \to 0\) 的极限——它是「无穷小的宽度」。这个看似多余的符号在换元积分时至关重要：它提醒我们要像处理微分一样处理它（详见性质 (7)）。

有向面积 (signed area)

当 \(f(x)\) 在 \([a,b]\) 上取负值时，\(f(x_i^*)\Delta x_i\) 为负，所以积分给出的是有向面积：\(x\) 轴上方取正，下方取负。

关键推论：\(\int_a^b f(x)\,dx\) 是净面积，不是总面积。要算总面积必须分段取绝对值：\(\displaystyle \int_a^b |f(x)|\,dx\)。

例：\(\displaystyle \int_0^{2\pi} \sin x\,dx = 0\)，因为 \([0,\pi]\) 上的正面积与 \([\pi,2\pi]\) 上的负面积恰好抵消。

定积分的基本性质

以下性质在 Notes PI 中列出，是估算和计算积分的基础。设 \(f,g\) 在 \([a,b]\) 上可积，\(c\) 为常数：

(1) 反向积分

\[ \int_a^b f(x)\,dx = -\int_b^a f(x)\,dx \]

特别地，上下限相同则积分为零。

(2) 区间可加性

\[ \int_a^c f(x)\,dx = \int_a^b f(x)\,dx + \int_b^c f(x)\,dx \]

无论 \(a,b,c\) 的相对位置如何，只要 \(f\) 在并起来的区间上可积，上式都成立。

(3) 线性性

\[ \int_a^b \bigl(f(x)+g(x)\bigr)\,dx = \int_a^b f(x)\,dx + \int_a^b g(x)\,dx \] \[ \int_a^b c\,f(x)\,dx = c\int_a^b f(x)\,dx \]

(4) 比较原理

若 \(f(x) \le g(x)\) 对所有 \(x\in[a,b]\) 成立，则

\[ \int_a^b f(x)\,dx \le \int_a^b g(x)\,dx. \]

(5) 绝对值不等式

\[ \Bigl|\int_a^b f(x)\,dx\Bigr| \le \int_a^b |f(x)|\,dx \]

左边让正负抵消，右边不会，所以右边更大。这是估算含正负波动被积函数的有力工具。

(6) 换元公式（变量替换）

这是保留 \(dx\) 符号最重要的理由。令 \(u = u(x)\) 可微且单调，\(c = u(a)\)，\(d = u(b)\)，则

\[ \int_c^d f(u)\,du = \int_a^b f\bigl(u(x)\bigr)\,u'(x)\,dx. \]

要点：(i) 把 \(du\) 换成 \(u'(x)\,dx\)；(ii) 把积分限从 \(u\) 的变成 \(x\) 的。

换元公式的证明思路：设 \(F'(u)=f(u)\)，则左边由第一基本定理为 \(F(d)-F(c)=F(u(b))-F(a)\)。右边对 \(F(u(x))\) 用链式法则再套用第一基本定理，得到相同结果。这体现了第一基本定理与链式法则的配合。

估算实战

例：估算 \(\displaystyle \int_0^1 \frac{dx}{1+x^3}\)。

在 \([0,1]\) 上，\(x^3 \ge 0\)，故 \(\displaystyle \frac{1}{1+x^3}\le 1\)，而最小值在 \(x=1\) 处为 \(1/2\)。由比较原理：

\[ \frac{1}{2}\cdot (1-0) \le \int_0^1 \frac{dx}{1+x^3} \le 1\cdot(1-0), \]

即积分值介于 \(0.5\) 与 \(1\) 之间。

例：估算 \(\displaystyle \int_0^1 e^{-x}\sin x\,dx\) 的大小。

因为 \(|\sin x|\le 1\)，由绝对值不等式与比较原理：

\[ \Bigl|\int_0^1 e^{-x}\sin x\,dx\Bigr| \le \int_0^1 e^{-x}|\sin x|\,dx \le \int_0^1 e^{-x}\,dx = \Bigl[-e^{-x}\Bigr]_0^1 = 1-e^{-1} < 1. \]

常见误区与边界情况

定积分 ≠ 不定积分：\(\int_a^b f(x)\,dx\) 是一个数；\(\int f(x)\,dx\) 是一个函数族（反导数加常数 \(C\)）。初学者常把两者混淆。

  • 有向面积 vs 总面积：\(\int_0^{2\pi}\sin x\,dx=0\) 不代表曲线下方没有面积，只是正负抵消。
  • 区间可加性与顺序：\(\int_a^c = \int_a^b + \int_b^c\) 对任意顺序都成立，不必 \(a<b<c\)。
  • 换元后忘换限：换元时如果没把 \(u\) 的限换成 \(x\) 的限，就会得到错误答案。
  • 绝对值不等式的方向：\(\bigl|\int f\bigr| \le \int |f|\)，不是 \(\ge\)。
  • 可积性假设：性质默认被积函数可积。对无界区间或无穷被积函数（反常积分，后面会学），这些性质需要重新审视。

本课要点

黎曼和定义

\(\int_a^b f(x)\,dx\) 是矩形面积和的极限

有向面积

上方为正，下方为负，积分给出净面积

六条性质

反向、可加、线性、比较、绝对值、换元

\(dx\) 的意义

它是极限过程留下的微分，换元时不可或缺
