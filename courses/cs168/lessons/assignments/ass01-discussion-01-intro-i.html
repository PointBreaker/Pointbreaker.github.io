Prediction → Work → Evidence

1 · Prediction

先不看答案：画 A→R1→R2→B 的五个时刻，标出 Ethernet 首部在哪些跳会被替换、IP/TCP/HTTP 哪些保持端到端。

2 · Work

每小问先写已知状态和允许发生的事件，再写公式/表项变化；答案旁标出使用了哪个不变量。不要从 solution 反推过程。

3 · Evidence

数值题保留单位，协议题保留事件顺序，图题保留每条边/表项来源。随后用官方 solution 逐行对照，错误归类为概念、状态、算术或边界。

失败签名与调试梯子

  • 把 router port 与 TCP/UDP port 当成同一对象
  • 认为 ICMP 是链路层协议
  • 能填首部却解释不出端到端原则为何成立
Hint 1 · Concept

ICMP error payload 带回触发错误的原始 IP 首部与前 8 B payload，因此发送端能把响应关联到 probe。

Hint 2 · Invariant

把题目当前时刻必须成立的一条关系写在纸顶；每一步更新后重新检查，而不是只看最终答案像不像。

Hint 3 · Debug strategy

缩到最小拓扑/最少包/最短时间线，固定 tie-break，并把一次事件拆成“输入 → 局部状态 → 输出”。

能力门

闭卷解释 UDP Traceroute 如何仅靠 TTL=1,2,… 和两类 ICMP 回复逐跳显影路径。
