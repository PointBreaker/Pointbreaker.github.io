官方题面翻译可离线作答官方解答已收录

完整题面

1. 连续概率入门（Continuous Intro）

参考 Note 21。

(a) 设

\[ f(x) = \begin{cases} 2x, & 0 \le x \le 1 \\ 0, & \text{其他} \end{cases} \]

\(f(x)\) 是否为合法的概率密度函数（PDF）？为什么？它是否为合法的累积分布函数（CDF）？为什么？

(b) 若随机变量 \(X\) 的 CDF 为

\[ F_X(x) = \begin{cases} 0, & x \le 0 \\ \dfrac{x}{\ell}, & 0 \le x \le \ell \\ 1, & x \ge \ell \end{cases} \]

求其概率密度函数 \(f_X(x)\)，以及 \(\mathbb{E}[X]\) 与 \(\operatorname{Var}(X)\)。

(c) 设 \(X\) 与 \(Y\) 相互独立，且密度函数分别为

\[ f_X(x) = \begin{cases} 2x, & 0 \le x \le 1 \\ 0, & \text{其他} \end{cases}, \qquad f_Y(y) = \begin{cases} 1, & 0 \le y \le 1 \\ 0, & \text{其他} \end{cases} \]

求它们的联合分布。（提示：对 (c) 与 (d) 问，可类比离散概率中独立性的用法。）

(d) 对 (c) 问中的 \(X\) 与 \(Y\)，计算 \(\mathbb{E}[XY]\)。

查看解题提示

回顾概率密度函数的两条公理（非负性、归一性）以及 CDF 的单调性与极限行为；对 (b) 问，对 CDF 求导得到 PDF 后再用积分求矩；对 (c)(d) 问，利用独立性，联合密度等于边缘密度的乘积。

展开官方参考解答

(a) 是合法的概率密度函数，因为 \(f(x)\) 非负且 \(\int_{-\infty}^{\infty} f(x)\,\mathrm{d}x = \int_0^1 2x\,\mathrm{d}x = 1\)。

不是合法的 CDF，因为当 \(x \to \infty\) 时 CDF 应趋于 1，且 CDF 必须单调不减；而此处 \(f(x)\) 在 \(x > 1\) 时为 0，不满足 CDF 的极限要求。

(b) 对 \(F_X(x)\) 求导：

\[ f_X(x) = \frac{\mathrm{d}}{\mathrm{d}x}F_X(x) = \begin{cases} \dfrac{1}{\ell}, & 0 \le x \le \ell \\ 0, & \text{其他} \end{cases} \]

\[ \mathbb{E}[X] = \int_0^{\ell} x \cdot \frac{1}{\ell}\,\mathrm{d}x = \frac{\ell}{2} \]

\[ \mathbb{E}[X^2] = \int_0^{\ell} x^2 \cdot \frac{1}{\ell}\,\mathrm{d}x = \frac{\ell^2}{3} \]

\[ \operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{\ell^2}{3} - \frac{\ell^2}{4} = \frac{\ell^2}{12} \]

这正是区间 \([0, \ell]\) 上的连续均匀分布，常记作 \(\operatorname{Uniform}[0, \ell]\)。

(c) 由独立性，

\[ f_{X,Y}(x,y)\,\mathrm{d}x\,\mathrm{d}y = \mathbb{P}\bigl[X \in [x, x+\mathrm{d}x], Y \in [y, y+\mathrm{d}y]\bigr] = \mathbb{P}\bigl[X \in [x, x+\mathrm{d}x]\bigr]\,\mathbb{P}\bigl[Y \in [y, y+\mathrm{d}y]\bigr] \approx f_X(x)f_Y(y)\,\mathrm{d}x\,\mathrm{d}y \]

因此联合分布为 \(f(x,y) = 2x\)，定义在单位正方形 \(0 \le x \le 1,\; 0 \le y \le 1\) 上。

(d)

\[ \mathbb{E}[XY] = \int_0^1 \int_0^1 xy \cdot 2x\,\mathrm{d}y\,\mathrm{d}x = \int_0^1 x^2\,\mathrm{d}x = \frac{1}{3} \]

或者，由 \(X\) 与 \(Y\) 独立，\(\mathbb{E}[XY] = \mathbb{E}[X]\,\mathbb{E}[Y]\)。其中

\[ \mathbb{E}[X] = \int_0^1 x \cdot 2x\,\mathrm{d}x = \left.\frac{2}{3}x^3\right|_0^1 = \frac{2}{3} \]

而 \(\mathbb{E}[Y] = \dfrac{1}{2}\)，因为 \(Y\) 的密度关于 \(\dfrac{1}{2}\) 对称。于是

\[ \mathbb{E}[XY] = \mathbb{E}[X]\,\mathbb{E}[Y] = \frac{1}{3} \]

2. 均匀分布（Uniform Distribution）

参考 Note 21。你有两个指尖陀螺（fidget spinner），每个的周长为 10。在每个陀螺上标记一个点作为指针，并将它们分别放在一个圆心处，圆周上标有取值范围 \([0, 10)\) 的刻度。若独立地旋转两个陀螺，设 \(X\) 为第一个陀螺标记的位置，\(Y\) 为第二个陀螺标记的位置。求在 \(Y \ge X\) 的条件下 \(X \ge 5\) 的概率，即 \(\mathbb{P}[X \ge 5 \mid Y \ge X]\)。

图表条件 · 图 1：陀螺联合概率密度图。在边长为 10 的正方形区域 \([0,10]\times[0,10]\) 中，横轴为 \(X\)（第一个陀螺位置），纵轴为 \(Y\)（第二个陀螺位置），画出对角线 \(y = x\)，并用阴影标出区域 \(A\)：位于 \(y = x\) 上方、\(y = 10\) 下方、\(x = 5\) 右侧、\(x = 10\) 左侧的直角三角形，顶点为 \((5,5)\)、\((5,10)\)、\((10,10)\)。

在平面直角坐标系中，画边长为 10 的正方形，横轴 \(X\) 范围 0→10，纵轴 \(Y\) 范围 0→10。画出对角线 \(y = x\)。用阴影标出区域 \(A\)：由直线 \(y = x\)、\(y = 10\)、\(x = 5\)、\(x = 10\) 所围成的直角三角形，其顶点为 \((5,5)\)、\((5,10)\)、\((10,10)\)。标注坐标轴刻度 0、5、10，并在图旁标注 "A"。

来源：solutions/discussion/dis13a-sol.pdf · 2

查看解题提示

写出条件概率定义 \(\mathbb{P}[X \ge 5 \mid Y \ge X] = \mathbb{P}[Y \ge X \cap X \ge 5]/\mathbb{P}[Y \ge X]\)。\((X,Y)\) 在正方形 \([0,10]\times[0,10]\) 上均匀分布，利用连续均匀定律把概率转化为面积比，结合图形求 \(\mathbb{P}[Y \ge X] = 1/2\) 与交集区域的面积。

展开官方参考解答

先写出所求概率并展开条件概率：

\[ \mathbb{P}[X \ge 5 \mid Y \ge X] = \frac{\mathbb{P}[Y \ge X \cap X \ge 5]}{\mathbb{P}[Y \ge X]} \]

由对称性，\(\mathbb{P}[Y \ge X] = 1/2\)。为求 \(\mathbb{P}[Y \ge X \cap X \ge 5]\)，观察概率空间的图形并利用连续均匀定律 \(\mathbb{P}[A] = \dfrac{A \text{ 的面积}}{\Omega \text{ 的面积}}\)。我们关心的是由 \(x < y < 10,\; 5 < x < 10\) 所界定的区域相对于整个正方形 \(0 < x < 10,\; 0 < y < 10\) 的相对面积。

如图 1 所示，

\[ \mathbb{P}[Y \ge X \cap X \ge 5] = \frac{5 \cdot 5/2}{10 \cdot 10} = \frac{1}{8} \]

因此

\[ \mathbb{P}[X \ge 5 \mid Y \ge X] = \frac{1/8}{1/2} = \frac{1}{4} \]

3. 飞镖再探（Darts Again）

参考 Note 21。Edward 与 Khalil 在圆形飞镖靶上玩飞镖。Edward 的投掷在整个镖靶上均匀分布，镖靶半径为 10 英寸。Khalil 准头很好：他的投掷点到靶心的距离服从参数为 \(\frac{1}{2}\) 的指数分布。

设两人各投一次飞镖。记 \(X\) 为 Edward 的飞镖到靶心的距离，\(Y\) 为 Khalil 的飞镖到靶心的距离。求 \(\mathbb{P}[X < Y]\)（Edward 的投掷比 Khalil 更靠近靶心的概率）。答案以一个未计算积分的形式表示。

提示： \(X\) 在 \([0,10]\) 上并非均匀分布。先求 \(X\) 的 CDF，即 \(\mathbb{P}[X < x]\)，再导出 \(X\) 的分布。

查看解题提示

Edward 的落点在圆内均匀分布，故 \(\mathbb{P}[X < x]\) 等于半径为 \(x\) 的圆面积与整个镖靶面积之比，由此求 \(F_X(x)\) 再得 \(f_X(x)\)。再用全概率公式 \(\mathbb{P}[X < Y] = \int_0^{10} \mathbb{P}[Y > x]f_X(x)\,\mathrm{d}x\)，代入 \(Y\) 的指数分布尾部概率。

展开官方参考解答

已知 \(Y \sim \operatorname{Exponential}(1/2)\)。先求 \(X\) 的分布，通过计算 \(X\) 的 CDF \(\mathbb{P}[X < x]\)。考虑靶心距离小于 \(x\) 的区域面积与整个可用面积之比：

\[ \mathbb{P}[X < x] = \frac{\pi x^2}{\pi \cdot 10^2} = \frac{x^2}{100} \]

求导得到 \(X\) 的 PDF：

\[ f_X(x) = \frac{x}{50} \]

利用全概率公式：

\[ \mathbb{P}[X < Y] = \int_0^{10} \mathbb{P}[Y > X \mid X = x]\,f_X(x)\,\mathrm{d}x = \int_0^{10} \mathbb{P}[Y > x]\,f_X(x)\,\mathrm{d}x = \int_0^{10} \frac{x}{50}\,e^{-0.5x}\,\mathrm{d}x \]

计算该积分得 \(\mathbb{P}[X < Y] \approx 0.0767\)。
