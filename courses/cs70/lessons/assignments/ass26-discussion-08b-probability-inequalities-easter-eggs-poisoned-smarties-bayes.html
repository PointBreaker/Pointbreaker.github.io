1概率杂烩 (Probability Potpourri)题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

概率杂烩 (Probability Potpourri)

Note 13 Note 14

为每个部分提供简要证明。

(a) 对任意概率空间 (probability space) 中的两个事件 \(A\) 和 \(B\)，证明 \(\mathbb{P}[A \setminus B] \geq \mathbb{P}[A] - \mathbb{P}[B]\)。

(b) 设 \(\mathbb{P}[D \mid C] = \mathbb{P}[D \mid C^c]\)，其中 \(C^c\) 是 \(C\) 的补事件 (complement)。证明 \(D\) 与 \(C\) 独立 (independent)。

(c) 如果 \(A\) 和 \(B\) 互不相交 (disjoint)，是否意味着它们独立？

图表条件 · 文氏图：两个相交圆分别标注 A 和 B，三块区域从左到右标注概率 P[A\B]、P[A∩B]、P[B\A]

两个相交圆 A 与 B，三块区域：

  • 仅 A（左月牙）：P[A \ B]

  • 交集（中间透镜）：P[A ∩ B]

  • 仅 B（右月牙）：P[B \ A]

来源：solutions/discussion/dis08b-sol.pdf · 1

查看解题提示

(a) 尝试在文氏图中将 \(\mathbb{P}[A]\) 和 \(\mathbb{P}[B]\) 分别写成交集与差集之和，再比较 \(\mathbb{P}[A] - \mathbb{P}[B]\) 与 \(\mathbb{P}[A \setminus B]\)。

(b)(c) 对于 (b)，对 \(\mathbb{P}[D]\) 使用全概率公式，代入已知条件看能否得到独立的定义 \(\mathbb{P}[D \mid C] = \mathbb{P}[D]\)；对于 (c) 回忆独立的定义 \(\mathbb{P}[A \cap B] = \mathbb{P}[A]\mathbb{P}[B]\)，并考虑一个公平骰子上的互不相交事件。

展开官方参考解答

(a) 可以先画一个文氏图 (Venn diagram)：

[见图表需求]

由图可知 \(\mathbb{P}[A] = \mathbb{P}[A \cap B] + \mathbb{P}[A \setminus B]\)，且 \(\mathbb{P}[B] = \mathbb{P}[A \cap B] + \mathbb{P}[B \setminus A]\)。

看不等式右边： \[ \mathbb{P}[A] - \mathbb{P}[B] = (\mathbb{P}[A \cap B] + \mathbb{P}[A \setminus B]) - (\mathbb{P}[A \cap B] + \mathbb{P}[B \setminus A]) = \mathbb{P}[A \setminus B] - \mathbb{P}[B \setminus A] \leq \mathbb{P}[A \setminus B] \]

(b) 由全概率公式： \[ \mathbb{P}[D] = \mathbb{P}[D \cap C] + \mathbb{P}[D \cap C^c] = \mathbb{P}[D \mid C] \cdot \mathbb{P}[C] + \mathbb{P}[D \mid C^c] \cdot \mathbb{P}[C^c] \] 由已知 \(\mathbb{P}[D \mid C] = \mathbb{P}[D \mid C^c]\)，化简得 \[ \mathbb{P}[D] = \mathbb{P}[D \mid C] \cdot (\mathbb{P}[C] + \mathbb{P}[C^c]) = \mathbb{P}[D \mid C] \cdot 1 = \mathbb{P}[D \mid C] \] 这正是独立的定义。

(c) 不能。如果两个事件互不相交，不能得出它们独立的结论。考虑掷一个公平的六面骰子。设 \(A\) 为掷出 1 的事件，\(B\) 为掷出 2 的事件。显然 \(A\) 与 \(B\) 互不相交，因为 \(\mathbb{P}[A \cap B] = 0\)。但它们不独立：\(\mathbb{P}[B \mid A] = 0\)，而 \(\mathbb{P}[B] = 1/6\)。

由于互不相交的事件满足 \(\mathbb{P}[A \cap B] = 0\)，只有当 \(\mathbb{P}[A] = 0\) 或 \(\mathbb{P}[B] = 0\) 时，互不相交的 \(A\) 与 \(B\) 才独立。

完整题面

复活节彩蛋 (Easter Eggs)

Note 14

你长途跋涉来到 Soda 楼参加一个以春假为主题的作业派对，每位参与者都可以带走一份派对礼物。你拿到一个袋子，里面有 20 颗巧克力蛋和 40 颗（空的）塑料蛋。你从袋中均匀地无放回 (without replacement) 地抽取 5 颗蛋。

(a) 你抽到的第一颗蛋是巧克力蛋的概率是多少？

(b) 你抽到的第二颗蛋是巧克力蛋的概率是多少？

(c) 已知你抽到的第一颗蛋是空塑料蛋，你抽到的第五颗蛋也是空塑料蛋的概率是多少？

查看解题提示

(a)(b) 每颗蛋被抽到的机会均等；对于 (b)，既可以用全概率公式对第一颗蛋的类型分类讨论，也可以利用对称性——在不知道第一颗蛋是什么的情况下，第二颗蛋的分布与第一颗相同。

(c) 已知第一颗是塑料蛋后，袋中剩余 59 颗蛋；由于第 2、3、4 颗蛋的信息未知，第五颗蛋面临的处境与第二颗蛋相同，由此推导条件概率。

展开官方参考解答

(a) \(\mathbb{P}[\text{巧克力蛋}] = \frac{20}{60} = \frac{1}{3}\)。

(b) 用全概率公式长算：设 \(C_i\) 表示第 \(i\) 颗蛋是巧克力蛋的事件，\(P_i\) 表示第 \(i\) 颗蛋是塑料蛋的事件。 \[ \mathbb{P}[C_2] = \mathbb{P}[C_1 \cap C_2] + \mathbb{P}[P_1 \cap C_2] = \mathbb{P}[C_1]\mathbb{P}[C_2 \mid C_1] + \mathbb{P}[P_1]\mathbb{P}[C_2 \mid P_1] = \frac{1}{3} \cdot \frac{19}{59} + \frac{2}{3} \cdot \frac{20}{59} = \frac{1}{3} \]

简算：由对称性，这个概率与 (a) 相同，为 \(1/3\)。因为我们不知道第一次抽到的是哪种蛋，所以第二颗蛋的分布与第一颗相同。严格地，注意到 \(\mathbb{P}[C_2 \cap P_1] = \mathbb{P}[P_2 \cap C_1]\)，因此 \[ \mathbb{P}[C_2] = \mathbb{P}[C_2 \cap C_1] + \mathbb{P}[C_2 \cap P_1] = \mathbb{P}[C_2 \cap C_1] + \mathbb{P}[P_2 \cap C_1] = \mathbb{P}[C_1] \]

(c) 由对称性，由于我们不知道第 2、3、4 颗蛋的信息，有 \[ \mathbb{P}[\text{第5颗是塑料} \mid \text{第1颗是塑料}] = \mathbb{P}[\text{第2颗是塑料} \mid \text{第1颗是塑料}] = \frac{39}{59} \]

严格地，注意到 \(\mathbb{P}[C_5 \cap P_2 \mid P_1] = \mathbb{P}[P_5 \cap C_2 \mid P_1]\)，因此 \[ \mathbb{P}[P_5 \mid P_1] = \mathbb{P}[P_5 \cap C_2 \mid P_1] + \mathbb{P}[P_5 \cap P_2 \mid P_1] = \mathbb{P}[C_5 \cap P_2 \mid P_1] + \mathbb{P}[P_5 \cap P_2 \mid P_1] = \mathbb{P}[P_2 \mid P_1] \]

当然也可以用全概率公式暴力计算（如上一部分那样），但计算相当繁琐。

3有毒 Smarties 糖题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

假设有三个人各自拥有一家 Smarties 糖工厂。Burr Kelly 是其中最聪明、最具创新力的老板，产量远超竞争对手，占据 \(50\%\) 的市场份额。Yousef See 继承了家业，落后于 Burr，生产全球 \(40\%\) 的 Smarties 糖。最后是 Stan Furd，仅占微不足道的 \(10\%\)。

然而，近期一系列与 Smarties 糖相关的食物中毒事件迫使 FDA 调查这些工厂以找出问题根源。调查发现：Kelly 工厂每 100 颗糖中有 2 颗有毒；See 工厂生产的糖中有 \(5\%\) 有毒；Furd 工厂中一颗糖有毒的概率为 \(0.1\)。

(a) 随机选取一颗 Smarties 糖，它可安全食用的概率是多少？

(b) 若已知某颗糖不是来自 Burr Kelly 的工厂，则这颗糖有毒的概率是多少？

(c) 在以上信息下，若随机选取的一颗糖有毒，则它来自 Stan Furd 的 Smarties 糖工厂的概率是多少？

图表条件 · 概率树图：第一层为工厂选择分支（BK 概率 1/2、YS 概率 2/5、SF 概率 1/10），第二层为各工厂下的糖状态分支（有毒 Kelly 1/50、安全 Kelly 49/50；有毒 See 1/20、安全 See 19/20；有毒 SF 1/10、安全 SF 9/10），并标注每条路径的联合概率。

概率树，根节点分两阶段：

  • 第一层（工厂选择）：

  • BK: \(P = \frac{1}{2}\)

  • YS: \(P = \frac{2}{5}\)

  • SF: \(P = \frac{1}{10}\)

  • 第二层（糖状态，有毒 / 安全）：

  • BK → 有毒: \(P = \frac{1}{50}\)；BK → 安全: \(P = \frac{49}{50}\)

  • YS → 有毒: \(P = \frac{1}{20}\)；YS → 安全: \(P = \frac{19}{20}\)

  • SF → 有毒: \(P = \frac{1}{10}\)；SF → 安全: \(P = \frac{9}{10}\)

  • 各叶节点联合概率：

  • BK∩有毒: \(\frac{1}{2} \cdot \frac{1}{50} = \frac{1}{100}\)

  • BK∩安全: \(\frac{1}{2} \cdot \frac{49}{50} = \frac{49}{100}\)

  • YS∩有毒: \(\frac{2}{5} \cdot \frac{1}{20} = \frac{2}{100}\)

  • YS∩安全: \(\frac{2}{5} \cdot \frac{19}{20} = \frac{38}{100}\)

  • SF∩有毒: \(\frac{1}{10} \cdot \frac{1}{10} = \frac{1}{100}\)

  • SF∩安全: \(\frac{1}{10} \cdot \frac{9}{10} = \frac{9}{100}\)

图表条件 · 先验与条件概率汇总表：列出三家工厂的市场份额（先验概率）以及各自生产有毒糖的条件概率。

Burr Kelly BK \(\frac{1}{2}\) (50%) \(\frac{2}{100} = \frac{1}{50}\) \(\frac{49}{50}\)

Stan Furd SF \(\frac{1}{10}\) (10%) \(0.1 = \frac{1}{10}\) \(\frac{9}{10}\)

查看解题提示

(a) 引入划分事件「糖来自 Kelly / See / Furd 工厂」，运用全概率公式计算「可安全食用」的总概率；注意「安全」是「有毒」的对立事件，可先利用题目给出的有毒概率求得各厂的安全概率。

(b) 这是对「非 Kelly 工厂」这一缩减样本空间的条件概率。可考虑直接套用条件概率定义，并通过全概率公式在该缩减空间中重新加权 See 与 Furd 的份额；也可先计算分子分母的联合概率再相比。

(c) 识别此问为典型的贝叶斯法则形式，将「来自 Furd 工厂」视为待推断的假设，「有毒」为观测证据，利用 (a) 所得的安全概率得到 \(P[\text{有毒}] = 1 - P[\text{安全}]\) 后代入公式。

展开官方参考解答

解答：

(a) 设 \(S\) 为糖可安全食用的事件，\(BK\) 为糖来自 Burr Kelly 工厂的事件，\(YS\) 为糖来自 Yousef See 工厂的事件，\(SF\) 为糖来自 Stan Furd 工厂的事件。

由全概率公式： \[ P[S] = P[BK] \cdot P[S \mid BK] + P[YS] \cdot P[S \mid YS] + P[SF] \cdot P[S \mid SF] \]

已知 \(P[BK] = \frac{1}{2}\)、\(P[YS] = \frac{2}{5}\)、\(P[SF] = \frac{1}{10}\)，且 \[ P[S \mid BK] = \frac{49}{50}, \quad P[S \mid YS] = \frac{19}{20}, \quad P[S \mid SF] = \frac{9}{10}. \]

代入： \[ P[S] = \frac{1}{2} \cdot \frac{49}{50} + \frac{2}{5} \cdot \frac{19}{20} + \frac{1}{10} \cdot \frac{9}{10} = \frac{49}{100} + \frac{38}{100} + \frac{9}{100} = \frac{96}{100} = \frac{24}{25} = 0.96. \]

因此，随机选取一颗糖可安全食用的概率为 \(0.96\)。

(b) 设 \(P\) 为糖有毒的事件。要求 \(P[P \mid \overline{BK}]\)。由条件概率定义并在 \(\overline{BK}\) 上应用全概率公式： \[ P[P \mid \overline{BK}] = \frac{P[P \cap \overline{BK}]}{P[\overline{BK}]} = \frac{P[YS \cap P] + P[SF \cap P]}{1 - P[BK]} \] \[ = \frac{P[P \mid YS] \cdot P[YS] + P[P \mid SF] \cdot P[SF]}{1 - P[BK]} = \frac{\frac{1}{20} \cdot \frac{2}{5} + \frac{1}{10} \cdot \frac{1}{10}}{1 - \frac{1}{2}} \] \[ = \frac{\frac{2}{100} + \frac{1}{100}}{\frac{1}{2}} = 2 \cdot \frac{3}{100} = \frac{6}{100} = \frac{3}{50} = 0.06. \]

因此，已知不是来自 Kelly 工厂时，该糖有毒的概率为 \(0.06\)。

(c) 由贝叶斯法则： \[ P[SF \mid P] = \frac{P[P \mid SF] \cdot P[SF]}{P[P]}. \]

由 (a) 知 \(P[P] = 1 - P[S] = 1 - \frac{24}{25} = \frac{1}{25}\)。代入： \[ P[SF \mid P] = \frac{\frac{1}{10} \cdot \frac{1}{10}}{\frac{1}{25}} = \frac{\frac{1}{100}}{\frac{1}{25}} = \frac{25}{100} = \frac{1}{4} = 0.25. \]

因此，已知一颗糖有毒时，它来自 Stan Furd 工厂的概率为 \(0.25\)。
