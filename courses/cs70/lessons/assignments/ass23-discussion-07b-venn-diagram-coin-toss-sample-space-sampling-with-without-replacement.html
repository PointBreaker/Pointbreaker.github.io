1文氏图题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

（参见 Note 13）在 1000 名计算机科学专业的学生中，400 人参加了社团（可能同时从事兼职工作），500 人从事兼职工作（可能同时参加社团），50 人既参加社团又从事兼职工作。

(a) 假设我们均匀随机地选取一名学生。设 \(C\) 为该学生参加社团的事件，\(P\) 为该学生从事兼职工作的事件。画出样本空间 \(\Omega\) 以及事件 \(C\) 和 \(P\) 的示意图。

(b) 该学生参加社团的概率是多少？

(c) 该学生从事兼职工作的概率是多少？

(d) 该学生既参加社团又从事兼职工作的概率是多少？

(e) 该学生参加社团或从事兼职工作的概率是多少？

图表条件 · 样本空间 \(\Omega\) 的文氏图：矩形表示 \(\Omega\)（共 1000 人），内含两个相交圆 \(C\) 与 \(P\)，各区域标注人数。

区域 人数
仅 \(C\)（参加社团但不兼职） \(400 - 50 = 350\)
仅 \(P\)（兼职但不参加社团） \(500 - 50 = 450\)
\(C \cap P\)（既参加社团又兼职） \(50\)
两者皆非（在 \(\Omega\) 内、两圆外） \(1000 - 350 - 450 - 50 = 150\)
总计 \(\Omega\) \(1000\)

绘制两个相交圆 \(C\) 和 \(P\) 置于矩形 \(\Omega\) 内；\(C\) 圆内标注 350（仅 \(C\) 部分）与 50（交集部分）；\(P\) 圆内标注 450（仅 \(P\) 部分）与 50（交集部分）；矩形内两圆外标注 150。

来源：solutions/discussion/dis07b-sol.pdf · 1

查看解题提示

将样本空间用文氏图表示为两个相交的圆，分别对应事件 \(C\) 和 \(P\)。利用已知的人数求出每个互不相交区域中的学生人数。

对于"或"事件的概率，考虑使用容斥原理：\(P[P \cup C] = P[P] + P[C] - P[P \cap C]\)。

展开官方参考解答

(a) 样本空间由文氏图表示：矩形 \(\Omega\) 内含两个相交的圆 \(C\) 和 \(P\)，各区域标注相应人数（详见图表需求）。

(b) \(P[C] = \frac{|C|}{|\Omega|} = \frac{400}{1000} = \frac{2}{5}\)。

(c) \(P[P] = \frac{|P|}{|\Omega|} = \frac{500}{1000} = \frac{1}{2}\)。

(d) \(P[P \cap C] = \frac{|P \cap C|}{|\Omega|} = \frac{50}{1000} = \frac{1}{20}\)。

(e) \(P[P \cup C] = P[P] + P[C] - P[P \cap C] = \frac{1}{2} + \frac{2}{5} - \frac{1}{20} = \frac{17}{20}\)。

2抛硬币题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

（参见 Note 13）设有一枚无偏硬币，结果为 \(H\)（正面）和 \(T\)（反面），正面概率 \(P[H] = \frac{1}{2}\)，反面概率 \(P[T] = \frac{1}{2}\)。现做实验：将硬币抛掷 3 次。该实验的一个结果为 \((X_1, X_2, X_3)\)，其中 \(X_i \in \{H, T\}\)。

(a) 该实验的样本空间是什么？

(b) 以下哪些是事件的例子？请选出所有符合的选项。

  • \(\{(H, H, T), (H, H), (T)\}\)

  • \(\{(T, H, H), (H, T, H), (H, H, T), (H, H, H)\}\)

  • \(\{(T, T, T)\}\)

  • \(\{(T, T, T), (H, H, H)\}\)

  • \(\{(T, H, T), (H, H, T)\}\)

(c) 事件 \(\{(H, H, H), (H, H, T), (H, T, H), (H, T, T), (T, T, T)\}\) 的补集是什么？

(d) 设 \(A\) 为结果中恰有 0 个正面的事件，\(B\) 为结果中恰有 2 个正面的事件。求 \(A \cup B\)。

(e) 结果 \((H, H, T)\) 的概率是多少？

(f) 结果中恰有两个正面的事件的概率是多少？

(g) 结果中至少有一个正面的事件的概率是多少？

查看解题提示

样本空间中的每个结果是一个长度为 3 的序列，每个位置可以是 \(H\) 或 \(T\)。事件是样本空间的子集，因此其中的每个元素都必须是长度为 3 的合法结果。

求补集时，找出样本空间中不在给定事件内的所有结果。对于"至少一个正面"的概率，考虑其对立事件。

展开官方参考解答

(a) \(\Omega = \{(H,H,H), (H,H,T), (H,T,H), (H,T,T), (T,H,H), (T,H,T), (T,T,H), (T,T,T)\}\)。

(b) 事件必须是 \(\Omega\) 的子集，即必须由可能的结果组成。

  • 否（\((H,H)\) 和 \((T)\) 不是长度为 3 的合法结果）

  • 是

  • 是

  • 是

  • 是

(c) \(\{(T,H,H), (T,H,T), (T,T,H)\}\)。

(d) \(A = \{(T,T,T)\}\)，\(B = \{(H,H,T), (H,T,H), (T,H,H)\}\)，故 \(A \cup B = \{(T,T,T), (H,H,T), (H,T,H), (T,H,H)\}\)。

(e) 因为 \(|\Omega| = 2^3 = 8\) 且每个结果出现的可能性相等，所以 \(P[(H,H,T)] = \frac{1}{8}\)。

(f) 所求事件为 \(E = \{(H,H,T), (H,T,H), (T,H,H)\}\)，其大小为 3。因此 \(P[E] = \frac{3}{8}\)。

(g) 若"至少看到一个正面"不发生，则必然恰好看到三个反面。恰好三个反面的事件 \(E' = \{(T,T,T)\}\) 是"至少一个正面"事件的补集。\(E'\) 发生的概率为 \(\left(\frac{1}{2}\right)^3 = \frac{1}{8}\)，因此其补集发生的概率为 \(1 - \frac{1}{8} = \frac{7}{8}\)。

完整题面

3 抽样（Sampling）

设有编号分别为 \(1, \ldots, n\) 的 \(n\) 个球放入一个咖啡杯中，其中 \(n\) 是满足 \(n \ge 2\) 的正整数。你从杯中均匀随机地抽取一个球，记下编号后将球放回杯中，再均匀随机地抽取第二个球。

(a) 求第一次抽到 1 号球且第二次抽到 2 号球的概率。

(b) 求第二次抽到的编号严格小于第一次抽到的编号的概率。

(c) 求第二次抽到的编号恰好比第一次大 1 的概率。

(d) 现在假设在查看第一个球后，你不再将球放回杯中（而是将其扔掉），然后像之前一样抽取第二个球。重新回答前面各小题。

查看解题提示

放回抽样时，每次抽取相互独立，样本空间大小为 \(n^2\)。对于比较两次编号大小的题目，可以通过古典概型直接计数，也可以考虑两次抽到相同编号的概率再利用对称性。不放回时样本空间变为 \(n(n-1)\)，注意此时两次编号不可能相同。

展开官方参考解答

解答：

(a) 从全部 \(n^2\) 个可能的有序对中，只有 \((1, 2)\) 这一个有序对对应我们所关心的事件，因此所求概率为 \[ \frac{1}{n^2}. \]

(b) 样本空间仍有 \(n^2\) 个等可能结果。将每个结果视为有序对 \((n_1, n_2)\)，其中 \(n_1\) 为第一次抽到的编号，\(n_2\) 为第二次抽到的编号。满足 \(n_1 > n_2\) 的结果共有 \(\binom{n}{2}\) 个：先从 \([1, n]\) 中任选两个不同的数字，再把较大的那个赋给 \(n_1\)。因此所求概率为 \[ \frac{\binom{n}{2}}{n^2} = \frac{n(n-1)/2}{n^2} = \frac{n-1}{2n}. \]

另解：两次抽到相同编号的概率为 \(\frac{n}{n^2} = \frac{1}{n}\)，因此两次编号不同的概率为 \(1 - \frac{1}{n} = \frac{n-1}{n}\)。由对称性，第一次编号更大与第二次编号更大的可能性相等，故将 \(\frac{n-1}{n}\) 除以 2，得到 \(\frac{n-1}{2n}\)。

(c) 共有 \(n^2\) 个可能的有序对，其中满足第二次编号恰好比第一次大 1 的有序对为 \(\{(1,2), (2,3), \ldots, (n-1, n)\}\)，共 \(n-1\) 个。因此所求概率为 \[ \frac{n-1}{n^2}. \]

(d) 不放回时，共有 \(n(n-1)\) 个可能的有序对，其中只有 \((1, 2)\) 对应所关心的事件，因此第一次为 1 且第二次为 2 的概率为 \[ \frac{1}{n(n-1)}. \]

此时两次编号不可能相同，但前述对称性仍然成立，因此第二次编号更小的概率为 \(\frac{1}{2}\)。

满足第二次编号恰好比第一次大 1 的有序对仍为 \(\{(1,2), (2,3), \ldots, (n-1, n)\}\)，共 \(n-1\) 个，因此所求概率为 \[ \frac{n-1}{n(n-1)} = \frac{1}{n}. \]
