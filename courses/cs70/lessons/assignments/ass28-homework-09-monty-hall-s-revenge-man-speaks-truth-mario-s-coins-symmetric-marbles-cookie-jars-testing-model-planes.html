1蒙蒂·霍尔的复仇题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

参见 Note 13、Note 14。

由于电视演播室招聘流程的一个奇特之处，蒙蒂·霍尔（Monty Hall）的游戏节目全部从以前的 CS70 学生中抽取参赛者。不幸的是，这些前学生出色的概率技能使得蒙蒂的“汽车与山羊”把戏对演播室来说无利可图。蒙蒂决定提高赌注，要求参赛者推广到三种新情况，这些情况具有可变数量的门、山羊和汽车：

（a）对于某个 \(n > 2\)，共有 \(n\) 扇门。其中一扇门后有一辆汽车，其余 \(n - 1\) 扇门后是山羊。与普通蒙蒂·霍尔问题一样，在你做出第一次选择后，蒙蒂会揭示一扇有山羊的门。换门会如何影响你选中汽车的概率？（计算两种情况下的获胜概率，并比较结果。）

提示：考虑“总是换门”实验的样本空间大小。其中有多少结果是有利的？

（b）同样有 \(n > 2\) 扇门，一扇门后有汽车，\(n - 1\) 扇门后有山羊，但这次蒙蒂会揭示 \(n - 2\) 扇有山羊的门，而不仅仅是一扇。换门会如何影响这种修改后情况下的获胜概率？

（c）最后，想象在 \(n > 2\) 扇门后有 \(k < n - 1\) 辆汽车和 \(n - k\) 只山羊。在你做出第一次选择后，蒙蒂会揭示 \(j < n - k\) 扇有山羊的门。什么 \(j\)、\(k\) 值能最大化如果你选择换门时获胜概率的相对提升？（即什么 \(j\)、\(k\) 能最大化换门获胜概率与不换门获胜概率之间的比值？）

查看解题提示

考虑用样本空间计数的方法：在“总是换门”策略下，分别计算第一次选中山羊和选中汽车的两种情况，统计所有可能结果和有利结果的数量。注意换门后可选门的数量取决于蒙蒂揭示了几扇门。

展开官方参考解答

在整个解答中，我们用 \(W\) 表示参赛者获胜的事件，用 \(P_S[W]\) 和 \(P_N[W]\) 分别表示参赛者在换门（Switching）和不换门（Not switching）策略下该事件发生的概率。

（a）不换门时，\(P_N[W] = 1/n\)，因为在 \(n\) 个初始选择中只有 1 个能让我们得到汽车。在换门策略下，可能发生两种情况：要么第一次选择就选中了汽车，那么换门（换到其余 \(n - 2\) 扇门中的任意一扇）必然会得到山羊；要么第一次选择选中山羊，那么在剩下的 \(n - 2\) 扇门中有一扇有汽车。这一选择序列——先从 \(n\) 扇门中选择，再换到剩下的 \(n - 2\) 扇门之一——给出的样本空间大小为 \(n(n - 2)\)。用有利结果数除以总结果数，得到

\[P_S[W] = \frac{(n - 1) \cdot 1}{n(n - 2)} = \frac{n - 1}{n(n - 2)} = \frac{1}{n} \cdot \frac{n - 1}{n - 2}\]

这大于 \(P_N[W] = 1/n\)（随着 \(n\) 变大，优势越来越小，这表明了蒙蒂的帮助随着门数增加而递减的直观事实），所以换门是更好的策略。

（b）\(P_N[W] = 1/n\) 保持不变。与（a）相同的方法得到与之前相同的分子。对于分母，我们需要确定先随机选择一扇门再换门的实验的样本空间大小。同样，第一次选择有 \(n\) 种方式。但在蒙蒂揭示 \(n - 2\) 扇门后，我们只有 1 个剩余选项可以换。因此分母小得多：

\[P_S[W] = \frac{(n - 1) \cdot 1}{n \cdot 1} = \frac{n - 1}{n} = 1 - \frac{1}{n}\]

所以换门再次成为更好的策略。

（c）现在 \(P_N[W] = k/n\)，因为有 \(k\) 扇门后藏着汽车。用与（b）相同的方式推理样本空间，可以得到 \(P_S[W]\) 的分母。然而，现在分子（换门情况下有利结果的数量）也发生了变化：

\[P_S[W] = \frac{k \cdot (k - 1) + (n - k) \cdot k}{n(n - j - 1)} = \frac{k(n - 1)}{n(n - j - 1)} = \frac{k}{n} \cdot \frac{n - 1}{n - j - 1}\]

由此我们看到 \(P_S[W]/P_N[W] = \frac{n - 1}{n - j - 1}\)，当 \(j = n - k - 1\) 时取最大值。换句话说，如果蒙蒂揭示了除一只山羊外的所有山羊（在原始节目中 \(n = 3\)、\(k = 1\) 且 \(j = 1 = n - k - 1\) 时就是这样），那么参赛者可以将获胜概率提高 \(\frac{n - 1}{k}\) 倍（在原始节目中是 2 倍）。特别地，当 \(k = 1\) 时，换门获得的最大相对优势最大。

完整题面

2. 说真话的人（Man Speaks Truth）

Note 14 考虑一名男子，他说真话的概率为 \(\frac{3}{4}\)。

(a) 假设该男子抛掷一枚有偏硬币（biased coin），正面朝上的概率为 \(\frac{1}{3}\)，然后他报告说正面朝上。 　(i) 硬币实际正面朝上的概率是多少？ 　(ii) 你不太信服，于是问他刚才是否对你撒了谎，他回答“没有”。此时硬币实际正面朝上的概率是多少？ 　(iii) 获得这条新信息后，概率是上升了、下降了，还是保持不变？请用语言解释为什么应该是这样。

(b) 假设该男子掷一个公平的六面骰子（fair 6-sided die）。当你问他骰子是否掷出了 6 时，他回答“是”。 　(i) 骰子实际掷出 6 的概率是多少？ 　(ii) 出于怀疑，你还问他骰子是否掷出了 1，他同样回答“是”。此时骰子实际掷出 6 的概率是多少？ 　(iii) 获得这条新信息后，概率是上升了、下降了，还是保持不变？请用语言解释为什么应该是这样。

查看解题提示

对每一小问，都可以把“男子所说的话”作为观测证据，利用贝叶斯法则（Bayes' rule）反推背后真实事件的后验概率。计算时需要借助全概率公式（total probability），枚举真实结果的所有可能情形，并注意该男子说真话（概率 \(\frac{3}{4}\)）与说谎（概率 \(\frac{1}{4}\)）的先验比例。

对于需要同时结合两次回答的小问（(a)(ii) 与 (b)(ii)），可以按时间顺序用乘法法则（product rule）展开联合条件概率；留意在给定真实结果的前提下，男子的各次回答之间是否条件独立，这将简化计算。

展开官方参考解答

解答：

(a)(i) 设 \(SH\) 表示“该男子说正面朝上”的事件，\(H\) 表示“硬币正面朝上”的事件，\(T\) 表示“硬币反面朝上”的事件（注意 \(H\) 与 \(T\) 互为补事件）。

已知该男子说正面朝上（即 \(SH\) 发生），要求硬币正面朝上的概率。使用贝叶斯法则与全概率公式，有

\[ P[H \mid SH] = \frac{P[SH \cap H]}{P[SH]} = \frac{P[SH \mid H]\,P[H]}{P[SH \mid H]\,P[H] + P[SH \mid T]\,P[T]}. \]

其中 \(P[H] = \frac{1}{3}\) 且 \(P[T] = \frac{2}{3}\)。该男子有 \(\frac{3}{4}\) 的时间说真话，因此也有条件概率 \(P[SH \mid H] = \frac{3}{4}\)（此时他说真话）和 \(P[SH \mid T] = \frac{1}{4}\)（此时他说谎）。

代入这些概率，得

\[ P[H \mid SH] = \frac{\frac{3}{4} \cdot \frac{1}{3}}{\frac{3}{4} \cdot \frac{1}{3} + \frac{1}{4} \cdot \frac{2}{3}} = \frac{3}{3 + 2} = \frac{3}{5}. \]

(a)(ii) 定义以下事件：

  • \(H\)：硬币正面朝上，\(T\)：硬币反面朝上。

  • \(SH\)：该男子说正面朝上，\(ST\)：该男子说反面朝上。

  • \(SY\)：该男子说自己撒了谎（对问题回答“是”），\(SN\)：该男子说自己没有撒谎（对问题回答“没有”）。

已知该男子说正面朝上（即 \(SH\) 发生），且该男子说自己没有撒谎（即 \(SN\) 发生）；要求硬币正面朝上的概率。使用贝叶斯法则配合乘法法则与全概率公式，有

\[ P[H \mid SN \cap SH] = \frac{P[SN \cap SH \cap H]}{P[SN \cap SH]} = \frac{P[SN \cap SH \cap H]}{P[SN \cap SH \cap H] + P[SN \cap SH \cap T]} \]

\[ = \frac{P[SN \mid SH \cap H]\,P[SH \mid H]\,P[H]}{P[SN \mid SH \cap H]\,P[SH \mid H]\,P[H] + P[SN \mid SH \cap T]\,P[SH \mid T]\,P[T]}. \]

其中仍有 \(P[H] = \frac{1}{3}\) 且 \(P[T] = \frac{2}{3}\)。我们也有 \(P[SH \mid H] = \frac{3}{4}\)（此时他说真话）和 \(P[SH \mid T] = \frac{1}{4}\)（此时他说谎）。

此外，\(P[SN \mid SH \cap H] = \frac{3}{4}\)（此时该男子说真话；他说正面朝上时并未撒谎，因为硬币确实是正面朝上），且 \(P[SN \mid SH \cap T] = \frac{1}{4}\)（此时该男子说谎；他之前说正面朝上时已经在撒谎，因此他回答自己没有撒谎也是在说谎）。

代入这些数值，得

\[ P[H \mid SN \cap SH] = \frac{\frac{3}{4} \cdot \frac{3}{4} \cdot \frac{1}{3}}{\frac{3}{4} \cdot \frac{3}{4} \cdot \frac{1}{3} + \frac{1}{4} \cdot \frac{1}{4} \cdot \frac{2}{3}} = \frac{9}{9 + 2} = \frac{9}{11}. \]

直观上讲，这里我们利用乘法法则考虑了事件发生的顺序。本质上我们有三个时间点：(1) 该男子抛硬币，(2) 该男子陈述硬币的结果，(3) 该男子回答自己是否撒了谎。给定问题情境下，后两个时间点的结果已经固定（我们知道该男子说硬币是正面朝上，也知道该男子说自己没有撒谎），因此唯一可能变化的是抛硬币的结果（即硬币可能是正面朝上或反面朝上）。这给出了分母中的两个分支，而分子只考察其中一个分支（即硬币正面朝上时）。

(a)(iii) 获得新信息后，概率上升了。直观上，这是因为该男子说真话的频率高于说谎。他重申自己没有撒谎，意味着硬币实际正面朝上的可能性更高了。

(b)(i) 设 \(R6\) 表示“掷出了 6”的事件，\(RN\) 表示“没有掷出 6”的事件，\(S6\) 表示“该男子说掷出了 6”的事件。

已知该男子说掷出了 6（即 \(S6\) 发生），要求实际掷出 6 的概率。使用贝叶斯法则与全概率公式，有

\[ P[R6 \mid S6] = \frac{P[R6 \cap S6]}{P[S6]} = \frac{P[S6 \mid R6]\,P[R6]}{P[S6 \mid R6]\,P[R6] + P[S6 \mid RN]\,P[RN]}. \]

由于骰子是公平的，\(P[R6] = \frac{1}{6}\) 且 \(P[RN] = \frac{5}{6}\)。我们也有 \(P[S6 \mid R6] = \frac{3}{4}\)（该男子说真话）和 \(P[S6 \mid RN] = \frac{1}{4}\)（该男子说谎）。

代入这些数值，得

\[ P[R6 \mid S6] = \frac{\frac{3}{4} \cdot \frac{1}{6}}{\frac{3}{4} \cdot \frac{1}{6} + \frac{1}{4} \cdot \frac{5}{6}} = \frac{3}{3 + 5} = \frac{3}{8}. \]

(b)(ii) 定义以下事件：

  • \(R6\)：掷出了 6，\(R1\)：掷出了 1，\(RN\)：掷出的既不是 1 也不是 6。

  • \(S6\)：该男子说骰子是 6，\(S1\)：该男子说骰子是 1。

已知该男子说骰子是 6（即 \(S6\) 发生）且该男子说骰子是 1（即 \(S1\) 发生）；要求骰子实际是 6 的概率。使用贝叶斯法则与全概率公式（注意此处有三个事件构成样本空间的划分），有

\[ P[R6 \mid S1 \cap S6] = \frac{P[S1 \cap S6 \cap R6]}{P[S1 \cap S6]} \]

\[ = \frac{P[S1 \cap S6 \cap R6]}{P[S1 \cap S6 \cap R1] + P[S1 \cap S6 \cap R6] + P[S1 \cap S6 \cap RN]} \]

\[ = \frac{P[S1 \mid S6 \cap R6]\,P[S6 \mid R6]\,P[R6]}{P[S1 \mid S6 \cap R6]\,P[S6 \mid R6]\,P[R6] + P[S1 \mid S6 \cap R1]\,P[S6 \mid R1]\,P[R1] + P[S1 \mid S6 \cap RN]\,P[S6 \mid RN]\,P[RN]}. \]

由于骰子公平，\(P[R1] = P[R6] = \frac{1}{6}\)，而 \(P[RN] = \frac{4}{6}\)。

对骰子结果的三种可能情形，有条件概率：

  • \(P[S6 \mid R1] = \frac{1}{4}\)，因为该男子说谎

  • \(P[S6 \mid R6] = \frac{3}{4}\)，因为该男子说真话

  • \(P[S6 \mid RN] = \frac{1}{4}\)，因为该男子说谎

注意到，若以骰子具有某特定结果为条件（例如以掷出了 6 为条件），则“该男子说骰子是 6”的事件与“该男子说骰子是 1”的事件实际上是独立的。直观上，这是因为我们已经知道骰子的结果，因此该男子说骰子是 6 这一事实并不影响他也说骰子是 1 的概率——这仅取决于他是否说了谎。

因此我们还有以下条件概率：

  • \(P[S1 \mid S6 \cap R1] = P[S1 \mid R1] = \frac{3}{4}\)，因为该男子说真话

  • \(P[S1 \mid S6 \cap R6] = P[S1 \mid R6] = \frac{1}{4}\)，因为该男子说谎

  • \(P[S1 \mid S6 \cap RN] = P[S1 \mid RN] = \frac{1}{4}\)，因为该男子说谎

代入所有数值，得

\[ P[R6 \mid S1 \cap S6] = \frac{\frac{1}{4} \cdot \frac{3}{4} \cdot \frac{1}{6}}{\frac{1}{4} \cdot \frac{3}{4} \cdot \frac{1}{6} + \frac{3}{4} \cdot \frac{1}{4} \cdot \frac{1}{6} + \frac{1}{4} \cdot \frac{1}{4} \cdot \frac{4}{6}} = \frac{3}{3 + 3 + 4} = \frac{3}{10}. \]

与上一部分类似，这里我们本质上也在考虑事件发生的顺序。不过在此处，我们同样可以先以 \(S1\) 为条件，再计算 \(S6\) 的概率（即交换上面 \(S1\) 和 \(S6\) 的位置），因为它们在给定 \(R1\)、\(R6\) 或 \(RN\) 的条件下相互独立。

我们现在考虑的三个时间点是 (1) 该男子掷骰子，(2) 该男子陈述是否为 6，(3) 该男子陈述是否为 1。同样，后两个结果因问题情境而固定，第一个结果可以自由变化。这就是为什么我们需要分母中的三个分支，分别对应 \(R1\)、\(R6\) 和 \(RN\)。我们也不能将其拆分为两个事件，因为对“骰子是否掷出 1”的回答取决于骰子是否真的掷出了 1，对“骰子是否掷出 6”的回答取决于骰子是否真的掷出了 6；最简便的做法是分别考虑每种情形。

(b)(iii) 获得新信息后，概率下降了。由于该男子不可能在两次陈述中都说真话（即骰子不可能同时掷出 1 和 6），因此其中必有一句是谎话。这会降低第一句陈述实际为真的概率，即骰子实际掷出了 6 的概率。

3马里奥的硬币题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

马里奥（Mario）拥有三枚外观完全相同（identical-looking）的硬币。第一枚硬币正面朝上的概率为 \(1/4\)，第二枚正面朝上的概率为 \(1/2\)，第三枚正面朝上的概率为 \(3/4\)。

(a) 马里奥随机选择一枚硬币并抛掷它。随后他在剩余的两枚硬币中随机选择一枚并抛掷它。设 \(X_1\) 与 \(X_2\) 分别为第 1 次与第 2 次抛掷正面朝上的事件。\(X_1\) 与 \(X_2\) 是否独立？请证明你的结论。

(b) 马里奥随机选择一枚硬币并抛掷它两次。设 \(Y_1\) 与 \(Y_2\) 分别为第 1 次与第 2 次抛掷正面朝上的事件。\(Y_1\) 与 \(Y_2\) 是否独立？请证明你的结论。

(c) 马里奥把他的三枚硬币排成一行。他先抛掷最左侧的硬币，结果为正面朝上；再抛掷正中间的硬币，结果也为正面朝上。最后他抛掷最右侧的硬币。求最右侧硬币也正面朝上的概率。

查看解题提示

(a)(b)：要判断两个事件是否独立，应当直接验证定义：计算 \(P[X_1 \cap X_2]\) 并与 \(P[X_1]P[X_2]\) 比较。注意 (a) 中两枚硬币必须不同，(b) 中两枚硬币是同一枚。

(c) 三枚硬币的所有 6 种排列顺序是等可能的（概率各为 \(1/6\)）。考虑利用贝叶斯公式，计算在已知前两枚硬币都正面朝上的条件下，第三枚硬币正面朝上的条件概率。

展开官方参考解答

(a) \(X_1\) 与 \(X_2\) 不独立。

首先计算 \(P[X_1]\)： \[P[X_1] = \frac{1}{3} \cdot \frac{1}{4} + \frac{1}{3} \cdot \frac{1}{2} + \frac{1}{3} \cdot \frac{3}{4} = \frac{1}{2}.\] 由对称性，\(P[X_2] = P[X_1] = \frac{1}{2}\)，因此 \[P[X_1]P[X_2] = \frac{1}{4}.\]

接下来计算 \(P[X_1 \cap X_2]\)。由于两次抛掷的硬币必须不同，共有 \(3 \times 2 = 6\) 种有序选择，每种概率为 \(\frac{1}{6}\)： \[\begin{aligned} P[X_1 \cap X_2] &= \frac{1}{6}\Bigg[\left(\frac{1}{4} \cdot \frac{1}{2}\right) + \left(\frac{1}{4} \cdot \frac{3}{4}\right) + \left(\frac{1}{2} \cdot \frac{1}{4}\right) + \left(\frac{1}{2} \cdot \frac{3}{4}\right) + \left(\frac{3}{4} \cdot \frac{1}{4}\right) + \left(\frac{3}{4} \cdot \frac{1}{2}\right)\Bigg] \\ &= \frac{22}{96} = \frac{11}{48}. \end{aligned}\] 由于 \(\frac{11}{48} \neq \frac{1}{4}\)，故 \(X_1\) 与 \(X_2\) 不独立。

(b) \(Y_1\) 与 \(Y_2\) 不独立。

同理可得 \(P[Y_1] = \frac{1}{2}\)，且由对称性 \(P[Y_2] = \frac{1}{2}\)，因此 \(P[Y_1]P[Y_2] = \frac{1}{4}\)。

计算 \(P[Y_1 \cap Y_2]\)。现在两次抛掷的是同一枚硬币，选中每枚硬币的概率均为 \(\frac{1}{3}\)： \[\begin{aligned} P[Y_1 \cap Y_2] &= \frac{1}{3} \cdot \left(\frac{1}{4}\right)^2 + \frac{1}{3} \cdot \left(\frac{1}{2}\right)^2 + \frac{1}{3} \cdot \left(\frac{3}{4}\right)^2 \\ &= \frac{1}{3} \cdot \frac{1}{16} + \frac{1}{3} \cdot \frac{1}{4} + \frac{1}{3} \cdot \frac{9}{16} = \frac{14}{48} = \frac{7}{24}. \end{aligned}\] 由于 \(\frac{7}{24} \neq \frac{1}{4}\)，故 \(Y_1\) 与 \(Y_2\) 不独立。

(c) 设 \(A\) 为正面概率为 \(1/4\) 的硬币，\(B\) 为正面概率为 \(1/2\) 的公平硬币，\(C\) 为正面概率为 \(3/4\) 的硬币。三枚硬币的 6 种排列顺序（ABC, ACB, BAC, BCA, CAB, CBA）等可能，概率各为 \(\frac{1}{6}\)。

\(P[\text{第三枚硬币正面朝上} \mid \text{前两枚硬币正面朝上}]\) \[{}= \frac{P[\text{三枚硬币都正面朝上}]}{P[\text{前两枚硬币正面朝上}]}.\]

分子：无论哪种排列，三枚都正面朝上的概率都是 \(\frac{1}{4} \cdot \frac{1}{2} \cdot \frac{3}{4} = \frac{3}{32}\)。

分母：对 6 种排列求和： \[\begin{aligned} P[\text{前两枚正面朝上}] &= \frac{1}{6}\Bigg[\left(\frac{1}{4} \cdot \frac{1}{2}\right) + \left(\frac{1}{4} \cdot \frac{3}{4}\right) + \left(\frac{1}{2} \cdot \frac{1}{4}\right) + \left(\frac{1}{2} \cdot \frac{3}{4}\right) + \left(\frac{3}{4} \cdot \frac{1}{4}\right) + \left(\frac{3}{4} \cdot \frac{1}{2}\right)\Bigg] \\ &= \frac{1}{6} \cdot \frac{11}{8} = \frac{11}{48}. \end{aligned}\]

因此所求条件概率为 \[\frac{3/32}{11/48} = \frac{3}{32} \cdot \frac{48}{11} = \frac{9}{22}.\]

4对称弹珠题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

一个袋子中包含 4 个红色弹珠和 4 个蓝色弹珠。Rachel 和 Brooke 玩一个游戏，他们总共抽取 4 个弹珠，每次抽取一个，均匀随机且不放回。如果红色弹珠比蓝色弹珠多，Rachel 获胜；如果蓝色弹珠比红色弹珠多，Brooke 获胜。如果两种颜色的弹珠数量相等，则游戏平局。

(a) 设 \(A_1\) 为第一个弹珠是红色的事件，\(A_2\) 为第二个弹珠是红色的事件。\(A_1\) 和 \(A_2\) 是否独立？

(b) Rachel 赢得游戏的概率是多少？

(c) 已知 Rachel 赢得游戏，所有弹珠都是红色的概率是多少？

现在假设袋子中包含 8 个红色弹珠和 4 个蓝色弹珠。此外，如果抽出的 4 个弹珠中红色和蓝色弹珠数量相等，那么当第三个弹珠是红色时 Rachel 获胜，当第三个弹珠是蓝色时 Brooke 获胜。所有其他规则保持不变。

(d) 第三个弹珠是红色的概率是多少？

(e) 已知抽出的 4 个弹珠中有 \(k\) 个红色弹珠，其中 \(0 \leq k \leq 4\)，第三个弹珠是红色的概率是多少？用 \(k\) 表示。

(f) 已知第三个弹珠是红色，Rachel 赢得游戏的概率是多少？

查看解题提示

(a) 考虑不放回抽取如何改变袋中弹珠的组成，以及这是否影响后续抽取的概率。 (b) 利用 Rachel 和 Brooke 之间的对称性，先计算平局的概率，再推导 Rachel 获胜的概率。 (d)–(f) 注意四个被抽位置之间的对称性，以及平局决胜规则如何改变获胜条件。

展开官方参考解答

(a) 它们不独立；移除一个红色弹珠会降低下一个弹珠是红色的概率。

(b) 设 \(p\) 为 Rachel 获胜的概率。由于红色和蓝色弹珠数量相等，由对称性，Rachel 获胜的概率与 Brooke 获胜的概率相同。因此，平局的概率为 \(1 - p - p = 1 - 2p\)。

现在我们计算平局的概率。为了出现平局，四个弹珠中需要有两个是红色的。从 8 个弹珠中选 4 个有 \(\binom{8}{4}\) 种方式，选 2 个红色和 2 个蓝色弹珠分别有 \(\binom{4}{2}\) 和 \(\binom{4}{2}\) 种方式，因此平局的概率为

\[ \frac{\binom{4}{2}\binom{4}{2}}{\binom{8}{4}} = \frac{36}{70} = \frac{18}{35}. \]

我们得出 \(1 - 2p = \frac{18}{35}\)。解得 \(p = \frac{17}{70}\)。

(c) 设 \(A\) 为抽到 3 个红色弹珠的事件，\(B\) 为抽到 4 个红色弹珠的事件。我们要求

\[ P[B \mid (A \cup B)] = \frac{P[B \cap (A \cup B)]}{P[A \cup B]} = \frac{P[B]}{P[A] + P[B]}. \]

与 (b) 中的计算类似，抽到 3 个红色弹珠的概率为

\[ \frac{\binom{4}{3}\binom{4}{1}}{\binom{8}{4}} = \frac{16}{70}, \]

抽到 4 个红色弹珠的概率为

\[ \frac{\binom{4}{4}\binom{4}{0}}{\binom{8}{4}} = \frac{1}{70}, \]

因此最终答案为

\[ \frac{1/70}{16/70 + 1/70} = \frac{1}{17}. \]

(d) 由对称性，第三个弹珠是红色的概率与第一个弹珠是红色的概率相同，也与任意一个弹珠是红色的概率相同。一种理解方式是：想象按顺序抽出四个弹珠，然后将第一个抽出的弹珠移到第三个位置。这是另一种抽取四个弹珠的方式，但产生相同的分布。

共有 8 个红色弹珠，12 个弹珠总数。因此，第三个弹珠是红色的概率为

\[ \frac{8}{12} = \frac{2}{3}. \]

(e) 已知 4 个抽出的弹珠中有 \(k\) 个是红色的。由对称性，每个弹珠是红色的概率相同，因此第三个弹珠是红色的概率为

\[ \frac{k}{4}. \]

(f) 已知第三个弹珠是红色，Rachel 输掉游戏的唯一情况是所有其他弹珠都是蓝色的。第三个弹珠是红色且所有其他弹珠都是蓝色的概率为

\[ \frac{4}{12} \cdot \frac{3}{11} \cdot \frac{8}{10} \cdot \frac{2}{9} = \frac{8}{495}, \]

而第三个弹珠是红色的概率为 \(\frac{8}{12} = \frac{2}{3}\)。因此，已知第三个弹珠是红色，Rachel 输的概率为

\[ \frac{8/495}{2/3} = \frac{4}{165}, \]

Rachel 赢的概率为

\[ 1 - \frac{4}{165} = \frac{161}{165}. \]

5饼干罐题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

你有两罐饼干，每罐最初都有 \(n\) 个饼干。每天回家后，你随机选择两个罐子中的一个（每个罐子被选中的概率为 \(1/2\)），然后从该罐子中吃掉一个饼干。有一天，你回家伸手进其中一个罐子，却发现它是空的！设 \(X\) 为该时刻非空罐子中剩余的饼干数量。求 \(X\) 的分布。

查看解题提示

考虑发现空罐子之前的整个过程：你已经吃了多少天饼干？在这段时间里，你分别选择了每个罐子多少次？将问题建模为一系列独立的伯努利试验，并考虑对称性。

展开官方参考解答

假设你发现 1 号罐是空的。\(X = k\) 且你发现 1 号罐为空的概率计算如下。

为了使剩余 \(k\) 个饼干，你必须已经吃了 \(2n - k\) 天的饼干，然后你必须选择了 1 号罐（以发现它是空的）。在这 \(2n - k\) 天中，恰好有 \(n\) 天你选择了 1 号罐。这种情况的概率为

\[ \binom{2n - k}{n} 2^{-(2n - k)}. \]

此外，你在第二天发现 1 号罐为空的概率是 \(1/2\)。因此，\(X = k\) 且你发现 1 号罐为空的概率为

\[ \binom{2n - k}{n} 2^{-(2n - k + 1)}. \]

然而，我们假设发现的是 1 号罐为空；由对称性，\(X = k\) 且 2 号罐为空的概率相同。因此，\(X = k\) 的总体概率为：

\[ P[X = k] = \binom{2n - k}{n} \frac{1}{2^{2n - k}}, \quad k \in \{0, \ldots, n\}. \]

6测试模型飞机题目 · 提示 · 答案
官方题面翻译可离线作答官方解答已收录

完整题面

Note 15

Amin 正在测试模型飞机。他一开始有 n 架模型飞机，每架飞机每次飞行时独立地以概率 p 成功飞行（不会坠毁），其中 \(0 < p < 1\)。每一天，他会放飞所有飞机，并保留那些成功飞行的飞机（即未坠毁的飞机），扔掉其余所有模型。他重复这一过程许多天，其中每一天包括 Amin 放飞任意剩余的模型飞机并扔掉任何坠毁的飞机。设随机变量 \(X_i\) 表示第 \(i\) 天后剩余的模型飞机数量。注意 \(X_0 = n\)。请为每个小问的答案提供理由。

(a) \(X_1\) 的分布是什么？即 \(P[X_1 = k]\) 是多少？

(b) \(X_2\) 的分布是什么？即 \(P[X_2 = k]\) 是多少？请识别 \(X_2\) 的分布为某个著名分布，并给出其名称和参数。

(c) 对任意 \(t \ge 1\)，对 \(X_t\) 重复上述小问。

(d) \(t\) 天后至少有一架模型飞机仍未坠毁（仍然剩余）的概率是多少？答案中不得包含求和符号。

(e) 仅考虑第一天的飞行，设事件 \(A_1\) 为第一架和第二架模型飞机坠毁，事件 \(B_1\) 为第二架和第三架模型飞机坠毁，\(A_1\) 与 \(B_1\) 是否独立？回顾：两个事件 \(A\) 和 \(B\) 独立当且仅当 \(P[A \cap B] = P[A]P[B]\)。请用这一定义证明你的答案。

(f) 仅考虑第一天的飞行，设事件 \(A_2\) 为第一架模型飞机坠毁且总共恰好有两架模型飞机坠毁。设事件 \(B_2\) 为第二架飞机在第一天坠毁。\(n\) 必须等于关于 \(p\) 的什么表达式才能使 \(A_2\) 与 \(B_2\) 独立？请用上一小问中所述的独立性定义证明你的答案。

(g) 随机变量 \(X_i\) 与 \(X_j\)（其中 \(i < j\)）是否独立？回顾：两个随机变量 \(X\) 和 \(Y\) 独立当且仅当对所有 \(k_1\) 和 \(k_2\) 都有 \(P[X = k_1 \cap Y = k_2] = P[X = k_1]P[Y = k_2]\)。请用这一定义证明你的答案。

查看解题提示

每架飞机的飞行结果可视为独立的伯努利试验，多架飞机的联合分布常指向二项分布。对于独立性的判断，可直接利用定义进行验证，或寻找一组使等式不成立的特例。

展开官方参考解答

(a) 由于 Amin 进行了 \(n\) 次试验（放飞一架飞机），每次试验独立地以概率 \(p\) 成功（未坠毁），因此 \(X_1 \sim \text{Binomial}(n, p)\)，即 \[P[X_1 = k] = \binom{n}{k} p^k (1-p)^{n-k}, \quad 0 \le k \le n.\]

(b) 每架模型飞机独立地以概率 \(p^2\) 存活两天。一架飞机存活两天与否与另一架飞机存活两天与否仍然独立，因此 \(X_2 \sim \text{Binomial}(n, p^2)\)，即 \[P[X_2 = k] = \binom{n}{k} p^{2k} (1-p^2)^{n-k}, \quad 0 \le k \le n.\]

(c) 通过推广上一小问，每架模型飞机以概率 \(p^t\) 存活 \(t\) 天，因此 \(X_t \sim \text{Binomial}(n, p^t)\)，即 \[P[X_t = k] = \binom{n}{k} (p^t)^k (1-p^t)^{n-k}, \quad 0 \le k \le n.\]

(d) 我们考虑其补事件，即 \(t\) 天后没有模型飞机剩余的概率。由上一小问可知 \[P[X_t = 0] = \binom{n}{0} (p^t)^0 (1-p^t)^{n-0} = (1-p^t)^n.\] 因此 \(t\) 天后至少有一架模型飞机剩余的概率为 \(1 - (1-p^t)^n\)。

(e) 不独立。\(P[A_1 \cap B_1]\) 是第一架、第二架和第三架模型飞机都坠毁的概率，即 \((1-p)^3\)。但 \[P[A_1]P[B_1] = (1-p)^2 \cdot (1-p)^2 = (1-p)^4.\] 因此 \(P[A_1 \cap B_1] \neq P[A_1]P[B_1]\)，\(A_1\) 与 \(B_1\) 不独立。

(f) \(P[A_2 \cap B_2]\) 是只有第一架和第二架模型飞机坠毁的概率，即 \((1-p)^2 p^{n-2}\)。\(P[A_2]\) 是第一架模型飞机坠毁且其余 \(n-1\) 架中恰好有一架坠毁的概率，因此 \[P[A_2] = (1-p) \cdot \binom{n-1}{1} (1-p) p^{n-2} = (n-1)(1-p)^2 p^{n-2}.\] 又有 \(P[B_2] = 1-p\)。由 \(P[A_2 \cap B_2] = P[A_2]P[B_2]\) 得 \[(1-p)^2 p^{n-2} = (n-1)(1-p)^2 p^{n-2} \cdot (1-p),\] 即 \[1 = (n-1)(1-p),\] 解得 \[n = 1 + \frac{1}{1-p}.\]

(g) 不独立。取 \(k_1 = 0\)，\(k_2 = 1\)。则 \(P[X_i = k_1 \cap X_j = k_2] = 0\)，因为如果第 \(i\) 天结束时已无飞机剩余，第 \(j\) 天结束时不可能还剩 \(1\) 架。但 \(P[X_i = k_1] > 0\) 且 \(P[X_j = k_2] > 0\)，因此 \(P[X_i = k_1]P[X_j = k_2] > 0\)。由于 \(P[X_i = k_1]P[X_j = k_2] \neq P[X_i = k_1 \cap X_j = k_2]\)，它们不独立。
