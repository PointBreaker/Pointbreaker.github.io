分布式并行策略

1

域分解 (Domain Decomposition)

将模拟空间划分为 p 个子域，每个进程负责一个子域内的粒子。

  • 1D / 2D / 3D 分解：3D 分解通信量最小但更复杂
  • 均匀分解 vs 自适应分解（负载均衡）
  • 每个子域大小 ≥ cutoff，避免跨域力计算遗漏
2

Ghost Layer / Halo Exchange

每个子域边界外扩 cutoff 距离，存储相邻进程的粒子副本（ghost particles）。

  • 每个时间步前交换 ghost 粒子位置
  • 只交换 cutoff 范围内的粒子
  • 使用 MPI_Sendrecv 或 MPI_Isend/Irecv
⚠️ 常见坑：Ghost Layer 的厚度必须 ≥ cutoff，否则会漏掉远距离相互作用。周期性边界条件需要特别处理角落 ghost。
3

粒子迁移 (Particle Migration)

粒子移动后可能离开当前子域，需要迁移到正确的进程。

  • 更新位置后检查粒子所属子域
  • 使用 MPI_Alltoallv 进行不规则数据交换
  • 注意：迁移后需要重新构建 Cell List
4

力计算并行化

每个进程独立计算本地粒子与本地 + ghost 粒子的相互作用。

  • 本地力计算：与 HW2-1 串行算法相同
  • 跨域力：利用 ghost 粒子，无需额外通信
  • 利用牛顿第三定律减少一半计算（但增加通信复杂度）
5

全局收集 (gather_for_save)

输出时需要把所有粒子收集到根进程。

  • 使用 MPI_Gather 或 MPI_Gatherv（粒子数不均）
  • 考虑异步 I/O 或并行文件系统避免瓶颈
  • 只在需要输出时收集，不要每步都收集

MPI 通信原语速查

原语 用途 类型
MPI_Send / MPI_Recv 点对点阻塞通信 点对点
MPI_Sendrecv 同时发送和接收，避免死锁 点对点
MPI_Isend / MPI_Irecv 非阻塞通信，可重叠计算 点对点
MPI_Allgather 全收集：每个进程获得所有数据 集合
MPI_Alltoallv 全交换：不规则数据分布 集合
MPI_Barrier 全局同步 集合

通信是分布式并行的最大敌人。 你的目标是最小化通信量、最大化计算/通信重叠。Ghost Halo 的厚度、迁移频率、Alltoallv 的数据分布——每一个选择都影响扩展性。

扩展性分析要点

扩展性类型 定义 关注指标
Strong Scaling 固定问题规模，增加处理器数 S = T₁ / Tₚ，理想 = p
Weak Scaling 固定每处理器问题规模，增加处理器数 E = T₁ / Tₚ，理想 = 1
通信开销 T_comm / T_total 随 p 的变化 应尽可能小
负载均衡 最大 / 平均负载比 理想 = 1

常见陷阱

⚠️ 死锁： 阻塞通信 MPI_Send / MPI_Recv 顺序不当会导致死锁。优先使用 MPI_Sendrecv 或非阻塞通信。
⚠️ 负载不均： 粒子分布不均匀时，某些进程空闲等待。考虑自适应域分解或动态负载均衡。
⚠️ 通信爆炸： 每步都做 MPI_Allgather 会让通信量 O(p) 增长。只在必要时收集数据。
⚠️ 忘记 PBC： 周期性边界条件下，ghost 粒子位置需要正确 wrap，否则力计算出错。
