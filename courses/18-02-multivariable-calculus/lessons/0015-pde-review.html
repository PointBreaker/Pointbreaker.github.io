第二单元复习主题

1. 多元函数与等高线
函数 \(f(x,y)\) 的图像、等高线 \(f(x,y)=c\)、等高线图解读。

2. 偏导数、切平面与梯度
\(f_x, f_y\) 的几何意义；切平面方程；线性近似 \(\Delta f \approx f_x\Delta x + f_y\Delta y\)；梯度 \(\nabla f = \langle f_x,f_y,f_z\rangle\) 垂直于等值面，指向最陡上升方向。

3. 方向导数
\(D_{\hat{u}}f = \nabla f \cdot \hat{u} = |\nabla f|\cos\theta\)，最大值 \(|\nabla f|\) 在梯度方向取得。

4. 极值与二阶导数检验
临界点 \(f_x=f_y=0\)；判别式 \(D=f_{xx}f_{yy}-(f_{xy})^2\)：\(D>0\) 且 \(f_{xx}>0\) 极小，\(f_{xx}<0\) 极大；\(D<0\) 鞍点；\(D=0\) 无法判断。

5. 绝对极值与边界
闭区域上的绝对极值需检查内部临界点、边界（参数化）以及无穷远处。

6. 最小二乘法
极小化平方偏差之和，导出法方程（但最小二乘不在本次考试范围内）。

7. 微分与链式法则
全微分 \(df = f_x dx + f_y dy + f_z dz\)；多变量链式法则；坐标变换（极坐标等）；注意偏导数不能"约分"。

8. 非独立变量
约束 \(g(x,y,z)=c\) 下的隐函数偏导数 \((\partial z/\partial x)_y = -g_x/g_z\)；全微分与链式法则两种方法；符号 \((\partial f/\partial x)_y\) 明确固定变量；注意 \(x=u\) 但 \(\partial f/\partial x \neq \partial f/\partial u\)。

9. Lagrange 乘子
约束极值 \(\nabla f = \lambda\nabla g\) 与 \(g=c\) 联立；几何意义为等高线与约束曲线相切。

偏微分方程简介

偏微分方程（Partial Differential Equation, PDE）是包含未知函数偏导数的方程，在物理学中极其重要。

例子：热方程（heat equation）描述温度 \(f(x,y,z,t)\) 随时间的演化：

\[ \frac{\partial f}{\partial t} = k\Bigl(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2}\Bigr) \]

其中 \(k\) 是热扩散系数。这个 PDE 把温度对时间的一阶导数与对空间的二阶导数联系起来。

核心思想：PDE 是描述自然现象（热传导、流体、电磁等）的基本语言，本课程后续还会遇到更多。

约束偏导数再梳理

设 \(f=f(x,y,z)\)，约束 \(g(x,y,z)=c\)。求 \((\partial f/\partial z)_y\)：

方法 1（全微分）：\(df = f_x dx + f_y dy + f_z dz\)。固定 \(y\)（\(dy=0\)），由约束微分 \(g_x dx + g_y dy + g_z dz = 0\) 得 \(dx = -(g_z/g_x)dz\)。代入 \(df\)：

\[ \Bigl(\frac{\partial f}{\partial z}\Bigr)_y = -\,\frac{f_x g_z}{g_x} + f_z \]

方法 2（链式法则）：\(\displaystyle\Bigl(\frac{\partial f}{\partial z}\Bigr)_y = f_x\Bigl(\frac{\partial x}{\partial z}\Bigr)_y + f_z\)，再由约束 \(0 = g_x(\partial x/\partial z)_y + g_z\) 解出 \((\partial x/\partial z)_y\)。两种方法本质相同。
