Vector Fields and Line Integrals (向量场与线积分)

引入平面向量场（vector fields）的概念，定义沿曲线的线积分（line integral）来计算力场做的功，并给出参数化计算法。

授课：Denis Auroux 日期：2007-10-25 难度：中等

学习目标

  • 理解向量场 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\) 的物理意义（速度场、力场等）。
  • 掌握线积分 \(\int_C \vec{F}\cdot d\vec{r}\) 的定义与计算方法。
  • 会用参数化把线积分化为一元积分。
  • 理解线积分的几何意义：\(\int_C \vec{F}\cdot\hat{T}\,ds\)。

向量场

平面上一个向量场（vector field）为每个点 \((x,y)\) 赋予一个向量：

\[ \vec{F}(x,y) = M(x,y)\,\hat{\imath} + N(x,y)\,\hat{\jmath} \]

物理中的例子：

  • 速度场（velocity field）：如风流（wind flow），每点的向量表示该点的速度。
  • 力场（force field）：如引力场，每点的向量表示该点受力。

常见向量场：
1. 常向量场：\(\vec{F} = 2\hat{\imath} + \hat{\jmath}\)（每点向量相同）。
2. 径向场：\(\vec{F} = x\hat{\imath} + y\hat{\jmath}\)（从原点向外辐射）。
3. 旋转场：\(\vec{F} = -y\hat{\imath} + x\hat{\jmath}\)（逆时针绕原点旋转，向量与位置向量垂直）。

线积分的定义

设力场 \(\vec{F}\) 作用在一个沿曲线 \(C\) 运动的质点上。在一小段位移 \(\Delta\vec{r}\) 上，力做的功近似为 \(\vec{F}\cdot\Delta\vec{r}\)。把曲线切成许多小段后求和取极限，得到线积分：

\[ W = \int_C \vec{F}\cdot d\vec{r} = \lim_{\Delta\vec{r}_i \to 0} \sum_i \vec{F}\cdot\Delta\vec{r}_i \]

核心思想：线积分是向量场沿曲线切向分量的累积——它衡量的是场在曲线方向上"推动"的程度。

参数化计算法

设曲线 \(C\) 由参数方程给出：\(x=x(t),\; y=y(t)\)，\(t_0 \le t \le t_1\)。则

\[ d\vec{r} = \langle dx, dy \rangle = \langle x'(t), y'(t)\rangle\,dt \]

代入线积分：

\[ \int_C \vec{F}\cdot d\vec{r} = \int_{t_0}^{t_1} \vec{F}(x(t),y(t)) \cdot \langle x'(t), y'(t)\rangle\,dt \]

最终化为一元积分。

例题 1：\(\vec{F} = \langle -y, x\rangle\) 沿抛物线 \(x=t,\; y=t^2\)

曲线从 \((0,0)\) 到 \((1,1)\)，\(0 \le t \le 1\)：

\[ \vec{F} = \langle -t^2, t\rangle,\quad \frac{d\vec{r}}{dt} = \langle 1, 2t\rangle \] \[ \int_C \vec{F}\cdot d\vec{r} = \int_0^1 \langle -t^2, t\rangle\cdot\langle 1, 2t\rangle\,dt = \int_0^1 (-t^2 + 2t^2)\,dt = \int_0^1 t^2\,dt = \frac13 \]

注意：线积分的值与参数化方式无关。例如选 \(x=\sin\theta,\; y=\sin^2\theta\)，\(0 \le \theta \le \pi/2\)，结果同样是 \(1/3\)。实际计算时选最简单的参数化即可。

新记号：\(\int M\,dx + N\,dy\)

设 \(\vec{F} = \langle M, N\rangle\)，\(d\vec{r} = \langle dx, dy\rangle\)，则

\[ \int_C \vec{F}\cdot d\vec{r} = \int_C M\,dx + N\,dy \]

这个记号看起来像两个独立积分的和，但实际上是一个沿曲线 \(C\) 的线积分。计算时必须把 \(x, y, dx, dy\) 都用同一个参数表示。

在例题 1 中：\(x=t,\; y=t^2\)，所以 \(dx = dt\)，\(dy = 2t\,dt\)：

\[ \int_C -y\,dx + x\,dy = \int_0^1 (-t^2\,dt + t\cdot 2t\,dt) = \int_0^1 t^2\,dt = \frac13 \]

几何方法

设 \(s\) 为弧长参数，\(\hat{T}\) 为单位切向量，则 \(d\vec{r} = \hat{T}\,ds\)，于是

\[ \int_C \vec{F}\cdot d\vec{r} = \int_C \vec{F}\cdot\hat{T}\,ds \]

即线积分 = 向量场在曲线切向的分量沿弧长的积分。

例题 2：径向场沿圆周

设 \(C\) 为半径 \(a\) 的圆周，\(\vec{F} = x\hat{\imath} + y\hat{\jmath}\)（径向向外）。在圆周上 \(\vec{F}\) 与 \(\hat{T}\) 垂直，所以 \(\vec{F}\cdot\hat{T} = 0\)，因此

\[ \int_C \vec{F}\cdot\hat{T}\,ds = 0 \]

例题 3：旋转场沿圆周

设 \(C\) 同上，\(\vec{F} = -y\hat{\imath} + x\hat{\jmath}\)（切向）。在圆周上 \(\vec{F}\) 与 \(\hat{T}\) 平行，\(|\vec{F}| = a\)，所以

\[ \int_C \vec{F}\cdot\hat{T}\,ds = \int_C a\,ds = a\cdot(2\pi a) = 2\pi a^2 \]

要点：几何方法在向量场与曲线有特殊位置关系（垂直或平行）时特别方便，可以避免繁琐的参数化计算。

本课要点

向量场

\(\vec{F} = M\hat{\imath} + N\hat{\jmath}\)，每点赋予一个向量。

线积分定义

\(\int_C \vec{F}\cdot d\vec{r}\) 衡量场沿曲线切向的累积效果。

参数化计算

代入 \(x(t), y(t)\)，化为一元积分。

几何方法

\(\int_C \vec{F}\cdot\hat{T}\,ds\)，在特殊位置关系时更简便。
