Green's Theorem (Green 定理)

Green 定理把平面闭合曲线上的线积分转化为其包围区域上的二重积分，建立了线积分与二重积分之间的桥梁。

授课：Denis Auroux 日期：2007-11-01 难度：较难

学习目标

  • 掌握 Green 定理的陈述与适用条件（正向闭曲线、\(\vec{F}\) 在区域内连续可微）。
  • 会用 Green 定理把复杂的线积分转化为二重积分。
  • 会用线积分计算区域面积：\(\text{Area} = \oint_C x\,dy\)。
  • 了解 Green 定理的证明思路（竖直简单区域 + 叠加）。

Green 定理的陈述

设 \(C\) 是一条正向（逆时针）闭合曲线，\(R\) 是 \(C\) 包围的区域，\(\vec{F} = M\hat{\imath} + N\hat{\jmath}\) 在 \(R\) 上连续可微，则

Green 定理：
\[ \oint_C M\,dx + N\,dy = \iint_R (N_x - M_y)\,dA \]
即环量（线积分）= 旋度在区域上的积分。

正向（positive orientation）：沿 \(C\) 行走时，区域 \(R\) 在左手边（即逆时针方向）。

记忆法：右边是 "curl" 的积分：\(\oint_C \vec{F}\cdot d\vec{r} = \iint_R \operatorname{curl}(\vec{F})\,dA\)。

例题：线积分化二重积分

设 \(C\) 是以 \((2,0)\) 为中心的单位圆（逆时针），计算

\[ \oint_C y e^{-x}\,dx + \left(\frac12 x^2 - e^{-x}\right) dy \]

这里 \(M = y e^{-x}\)，\(N = \frac12 x^2 - e^{-x}\)，所以

\[ N_x - M_y = (x + e^{-x}) - e^{-x} = x \]

由 Green 定理：

\[ \oint_C = \iint_R x\,dA = \bar{x} \cdot \text{Area}(R) = 2 \cdot \pi = 2\pi \]

直接计算线积分需要设 \(x = 2+\cos\theta,\; y = \sin\theta\)，计算非常繁琐；Green 定理一步到位！

应用：用线积分求面积

在 Green 定理中取 \(M = -y\)，\(N = x\)，则 \(N_x - M_y = 2\)，于是

\[ \oint_C x\,dy - y\,dx = \iint_R 2\,dA = 2\,\text{Area}(R) \]

所以区域 \(R\) 的面积为：

\[ \text{Area}(R) = \frac12 \oint_C (x\,dy - y\,dx) = \oint_C x\,dy = -\oint_C y\,dx \]

这给出了用边界曲线计算面积的方法！

历史注记：这个原理被用于制造求积仪（planimeter）——一种机械装置，沿曲线运动后直接读出所围区域的面积。

Green 定理的证明思路

Green 定理分为两个独立等式：

\[ \oint_C M\,dx = -\iint_R M_y\,dA,\qquad \oint_C N\,dy = \iint_R N_x\,dA \]

下面证明第一个。

第一步：竖直简单区域

设区域 \(R\) 是竖直简单的（vertically simple）：\(a \le x \le b\)，\(f_0(x) \le y \le f_1(x)\)。

把边界 \(C\) 分成四段：下边 \(C_1\)、右边 \(C_2\)、上边 \(C_3\)、左边 \(C_4\)。

\(C_2\) 和 \(C_4\) 上 \(x\) 为常数，所以 \(dx = 0\)，对 \(\oint M\,dx\) 无贡献。

在 \(C_1\) 上：\(y = f_0(x)\)，\(a \le x \le b\)，正向从左到右。

在 \(C_3\) 上：\(y = f_1(x)\)，正向从右到左，所以：

\[ \oint_C M\,dx = \int_a^b M(x,f_0(x))\,dx - \int_a^b M(x,f_1(x))\,dx \]

另一方面：

\[ -\iint_R M_y\,dA = -\int_a^b\!\int_{f_0(x)}^{f_1(x)} M_y\,dy\,dx = -\int_a^b [M(x,f_1(x)) - M(x,f_0(x))]\,dx \]

两者相等！

第二步：叠加

任何区域都可以分割成竖直简单小块，由叠加性（内部边界线积分相互抵消），Green 定理对整个区域成立。

证明要点：Green 定理的证明本质上就是把曲线边界上的贡献"累加"成区域内部的贡献——与微积分基本定理 \(\int_a^b f'(x)\,dx = f(b)-f(a)\) 一脉相承。

应用：证明梯度场判别法

Green 定理可以用来证明第 21 课的结论：

定理：若 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\) 在整个平面上连续可微，则

\[ N_x = M_y \implies \vec{F} \text{ 是保守场} \]

证明：若 \(N_x = M_y\)，则由 Green 定理，对任意闭合曲线 \(C\)：

\[ \oint_C \vec{F}\cdot d\vec{r} = \iint_R (N_x - M_y)\,dA = \iint_R 0\,dA = 0 \]

关键条件：这个证明要求 \(\vec{F}\) 在 \(C\) 包围的整个区域 \(R\) 上有定义。如果 \(R\) 包含 \(\vec{F}\) 的奇点（如原点），Green 定理不能直接应用！

本课要点

Green 定理

\(\oint_C M\,dx + N\,dy = \iint_R (N_x - M_y)\,dA\)，线积分 ⇔ 二重积分。

正向曲线

逆时针方向，区域在左手边。

面积公式

\(\text{Area} = \oint_C x\,dy\)，用边界计算面积。

应用条件

要求向量场在整个区域上有定义。
