Gravitation Application (引力应用与 Newton 定理)

继续引力专题：用对称性化简引力积分，在球坐标下建立 \(F_z\) 的累次积分，并给出 Newton 球壳定理的完整计算证明。

授课：Denis Auroux 日期：2007-11-16 难度：较难

学习目标

  • 把引力问题转化为三重积分，并用对称性化简为单分量计算。
  • 在球坐标下写出 \(F_z\) 的累次积分，正确确定积分限。
  • 完成 Newton 定理（均匀球体等价于质点）的计算证明。

核心思想：引力问题的难点在于矢量积分。关键技巧是把物体放得使 \(z\) 轴成为对称轴，这样 \(x,y\) 分量抵消，只剩 \(F_z\)，再用球坐标计算。

引力积分的建立

质量为 \(m\) 的测试质点位于原点。物体占有区域 \(R\)，密度 \(\delta\)。物体上一小块 \(\Delta M = \delta\,\Delta V\) 在原点产生的引力为

\[\Delta\vec F = Gm\,\frac{\langle x,y,z\rangle}{\rho^3}\,\delta\,\Delta V.\]

对整个物体积分：

\[\vec F = Gm\iiint_R \frac{\langle x,y,z\rangle}{\rho^3}\,\delta\,dV,\qquad F_z = Gm\iiint_R \frac{z}{\rho^3}\,\delta\,dV.\]

对称性化简

把物体放置得使 \(z\) 轴是物体的对称轴。则对每一点 \((x,y,z)\) 都有对称点 \((-x,-y,z)\)，\(x,y\) 方向的贡献抵消：

\[F_x = 0,\qquad F_y = 0,\qquad \vec F = \langle 0,0,F_z\rangle.\]

注意：对称性的使用前提是物体真的关于 \(z\) 轴对称。如果物体形状不规则，就不能这样化简。

球坐标下的 \(F_z\)

在球坐标下，\(z=\rho\cos\phi\)，\(dV=\rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)，代入得

\[F_z = Gm\iiint_R \frac{\rho\cos\phi}{\rho^3}\,\delta\,\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = Gm\iiint_R \delta\cos\phi\sin\phi\,d\rho\,d\phi\,d\theta.\]

关键简化：\(\rho\) 被完全约掉！这意味着只要知道角度范围，径向积分只是乘以径向厚度。

Newton 定理的证明

定理（Newton 球壳定理）：均匀球体对球外质点的引力，等价于全部质量集中在球心时的引力。

设置：半径为 \(a\)、密度 \(\delta\) 的球体与 \(xy\) 平面在原点相切，球心在 \((0,0,a)\)。测试质点 \(m\) 位于原点。

在过球心的竖直截面（\(zr\) 平面）中，球面的边界满足：直径 \(2a\) 所对的圆周角是直角，因此球面方程为

\[\rho = 2a\cos\phi.\]

\(\phi\) 的范围是 \(0\) 到 \(\pi/2\)（从北极到赤道），\(\theta\) 的范围是 \(0\) 到 \(2\pi\)。

积分设置：
\[F_z = Gm\int_0^{2\pi}\int_0^{\pi/2}\int_0^{2a\cos\phi} \delta\cos\phi\sin\phi\,d\rho\,d\phi\,d\theta.\]

先对 \(\rho\) 积分（被积函数与 \(\rho\) 无关）：

\[\int_0^{2a\cos\phi} d\rho = 2a\cos\phi,\]

所以

\[F_z = Gm\int_0^{2\pi}\int_0^{\pi/2} \delta\cos\phi\sin\phi\cdot 2a\cos\phi\,d\phi\,d\theta = 2\pi Gm\delta\cdot 2a\int_0^{\pi/2}\cos^2\phi\sin\phi\,d\phi.\]

计算角度积分：令 \(u=\cos\phi\)，

\[\int_0^{\pi/2}\cos^2\phi\sin\phi\,d\phi = \int_0^1 u^2\,du = \frac{1}{3}.\]

因此

\[F_z = 2\pi Gm\delta\cdot 2a\cdot\frac{1}{3} = \frac{4\pi Gm\delta a}{3}.\]

球体总质量 \(M = \dfrac{4}{3}\pi a^3\delta\)，代入得

\[F_z = \frac{GMm}{a^2}.\]

核心思想：这正是把全部质量 \(M\) 放在球心（距离原点 \(a\)）时的 Newton 万有引力公式！Newton 定理得证。

几何直觉

为什么球壳定理成立？直观理解：

  • 近处的质量虽然距离近，但对应的 \(\phi\) 角度大，\(\cos\phi\) 小，贡献被"稀释"。
  • 远处的质量虽然 \(\cos\phi\) 大，但距离远，\(1/\rho^2\) 衰减。
  • 两种效应恰好抵消，使得总效果等价于质量集中在中心。
注意：Newton 定理只适用于球对称的质量分布。如果物体是椭球或不规则形状，引力不等价于质点。

本课要点

引力积分

\(\vec F = Gm\iiint \dfrac{\langle x,y,z\rangle}{\rho^3}\delta\,dV\)，对称性化简为单分量。

球坐标化简

代入后 \(\rho\) 被约掉，只剩角度函数，径向积分只是乘以厚度。

Newton 定理

均匀球体对球外质点的引力等价于质量集中在球心，是天体力学基础。

球面方程

与原点相切、球心在 \((0,0,a)\) 的球面：\(\rho=2a\cos\phi\)。
