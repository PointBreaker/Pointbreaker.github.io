矩阵与逆矩阵 (Matrices; Inverse Matrices)

把线性变换写成矩阵乘法，用逆矩阵"反向操作"，并掌握用余子式 (cofactor) 方法计算逆矩阵。

授课：Denis Auroux 日期：2007-09-11 难度：中等

学习目标

  • 把线性变换写成矩阵形式 \(AX=U\)。
  • 理解矩阵乘法的定义：每个元 = 左边矩阵的行与右边矩阵的列的点积。
  • 理解矩阵乘法对应线性变换的复合，以及它不可交换。
  • 掌握单位矩阵与逆矩阵的定义 \(AA^{-1}=A^{-1}A=I\)。
  • 用余子式法求 \(A^{-1}=\frac{1}{\det A}\operatorname{adj}(A)\)。

线性变换与矩阵

许多物理和几何问题中，新坐标 \((u_1,u_2,u_3)\) 由旧坐标 \((x_1,x_2,x_3)\) 经线性变换 (linear transformation) 得到。课堂上的例子是：

\[\begin{cases} u_1 = 2x_1+3x_2+3x_3\\ u_2 = 2x_1+4x_2+5x_3\\ u_3 = x_1+x_2+2x_3 \end{cases}\]

把它写成矩阵乘法 (matrix product) 形式：

\[\underbrace{\begin{bmatrix}2&3&3\\2&4&5\\1&1&2\end{bmatrix}}_{A} \underbrace{\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}}_{X} = \underbrace{\begin{bmatrix}u_1\\u_2\\u_3\end{bmatrix}}_{U},\quad\text{即 } AX=U.\]

矩阵乘法的规则：乘积 \(AX\) 的第 \(i\) 个分量，是 \(A\) 的第 \(i\) 行与 \(X\) 这一列的点积。这里 \(A\) 是 \(3\times3\) 矩阵，\(X\) 是 \(3\times1\) 的列向量。

一般矩阵乘法

更一般地，乘积 \(AB\) 中，第 \(i\) 行第 \(j\) 列的元 = \(A\) 的第 \(i\) 行与 \(B\) 的第 \(j\) 列的点积。前提：\(A\) 的列数必须等于 \(B\) 的行数，乘法才有意义。

矩阵乘法的意义：复合变换

设 \(B\) 是一个线性变换，则 \(BX\) 表示把向量 \(X\) 用 \(B\) 变换。于是

\[(AB)X = A(BX)\]

表示：先做 \(B\)，再做 \(A\)。也就是说，矩阵乘法对应线性变换的复合 (composition)，但顺序是从右到左！

注意：矩阵乘法不可交换 (non-commutative)：一般 \(AB\neq BA\)。甚至当 \(A,B\) 尺寸不同时，\(AB\) 与 \(BA\) 可能一个存在、一个不存在。

单位矩阵与逆矩阵

单位矩阵 (identity matrix)：\(IX=X\)。\(3\times3\) 单位矩阵为 \[I_{3\times3} = \begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix}.\]

旋转例子：\(2\times2\) 矩阵

\[R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\]

表示把平面逆时针旋转 \(90^\circ\)：\(R\hat{\imath}=\hat{\jmath}\)，\(R\hat{\jmath}=-\hat{\imath}\)，且 \(R^2=-I\)（转两次 \(90^\circ\) 等于反向）。

逆矩阵 (inverse matrix)：对于方阵 \(A\)，若存在方阵 \(M=A^{-1}\) 使得 \[AM=MA=I_n,\] 则称 \(A\) 可逆，\(M\) 为其逆矩阵。它对应线性变换的逆操作。

应用：解线性方程组。若 \(AX=U\)，则

\[X = A^{-1}U.\]

只要我们能算出 \(A^{-1}\)，就能直接写出解。

余子式法求逆矩阵

对于小矩阵，逆矩阵有一个显式公式：

\[A^{-1} = \frac{1}{\det A}\,\operatorname{adj}(A),\]

其中 \(\operatorname{adj}(A)\) 称为 伴随矩阵 (adjoint/adjugate)。下面以课堂上的例子逐步演示。

例题

设 \(A = \begin{bmatrix}2&3&3\\2&4&5\\1&1&2\end{bmatrix}\)，求 \(A^{-1}\)。

第 1 步：余子式矩阵 (matrix of minors)

删去第 \(i\) 行第 \(j\) 列，剩下的 \(2\times2\) 行列式就是 \((i,j)\) 位置的余子式 (minor)：

\[\begin{bmatrix} \begin{vmatrix}4&5\\1&2\end{vmatrix}& \begin{vmatrix}2&5\\1&2\end{vmatrix}& \begin{vmatrix}2&4\\1&1\end{vmatrix}\\ \begin{vmatrix}3&3\\1&2\end{vmatrix}& \begin{vmatrix}2&3\\1&2\end{vmatrix}& \begin{vmatrix}2&3\\1&1\end{vmatrix}\\ \begin{vmatrix}3&3\\4&5\end{vmatrix}& \begin{vmatrix}2&3\\2&5\end{vmatrix}& \begin{vmatrix}2&3\\2&4\end{vmatrix} \end{bmatrix} = \begin{bmatrix}3&-1&-2\\3&1&-1\\3&4&2\end{bmatrix}.\]

例如左上角：删去第 1 行第 1 列，\(\begin{vmatrix}4&5\\1&2\end{vmatrix}=4\cdot2-5\cdot1=3\)。

第 2 步：代数余子式 (cofactors)

按"棋盘"符号模式 \((+,-,+;-,-,+;+,-,+)\) 交错变号：

\[\begin{bmatrix}3&+1&-2\\-3&1&+1\\3&-4&2\end{bmatrix}.\]

第 3 步：转置得到伴随矩阵

把行与列互换（"横着读、竖着写"）：

\[\operatorname{adj}(A)=M^{\mathsf{T}} = \begin{bmatrix}3&-3&3\\1&1&-4\\-2&1&2\end{bmatrix}.\]

第 4 步：除以 \(\det A\)

这里 \(\det A = 3\)，于是

\[A^{-1} = \frac{1}{3}\begin{bmatrix}3&-3&3\\1&1&-4\\-2&1&2\end{bmatrix}.\]

核心思想：逆矩阵把"作用"反向。只要 \(\det A\neq0\)，就能用余子式显式地写出 \(A^{-1}\)。大矩阵则交给计算机。

问题 3：若 \(A\) 可逆，则线性系统 \(AX=U\) 的解为？

问题 4：用余子式法求 \(A^{-1}\) 时，必须满足什么条件？

本课要点

矩阵乘法

\(AX=U\)，每个元 = 行与列的点积；要求左列数 = 右行数。

复合与不可交换

\((AB)X=A(BX)\)：先 \(B\) 后 \(A\)；一般 \(AB\neq BA\)。

逆矩阵

\(AA^{-1}=A^{-1}A=I\)；解 \(AX=U\) 等价于 \(X=A^{-1}U\)。

余子式法

minors → cofactors（棋盘变号）→ 转置得 adj → 除以 \(\det A\)。
