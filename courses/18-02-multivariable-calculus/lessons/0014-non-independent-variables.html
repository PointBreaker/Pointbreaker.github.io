Non-Independent Variables (非独立变量)

处理变量之间存在约束关系时的隐函数偏导数，引入全微分与链式法则两种系统方法，并澄清偏导数符号的歧义。

授课：Denis Auroux 日期：2007-10-11 难度：较难

学习目标

  • 会求隐式约束 \(g(x,y,z)=c\) 下的隐函数偏导数 \(\displaystyle\Bigl(\frac{\partial z}{\partial x}\Bigr)_y\)。
  • 掌握全微分与链式法则两种系统方法。
  • 理解偏导数记号 \((\partial f/\partial x)_y\) 的含义，避免符号歧义。

隐函数偏导数

设变量满足约束 \(g(x,y,z)=c\)，则可局部地把 \(z\) 看作 \(x,y\) 的函数。如何求 \(\displaystyle\Bigl(\frac{\partial z}{\partial x}\Bigr)_y\)？

方法：取全微分。由 \(g(x,y,z)=c\) 得

\[ g_x\,dx + g_y\,dy + g_z\,dz = 0 \]

固定 \(y\)（即 \(dy=0\)），得到 \(g_x\,dx + g_z\,dz = 0\)，于是

\[ \boxed{\displaystyle\Bigl(\frac{\partial z}{\partial x}\Bigr)_y = -\,\frac{g_x}{g_z}} \]

例题：\(x^2 + yz + z^3 = 8\) 在点 \((2,3,1)\) 处。
全微分：\(2x\,dx + z\,dy + (y+3z^2)\,dz = 0\)，代入得 \(4\,dx + dy + 6\,dz = 0\)。
固定 \(y\)：\(4\,dx + 6\,dz =0 \Rightarrow (\partial z/\partial x)_y = -4/6 = -2/3\)。
固定 \(x\)：\(dy + 6\,dz =0 \Rightarrow (\partial z/\partial y)_x = -1/6\)。

符号歧义警告

偏导数 \(\partial f/\partial x\) 的含义依赖于"把谁固定"。

经典陷阱：设 \(f(x,y) = x+y\)，则 \(\partial f/\partial x = 1\)。
换元 \(x=u,\; y=u+v\)，则 \(f = 2u+v\)，\(\partial f/\partial u = 2\)。
虽然 \(x=u\)，但 \(\partial f/\partial x \neq \partial f/\partial u\)！
因为 \(\partial/\partial x\) 固定 \(y\)，而 \(\partial/\partial u\) 固定 \(v\)，即固定 \(y-x\)。

有歧义时应明确写出被固定的变量：\(\displaystyle\Bigl(\frac{\partial f}{\partial x}\Bigr)_y\) 表示固定 \(y\)；\(\displaystyle\Bigl(\frac{\partial f}{\partial u}\Bigr)_v\) 表示固定 \(v\)。

三角形面积的三个解释

设三角形两边 \(a,b\) 夹角 \(\theta\)，面积 \(A = \frac{1}{2}ab\sin\theta\)。若还满足直角三角形约束 \(a = b\cos\theta\)，则关于 \(\theta\) 的变化率有三种理解：

  1. \(\displaystyle\Bigl(\frac{\partial A}{\partial\theta}\Bigr)_{a,b}\)：把 \(a,b\) 看作独立变量，固定 \(a,b\) 让 \(\theta\) 变化（三角形不再是直角三角形）。
  2. \(\displaystyle\Bigl(\frac{\partial A}{\partial\theta}\Bigr)_a\)：固定 \(a\)，让 \(\theta\) 变化，\(b\) 按约束调整。
  3. \(\displaystyle\Bigl(\frac{\partial A}{\partial\theta}\Bigr)_b\)：固定 \(b\)，让 \(\theta\) 变化，\(a\) 按约束调整。

计算方法——以 \((\partial A/\partial\theta)_a\) 为例：

方法 1（代入）：由 \(a=b\cos\theta\) 得 \(b=a\sec\theta\)，代入面积公式：

\[ A = \frac{1}{2}ab\sin\theta = \frac{1}{2}a^2\tan\theta \] \[ \Bigl(\frac{\partial A}{\partial\theta}\Bigr)_a = \frac{1}{2}a^2\sec^2\theta = \frac{ab}{\cos\theta} = ab\sec\theta \]

方法 2（全微分）：\(dA = \frac{1}{2}b\sin\theta\,da + \frac{1}{2}a\sin\theta\,db + \frac{1}{2}ab\cos\theta\,d\theta\)。固定 \(a\)（\(da=0\)），约束微分 \(da = \cos\theta\,db - b\sin\theta\,d\theta\) 给出 \(db = b\tan\theta\,d\theta\)，代入得 \(dA = \frac{1}{2}ab(\cos\theta+\sin\theta\tan\theta)\,d\theta = \frac{1}{2}ab\sec^2\theta\,d\theta\)。

方法 3（链式法则）：\(\displaystyle\Bigl(\frac{\partial A}{\partial\theta}\Bigr)_a = A_\theta + A_b\Bigl(\frac{\partial b}{\partial\theta}\Bigr)_a\)，再由约束 \(a=b\cos\theta\) 对 \(\theta\) 求导得 \((\partial b/\partial\theta)_a = b\tan\theta\)，代入即得相同结果。

核心思想：三种方法本质上是同一计算的不同写法；全微分与链式法则都是系统性的通用工具。

知识检查

问题 1：设 \(g(x,y,z)=c\) 确定隐函数 \(z=z(x,y)\)，则 \(\displaystyle\Bigl(\frac{\partial z}{\partial x}\Bigr)_y\) 等于？

问题 2：为什么 \(x=u\) 但 \(\partial f/\partial x\) 可能不等于 \(\partial f/\partial u\)？

问题 3：处理非独立变量约束下的偏导数，两种系统方法是？

本课要点

隐函数偏导

\((\partial z/\partial x)_y = -g_x/g_z\)。

符号歧义

偏导数依赖于哪些变量被固定。

显式标记

\((\partial f/\partial x)_y\) 明确固定 \(y\)。

系统方法

全微分与链式法则本质相同。
