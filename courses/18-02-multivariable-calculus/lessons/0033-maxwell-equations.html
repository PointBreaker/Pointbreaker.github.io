Topological Considerations; Maxwell's Equations (Maxwell 方程组)

把散度和旋度应用于物理学：力场的旋度对应力矩与角加速度，势场无旋不产生转动；最后用 div 和 curl 统一写出 Maxwell 方程组。

授课：Denis Auroux 日期：2007-12-06 难度：中等

学习目标

  • 理解力场旋度的物理意义：力矩、角加速度、旋转效应。
  • 解释为什么势场（梯度场）不会诱发放物体的旋转。
  • 用 div 和 curl 写出 Maxwell 方程组的微分形式与积分形式。
  • 了解 Stokes 定理和散度定理在电磁学中的应用。

核心思想：向量分析不仅是数学工具，更是物理学的语言。Maxwell 方程组用四个 div/curl 方程统一描述了电磁现象，而 Stokes 定理和散度定理把这四个方程在积分形式与微分形式之间转换。

力场的旋度——旋转效应

设一个物体处于力场 \(\vec F\) 中（更准确地说，是加速度场）。物体上一小块 \(\Delta m\) 受到力 \(\vec F\,\Delta m\)。

平动：由 Newton 第二定律

\[\frac{\text{Force}}{\text{Mass}} = \text{加速度} = \frac{d}{dt}(\text{速度}).\]

转动：力矩 (torque) 定义为 \(\vec\tau = \vec r\times\vec F\)，则

\[\frac{\text{Torque}}{\text{Moment of inertia}} = \text{角加速度} = \frac{d}{dt}(\text{角速度}).\]

因此

\[\frac{\text{Force}}{\text{Mass}} = \vec F,\qquad \frac{\text{Torque}}{\text{Moment of inertia}} = \frac{\vec r\times\vec F}{I}.\]

旋度的物理含义：
\[\nabla\times\Bigl(\frac{\text{Force}}{\text{Mass}}\Bigr) = 2\times\frac{\text{角加速度}}{\text{转动惯量}}.\]

即力场除以质量后的旋度的两倍，等于"单位转动惯量的角加速度"。

势场不产生转动

若力场是势场（保守场），即 \(\vec F=\nabla f\)，则

\[\nabla\times\vec F = \nabla\times(\nabla f) = \vec 0.\]

恒等式：\(\nabla\times(\nabla f)=\vec 0\) —— 梯度的旋度恒为零。这是向量分析的另一基本恒等式。

因此势场不会诱发放物体的旋转运动。例如，引力本身不会影响地球的自转。

注意：严格来说，地球是可变形的，潮汐摩擦等效应确实会影响自转（月球的自转与公转同步就是潮汐锁定的结果）。但在刚体近似下，势场确实不产生转动。

运动分解总结：

  • 散度提取运动的伸缩/压缩分量。
  • 旋度提取运动的旋转分量。
  • 势场（梯度场）无旋，只产生平动，不产生转动。

Maxwell 方程组

Maxwell 方程组是电磁学的基本方程，描述了电场 \(\vec E\) 和磁场 \(\vec B\) 与电荷、电流的关系。

1. Gauss-Coulomb 定律（电场的散度）

微分形式：
\[\nabla\cdot\vec E = \frac{\rho}{\varepsilon_0},\]
其中 \(\rho\) 是电荷密度，\(\varepsilon_0\) 是真空介电常数。

物理含义：电荷是电场的源。正电荷发出电场线，负电荷吸收电场线。

积分形式（用散度定理）：

\[\oiint_S \vec E\cdot\hat n\,dS = \frac{1}{\varepsilon_0}\iiint_D \rho\,dV = \frac{Q}{\varepsilon_0},\]

即通过闭曲面的电通量 = 内部总电荷 / \(\varepsilon_0\)。这是电容器、静电学的基础。

2. Faraday 定律（电场的旋度）

微分形式：
\[\nabla\times\vec E = -\frac{\partial\vec B}{\partial t}.\]

物理含义：变化的磁场产生电场的旋度。若磁场随时间变化，电场不再是保守场！

积分形式（用 Stokes 定理）：

\[\oint_C \vec E\cdot d\vec r = -\frac{d}{dt}\iint_S \vec B\cdot\hat n\,dS.\]

即沿闭曲线的电压（电动势）= 磁通量的变化率。这是电磁感应的数学表达。

核心思想：变压器的工作原理就是 Faraday 定律：初级线圈中的交流电产生交变磁场，次级线圈中的磁通量变化产生感应电压。

3. 磁场的散度

微分形式：
\[\nabla\cdot\vec B = 0.\]

物理含义：不存在磁单极子。磁场线总是闭合的，没有起点和终点。

积分形式：\(\displaystyle\oiint_S \vec B\cdot\hat n\,dS = 0\)，即通过任何闭曲面的磁通量恒为零。

4. Ampère-Maxwell 定律（磁场的旋度）

微分形式：
\[\nabla\times\vec B = \mu_0\vec J + \varepsilon_0\mu_0\frac{\partial\vec E}{\partial t},\]
其中 \(\vec J\) 是电流密度，\(\mu_0\) 是真空磁导率。

物理含义：电流和变化的电场都能产生磁场的旋度。Maxwell 加入了位移电流项 \(\varepsilon_0\mu_0\,\partial\vec E/\partial t\)，这是电磁波理论的关键。

Maxwell 方程组一览

Maxwell 方程组（微分形式）：
\[\nabla\cdot\vec E = \frac{\rho}{\varepsilon_0}\quad\text{（电荷产生电场）}\]
\[\nabla\cdot\vec B = 0\quad\text{（无磁单极子）}\]
\[\nabla\times\vec E = -\frac{\partial\vec B}{\partial t}\quad\text{（变化磁场产生电场）}\]
\[\nabla\times\vec B = \mu_0\vec J + \varepsilon_0\mu_0\frac{\partial\vec E}{\partial t}\quad\text{（电流与变化电场产生磁场）}\]

这四个方程加上 Lorentz 力公式 \(\vec F = q(\vec E + \vec v\times\vec B)\)，就完整描述了经典电磁学。

核心思想：Maxwell 方程组是向量分析的巅峰应用。散度描述"源"（电荷产生电场），旋度描述"感应"（变化场产生旋度场）。Stokes 定理和散度定理是积分形式与微分形式之间的桥梁。

本课要点

力场旋度

力场/质量的旋度 = 2 × 角加速度/转动惯量，衡量旋转效应。

势场无旋

\(\nabla\times(\nabla f)=\vec 0\)，势场不产生转动。

Maxwell 方程组

四个 div/curl 方程统一电磁学，积分与微分形式由散度定理和 Stokes 定理联系。

电磁感应

Faraday 定律 \(\nabla\times\vec E=-\partial\vec B/\partial t\)，变压器的工作原理。
