Stokes' Theorem (Stokes 定理)

三维中的"环量—旋度"恒等式：向量场沿闭曲线的环量等于其旋度通过以该曲线为边界的曲面的通量，是 Green 定理的做功形式在三维的推广。

授课：Denis Auroux 日期：2007-11-29 难度：较难

学习目标

  • 陈述 Stokes 定理并理解其与 Green 定理、散度定理的关系。
  • 掌握 Stokes 定理中曲线与曲面之间的定向相容规则。
  • 用 Stokes 定理把线积分转化为曲面积分（或反之）。
  • 理解"可以选择任意以 \(C\) 为边界的曲面 \(S\)"的灵活性。

核心思想：Stokes 定理是 Green 定理做功形式的三维推广：线积分（环量）= 旋度的曲面积分。散度定理处理通量（法向分量），Stokes 定理处理环量（切向分量）。两者合起来就是三维的 Green 定理。

Stokes 定理的陈述

Stokes 定理：设 \(C\) 是一条定向闭曲线，\(S\) 是以 \(C\) 为边界的任意定向曲面，定向相容。则
\[\oint_C \vec F\cdot d\vec r = \iint_S (\nabla\times\vec F)\cdot\hat n\,dS.\]

记忆口诀：环量（线积分）= 旋度的通量（面积分）。

定向相容规则

曲线 \(C\) 的方向与曲面 \(S\) 的法向 \(\hat n\) 必须相容，否则等式两边同时变号。

规则 1：沿 \(C\) 的正方向行走时，曲面 \(S\) 在左手边，则 \(\hat n\) 指向上方。

规则 2（右手定则）：拇指沿 \(C\) 方向（1D 物体），食指指向 \(D\)（2D 物体），中指指向 \(\hat n\)（3D 物体）。

注意：改变 \(C\) 的方向或 \(\hat n\) 的方向都会使等式两边同时变号，所以只要保持相容，Stokes 定理就成立。

Stokes 与 Green 的关系

Green 定理的做功形式：

\[\oint_C P\,dx+Q\,dy = \iint_R (Q_x-P_y)\,dA.\]

Stokes 定理在 \(xy\) 平面上的特例：设 \(S\) 是 \(xy\) 平面上的区域 \(R\)，\(\hat n=\hat k\)，则

\[\nabla\times\vec F\cdot\hat k = (R_y-Q_z)\cdot0 + (P_z-R_x)\cdot0 + (Q_x-P_y)\cdot1 = Q_x-P_y,\]

所以

\[\oint_C \vec F\cdot d\vec r = \iint_R (\nabla\times\vec F)\cdot\hat k\,dA = \iint_R (Q_x-P_y)\,dA.\]

这与 Green 定理完全相同！Stokes 定理是 Green 定理在三维空间的推广。

核心思想：Green 定理是 Stokes 定理的特例。两者都表达"边界上的环量 = 内部的旋度"。

曲面的任意性

Stokes 定理的一个惊人特点是：我们可以选择任意以 \(C\) 为边界的曲面 \(S\)！

例如，若 \(C\) 是平面上的一个圆，\(S\) 可以是：

  • 平面圆盘
  • 半球面
  • 圆锥面
  • 任何以 \(C\) 为边界的曲面

只要曲面以 \(C\) 为边界且定向相容，旋度的曲面积分结果就相同。

证明思路：设 \(S_1\) 和 \(S_2\) 都以 \(C\) 为边界。把 \(S_2\) 反向，则 \(S=S_1-S_2\) 是闭曲面。由散度定理，
\[\oiint_S (\nabla\times\vec F)\cdot\hat n\,dS = \iiint_D \nabla\cdot(\nabla\times\vec F)\,dV = 0,\]
因为 \(\nabla\cdot(\nabla\times\vec F)=0\) 恒成立。所以两个曲面的通量相等。

Stokes 定理的"证明"

Auroux 给出了一个直观证明：

  1. 平面情形：若 \(C\) 和 \(S\) 在同一平面内，就是 Green 定理。
  2. 斜平面情形：Green/Stokes 定理在任意平面中成立，因为功、旋度、通量在旋转变换下不变。可以选取适配平面的坐标系 \((u,v,w)\)，把问题化为平面情形。
  3. 一般情形：把曲面 \(S\) 切成小块，每小块近似为平面片。在每小块上近似用 Green 定理，求和时内部边界上的线积分相互抵消，只剩边界 \(C\) 上的线积分；通量积分相加得到整个曲面的通量。

核心思想：证明的关键仍然是"内部抵消"——相邻小块公共边界上的线积分方向相反，求和时消去。

例：验证 Stokes 定理

设 \(\vec F = z\hat\imath + x\hat\jmath + y\hat k\)，\(C\) 是 \(xy\) 平面上的单位圆（逆时针），\(S\) 是抛物面 \(z=1-x^2-y^2\) 在圆上方的部分。

直接计算线积分：在 \(C\) 上 \(z=0\)，\(x=\cos\theta,\;y=\sin\theta\)，\(d\vec r=\langle -\sin\theta,\cos\theta,0\rangle\,d\theta\)：

\[\oint_C \vec F\cdot d\vec r = \int_0^{2\pi} (0\cdot(-\sin\theta) + \cos\theta\cdot\cos\theta + \sin\theta\cdot 0)\,d\theta = \int_0^{2\pi}\cos^2\theta\,d\theta = \pi.\]

用 Stokes 定理：\(\nabla\times\vec F = \langle 1,1,1\rangle\)。对曲面 \(z=1-x^2-y^2\)，\(f_x=-2x,\;f_y=-2y\)，\(\vec{dS}=\langle 2x,2y,1\rangle\,dx\,dy\)：

\[\iint_S (\nabla\times\vec F)\cdot\vec{dS} = \iint_{\text{unit disk}}(2x+2y+1)\,dx\,dy.\]

\(x\) 和 \(y\) 的积分由对称性为零，所以

\[\iint_S (\nabla\times\vec F)\cdot\vec{dS} = \iint_{\text{unit disk}} 1\,dx\,dy = \text{圆盘面积} = \pi.\]

两种方法结果一致！

本课要点

Stokes 定理

\(\oint_C \vec F\cdot d\vec r = \iint_S (\nabla\times\vec F)\cdot\hat n\,dS\)，环量 = 旋度通量。

与 Green 的关系

Green 定理是 Stokes 定理在平面上的特例，两者都表达环量—旋度关系。

曲面任意性

可以选择任意以 \(C\) 为边界的曲面，结果不变（因 \(\nabla\cdot(\nabla\times\vec F)=0\)）。

定向相容

曲线方向与曲面法向必须相容，用右手定则判断。
