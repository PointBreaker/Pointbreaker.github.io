考试覆盖课堂讲过的所有内容，题型与《Practice 1A》类似、或略难。课堂上明确列出四大板块（题号以 Practice 1A 为准）：

  2. 叉积、空间三角形面积、平面方程（Problem 5）
  3. 矩阵、逆矩阵、线性系统（Problem 3）

1) 向量与点积

  • 表示：\(\vec{A}=\langle a_1,a_2,a_3\rangle\)，加法与标量乘法按分量进行。
  • 长度：\(|\vec{A}|=\sqrt{a_1^2+a_2^2+a_3^2}\)。
  • 代数定义：\(\vec{A}\cdot\vec{B}=a_1b_1+a_2b_2+a_3b_3\)。
  • 几何定理：\(\vec{A}\cdot\vec{B}=|\vec{A}||\vec{B}|\cos\theta\)，用于求夹角。
  • 符号：正（锐角）、零（垂直）、负（钝角）。
  • 应用：点积为零 \(\iff\) 垂直；\(ax+by+cz=0\) 是以 \(\langle a,b,c\rangle\) 为法向量的过原点平面。

2) 叉积、面积与平面方程

  • 投影分量：\(\vec{A}\cdot\hat{u}=|\vec{A}|\cos\theta\)。
  • 2D 行列式：\(\det(\vec{A},\vec{B})=a_1b_2-a_2b_1=\pm\) 平行四边形面积。
  • 3D 行列式：\(\det(\vec{A},\vec{B},\vec{C})=\pm\) 平行六面体体积。
  • 叉积 \(\vec{A}\times\vec{B}\)：模长 = 面积，方向由右手定则决定；\(\vec{A}\times\vec{B}=-\vec{B}\times\vec{A}\)。
  • 三重积：\(\vec{A}\cdot(\vec{B}\times\vec{C})=\det(\vec{A},\vec{B},\vec{C})=\pm\) 体积。
  • 平面方程 \(ax+by+cz=d\)：系数就是法向量；可用平面上两向量的叉积求法向量。
  • 空间三角形面积 = \(\frac12|\vec{A}\times\vec{B}|\)。

3) 矩阵、逆矩阵与线性系统

  • 矩阵乘法：元 = 行与列的点积；\((AB)X=A(BX)\) 表示先 \(B\) 后 \(A\)。
  • 不可交换：一般 \(AB\neq BA\)。
  • 逆矩阵：\(AA^{-1}=A^{-1}A=I\)，解 \(AX=U\) 等价于 \(X=A^{-1}U\)。
  • 余子式法：\(A^{-1}=\frac{1}{\det A}\operatorname{adj}(A)\)，步骤为 minors → cofactors → 转置 → 除以 \(\det A\)。
  • \(3\times3\) 系统 = 三张平面相交：\(\det A\neq0 \iff\) 唯一解 \(X=A^{-1}B\)。
  • \(\det A=0 \iff A\) 不可逆：无穷多解或无解；几何上法向量共面。
  • 齐次系统 \(AX=0\)：总有零解；\(\det A=0\) 时有非零的无穷多解。

4) 参数方程、速度与加速度

  • 直线参数方程：\(\vec{Q}(t)=\vec{Q}_0+t\vec{v}\)。
  • 点相对于平面：代入 \(ax+by+cz\) 与 \(d\) 比较。
  • 线面交点：代入参数方程，解 \(t\)。
  • 摆线：\(\langle a\theta-a\sin\theta,\;a-a\cos\theta\rangle\)，由位矢分解得到。
  • 速度 \(\vec{v}=d\vec{r}/dt\)，加速度 \(\vec{a}=d\vec{v}/dt\)，速率 \(|\vec{v}|\neq d|\vec{r}|/dt\)。
  • 单位切向量 \(\hat{T}=\vec{v}/|\vec{v}|\)，\(d\vec{r}/dt=\hat{T}|\vec{v}|\)。
  • Kepler 第二定律：面积速度恒定 \(\iff\) \(\vec{r}\times\vec{v}=\) 常数 \(\iff\) \(\vec{r}\times\vec{a}=0\) \(\iff\) 有心力。

核心思想：Unit I 的主线是"用代数（分量、矩阵）做几何（方向、面积、平面、运动）"。点积处理"夹角与垂直"，叉积处理"面积与法向"，行列式处理"体积与可逆性"，矩阵处理"线性变换与方程组"。掌握它们之间的对应，就掌握了整个单元。

本课要点

点积

夹角、垂直、投影——点积是"角度工具"。

叉积与行列式

面积、体积、法向——叉积是"面积工具"。

矩阵与逆

线性变换与方程组——矩阵是"变换工具"。

平面方程

系数 = 法向量，三平面相交对应 \(3\times3\) 系统。

参数与运动

参数方程、速度、加速度、Kepler 第二定律。
