Triple Integrals in Rectangular and Cylindrical Coordinates (柱坐标下的三重积分)

把二重积分的思想推向空间：用三重积分 \(\iiint_R f\,dV\) 求体积、质量、转动惯量，并在柱坐标 \((r,\theta,z)\) 下写出体积元 \(dV = r\,dr\,d\theta\,dz\)。

授课：Denis Auroux 日期：2007-11-02 难度：中等

学习目标

  • 把三重积分 \(\iiint_R f\,dV\) 化为累次积分 (iterated integral)，掌握确定积分限的"投影法"。
  • 熟练地在直角坐标、柱坐标之间切换，记住 Jacobian 带来的体积元。
  • 应用三重积分求空间区域的体积、质量、质心与转动惯量。

核心思想：三重积分本质上与二重积分相同——把区域切成小"盒子"，在每个盒子上取 \(f\) 乘体积微元 \(dV\)，再求和取极限。难点不在于概念，而在于确定积分上下限：先固定外层变量，再逐层确定内层范围。

直角坐标下的三重积分

设 \(R\) 是 \(\mathbb{R}^3\) 中的有界区域。把 \(R\) 切成小立方体 \(\Delta x\,\Delta y\,\Delta z\)，则体积微元为

\[dV = dx\,dy\,dz.\]

函数 \(f(x,y,z)\) 在 \(R\) 上的三重积分定义为

\[\iiint_R f(x,y,z)\,dV = \lim \sum f(x_i,y_j,z_k)\,\Delta x\,\Delta y\,\Delta z.\]

Fubini 定理保证，只要 \(f\) 连续且 \(R\) 形状良好，我们可以按任意顺序做累次积分。

如何确定积分限——投影法

以积分顺序 \(dz\,dy\,dx\) 为例，步骤是：

  1. 先对 \(z\) 积分：固定一点 \((x,y)\)，过该点作一条竖直线，找出它进入和离开 \(R\) 的 \(z\) 值，即为 \(z\) 的下、上限 \(z_{\text{bottom}}(x,y)\) 与 \(z_{\text{top}}(x,y)\)。
  2. 把 \(R\) 投影到 \(xy\) 平面：让 \((x,y)\) 取遍所有"上方有区域"的点，得到投影区域 \(U\)。
  3. 在 \(U\) 上做二重积分：把第二步的投影区域再用通常方法确定 \(x,y\) 的范围。

例 1：两抛物面之间的体积

求介于 \(z = x^2+y^2\) 与 \(z = 4-x^2-y^2\) 之间的区域 \(R\) 的体积。

两曲面的交线由 \(x^2+y^2 = 4-x^2-y^2\) 给出，即 \(x^2+y^2=2\)，位于平面 \(z=2\) 上。投影区域 \(U\) 是半径为 \(\sqrt{2}\) 的圆盘。于是

\[V = \iiint_R 1\,dV = \int_{-\sqrt{2}}^{\sqrt{2}}\int_{-\sqrt{2-x^2}}^{\sqrt{2-x^2}}\int_{x^2+y^2}^{4-x^2-y^2} dz\,dy\,dx.\]

注意：这个积分在直角坐标下虽然能写出来，但计算非常繁琐。注意到投影是圆盘，应该改用极坐标（柱坐标）来简化！

令 \(x=r\cos\theta,\;y=r\sin\theta\)，则 \(x^2+y^2=r^2\)，体积元多一个因子 \(r\)：

\[V = \int_0^{2\pi}\int_0^{\sqrt{2}}\int_{r^2}^{4-r^2} r\,dz\,dr\,d\theta.\]

这个形式可以直接算出结果（留给读者）。

柱坐标 (Cylindrical Coordinates)

柱坐标 \((r,\theta,z)\) 与直角坐标的关系为

\[x = r\cos\theta,\qquad y = r\sin\theta,\qquad z = z.\]

几何含义：\(r\) 是点到 \(z\) 轴的距离，\(\theta\) 是与 \(xz\) 平面的夹角（与极坐标相同），\(z\) 保持不变。

体积元：在柱坐标下，一个"小盒子"的底面积是 \(r\,dr\,d\theta\)，高是 \(dz\)，因此
\[dV = r\,dr\,d\theta\,dz.\]

常见曲面方程：

  • \(r=a\)：半径为 \(a\)、中心在 \(z\) 轴的圆柱面。
  • \(\theta=\theta_0\)：过 \(z\) 轴的半平面。
  • \(z=z_0\)：水平平面。

物理应用

设物体占有区域 \(R\)，密度为 \(\delta(x,y,z)\)，则

  • 质量：\(M = \iiint_R \delta\,dV\)。
  • 平均值：\(\bar f = \dfrac{1}{\text{Vol}(R)}\iiint_R f\,dV\)；加权平均 \(\bar f = \dfrac{1}{M}\iiint_R f\,\delta\,dV\)。
  • 质心：\(\bar x = \dfrac{1}{M}\iiint_R x\,\delta\,dV\)（\(\bar y,\bar z\) 类似）。常常利用对称性直接判断 \(\bar x=\bar y=0\)。
  • 转动惯量 (moment of inertia)：关于某轴的转动惯量 = \(\displaystyle I = \iiint_R (\text{到轴距离})^2\,\delta\,dV\)。

具体地：

\[I_z = \iiint_R (x^2+y^2)\,\delta\,dV = \iiint_R r^2\,\delta\,dV,\] \[I_x = \iiint_R (y^2+z^2)\,\delta\,dV,\qquad I_y = \iiint_R (x^2+z^2)\,\delta\,dV.\]

核心思想：\(I_z\) 的公式与平面情形的 \(I_0\) 完全一致——只要把 \(z=0\) 代入，就回到熟悉的 \(\iint (x^2+y^2)\,\delta\,dA\)。

例 2：圆锥的转动惯量

求介于 \(z=ar\) 与 \(z=b\) 之间、密度 \(\delta=1\) 的实心圆锥关于 \(z\) 轴的转动惯量。

固定 \(z\)，截面是圆盘 \(0\le r\le z/a\)。于是

\[I_z = \int_0^{b}\int_0^{2\pi}\int_0^{z/a} r^2\cdot r\,dr\,d\theta\,dz = \frac{\pi b^5}{10a^4}.\]

积分次序的选择：这里先对 \(r\)，再对 \(\theta\)，最后对 \(z\)，是因为"固定 \(z\) 然后切圆盘"最直观。如果区域形状不同，可能需要换序。

例 3：球面与平面围成的区域

求满足 \(z>1-y\) 且 \(x^2+y^2+z^2<1\) 的区域体积。上方是球面 \(z=\sqrt{1-x^2-y^2}\)，下方是平面 \(z=1-y\)。

投影到 \(xy\) 平面：令 \(1-y<\sqrt{1-x^2-y^2}\)，平方化简得 \(x^2<2y-2y^2\)，即

\[-\sqrt{2y-2y^2}因此

\[V = \int_0^1\int_{-\sqrt{2y-2y^2}}^{\sqrt{2y-2y^2}}\int_{1-y}^{\sqrt{1-x^2-y^2}} dz\,dx\,dy.\]

这个积分在直角坐标下相当复杂——下节课引入球坐标后，类似问题会变得简单。

本课要点

投影法

确定三重积分限：先定最内层变量范围，再把区域投影到低一维，逐层进行。

柱坐标体积元

\(dV = r\,dr\,d\theta\,dz\)，Jacobian 因子 \(r\) 不能漏。

物理应用

质量、质心、转动惯量都是三重积分，对称性可以简化计算。

坐标选择

投影是圆盘或区域有旋转对称时，优先用柱坐标。
