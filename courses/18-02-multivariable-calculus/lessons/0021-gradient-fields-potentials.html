Gradient Fields and Potential Functions (梯度场与势函数)

给出判断一个向量场是否为梯度场的检验法（\(N_x = M_y\)），并介绍两种求势函数的方法：线积分法和不定积分法。

授课：Denis Auroux 日期：2007-10-30 难度：中等

学习目标

  • 掌握梯度场的检验法：\(\vec{F} = M\hat{\imath} + N\hat{\jmath}\) 是梯度场当且仅当 \(N_x = M_y\)（在平面上）。
  • 会用两种方法求势函数 \(f\)：线积分法（方法 1）和不定积分法（方法 2）。
  • 理解旋度（curl）的定义及其物理意义。

梯度场的检验法

若 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\) 是梯度场，即存在 \(f\) 使得 \(M = f_x\)，\(N = f_y\)，则由混合偏导数相等：

\[ N_x = f_{yx} = f_{xy} = M_y \]

核心定理：若 \(\vec{F}\) 在整个平面上可微，则
\[ \vec{F} \text{ 是梯度场} \iff N_x = M_y \]
即 \(\vec{F}\) 是保守场当且仅当旋度（curl）为零。

例题 1：判断

\(\vec{F} = -y\hat{\imath} + x\hat{\jmath}\)：\(N_x = 1\)，\(M_y = -1\)，不相等，所以不是梯度场。

例题 2：参数问题

对于哪些 \(a\)，\(\vec{F} = (4x^2 + axy)\hat{\imath} + (3y^2 + 4x^2)\hat{\jmath}\) 是梯度场？

\(N_x = 8x\)，\(M_y = ax\)，所以需要 \(a = 8\)。

求势函数的两种方法

以 \(\vec{F} = (4x^2 + 8xy)\hat{\imath} + (3y^2 + 4x^2)\hat{\jmath}\)（取 \(a=8\)）为例。

方法 1：线积分法（FTC 逆用）

若 \(\vec{F} = \nabla f\)，则从 \((0,0)\) 到 \((x_1,y_1)\) 的线积分等于 \(f(x_1,y_1) - f(0,0)\)。选择最简单的路径：先沿 \(x\) 轴到 \((x_1,0)\)，再垂直到 \((x_1,y_1)\)。

沿 \(C_1\)：\(y=0\)，\(dy=0\)，\(0 \le x \le x_1\)：

\[ \int_{C_1} = \int_0^{x_1} 4x^2\,dx = \frac{4x_1^3}{3} \]

沿 \(C_2\)：\(x=x_1\)，\(dx=0\)，\(0 \le y \le y_1\)：

\[ \int_{C_2} = \int_0^{y_1} (3y^2 + 4x_1^2)\,dy = y_1^3 + 4x_1^2 y_1 \]

所以 \(f(x_1,y_1) = \frac{4x_1^3}{3} + y_1^3 + 4x_1^2 y_1 + c\)（\(c = f(0,0)\) 为任意常数）。

方法 2：不定积分法

要找 \(f\) 使得 \(f_x = 4x^2 + 8xy\)，\(f_y = 3y^2 + 4x^2\)。

第一步：对第一个方程关于 \(x\) 积分（视 \(y\) 为常数）：

\[ f = \frac{4x^3}{3} + 4x^2y + g(y) \]

其中 \(g(y)\) 是只依赖于 \(y\) 的"积分常数"。

第二步：对 \(y\) 求偏导并与第二个方程比较：

\[ f_y = 4x^2 + g'(y) = 3y^2 + 4x^2 \implies g'(y) = 3y^2 \implies g(y) = y^3 + c \]

第三步：代回得到

\[ f(x,y) = \frac{4x^3}{3} + 4x^2y + y^3 + c \]

与方法 1 的结果一致！

比较：线积分法不需要积分技巧，但需要选择合适的路径；不定积分法更系统，但需要注意匹配两个条件。

旋度（Curl）

定义二维向量场的旋度（标量 curl）：

\[ \operatorname{curl}(\vec{F}) = N_x - M_y \]

等价关系：\(\vec{F}\) 是梯度场 \(\iff\) \(\vec{F}\) 是保守场 \(\iff\) \(\operatorname{curl}(\vec{F}) = 0\)。
（要求 \(\vec{F}\) 在整个区域上有定义且可微。）

物理意义

  • 对于速度场，\(\operatorname{curl}(\vec{F})\) = 2×角速度（旋转分量）。
  • 对于力场，\(\operatorname{curl}(\vec{F})\) = 施加在测试质量上的力矩，衡量场的旋转效应。

例子：

  • \(\vec{F} = \langle a, b\rangle\)（平移）：curl = 0。
  • \(\vec{F} = \langle x, y\rangle\)（膨胀）：curl = 0。
  • \(\vec{F} = \langle -y, x\rangle\)（旋转）：curl = 2。

注意：\(N_x = M_y \iff\) 梯度场，只在向量场在整个区域上有定义且区域"单连通"时才严格成立——下节课会详细讨论。

知识检查

问题 1：设 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\)，它在平面上是梯度场的条件是？

问题 2：对于哪些 \(a\)，\(\vec{F} = (4x^2 + axy)\hat{\imath} + (3y^2 + 4x^2)\hat{\jmath}\) 是梯度场？

问题 3：用不定积分法求势函数时，对 \(f_x = M\) 积分得到 \(f = \int M\,dx + g(y)\)，其中 \(g(y)\) 是？

问题 4：\(\vec{F} = \langle -y, x\rangle\) 的旋度 \(\operatorname{curl}(\vec{F})\) 等于？

本课要点

检验法

\(\vec{F}\) 是梯度场 ⇔ \(N_x = M_y\)（curl = 0）。

线积分法

通过沿简单路径的线积分求 \(f\)，\(f(0,0)\) 为任意常数。

不定积分法

对 \(f_x\) 积分后，用 \(f_y\) 匹配确定 \(g(y)\)。

旋度

\(\operatorname{curl}(\vec{F}) = N_x - M_y\)，衡量场的旋转效应。
