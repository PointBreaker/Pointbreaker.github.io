Differentials; Chain Rule (微分与链式法则)

引入全微分（total differential）作为线性近似的代数工具，并由此导出多元链式法则（chain rule）。

授课：Denis Auroux 日期：2007-10-04 难度：中等

学习目标

  • 理解全微分 \(df = f_x\,dx + f_y\,dy + f_z\,dz\) 的含义与用法。
  • 会用微分除以 \(dt\) 得到链式法则。
  • 会处理中间变量、多变量链式法则与坐标变换。

全微分（Total Differential）

回顾一元情形：\(y=f(x)\) 时，\(dy = f'(x)\,dx\)。对多元函数 \(f(x,y,z)\)，定义全微分

\[ df = f_x\,dx + f_y\,dy + f_z\,dz \]

核心思想：\(df\) 是一个新的对象，它编码了 \(f\) 的变化量与自变量变化量之间的关系。注意 \(df\) 与 \(\Delta f\) 是不同的！

两种用法：

  1. 近似公式：\(\Delta f \approx f_x\,\Delta x + f_y\,\Delta y + f_z\,\Delta z\)。
  2. 除以 \(dt\) 得链式法则：若 \(x=x(t), y=y(t), z=z(t)\)，则
\[ \frac{df}{dt} = f_x\frac{dx}{dt} + f_y\frac{dy}{dt} + f_z\frac{dz}{dt} \]

例题：设 \(w = x^2y + z\)，则 \(dw = 2xy\,dx + x^2\,dy + dz\)。
若 \(x=t, y=e^t, z=\sin t\)，则
\(\displaystyle \frac{dw}{dt} = 2t e^t \cdot 1 + t^2 \cdot e^t + \cos t\)。

注意：教材中常把 \(df\) 与 \(\Delta f\) 混用，这是不准确的。\(df\) 是线性主部，\(\Delta f\) 是真实增量。

链式法则（Chain Rule）

情形 1（单参数）：\(f(x,y)\)，\(x=x(t)\)，\(y=y(t)\)，则

\[ \frac{df}{dt} = f_x \frac{dx}{dt} + f_y \frac{dy}{dt} \]

情形 2（多中间变量）：\(w = f(x,y)\)，\(x=x(u,v)\)，\(y=y(u,v)\)，则

\[ dw = f_x\,dx + f_y\,dy = f_x(x_u\,du + x_v\,dv) + f_y(y_u\,du + y_v\,dv) \]

比较 \(du, dv\) 系数得

\[ \frac{\partial f}{\partial u} = f_x\,x_u + f_y\,y_u, \qquad \frac{\partial f}{\partial v} = f_x\,x_v + f_y\,y_v \]

警告：不能把 \(\partial f/\partial u = f_x\,x_u + f_y\,y_u\) 中的 \(\partial x\) "约掉"！偏导数不是商，不能这样简化。

应用：积、商与坐标变换

积的微分法则：设 \(f=uv\)，\(u=u(t)\)，\(v=v(t)\)，则

\[ \frac{d(uv)}{dt} = v\frac{du}{dt} + u\frac{dv}{dt} \]

商的微分法则：设 \(g = u/v\)，则

\[ \frac{d(u/v)}{dt} = \frac{1}{v}\frac{du}{dt} - \frac{u}{v^2}\frac{dv}{dt} = \frac{u'v - uv'}{v^2} \]

极坐标变换：\(x = r\cos\theta\)，\(y = r\sin\theta\)，则

\[ f_r = f_x \cos\theta + f_y \sin\theta, \qquad f_\theta = -f_x\,r\sin\theta + f_y\,r\cos\theta \]

核心思想：链式法则的本质是"沿路径累积变化率"——每个中间变量对自变量的变化率乘以函数对该中间变量的变化率，再求和。

知识检查

问题 1：设 \(f(x,y,z)\) 可微，则全微分 \(df\) 等于？

问题 2：设 \(w=f(x,y,z)\)，\(x=x(t), y=y(t), z=z(t)\)，则 \(dw/dt\) 等于？

问题 3：极坐标 \(x=r\cos\theta, y=r\sin\theta\) 下，\(f_r\) 等于？

本课要点

全微分

\(df = f_x dx + f_y dy + f_z dz\)，是线性近似的代数形式。

链式法则

沿每条路径累积变化率，再求和。

注意：偏导数不能像分数一样"约分"。

应用

积、商法则，极坐标变换等。
