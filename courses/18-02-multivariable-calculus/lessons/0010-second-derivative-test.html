Second Derivative Test; Boundaries (二阶导数检验)

用二阶偏导数判别临界点的类型，并讨论在闭区域上求绝对极值时如何处理边界。

授课：Denis Auroux 日期：2007-10-02 难度：中等

学习目标

  • 会用二阶导数检验（second derivative test）判断临界点是极大、极小还是鞍点。
  • 理解绝对极值可能出现在临界点或边界上。
  • 会处理定义域边界与无穷远处的极值讨论。

先看二次型情形

考虑 \(w = ax^2 + bxy + cy^2\) 在原点 \((0,0)\) 附近的行为。

若 \(a \neq 0\)，配方：

\[ w = a\Bigl(x+\frac{b}{2a}y\Bigr)^2 + \Bigl(c-\frac{b^2}{4a}\Bigr)y^2 \]

记 \(4ac-b^2 = 4aA\)，其中 \(A = ac - b^2/4\)。三种情况：

  • \(4ac-b^2 > 0\)：两项同号——\(a>0\) 时极小，\(a<0\) 时极大。
  • \(4ac-b^2 < 0\)：两项异号——鞍点。
  • \(4ac-b^2 = 0\)：退化情形，无法仅凭二阶项判断。

从二次方程判别式角度看：把 \(w\) 写成关于 \(x/y\) 的二次式，判别式 \(b^2-4ac\) 的符号决定是否有实根、是否有定号。

二阶导数检验

记二阶偏导数 \(f_{xx}, f_{xy}, f_{yy}\)，并注意 \(f_{xy} = f_{yx}\)。在临界点 \((x_0,y_0)\) 处令

\[ A = f_{xx}(x_0,y_0),\quad B = f_{xy}(x_0,y_0),\quad C = f_{yy}(x_0,y_0) \]

二阶导数检验：计算判别式 \(D = AC - B^2\)。
• 若 \(D>0\) 且 \(A>0\)（或 \(C>0\)）：局部极小。
• 若 \(D>0\) 且 \(A<0\)（或 \(C<0\)）：局部极大。
• 若 \(D<0\)：鞍点。
• 若 \(D=0\)：无法得出结论。

验证与二次型一致：对于 \(w=ax^2+bxy+cy^2\)，有 \(A=2a, B=b, C=2c\)，于是 \(D = 4ac-b^2\)，与上一节一致。

原理（二次近似）：在临界点处，\(\Delta f \approx \frac{1}\.2 A(x-x_0)^2 + B(x-x_0)(y-y_0) + \frac{1}\.2 C(y-y_0)^2\)。其正负定号决定极值类型。

绝对极值与边界

重要提醒：绝对极值（global min/max）不一定在临界点上！它可能出现在定义域的边界或无穷远处。

注意：求闭有界区域上的绝对极值时，必须同时检查：
（1）区域内部的临界点；
（2）边界上的极值（边界可能需要参数化）；
（3）无穷远（如果区域无界）。

例题：\(f(x,y) = x + y + \dfrac{1}{xy}\)，定义域 \(x>0, y>0\)。
解 \(f_x = 1 - \dfrac{1}{x^2y}=0\)，\(f_y = 1 - \dfrac{1}{xy^2}=0\)，得唯一临界点 \((1,1)\)。
\(f_{xx}=\dfrac{2}{x^3y}\)，\(f_{xy}=\dfrac{1}{x^2y^2}\)，\(f_{yy}=\dfrac{2}{xy^3}\)。在 \((1,1)\) 处 \(A=2, B=1, C=2\)，\(D=3>0, A>0\)，故为局部极小。
最大值？当 \(x\to 0^+\) 或 \(y\to 0^+\) 或 \(x,y\to\infty\) 时 \(f\to\infty\)，所以该区域上没有最大值。

知识检查

问题 1：若在临界点处判别式 \(D = f_{xx}f_{yy} - (f_{xy})^2 > 0\) 且 \(f_{xx} < 0\)，则该点是？

问题 2：若 \(D = f_{xx}f_{yy} - (f_{xy})^2 < 0\)，则临界点为？

问题 3：求闭区域上的绝对极值时，必须检查哪些位置？

本课要点

判别式

\(D=f_{xx}f_{yy}-(f_{xy})^2\) 的符号决定临界点类型。

\(D>0\)

由 \(f_{xx}\) 的符号判断极大（负）或极小（正）。

\(D<0\)

鞍点。

边界检查

绝对极值可能出现在边界或无穷远处。
