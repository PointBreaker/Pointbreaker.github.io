MIT 18.02 · 第 36 课

Final Exam (期末考试)

期末考试备考指南：整门课程的知识框架、核心公式、三大定理与应试策略。

授课：Denis Auroux 日期：2007-12-18 难度：中等

考试概览

MIT 18.02 期末考试覆盖全课程 36 讲的内容，分为三大单元：

  • Unit I：向量与矩阵（Lecture 1–7）
  • Unit II：偏导数与重积分（Lecture 8–18）
  • Unit III：向量分析（Lecture 19–36）

核心思想：期末考试的本质是检验你对三大定理的理解与应用：微积分基本定理（线积分与梯度）、散度定理（通量与散度）、Stokes 定理（环量与旋度）。掌握这三个定理，就掌握了整门课的骨架。

核心公式速查

坐标系与体积/面积元

极坐标：\(x=r\cos\theta,\;y=r\sin\theta,\;dA=r\,dr\,d\theta\)
柱坐标：\(x=r\cos\theta,\;y=r\sin\theta,\;z=z,\;dV=r\,dr\,d\theta\,dz\)
球坐标：\(x=\rho\sin\phi\cos\theta,\;y=\rho\sin\phi\sin\theta,\;z=\rho\cos\phi,\;dV=\rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)

Del 算子

梯度：\(\nabla f = \langle f_x,f_y,f_z\rangle\)
散度：\(\nabla\cdot\vec F = P_x+Q_y+R_z\)
旋度：\(\nabla\times\vec F = \langle R_y-Q_z,P_z-R_x,Q_x-P_y\rangle\)
Laplace：\(\nabla^2 f = f_{xx}+f_{yy}+f_{zz}\)

面积元公式

曲面 \(z=f(x,y)\)：\(\vec{dS}=\pm\langle -f_x,-f_y,1\rangle\,dx\,dy\)
球面 \(\rho=a\)：\(\hat n=\dfrac{1}{a}\langle x,y,z\rangle,\;dS=a^2\sin\phi\,d\phi\,d\theta\)
圆柱面 \(r=a\)：\(\hat n=\dfrac{1}{a}\langle x,y,0\rangle,\;dS=a\,dz\,d\theta\)

Jacobian

变量替换：\(dA = \left|\dfrac{\partial(x,y)}{\partial(u,v)}\right|du\,dv\)。

三大定理

1. 微积分基本定理（线积分版）：
\[f(P_1)-f(P_0) = \int_C \nabla f\cdot d\vec r.\]

2. 散度定理（Gauss-Green）：
\[\oiint_S \vec F\cdot\vec{dS} = \iiint_D \nabla\cdot\vec F\,dV.\]

3. Stokes 定理：
\[\oint_C \vec F\cdot d\vec r = \iint_S (\nabla\times\vec F)\cdot\hat n\,dS.\]

核心思想：三大定理的统一图景——边界上的积分 = 内部微分的积分。微积分基本定理（1D 边界 ↔ 1D 内部）、Stokes 定理（1D 边界 ↔ 2D 内部）、散度定理（2D 边界 ↔ 3D 内部）。

重要恒等式

基本恒等式：
\[\nabla\times(\nabla f)=\vec 0\quad\text{（梯度的旋度为零）}\]
\[\nabla\cdot(\nabla\times\vec F)=0\quad\text{（旋度的散度为零）}\]

这两个恒等式是 Stokes 定理和散度定理成立的基础，也是梯度场和旋度场之间关系的体现。

应试策略

时间分配

期末考试通常 3 小时，6–8 道大题。建议：

  • 先快速浏览全卷，识别熟悉的题型。
  • 先做有把握的题，建立信心。
  • 每道题控制在 20–30 分钟内。

常见题型

  1. 坐标变换与 Jacobian：给出变换，计算 Jacobian，设置累次积分。
  2. 梯度与方向导数：求梯度、方向导数、切平面方程。
  3. Lagrange 乘子：约束极值问题。
  4. 重积分计算：直角/柱/球坐标，选择合适坐标系。
  5. 线积分：直接计算或用 Stokes/微积分基本定理。
  6. 通量计算：直接计算或用散度定理。
  7. 验证定理：用两种方法计算同一积分，验证散度定理或 Stokes 定理。
  8. 场论问题：判断保守场、求势函数、计算散度/旋度。

常见错误

注意：以下是历年学生最常犯的错误：

  • 忘记柱坐标/球坐标的 Jacobian 因子（\(r\) 或 \(\rho^2\sin\phi\)）。
  • 混淆 Stokes 定理与散度定理的适用场景。
  • 线积分参数化时，忘记把 \(dx,dy,dz\) 都用 \(dt\) 表示。
  • 通量计算时，\(\vec{dS}\) 的方向选错（闭曲面应取外法向）。
  • Stokes 定理的定向不相容。
  • 梯度场判别时忘记检查区域是否单连通。

考前复习计划

  • 熟记公式：体积元、面积元、三大定理、del 算子公式。
  • 做往年题：prac1a.pdf 至 prac4bsol.pdf 是最好的练习材料。
  • 画图：每道题先画区域草图，帮助选择坐标系和确定积分限。
  • 检查量纲：结果的单位是否符合预期（体积？面积？力？）。
  • 交叉验证：用不同方法（直接计算 vs 定理）验证结果。
