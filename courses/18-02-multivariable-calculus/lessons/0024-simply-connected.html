Simply Connected Regions; Review (单连通区域)

讨论 Green 定理适用的拓扑条件——单连通区域（simply connected regions），并通过一个经典反例说明为什么需要这一条件；最后对 Unit IIIa 进行复习。

授课：Denis Auroux 日期：2007-11-06 难度：中等

学习目标

  • 理解单连通区域（simply connected region）的定义。
  • 了解为什么 Green 定理要求区域单连通。
  • 用经典反例 \(\vec{F} = \frac{-y\,\hat{\imath} + x\,\hat{\jmath}}{x^2+y^2}\) 理解"洞"的影响。
  • 掌握 Unit IIIa 的核心知识结构（二重积分 + 线积分）。

两类 Green 定理回顾

设 \(C\) 是正向（逆时针）闭合曲线，\(R\) 是其包围的区域，向量场在 \(R\) 上连续可微：

两类 Green 定理：
切向形式（功）： \(\oint_C \vec{F}\cdot d\vec{r} = \iint_R \operatorname{curl}(\vec{F})\,dA\)
法向形式（通量）： \(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA\)
其中 \(\operatorname{curl}(M\hat{\imath} + N\hat{\jmath}) = N_x - M_y\)，\(\nabla\cdot(P\hat{\imath} + Q\hat{\jmath}) = P_x + Q_y\)。

关键条件：Green 定理要求向量场 \(\vec{F}\) 在 \(C\) 包围的整个区域 \(R\) 上有定义且连续可微。如果 \(R\) 包含 \(\vec{F}\) 的奇点（如原点），Green 定理不能直接应用！

经典反例

考虑向量场

\[ \vec{F} = \frac{-y\,\hat{\imath} + x\,\hat{\jmath}}{x^2+y^2} \]

它在除原点外的平面上处处有定义。计算其旋度：

\[ \operatorname{curl}(\vec{F}) = \frac{\partial}{\partial x}\left(\frac{x}{x^2+y^2}\right) - \frac{\partial}{\partial y}\left(\frac{-y}{x^2+y^2}\right) = 0 \quad (\text{在 } x^2+y^2 > 0 \text{ 处}) \]

但沿单位圆周 \(C\)（逆时针）的线积分：

\[ \oint_C \vec{F}\cdot d\vec{r} = 2\pi \neq 0 \]

这看似与 Green 定理矛盾——实际上是因为区域 \(R\)（单位圆盘）包含了原点，而 \(\vec{F}\) 在原点没有定义，所以 Green 定理不适用。

单连通区域的定义

平面区域 \(R\) 称为单连通（simply connected）的，如果：对于 \(R\) 内的任意闭合曲线 \(C\)，\(C\) 所包围的整个区域也都包含在 \(R\) 内。

直观理解：没有洞的区域。

例子：
单连通：整个平面、圆盘、矩形、半平面。
非单连通：平面去掉原点（穿孔平面）、环形区域、圆环。

为什么重要：若 \(\vec{F}\) 在单连通区域 \(R\) 上有定义且可微，则对 \(R\) 内任意闭合曲线 \(C\)，\(\vec{F}\) 自动在 \(C\) 包围的区域内有定义，Green 定理一定适用。

环形区域上的 Green 定理

对于非单连通区域，Green 定理可以"绕开奇点"来使用。例如，对上述向量场，考虑环形区域 \(R'\)：单位圆盘内部挖去一个以原点为心的小圆盘。

边界 \(C'\) = 单位圆（逆时针）+ 小圆（顺时针），由叠加法：

\[ \oint_{C'} \vec{F}\cdot d\vec{r} = \iint_{R'} 0\,dA = 0 \]

所以

\[ \oint_C \vec{F}\cdot d\vec{r} = \oint_{C_2} \vec{F}\cdot d\vec{r} \]

即绕任何包含原点的闭合曲线的线积分都相等——这就是绕数（winding number）的雏形。

Unit IIIa 复习（Exam 3 范围）

两大主题

  1. 二重积分（Double Integrals）
  2. 线积分（Line Integrals）

二重积分

  • 设置积分：画出区域，用切片法确定积分限。
  • 极坐标：\(dA = r\,dr\,d\theta\)，用于圆形/扇形区域。
  • 变量替换：三步法——Jacobian → 被积函数 → 积分限。
  • 应用：面积、质量、质心、转动惯量。

线积分

  • 计算：\(\int_C \vec{F}\cdot d\vec{r} = \int_C M\,dx + N\,dy\)，用参数化代入。
  • 梯度场：\(\vec{F}\) 保守 ⇔ 路径无关 ⇔ \(\vec{F} = \nabla f\) ⇔ \(\operatorname{curl} = 0\)。
  • 求势函数：线积分法或不定积分法。
  • 通量：\(\int_C \vec{F}\cdot\hat{n}\,ds = \int_C -Q\,dx + P\,dy\)。

Green 定理

  • 切向形式：\(\oint_C \vec{F}\cdot d\vec{r} = \iint_R \operatorname{curl}(\vec{F})\,dA\)
  • 法向形式：\(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA\)
  • 适用条件：\(\vec{F}\) 在 \(R\) 上有定义且连续可微；区域单连通（无洞）。

考试提示：需要掌握基本积分、换元法；不需要复杂的三角积分（如 \(\cos^4\theta\)）或分部积分。变量替换的题目会被设计得相对简单。

本课要点

单连通区域

没有洞的区域，任何闭合曲线的内部都在区域内。

Green 定理条件

要求向量场在整个区域上有定义，否则可能失效。

经典反例

\(\frac{-y\hat{\imath} + x\hat{\jmath}}{x^2+y^2}\) 旋度为零但线积分非零。

Unit IIIa 框架

二重积分 + 线积分 + Green 定理，两大主题。
