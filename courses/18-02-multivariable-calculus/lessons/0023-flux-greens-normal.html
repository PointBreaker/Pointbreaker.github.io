Flux; Normal Form of Green's Theorem (通量与 Green 定理法向形式)

引入向量场沿曲线的通量（flux）概念，并给出 Green 定理的法向形式：闭合曲线的通量等于散度（divergence）在区域上的积分。

授课：Denis Auroux 日期：2007-11-02 难度：较难

学习目标

  • 理解通量（flux）的物理意义：单位时间内通过曲线的流量。
  • 掌握通量的计算公式：\(\int_C \vec{F}\cdot\hat{n}\,ds = \int_C -Q\,dx + P\,dy\)。
  • 掌握 Green 定理的法向形式：\(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA\)。
  • 理解散度（divergence）的物理意义：源的强度。

两类线积分

在第 19 课我们学习了功（work）的线积分：沿曲线的切向分量积分：

\[ \int_C \vec{F}\cdot d\vec{r} = \int_C \vec{F}\cdot\hat{T}\,ds \]

现在引入第二类线积分——通量（flux）：沿曲线的法向分量积分：

核心思想：通量衡量的是向量场"穿过"曲线的程度：
\[ \text{Flux} = \int_C \vec{F}\cdot\hat{n}\,ds \]
其中 \(\hat{n}\) 是曲线 \(C\) 的单位法向量（从 \(\hat{T}\) 顺时针旋转 90°）。

物理意义：若 \(\vec{F}\) 是流体的速度场，通量 = 单位时间内通过曲线 \(C\) 的流体总量（右侧为正，左侧为负）。

通量的计算公式

设 \(d\vec{r} = \hat{T}\,ds = \langle dx, dy\rangle\)。把 \(\hat{T}\) 顺时针旋转 90° 得到 \(\hat{n}\)：

\[ \hat{n}\,ds = \langle dy, -dx\rangle \]

所以，若 \(\vec{F} = P\hat{\imath} + Q\hat{\jmath}\)（这里用新字母以示区别），则

\[ \vec{F}\cdot\hat{n}\,ds = \langle P, Q\rangle\cdot\langle dy, -dx\rangle = -Q\,dx + P\,dy \]

通量公式：
\[ \int_C \vec{F}\cdot\hat{n}\,ds = \int_C -Q\,dx + P\,dy \]
若 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\)，则为 \(\int_C -N\,dx + M\,dy\)。

计算方法与功的线积分相同：把 \(x, y, dx, dy\) 用参数表示后积分。

例题 1：径向场沿圆周的通量

设 \(C\) 为半径 \(a\) 的圆周（逆时针），\(\vec{F} = x\hat{\imath} + y\hat{\jmath}\)。在圆周上 \(\vec{F}\) 与 \(\hat{n}\) 平行，\(|\vec{F}| = a\)，所以

\[ \int_C \vec{F}\cdot\hat{n}\,ds = \int_C a\,ds = a \cdot (2\pi a) = 2\pi a^2 \]

而旋转场 \(\vec{F} = -y\hat{\imath} + x\hat{\jmath}\) 沿同一圆周的通量为零（场与曲线相切）。

Green 定理的法向形式

与切向形式（功）类似，Green 定理也有法向形式（通量）：

Green 定理（法向形式）：设 \(C\) 是正向（逆时针）闭合曲线，\(R\) 是其包围的区域，\(\vec{F} = P\hat{\imath} + Q\hat{\jmath}\) 在 \(R\) 上连续可微，则
\[ \oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA \]
其中散度（divergence）定义为 \(\nabla\cdot\vec{F} = P_x + Q_y\)。

证明：把 \(\int_C -Q\,dx + P\,dy\) 看作通常的线积分，令 \(M = -Q\)，\(N = P\)，应用切向 Green 定理：

\[ \oint_C -Q\,dx + P\,dy = \iint_R (P_x - (-Q_y))\,dA = \iint_R (P_x + Q_y)\,dA = \iint_R \nabla\cdot\vec{F}\,dA \]

例题 2：用散度定理验证通量

对 \(\vec{F} = x\hat{\imath} + y\hat{\jmath}\) 沿半径 \(a\) 的圆周，\(\nabla\cdot\vec{F} = 1 + 1 = 2\)，所以

\[ \oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R 2\,dA = 2\cdot\pi a^2 = 2\pi a^2 \]

与直接计算结果一致！而且即使把圆心移到其他地方，总通量仍是 \(2\pi a^2\)（因为散度是常数）。

散度的物理意义

散度 \(\nabla\cdot\vec{F}\) 衡量的是场的源/汇强度：

  • \(\nabla\cdot\vec{F} > 0\)：该点是源（source），有流体流出。
  • \(\nabla\cdot\vec{F} < 0\)：该点是汇（sink），有流体流入。
  • \(\nabla\cdot\vec{F} = 0\)：无源无汇（不可压缩流体的速度场）。

Green 定理的法向形式告诉我们：穿过闭合曲线的总通量 = 内部所有源的强度之和。

记忆法：两类 Green 定理对照——
切向形式（功）：\(\oint_C \vec{F}\cdot d\vec{r} = \iint_R \operatorname{curl}(\vec{F})\,dA\)
法向形式（通量）：\(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA\)

知识检查

问题 1：向量场 \(\vec{F}\) 沿曲线 \(C\) 的通量 \(\int_C \vec{F}\cdot\hat{n}\,ds\) 衡量的是什么？

问题 2：设 \(\vec{F} = P\hat{\imath} + Q\hat{\jmath}\)，则通量 \(\int_C \vec{F}\cdot\hat{n}\,dy\) 用 \(dx, dy\) 表示为？

问题 3：Green 定理的法向形式 \(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \) 的右边是？

问题 4：若 \(\nabla\cdot\vec{F} > 0\) 在某点，这表示该点是什么？

本课要点

通量

\(\int_C \vec{F}\cdot\hat{n}\,ds\) 衡量场穿过曲线的程度。

计算公式

\(\int_C -Q\,dx + P\,dy\)，用法向分量。

Green 定理（法向）

\(\oint_C \vec{F}\cdot\hat{n}\,ds = \iint_R \nabla\cdot\vec{F}\,dA\)。

散度

\(\nabla\cdot\vec{F} = P_x + Q_y\)，衡量源/汇强度。
