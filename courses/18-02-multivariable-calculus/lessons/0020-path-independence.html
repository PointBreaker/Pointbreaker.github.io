Path Independence and Conservative Fields (路径无关与保守场)

对于梯度场（gradient field），线积分满足微积分基本定理，从而具有路径无关性和守恒性——这是保守力场能量守恒的数学基础。

授课：Denis Auroux 日期：2007-10-26 难度：中等

学习目标

  • 掌握线积分的微积分基本定理（FTC for line integrals）：\(\int_C \nabla f\cdot d\vec{r} = f(P_1) - f(P_0)\)。
  • 理解梯度场的路径无关性（path independence）和守恒性（conservativeness）。
  • 了解四个等价性质及其物理意义（势能、能量守恒）。

线积分的微积分基本定理

若向量场 \(\vec{F}\) 是一个梯度场（gradient field），即存在势函数 \(f\) 使得

\[ \vec{F} = \nabla f = \langle f_x, f_y\rangle \]

则线积分可以像一元微积分基本定理一样直接计算：

核心定理：设曲线 \(C\) 从 \(P_0\) 到 \(P_1\)，则
\[ \int_C \nabla f\cdot d\vec{r} = f(P_1) - f(P_0) \]
等价地，\(\int_C f_x\,dx + f_y\,dy = \int_C df = f(P_1) - f(P_0)\)。

证明：设 \(C\) 由 \(x(t), y(t)\) 参数化，\(t_0 \le t \le t_1\)，则

\[ \int_C \nabla f\cdot d\vec{r} = \int_{t_0}^{t_1} \left(f_x \frac{dx}{dt} + f_y \frac{dy}{dt}\right) dt = \int_{t_0}^{t_1} \frac{d}{dt}f(x(t),y(t))\,dt = f(P_1) - f(P_0) \]

例题：\(\vec{F} = \langle y, x\rangle = \nabla(xy)\)

沿第 19 课的三段曲线 \(C = C_1 + C_2 + C_3\)（从 \((0,0)\) 沿 \(x\) 轴到 \((1,0)\)，再沿圆弧到 \((\frac1{\sqrt2},\frac1{\sqrt2})\)，再沿直线回到原点），用 FTC：

\[ \int_C \vec{F}\cdot d\vec{r} = f(\text{终点}) - f(\text{起点}) = f(0,0) - f(0,0) = 0 \]

与第 19 课逐段计算的结果 \(0 + \frac12 - \frac12 = 0\) 一致，但计算量大大减少！

梯度场的两个重要性质

1. 路径无关性（Path Independence）

若 \(\vec{F} = \nabla f\)，则线积分只与起点和终点有关，与路径无关：

\[ \int_{C_1} \vec{F}\cdot d\vec{r} = \int_{C_2} \vec{F}\cdot d\vec{r} \quad \text{（若 } C_1, C_2 \text{ 有相同端点）} \]

2. 守恒性（Conservativeness）

沿任意闭合回路 \(C\) 的线积分为零：

\[ \oint_C \vec{F}\cdot d\vec{r} = 0 \]

重要警告：这些性质只对梯度场成立！例如 \(\vec{F} = \langle -y, x\rangle\) 不是梯度场，沿圆周的线积分为 \(2\pi a^2 \neq 0\)，不满足守恒性。

物理意义：势能与能量守恒

若力场 \(\vec{F}\) 是某个势函数 \(f\) 的梯度（物理学家通常用负号 \(\vec{F} = -\nabla V\)），则：

  • 力做的功 = 势能的减少：\(W = -\Delta V\)。
  • 沿闭合回路做功为零：不能从保守场中持续提取能量。
  • 能量守恒：动能的变化 = 力做的功 = 势能的变化。

例子：引力场、静电场都是保守场。

四个等价性质

对于向量场 \(\vec{F} = M\hat{\imath} + N\hat{\jmath}\)，以下四个命题等价：

  1. \(\vec{F}\) 是保守场：\(\oint_C \vec{F}\cdot d\vec{r} = 0\) 对任意闭合曲线 \(C\)。
  2. \(\vec{F}\) 的线积分路径无关。
  3. \(\vec{F}\) 是梯度场：\(\vec{F} = \nabla f\)。
  4. \(M\,dx + N\,dy\) 是恰当微分（exact differential）：存在 \(f\) 使得 \(df = M\,dx + N\,dy\)。

用途：若已知路径无关性，可通过计算线积分 \(\int_{(0,0)}^{(x,y)} \vec{F}\cdot d\vec{r}\) 来求势函数 \(f(x,y)\)。

本课要点

FTC for line integrals

\(\int_C \nabla f\cdot d\vec{r} = f(P_1) - f(P_0)\)，直接计算线积分。

路径无关

梯度场的线积分只与端点有关，与路径无关。

守恒性

梯度场沿闭合回路的线积分为零。

物理意义

保守力场 ⇔ 势能存在 ⇔ 能量守恒。
