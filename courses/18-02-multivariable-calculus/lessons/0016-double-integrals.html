Double Integrals (二重积分)

把一元定积分的"曲线下面积"推广到二元函数，用二重积分（double integral）计算曲面下的体积，并通过化为累次积分（iterated integrals）来实际求值。

授课：Denis Auroux 日期：2007-10-18 难度：入门

学习目标

  • 理解二重积分 \(\iint_R f(x,y)\,dA\) 的几何意义：曲面 \(z=f(x,y)\) 在平面区域 \(R\) 上方的有符号体积。
  • 会把二重积分化为累次积分（iterated integral），即两次一元积分。
  • 会根据区域 \(R\) 的形状正确设置积分上下限。
  • 会交换积分次序以简化计算。

二重积分的定义

回顾一元微积分中，定积分

\[ \int_a^b f(x)\,dx \]

表示曲线 \(y=f(x)\) 在区间 \([a,b]\) 下方的有符号面积。现在把它推广到二元函数：

核心思想：把区域 \(R\) 切成许多小面积元 \(\Delta A_i\)，在每个小片上取函数值 \(f(x_i,y_i)\)，乘上小面积后求和取极限：
\[ \iint_R f(x,y)\,dA = \lim_{\Delta A_i \to 0} \sum_i f(x_i,y_i)\,\Delta A_i \]
若 \(f \ge 0\)，这个积分就等于曲面 \(z=f(x,y)\) 在 \(R\) 上方的体积（volume）。

化为累次积分

如何实际计算二重积分？基本思路是切片法（slicing）：用平行于 \(yz\) 平面的平面去截立体，得到截面积 \(S(x)\)，然后

\[ \text{体积} = \int_{x_{\min}}^{x_{\max}} S(x)\,dx \]

对于固定的 \(x\)，截面面积 \(S(x)\) 本身又是一个一元积分：

\[ S(x) = \int_{y_{\text{bot}}(x)}^{y_{\text{top}}(x)} f(x,y)\,dy \]

内层积分中 \(x\) 视为常数，\(y\) 是积分变量。合起来得到累次积分：

\[ \iint_R f(x,y)\,dA = \int_{x_{\min}}^{x_{\max}} \left( \int_{y_{\text{bot}}(x)}^{y_{\text{top}}(x)} f(x,y)\,dy \right) dx \]

Fubini 定理：若 \(f\) 在矩形区域 \(R: a \le x \le b,\; c \le y \le d\) 上连续，则
\[ \iint_R f\,dA = \int_a^b\!\int_c^d f(x,y)\,dy\,dx = \int_c^d\!\int_a^b f(x,y)\,dx\,dy \]
两种积分次序结果相同，都是该矩形区域的二重积分。

例题 1：矩形区域上的二重积分

设 \(f(x,y) = 1 - x^2 - y^2\)，区域 \(R: 0 \le x \le 1,\; 0 \le y \le 1\)。

化为累次积分（先对 \(y\) 后对 \(x\)）：

\[ \int_0^1 \int_0^1 (1 - x^2 - y^2)\,dy\,dx \]

第一步：内层积分（视 \(x\) 为常数）：

\[ \int_0^1 (1 - x^2 - y^2)\,dy = \left[ (1-x^2)y - \frac{y^3}{3} \right]_0^1 = (1-x^2) - \frac13 = \frac23 - x^2 \]

第二步：外层积分：

\[ \int_0^1 \left(\frac23 - x^2\right) dx = \left[ \frac23 x - \frac{x^3}{3} \right]_0^1 = \frac23 - \frac13 = \frac13 \]

要点：内层积分时把外层的变量 \(x\) 当成常数，就像求偏导数时固定一个变量一样。最终结果是一个数——即立体体积。

例题 2：四分之一圆盘区域

同样的函数 \(f(x,y) = 1-x^2-y^2\)，但区域变为第一象限的四分之一圆盘 \(R: x^2+y^2 \le 1,\; x \ge 0,\; y \ge 0\)。

关键是确定积分限：固定 \(x\)，看 \(y\) 的取值范围是从 \(y=0\) 到 \(y=\sqrt{1-x^2}\)；然后 \(x\) 从 \(0\) 到 \(1\)：

\[ \int_0^1 \int_0^{\sqrt{1-x^2}} (1-x^2-y^2)\,dy\,dx \]

注意：内层积分限可以依赖于外层变量 \(x\)（这里是 \(\sqrt{1-x^2}\)），但外层积分限必须是常数（这里是 0 和 1）。

内层积分：

\[ \left[ (1-x^2)y - \frac{y^3}{3} \right]_0^{\sqrt{1-x^2}} = \frac23(1-x^2)^{3/2} \]

外层积分：\(\int_0^1 \frac23(1-x^2)^{3/2}\,dx\)，需用三角代换 \(x=\sin\theta\) 计算（本课只演示了部分过程，最终结果为 \(\pi/8\)）。

交换积分次序

对于矩形区域，交换积分次序是平凡的：\(\int_0^1\!\int_0^2 dx\,dy = \int_0^2\!\int_0^1 dy\,dx\)。

对于一般区域，交换次序需要重新确定积分限。经典例子：

例题 3：\(\int_0^1\!\int_x^{\sqrt{x}} e^{y^2}\,dy\,dx\)

内层积分 \(\int e^{y^2}\,dy\) 没有初等函数表达式，无法直接计算。必须交换次序。

步骤 1：画出积分区域 \(x \le y \le \sqrt{x}\)，\(0 \le x \le 1\)。由 \(y=x\) 与 \(y=\sqrt{x}\) 得 \(x=y^2\) 和 \(x=y\)。

步骤 2：固定 \(y\)，看 \(x\) 的范围：左边是 \(x=y^2\)，右边是 \(x=y\)；\(y\) 从 0 到 1。于是：

\[ \int_0^1 \int_{y^2}^{y} e^{y^2}\,dx\,dy = \int_0^1 (y - y^2) e^{y^2}\,dy \]

内层对 \(x\) 积分后得到 \(y-y^2\)，外层积分可用凑微分法：

\[ \int_0^1 (y-y^2)e^{y^2}\,dy = \left[ -y e^{y^2} + 2e^{y^2} \right]_0^1 = e - 2 \]

核心技巧：交换积分次序三步法——(1) 画出区域草图；(2) 用另一种方向的切片重新描述区域；(3) 写出新的积分限。

本课要点

几何意义

\(\iint_R f\,dA\) 表示曲面 \(z=f(x,y)\) 在区域 \(R\) 上方的有符号体积。

累次积分

通过切片法把二重积分化为两次一元积分，内层积分视外层变量为常数。

设置积分限

画区域草图，固定外层变量，找出内层变量的起止范围；外层限必须是常数。

交换次序

当内层积分无法计算时，重新画图、用另一方向切片来确定新的积分限。
