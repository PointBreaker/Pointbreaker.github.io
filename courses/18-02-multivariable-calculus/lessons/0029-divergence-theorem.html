Divergence Theorem (散度定理)

三维中的"通量—源"恒等式：向量场通过闭曲面的通量等于其散度在内部区域上的三重积分，由此引出 diffusion（热）方程。

授课：Denis Auroux 日期：2007-11-20 难度：较难

学习目标

  • 陈述散度定理 (divergence theorem / Gauss-Green 定理) 并会应用它把通量积分转化为三重积分。
  • 理解 del 算子 \(\nabla\) 及其与散度 \(\nabla\cdot\vec F\) 的关系。
  • 掌握散度的物理意义：单位体积的源强度。
  • 从散度定理推导出扩散方程 \(\partial u/\partial t = k\nabla^2 u\)。

核心思想：散度定理是 Green 定理法向形式的三维推广：闭曲面上的通量 = 内部散度的体积分。它把"边界上的量"与"内部的量"联系起来，是向量分析的三大定理之一。

散度定理的陈述

散度定理（Gauss-Green 定理）：设 \(S\) 是空间中的闭曲面，围成区域 \(D\)，外法向为 \(\hat n\)。若 \(\vec F\) 在 \(D\) 上连续可微，则
\[\oiint_S \vec F\cdot\vec{dS} = \iiint_D \operatorname{div}\vec F\,dV,\qquad \operatorname{div}(P\hat\imath+Q\hat\jmath+R\hat k) = P_x+Q_y+R_z.\]

记忆口诀：通量（面积分）= 散度（体积分）。

Del 算子 \(\nabla\)

引入符号算子

\[\nabla = \Bigl\langle\frac{\partial}{\partial x},\,\frac{\partial}{\partial y},\,\frac{\partial}{\partial z}\Bigr\rangle.\]

则

\[\nabla f = \langle f_x,f_y,f_z\rangle = \text{梯度},\] \[\nabla\cdot\vec F = \langle \partial_x,\partial_y,\partial_z\rangle\cdot\langle P,Q,R\rangle = P_x+Q_y+R_z = \text{散度}.\]

注意：\(\nabla\) 只是一个符号记法，不是真正的向量。\(\nabla\cdot\vec F\) 是"形式上的点乘"，\(\nabla f\) 是"形式上的数乘"。

散度的物理意义

散度 = 源强度 = 单位体积产生的通量。

想象不可压缩流体的流速场 \(\vec F\)。取一小块区域 \(D\) 被闭曲面 \(S\) 包围，则：

\[\oiint_S \vec F\cdot\hat n\,dS = \text{单位时间内从 }D\text{ 流出的净流体量}.\]

根据散度定理，这也等于 \(\displaystyle\iiint_D \operatorname{div}\vec F\,dV\)。因此

\[\operatorname{div}\vec F = \lim_{|D|\to 0}\frac{1}{|D|}\oiint_S \vec F\cdot\hat n\,dS.\]

物理含义：

  • \(\operatorname{div}\vec F > 0\)：该点是源（流体从这里冒出来）。
  • \(\operatorname{div}\vec F < 0\)：该点是汇（流体被吸走）。
  • \(\operatorname{div}\vec F = 0\)：该点无源无汇（不可压缩流体的典型特征）。

散度定理的证明思路

只需证明 \(\displaystyle\oiint_S R\hat k\cdot\vec{dS} = \iiint_D R_z\,dV\)，对 \(P\hat\imath\) 和 \(Q\hat\jmath\) 同理。

竖直简单区域 (vertically simple)：顶部和底部都是曲面 \(z=z_2(x,y)\) 和 \(z=z_1(x,y)\)，侧面竖直。

右边：

\[\iiint_D R_z\,dV = \iint_U \bigl(R(x,y,z_2)-R(x,y,z_1)\bigr)\,dx\,dy.\]

左边：

  • 顶部：\(\vec{dS}=\langle -z_{2x},-z_{2y},1\rangle\,dx\,dy\)，贡献 \(\displaystyle\iint R(x,y,z_2)\,dx\,dy\)。
  • 底部：\(\vec{dS}=\langle z_{1x},z_{1y},-1\rangle\,dx\,dy\)，贡献 \(\displaystyle-\iint R(x,y,z_1)\,dx\,dy\)。
  • 侧面：法向量水平，\(\vec F\) 竖直，通量为零。

两边相等！对一般区域，可分解为竖直简单块的并，内部边界上的通量相互抵消，只剩外表面的通量。

核心思想：证明的关键是"内部抵消"——两个相邻块在公共面上法向相反，通量符号相反，求和时消去。

例：验证散度定理

对 \(\vec F = z\hat k\) 穿过半径 \(a\) 的球面（第 27 课例 2），直接计算得通量 \(\Phi = \dfrac{4}{3}\pi a^3\)。

用散度定理：\(\operatorname{div}\vec F = 0+0+1 = 1\)，所以

\[\iiint_D 1\,dV = \text{球的体积} = \frac{4}{3}\pi a^3.\]

两种方法结果一致！

扩散方程的推导

扩散方程 (diffusion equation / heat equation) 描述烟雾在静止空气中的传播、染料在溶液中的扩散、热的传导等：

\[\frac{\partial u}{\partial t} = k\nabla^2 u = k\Bigl(\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+\frac{\partial^2 u}{\partial z^2}\Bigr),\]

其中 \(u(x,y,z,t)\) 是浓度（或温度），\(k\) 是扩散系数。

推导基于两个输入：

  1. 物理定律（Fick / Fourier）：流动方向从高浓度到低浓度，流速正比于浓度梯度：
    \[\vec F = -k\nabla u.\]
  2. 质量守恒：流出 \(D\) 的通量 = 内部总量的减少率：
    \[\oiint_S \vec F\cdot\hat n\,dS = -\frac{d}{dt}\iiint_D u\,dV.\]

对左边用散度定理：\(\oiint_S \vec F\cdot\hat n\,dS = \iiint_D \nabla\cdot\vec F\,dV\)。

对右边交换导数与积分：\(\dfrac{d}{dt}\iiint_D u\,dV = \iiint_D \dfrac{\partial u}{\partial t}\,dV\)。

因此对任意区域 \(D\)：

\[\iiint_D \nabla\cdot\vec F\,dV = -\iiint_D \frac{\partial u}{\partial t}\,dV.\]

令 \(D\) 收缩到一点，得到逐点等式

\[-\frac{\partial u}{\partial t} = \nabla\cdot\vec F.\]

代入 \(\vec F = -k\nabla u\)：

\[\frac{\partial u}{\partial t} = -\nabla\cdot(-k\nabla u) = k\nabla\cdot(\nabla u) = k\nabla^2 u.\]

扩散方程：
\[\boxed{\frac{\partial u}{\partial t} = k\nabla^2 u}\]

核心思想：散度定理把"边界上的通量"与"内部的散度"联系起来，是推导守恒律偏微分方程的通用工具。除了扩散方程，流体力学、电磁学的基本方程都由此推出。

散度定理
