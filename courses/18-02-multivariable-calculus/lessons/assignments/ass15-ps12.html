Problem Set 12: Divergence & Curl (散度与旋度)

三大定理的收官：散度定理 (Divergence Theorem)、散度 \(\nabla\cdot\vec{F}\) 与旋度 \(\nabla\times\vec{F}\) 的计算与物理意义、空间中的梯度场与线积分，以及扩散方程的推导。这是 Unit IIIb 通向 Maxwell 方程的最后一块拼图。

发布：2007-11-16 截止：2007-11-29 范围：Lectures 29, 30 难度：较难

目标

完成本次习题后，你应该能够：计算向量场 \(\vec{F}=\langle P,Q,R\rangle\) 的散度 \(\nabla\cdot\vec{F}=P_x+Q_y+R_z\) 与旋度 \(\nabla\times\vec{F}\)；用散度定理把闭曲面通量积分化为三重积分；在空间中判断梯度场（准则 \(P_y=Q_x,\ P_z=R_x,\ Q_z=R_y\)）并求势函数；理解散度与旋度的物理意义（源密度与旋转强度）。

核心思想：散度定理 \(\displaystyle\iint_S \vec{F}\cdot\hat{n}\,dS = \iiint_D \nabla\cdot\vec{F}\,dV\) 是 Green 通量形式在三维的推广。Auroux 在第 29 讲用"烟雾扩散"的类比解释：散度 = 源密度（单位体积产生的流量），散度定理说"流出闭曲面的净流量 = 内部总源强"。

核心知识要点

1. del 算子

符号算子 \(\nabla=\bigl\langle\frac{\partial}{\partial x},\frac{\partial}{\partial y},\frac{\partial}{\partial z}\bigr\rangle\)。三种用法：

  • 梯度：\(\nabla f = \langle f_x,f_y,f_z\rangle\)
  • 散度：\(\nabla\cdot\vec{F} = P_x+Q_y+R_z\)（点乘）
  • 旋度：\(\nabla\times\vec{F} = \det\begin{pmatrix}\hat{\imath}&\hat{\jmath}&\hat{k}\\\partial_x&\partial_y&\partial_z\\P&Q&R\end{pmatrix}\)（叉乘）

2. 散度 (divergence)

\(\displaystyle \nabla\cdot\vec{F} = \frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\)。

物理意义：对不可压缩流体的速度场 \(\vec{F}\)，\(\nabla\cdot\vec{F}\) 等于源密度——单位时间、单位体积内产生的流体体积。正散度 = 源（冒出），负散度 = 汇（吸入），零散度 = 无源。

3. 散度定理 (Divergence Theorem)

设 \(S\) 是闭曲面，围成空间区域 \(D\)，外法向 \(\hat{n}\)。向量场 \(\vec{F}\) 在 \(D\) 上连续可微，则：

\[ \iint_S \vec{F}\cdot\hat{n}\,dS = \iiint_D \nabla\cdot\vec{F}\,dV. \]

证明思路（Auroux）：对竖直简单区域先证 \(\displaystyle\iint_S R\hat{k}\cdot\hat{n}\,dS=\iiint_D R_z\,dV\)（顶面 + 底面 + 侧面 = 0），再分解为一般区域。

例子：\(\vec{F}=z\hat{k}\) 沿半径 \(a\) 的球面通量。\(\nabla\cdot\vec{F}=1\)，故通量 = \(\iiint_D 1\,dV = \frac43\pi a^3\)。

核心思想：散度定理说"流出闭曲面的净流量 = 内部总源强"。Auroux 的烟雾类比：烟雾浓度 \(u\)，流速 \(\vec{F}=-k\nabla u\)（从浓到稀），则浓度变化率 \(\partial u/\partial t = -\nabla\cdot\vec{F} = k\nabla^2 u\)——这就是扩散方程。

4. 三维旋度 (curl)

\(\displaystyle \nabla\times\vec{F} = \bigl\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\bigr\rangle\)。

记忆法：\(\nabla\times\vec{F}=\det\begin{pmatrix}\hat{\imath}&\hat{\jmath}&\hat{k}\\\partial_x&\partial_y&\partial_z\\P&Q&R\end{pmatrix}\)。

物理意义：对速度场 \(\vec{v}\)，\(\nabla\times\vec{v} = 2\omega\)，其中 \(\omega\) 是流体微团的角速度向量。例子：绕 \(z\) 轴以角速度 \(\omega\) 旋转的速度场 \(\vec{v}=\langle -\omega y,\omega x,0\rangle\)，则 \(\nabla\times\vec{v}=\langle 0,0,2\omega\rangle\)。

5. 空间中的线积分与梯度场

空间线积分 \(\displaystyle\int_C \vec{F}\cdot d\vec{r}=\int_C P\,dx+Q\,dy+R\,dz\)，计算方法同二维：参数化后代入。

空间梯度场判定：\(\vec{F}=\langle P,Q,R\rangle\) 是梯度场 ⇔（在单连通区域上）

\[ \frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x},\quad \frac{\partial P}{\partial z}=\frac{\partial R}{\partial x},\quad \frac{\partial Q}{\partial z}=\frac{\partial R}{\partial y}. \]

等价地：\(\nabla\times\vec{F}=\vec{0}\)。

求势函数的反导数法：对 \(f_x=P\) 关于 \(x\) 积分 → 对 \(y\) 求偏与 \(Q\) 比较 → 对 \(z\) 求偏与 \(R\) 比较。

例子：\(\vec{F}=\langle 2xy,\ x^2+z^3,\ 3yz^2-4z^3\rangle\) 是梯度场，势函数 \(f=x^2y+yz^3-z^4+C\)。

6. 扩散方程

Auroux 在第 29–30 讲推导扩散方程（也是热方程）。设 \(u(x,y,z,t)\) 是烟雾浓度，\(\vec{F}\) 是烟雾流速：

  1. 物理：\(\vec{F}=-k\nabla u\)（流速正比于浓度负梯度——从浓到稀）
  2. 质量守恒 + 散度定理：\(\displaystyle\frac{\partial u}{\partial t}=-\nabla\cdot\vec{F}\)

合并得：

\[ \frac{\partial u}{\partial t} = -\nabla\cdot(-k\nabla u) = k\nabla^2 u = k\left(\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+\frac{\partial^2 u}{\partial z^2}\right). \]

典型题型与解题策略

1

散度与旋度的计算

代表：PS12 中直接计算 \(\nabla\cdot\vec{F}\) 或 \(\nabla\times\vec{F}\) 的题目。

策略：散度 = 三个偏导之和；旋度 = 用行列式展开。注意旋度的每个分量是两个偏导之差。

2

散度定理应用

代表：PS12 中闭曲面通量题；复杂曲面用散度定理简化。

策略：闭曲面通量 → 考虑散度定理 → 算 \(\nabla\cdot\vec{F}\) → 化为三重积分。当 \(\nabla\cdot\vec{F}\) 简单（如常数、零）时特别有效。

3

空间梯度场判定与求势

代表：含参向量场题（哪些参数使 \(\vec{F}\) 为梯度场）；求空间势函数。

策略：令三个偏导等式成立，解参数。求势用反导数法逐分量积分、逐分量比较。

4

空间线积分

代表：给定参数化的空间曲线；分段路径。

策略：参数化 → 代入 \(\vec{F}\) 与 \(d\vec{r}\) → 单变量积分。若场是梯度场，用 FTC 简化。

常见错误

旋度分量符号出错：\(\nabla\times\vec{F}=\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\rangle\)。中间分量 \(P_z-R_x\) 是减，不是加。用行列式记忆可避免。

散度定理用于非闭曲面：散度定理只对闭曲面成立。若曲面不封闭，需要补面后再用定理，减去补面的通量。

空间梯度场判据漏条件：需要三个等式 \(P_y=Q_x,\ P_z=R_x,\ Q_z=R_y\) 都成立。只验证一个或两个是不够的。

混淆散度与旋度的物理意义：散度衡量源/汇（流出 vs 流入）；旋度衡量旋转。不可压缩流体 \(\nabla\cdot\vec{v}=0\)；无旋流动 \(\nabla\times\vec{v}=\vec{0}\)。两者独立。
