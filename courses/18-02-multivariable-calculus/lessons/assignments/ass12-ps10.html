Problem Set 10: Line Integrals (线积分)

进入向量微积分的核心：向量场沿曲线的积分、功与通量的计算、梯度场与路径无关性，以及判定保守场的准则 \(P_y=Q_x\)。这是第三单元 Unit IIIa 的综合习题，Exam 3 的直接前奏。

发布：2007-10-25 截止：2007-11-01 范围：Lectures 19, 20, 21 难度：中等 → 较难

目标

完成本次习题后，你应该能够：对参数化的曲线 \(C\) 计算向量场 \(\vec{F}=\langle M,N\rangle\) 的线积分 \(\int_C \vec{F}\cdot d\vec{r} = \int_C M\,dx+N\,dy\)；用几何方法 \(\int_C \vec{F}\cdot\hat{T}\,ds\) 处理特殊情形；识别梯度场并用 FTC for line integrals \(\int_C \nabla f\cdot d\vec{r}=f(P_1)-f(P_0)\) 简化计算；用准则 \(P_y=Q_x\) 判断保守性，并用两种方法求势函数。

核心思想：线积分 \(\int_C \vec{F}\cdot d\vec{r}\) 的物理意义是力 \(\vec{F}\) 沿路径 \(C\) 做的功。Auroux 在第 19 讲强调：无论用参数化 \(\vec{r}(t)\)、微分形式 \(M\,dx+N\,dy\)、还是几何形式 \(\vec{F}\cdot\hat{T}\,ds\)，结果都是同一个数——选择最简便的那条路。

核心知识要点

1. 线积分的定义

设 \(C\) 是以 \(\vec{r}(t)=\langle x(t),y(t)\rangle\)（\(t_0\le t\le t_1\)）参数化的曲线，\(\vec{F}=\langle M(x,y),N(x,y)\rangle\) 是向量场。线积分：

\[ \int_C \vec{F}\cdot d\vec{r} = \int_{t_0}^{t_1} \vec{F}(\vec{r}(t))\cdot\vec{r}'(t)\,dt = \int_C M\,dx + N\,dy. \]

关键：把 \(x,y,dx,dy\) 全部用参数 \(t\) 表示。Auroux 的例子：\(\vec{F}=\langle -y,x\rangle\)，\(C: x=t,\ y=t^2,\ 0\le t\le1\)：

\[ \int_C -y\,dx + x\,dy = \int_0^1 (-t^2\cdot 1 + t\cdot 2t)\,dt = \int_0^1 t^2\,dt = \frac13. \]

注意：\(M\,dx+N\,dy\) 不是对 \(x\) 和对 \(y\) 的两个独立积分，而是沿曲线 \(C\) 的线积分。必须先参数化，再代入计算。

2. 几何方法

因为 \(d\vec{r} = \hat{T}\,ds\)（\(\hat{T}\) 是单位切向量，\(ds\) 是弧长微元），所以：

\[ \int_C \vec{F}\cdot d\vec{r} = \int_C (\vec{F}\cdot\hat{T})\,ds. \]

当 \(\vec{F}\) 与 \(\hat{T}\) 的夹角简单时，这比参数化更直观。例如 \(\vec{F}=\langle -y,x\rangle\) 沿逆时针单位圆：\(\vec{F}\) 与 \(\hat{T}\) 平行且同向，\(|\vec{F}|=1\)，所以 \(\int_C \vec{F}\cdot\hat{T}\,ds = \int_C 1\cdot ds = 2\pi\)。

3. 线积分的微基本定理 (FTC for line integrals)

若 \(\vec{F}=\nabla f = \langle f_x,f_y\rangle\)（即 \(\vec{F}\) 是梯度场，\(f\) 是势函数），则：

\[ \int_C \nabla f\cdot d\vec{r} = f(P_1) - f(P_0), \]

其中 \(P_0,P_1\) 是 \(C\) 的起止点。与路径无关！

证明：\(\displaystyle \int_C \nabla f\cdot d\vec{r} = \int_{t_0}^{t_1} \frac{d}{dt}f(x(t),y(t))\,dt = f(P_1)-f(P_0)\)。

4. 路径无关性、保守场与等价命题

对梯度场，以下四个命题等价：

  1. \(\vec{F}\) 是保守场：\(\displaystyle\oint_C \vec{F}\cdot d\vec{r}=0\) 对任意闭路 \(C\)
  2. 线积分路径无关：同一端点的任何两条路径积分相等
  3. \(\vec{F}\) 是梯度场：\(\vec{F}=\nabla f\)
  4. \(M\,dx+N\,dy\) 是恰当微分：存在 \(f\) 使 \(df=M\,dx+N\,dy\)

重要反例：\(\vec{F}=\langle -y,x\rangle\) 不是梯度场——沿单位圆逆时针的积分是 \(2\pi\neq0\)。物理上，这个场对应旋转运动，做功与路径有关。

5. 保守场的判定准则

若 \(\vec{F}=\langle M,N\rangle\) 在整个平面（或单连通区域）上连续可微，则：

\[ \vec{F}\text{ 是保守场} \quad\Longleftrightarrow\quad \frac{\partial N}{\partial x} = \frac{\partial M}{\partial y}. \]

定义二维旋度 (curl)：

\[ \operatorname{curl}\vec{F} = N_x - M_y. \]

保守场 ⇔ curl = 0。

例子：\(\vec{F}=\langle 4x^2+8xy,\ 3y^2+4x2\rangle\)，则 \(N_x=8x=M_y\)，是保守场。

核心思想：\(\operatorname{curl}\vec{F}\) 衡量场的旋转程度。均匀平移场 \(\vec{F}=\langle a,b\rangle\)、径向膨胀场 \(\vec{F}=\langle x,y\rangle\) 的 curl 都为零；而旋转场 \(\vec{F}=\langle -y,x\rangle\) 的 curl = 2（对应单位角速度）。

6. 求势函数的两种方法

已知 \(\vec{F}=\langle M,N\rangle\) 是保守场，求 \(f\) 使 \(\nabla f=\vec{F}\)：

方法一（反向 FTC）：选一条从 \((0,0)\) 到 \((x_1,y_1)\) 的简单路径（如先沿 \(x\) 轴再垂直向上）：

\[ f(x_1,y_1) = f(0,0) + \int_0^{x_1} M(x,0)\,dx + \int_0^{y_1} N(x_1,y)\,dy. \]

方法二（反导数法）：

  1. 对 \(f_x=M\) 关于 \(x\) 积分：\(f = \int M\,dx + g(y)\)
  2. 对 \(y\) 求偏导得 \(f_y = \partial/\partial y(\int M\,dx) + g'(y)\)，与 \(N\) 比较
  3. 解出 \(g'(y)\) 并积分

典型题型与解题策略

1

直接计算线积分

代表：PS10 中给定参数化曲线的题目；分段路径（如扇形的三条边）。

策略：参数化 → 代入 \(\vec{F}\) 和 \(d\vec{r}\) → 化为单变量积分。对分段路径逐段计算再求和。几何法（\(\vec{F}\cdot\hat{T}\)）在特殊情形下更快捷。

2

识别梯度场并用 FTC

代表：PS10 中形如 \(\int_C \nabla f\cdot d\vec{r}\) 或可识别为梯度场的题目。

策略：验证 \(N_x=M_y\) → 确认是保守场 → 找势函数 \(f\) → 用 \(f(P_1)-f(P_0)\) 得结果，省去参数化。

3

判断保守性并求势函数

代表：含参数的向量场题（如"对哪些 \(a,b\) 是保守场"）；求势函数。

策略：令 \(N_x=M_y\) 解出参数。求 \(f\) 时用方法一（简单路径）或方法二（反导数），互为验证。

4

比较不同路径的积分

代表：同一向量场沿不同路径从 \(P_0\) 到 \(P_1\) 的积分比较。

策略：若场是保守场，所有路径积分相等，选最简单的路径（如折线）计算。若不是保守场，必须按指定路径参数化计算。

常见错误

把 \(M\,dx+N\,dy\) 当两个独立积分：线积分是沿曲线的积分，必须通过参数化把 \(x,y,dx,dy\) 都写成同一个变量的函数。直接"对 \(x\) 积 \(M\)、对 \(y\) 积 \(N\)"会得到错误结果。

忽略方向：线积分与路径方向有关：\(\displaystyle\int_{-C} \vec{F}\cdot d\vec{r} = -\int_C \vec{F}\cdot d\vec{r}\)。闭路的方向（逆时针 vs 顺时针）影响正负号。

盲目用 FTC：FTC for line integrals 只对梯度场成立。\(\vec{F}=\langle -y,x\rangle\) 沿单位圆积分是 \(2\pi\) 而非 0——必须先验证 \(N_x=M_y\) 才能用 FTC。

势函数遗漏积分常数：方法一中 \(f(0,0)\) 是任意常数；方法二中 \(g(y)\) 的常数项。势函数不唯一，但任意两个势函数只差一个常数。
