核心知识要点

1. 三重积分

柱面坐标：\(dV=r\,dr\,d\theta\,dz\)，适用于绕 \(z\) 轴对称的区域。

球面坐标：\(dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\)，适用于球形/锥形区域。

建立步骤：画区域 → 找投影 → 定上下曲面 → 选合适坐标系 → 写累次积分。

2. 曲面积分与通量

通量 \(\displaystyle\iint_S \vec{F}\cdot\hat{n}\,dS\)。关键公式（Auroux 在第 27 讲列出）：

  • 平面 \(z=a\)（平行 \(xy\) 平面）：\(\hat{n}=\pm\hat{k}\)，\(dS=dx\,dy\)
  • 球面 \(\rho=a\)：\(\hat{n}=\dfrac{1}{a}\langle x,y,z\rangle\)，\(dS=a^2\sin\varphi\,d\varphi\,d\theta\)
  • 圆柱面 \(r=a\)：\(\hat{n}=\dfrac{1}{a}\langle x,y,0\rangle\)，\(dS=a\,dz\,d\theta\)
  • 曲面 \(z=f(x,y)\)：\(\hat{n}\,dS=\langle -f_x,-f_y,1\rangle\,dx\,dy\)
  • 隐式曲面 \(g(x,y,z)=0\)：\(\hat{n}\,dS=\pm\dfrac{\nabla g}{\nabla g\cdot\hat{k}}\,dx\,dy\)

注意：对曲面 \(z=f(x,y)\)，\(\hat{n}\,dS=\langle -f_x,-f_y,1\rangle\,dx\,dy\) 不是把 \(\hat{n}\) 和 \(dS\) 分开——\(\hat{n}\) 不是 \(\langle -f_x,-f_y,1\rangle\)（未归一化），\(dS\) 也不是 \(dx\,dy\)。只有乘积 \(\hat{n}\,dS\) 整体等于这个表达式。

3. 散度定理

\[ \iint_S \vec{F}\cdot\hat{n}\,dS = \iiint_D \nabla\cdot\vec{F}\,dV. \]

适用于闭曲面 \(S\) 围成的区域 \(D\)。物理意义：流出闭曲面的净通量 = 内部总源强。

4. Stokes 定理

\[ \oint_C \vec{F}\cdot d\vec{r} = \iint_S (\nabla\times\vec{F})\cdot\hat{n}\,dS. \]

适用于闭路 \(C\) 所张的任意曲面 \(S\)（只要定向相容）。Auroux 强调：可以选最方便的曲面——例如圆周 \(C\) 可张成平面圆盘、半球面、锥面，选最简单的。

定向规则：沿 \(C\) 正方向行走，曲面在左手边 → \(\hat{n}\) 朝上（右手法则）。

5. 三大定理的统一

三个定理都是"边界上的积分 = 内部微分的积分"这一原理的特例：

定理边界积分内部积分维度
FTC for line integrals\(\displaystyle\int_C \nabla f\cdot d\vec{r}\)\(f(P_1)-f(P_0)\)1D ↔ 0D
Stokes\(\displaystyle\oint_C \vec{F}\cdot d\vec{r}\)\(\displaystyle\iint_S (\nabla\times\vec{F})\cdot\hat{n}\,dS\)1D ↔ 2D
散度定理\(\displaystyle\iint_S \vec{F}\cdot\hat{n}\,dS\)\(\displaystyle\iiint_D \nabla\cdot\vec{F}\,dV\)2D ↔ 3D

Green 定理是 Stokes 定理的特例（当 \(S\) 在 \(xy\) 平面时，\(\nabla\times\vec{F}\cdot\hat{k}=N_x-M_y\)）。

6. 单连通区域（空间）

空间区域是单连通的，如果其内任何闭路都能张成完全在区域内的曲面。

定理：在单连通区域上，\(\nabla\times\vec{F}=\vec{0}\) ⇔ \(\vec{F}\) 是梯度场（保守场）。

反例：去掉 \(z\) 轴的区域不是单连通的——绕 \(z\) 轴的闭路无法在区域内张成曲面。

典型题型与解题策略

1

三重积分计算

代表：Practice 4B 中柱面/球面区域题；两曲面之间的体积。

策略：画区域 → 判断对称性 → 选柱面或球面坐标 → 定限。柱面用于绕 \(z\) 轴旋转体；球面用于球/锥形。

2

曲面积分与通量

代表：Practice 4B 中球面/柱面/平面通量题；曲面 \(z=f(x,y)\) 的通量。

策略：识别曲面类型 → 用对应的 \(\hat{n}\,dS\) 公式 → 投影到坐标平面 → 化为二重积分。

3

散度定理应用

代表：Practice 4B 中闭曲面通量题；复杂曲面用定理简化。

策略：闭曲面通量 → 考虑散度定理 → 算 \(\nabla\cdot\vec{F}\) → 三重积分。当散度简单（常数、零）时特别有效。

4

Stokes 定理应用

代表：Practice 4B 中闭路线积分题；用 Stokes 简化。

策略：闭路线积分 → 考虑 Stokes → 选简单曲面（平面圆盘优先）→ 算 \(\nabla\times\vec{F}\) → 曲面积分。

5

空间梯度场与势函数

代表：Practice 4B 中空间保守场判定；求势函数。

策略：验证三个偏导等式 → 反导数法求 \(f\) → 用 FTC 算线积分。

常见错误

散度定理用于非闭曲面：散度定理只对闭曲面成立。若曲面不封闭，需补面后应用定理，再减去补面的通量。

Stokes 定理定向不匹配：曲线 \(C\) 的方向与曲面 \(S\) 的定向必须相容（右手法则）。方向反了差一个负号。

球面坐标 \(\varphi\) 范围错误：\(\varphi\in[0,\pi]\)。半球是 \([0,\pi/2]\)，不是 \([0,\pi]\)。

混淆三大定理的适用情形：闭路积分 → Stokes（或 Green）；闭曲面通量 → 散度定理；梯度场 → FTC。不要张冠李戴。
