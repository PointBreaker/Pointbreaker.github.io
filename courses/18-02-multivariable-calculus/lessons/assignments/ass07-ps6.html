Problem Set 6: Non-Independent Variables and Partial Differential Equations（非独立变量与偏微分方程）

本习题集聚焦于非独立变量下的偏导数运算与偏微分方程初步，涵盖链式法则、隐函数求导、变量变换以及波动方程、热方程等经典偏微分方程的求解与验证。建议在掌握全微分与基本 PDE 解法后完成。

本地官方资料整理中文自包含可离线作答

目标

  • 理解非独立变量下偏导数的记号 (∂w/∂x)_y 的含义，明确哪些变量被保持不变
  • 能够应用链式法则进行变量变换，理解雅可比行列式的计算
  • 掌握隐函数求导与循环关系（如热力学中的三变量循环乘积为 −1）
  • 能够验证给定函数是否满足波动方程、热方程或拉普拉斯方程
  • 掌握分离变量法求解一维热方程
  • 理解恰当微分方程的判定条件并求原函数

核心知识要点

偏导数下标的含义

(∂w/∂x)_y 表示保持 y 不变时 w 对 x 的变化率，与全导数 dw/dx 不同。当变量之间存在约束时，必须明确哪些变量被保持不变。

隐函数求导与循环关系

状态方程 f(P,V,T)=0 联系三个变量，循环关系 (∂P/∂V)_T (∂V/∂T)_P (∂T/∂P)_V = −1 恒成立。这是隐函数求导的直接推论。

链式法则与变量变换

极坐标下拉普拉斯算子 ∂²w/∂x² + ∂²w/∂y² = ∂²w/∂r² + (1/r)∂w/∂r + (1/r²)∂²w/∂θ²。这是链式法则在坐标变换中的典型应用。

恰当微分方程

ω = M dx + N dy 恰当当且仅当 ∂M/∂y = ∂N/∂x。此时存在原函数 F 使得 dF = ω，可通过线积分或逐次积分求得。

分离变量法

设 u(x,t) = X(x)T(t)，将热方程 ∂u/∂t = k ∂²u/∂x² 分解为两个常微分方程：X'' + λX = 0 和 T' + λkT = 0。结合边界条件确定本征值 λ。

2

PDE 的直接验证

对 PDE 验证题，直接计算二阶偏导数并代入方程检验。注意链式法则中的符号（如 ∂/∂t sin(x−ct) = −c cos(x−ct)）。

3

分离变量的标准步骤

常见错误

混淆 (∂w/∂x)_y 与全导数 dw/dx，忽略约束导致的变量依赖

链式法则中遗漏中间变量对自变量的偏导数项

验证 PDE 时二阶偏导数计算符号错误（特别注意链式法则中的负号）

分离变量时未正确处理边界条件导致本征值错误

隐函数求导时忘记负号或分母
