Problem Set 3: 3D Projection, Differentiation of x^y, and Contour Maps（三维投影、x^y 的微分与等高线图）

本习题集围绕三个主题展开：三维图形投影与消失点、幂函数 x^y 的微分与灵敏度分析，以及等高线图与偏导数。题目从几何直观出发，逐步过渡到利用偏导数进行局部线性近似和临界点分析。

目标

  • 理解三维点到屏幕平面的投影原理，能写出投影坐标公式
  • 掌握消失点（灭点）的概念，理解其对应方向向量在无穷远处的投影
  • 能够计算幂函数 x^y 的偏导数与全微分，理解线性近似的误差来源
  • 能够由全微分进行灵敏度分析，比较底数变化与指数变化对函数值的影响
  • 能够由等高线图判断偏导数符号，并找出函数的临界点
  • 掌握临界点附近等高线结构的描述方法

核心知识要点

投影的参数化表示

过视点 E 与点 P 的直线与屏幕平面的交点即为投影点。将直线参数化后令 x=0（屏幕平面）即可解出参数 t，再代回求投影坐标。

消失点的几何含义

消失点对应方向向量在无穷远处的投影，是平行线在屏幕上的汇聚点。当参数 t→∞ 时，投影点趋于一个极限位置，该极限点与线段端点无关。

幂函数的偏导数

w = x^y 对底数 x 求导时 y 视为常数，∂w/∂x = yx^(y−1)；对指数 y 求导时利用 e^(y ln x)，∂w/∂y = x^y ln x。两者含义不同，不可混淆。

全微分与线性近似

全微分 dw = (∂w/∂x)dx + (∂w/∂y)dy 用于近似计算 Δw ≈ dw。灵敏度分析中比较两项的大小可判断哪个自变量对函数值影响更大。

等高线图与偏导数

沿 +x 方向函数值递增则 f_x > 0，递减则 f_x < 0；沿 +y 方向同理。临界点满足 f_x = f_y = 0，附近等高线呈现闭合、交叉或稀疏等特征。

典型题型与解题策略

1

投影问题的参数化方法

从视点与目标点连线并参数化，再求该直线与屏幕平面的交点。令 x=0 解出参数 t，代入 y、z 即得投影坐标。

2

微分近似的步骤

先写出全微分 dw = (∂w/∂x)dx + (∂w/∂y)dy，再代入微小增量 Δx、Δy 得到 Δw 的近似值，最后与精确值比较估计误差。

3

等高线图的读图方法

先根据移动方向与等高线疏密判断偏导数符号，再与解析计算对照。沿 +x 方向跨越到更高等高线则 f_x > 0，反之则 f_x < 0。

常见错误

投影时注意 x₀ < 2 保证点在视点前方，投影才有意义

x^y 的偏导数要区分对底数 x 与对指数 y 求导，不要混淆

由等高线图判断偏导数时，注意沿 +x 或 +y 方向是否跨越到更高或更低的等高线

消失点对应方向向量在无穷远处的投影，而非线段端点的投影

题目 1 三维计算机图形投影 参数化投影 · 消失点（灭点） · 栅栏/平面遮挡
官方题面翻译可离线作答

在三维计算机图形学中，需要把三维物体表现在平面屏幕上：对给定点 \(P\)，画出从 \(P\) 到视点（eye）的连线与屏幕的交点。设屏幕为 \(yz\) 平面，视点位于 \(E: (2, 0, 0)\)。

  1. a) 在 \(yz\) 平面上，点 \(P: (x_0, y_0, z_0)\) 应表示为哪一点 \(Q: (y, z)\)？（用 \(P\) 的坐标表示 \(y\) 和 \(z\)。假设 \(x_0 < 2\)，这一假设为何是合理的？）
  2. b) 空间中一条线段在屏幕上的像是什么？（证明你的结论。）
  3. c) 一条线段连接 \(P_0: (-1, -3, 1)\) 与 \(P_1: (-2, 4, 6)\)。屏幕上画出的是什么？
  4. d) 一只鸟在时刻 \(t = 0\) 从 \(P_0\) 出发，以恒定速度沿直线飞行，使得它在时刻 \(t = 1\) 经过 \(P_1\)。鸟的轨迹（\(t \ge 0\)）在屏幕上呈现什么形状？证明当 \(t\) 趋于无穷时，屏幕上的轨迹趋于一个极限点（即"消失点"），并给出该点坐标。
  5. e) 实际上，鸟的轨迹有一部分被观察者正前方的一道垂直栅栏遮挡。栅栏位于平面 \(x = 1\) 上，其顶端高度为 \(z = 1\)。轨迹的哪一部分被遮挡？（提示：被栅栏遮挡的点恰好位于过视点 \(E\) 的某一平面下方。）

公式与已知条件

  • 视点 \(E = (2, 0, 0)\)；屏幕为 \(yz\) 平面（\(x = 0\)）
  • \(P_0 = (-1, -3, 1)\)，\(P_1 = (-2, 4, 6)\)
  • 栅栏：平面 \(x = 1\)，顶端位于 \(z = 1\)
解题入口

对过 \(E\) 与 \(P\) 的直线参数化，再求与 \(x = 0\) 的交点即得 \(Q\)。对鸟的轨迹，先将位置写成 \(t\) 的函数再投影；对栅栏问题，求过 \(E\) 与栅栏顶端的平面，再判断哪些投影点位于该平面下方。

完成后检查

  • 验证 \(x_0 < 2\) 保证点在视点前方，投影有定义
  • 确认 (d) 中的极限点是方向向量在无穷远处的投影
  • 检查 (e) 中被遮挡部分对应参数 \(t\) 的取值区间

题目 2 w = x^y 的微分与灵敏度 微分 · 切线近似 · 灵敏度分析
官方题面翻译可离线作答

设 \(w = x^y\)（即 \(e^{y \ln x}\)）。

  1. a) 给出由 \(x\) 和 \(y\) 的微小变化 \(\Delta x\)、\(\Delta y\) 引起 \(w\) 的微小变化 \(\Delta w\) 的近似公式。利用该公式计算 \(1.98^{2.01}\) 的近似值，并与精确值比较。
  2. b) 从 \(2^2 = 4\) 出发，\(x^y\) 的值对底数 \(x\) 的微小变化与对指数 \(y\) 的微小变化，哪个更敏感？（证明你的结论。）

公式与已知条件

  • \(w = x^y = e^{y \ln x}\)
  • 微分：\(\mathrm{d}w = (y x^{y-1}) \mathrm{d}x + (x^y \ln x) \mathrm{d}y\)
  • (b) 的基准点：\(x = 2, y = 2, w = 4\)
解题入口

计算 \(x^y\) 的偏导数，写出全微分 \(\mathrm{d}w\)，再代入微小的 \(\Delta x\)、\(\Delta y\)。对 (b)，比较 \((2,2)\) 处两个偏导数项的大小。

完成后检查

  • 确认近似值 \(1.98^{2.01}\) 与精确值接近
  • (b) 中比较的是 \(|y x^{y-1} \Delta x|\) 与 \(|x^y \ln x \Delta y|\) 的大小
  • 注意 \(x > 0\) 保证 \(\ln x\) 有定义

题目 3 等高线图与偏导数 等高线图 · 由等高线图判断偏导数 · 临界点 · 等高线结构

本站等价练习：本题依据原题覆盖的知识点（等高线图与偏导数、临界点分析）重新设计，供离线练习使用。设二元函数 \[f(x, y) = x^3 - x y^2 - 4x^2 + 3x + x^2 y\] 定义域为 \([0, 2] \times [0, 2]\)，等高线间距为 \(0.2\)。已知该函数在以下网格点处的取值： | x\y | 0 | 0.5 | 1 | 1.5 | 2 | |------|---|-----|---|-----|---|---| | 0 | 0 | 0 | 0 | 0 | 0 | | 0.5 | 0.625 | 0.625 | 0.375 | -0.125 | -0.875 | | 1 | 0 | 0.25 | 0 | 0 | 0 | | 1.5 | -1.125 | -0.375 | -0.375 | -1.125 | -2.625 | | 2 | -2 | -0.5 | 0 | -0.5 | -2 |

  1. a) 利用上表判断在点 \((0.5, 1)\) 和 \((1.5, 1)\) 处，\(f_x\) 和 \(f_y\) 的符号（\(> 0\)、\(= 0\) 或 \(< 0\)）。
  2. b) 计算 \(f_x\) 和 \(f_y\) 在 \((0.5, 1)\) 和 \((1.5, 1)\) 处的精确值，并与 (a) 中判断的符号对照。
  3. c) 令 \(f_x = 0\) 且 \(f_y = 0\)，求出 \(f\) 在 \([0, 2] \times [0, 2]\) 内的所有临界点，并给出其近似坐标。
  4. d) 对 (c) 中找到的每个临界点，描述等高线在该点附近的结构特征，并分别说明沿北、南、东、西四个方向移动时，\(f\) 的值如何变化（增大、减小或保持不变）。

公式与已知条件

  • \(f(x, y) = x^3 - x y^2 - 4x^2 + 3x + x^2 y\)
  • \(f_x = 3x^2 - y^2 - 8x + 3 + 2xy\)
  • \(f_y = -2xy + x^2\)
  • 定义域：\([0, 2] \times [0, 2]\)，等高线间距：\(0.2\)
解题入口

根据网格点函数值的变化趋势判断偏导数符号：沿 \(+x\) 方向函数值递增则 \(f_x > 0\)，递减则 \(f_x < 0\)；沿 \(+y\) 方向同理。求临界点时，联立 \(f_x = 0\) 与 \(f_y = 0\) 求解。

完成后检查

  • (a) 中判断的符号应与 (b) 中计算的符号一致
  • 临界点应满足 \(f_x \approx 0\) 且 \(f_y \approx 0\)
  • 检查临界点附近等高线是否呈现闭合、交叉或稀疏等特征
