Problem Set 8: Line Integrals, Curl, Conservatism, and Potential Functions（线积分、旋度、保守性与势函数）

本习题集围绕平面向量场的线积分、旋度、保守性与势函数展开，核心工具是格林定理与梯度场理论。第 1 题建立线积分与极转动惯量的联系；第 2、3 题通过具体场探讨旋度为零与保守性之间的关系，以及单连通区域的关键作用。

本地官方资料整理中文自包含可离线作答

目标

  • 理解平面向量场线积分的定义与物理意义。
  • 掌握格林定理及其应用条件，能把闭合回路线积分转化为二重积分。
  • 理解保守场的等价条件：势函数存在、路径无关、旋度为零、区域单连通。
  • 学会计算平面向量场的旋度 \(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\)。
  • 对径向场 \(\mathbf{F}=r^n(x\hat{\mathbf{i}}+y\hat{\mathbf{j}})\) 求势函数，并识别 \(n=-2\) 的例外。
  • 区分局部（单连通子区域）保守与全局保守的差别。

核心知识要点

格林定理

正向闭合曲线 \(C\) 上的线积分等于区域 \(R\) 上旋度的二重积分：\[\oint_C P\,dx+Q\,dy = \iint_R \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA.\] 它把一维的线积分与二维的面积分联系起来。

旋度与保守性

旋度 \(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}=0\) 在每一点成立，是局部性质；保守性（路径无关）是全局性质。两者等价需要区域单连通。

势函数与路径无关

若 \(\mathbf{F}=\nabla f\)，则 \(\int_C \mathbf{F}\cdot d\mathbf{r}=f(B)-f(A)\)，只与端点有关。势函数的存在性等价于保守性。

单连通区域的关键作用

单连通区域内任意闭合曲线可连续缩为一点，因此旋度处处为零即可保证保守；去掉原点的平面非单连通，旋度为零也可能非保守。

径向场的势函数

对 \(\mathbf{F}=r^n(x\hat{\mathbf{i}}+y\hat{\mathbf{j}})\)，尝试 \(g=g(r)\) 型势函数，由 \(g'(r)=r^{n+1}\) 积分得到，但 \(n=-2\) 时幂律失效，需改用对数型势函数。

典型题型与解题策略

1

补全闭合回路再用格林定理

当曲线不闭合时，补上坐标轴上的线段构成闭合回路，应用格林定理转化为二重积分，再减去补上的那段贡献。

2

用势函数简化线积分

若场在区域内保守且能求出势函数，直接代入端点求差即可，避免繁琐的参数化计算。

3

参数化直接计算作为验证

对半圆、圆弧等简单曲线，用角度参数化直接计算线积分，可验证势函数或格林定理的结果。

常见错误

旋度处处为零并不保证在整个挖去原点的平面上保守，必须检查区域是否单连通。

极角函数 \(\theta(x,y)=\tan^{-1}(y/x)\) 只在 \(x>0\) 有定义，不能延拓到整个定义域。

\(n=-2\) 时幂律积分失效，应改用对数型势函数 \(g=\ln r\)。

应用格林定理前要确认曲线闭合、方向为正向，且场在区域内处处可微。

知识检查

问题 1：设向量场 \(\mathbf{F}(x,y)=\frac{-y\hat{\mathbf{i}}+x\hat{\mathbf{j}}}{x^2+y^2}\)。\(C_1\) 是从 \((1,0)\) 到 \((-1,0)\) 的上半单位圆。\(\int_{C_1} \mathbf{F}\cdot d\mathbf{r}\) 的值是多少？

问题 2：设平面向量场 \(\mathbf{F}=P\hat{\mathbf{i}}+Q\hat{\mathbf{j}}\) 在区域 \(D\) 上具有连续一阶偏导数。下列哪个条件能保证 \(\mathbf{F}\) 在 \(D\) 上为保守场？

问题 3：设 \(\mathbf{F}=r^n(x\hat{\mathbf{i}}+y\hat{\mathbf{j}})\)，其中 \(r=\sqrt{x^2+y^2}\)。当 \(n=-2\) 时，下列哪个函数是 \(\mathbf{F}\) 的势函数？

题目 1 线积分与极转动惯量 线积分 · 极转动惯量 · 平面向量场
官方题面翻译可离线作答

设向量场 \(\mathbf{F} = (x^2 y + 31 y^3)\,\hat{\mathbf{i}}\)，\(C\) 为曲线 \(y = f(x)\) 上从 \((x_1, f(x_1))\) 到 \((x_2, f(x_2))\) 的一段（设 \(x_1 < x_2\) 且 \(f\) 取正值）。证明线积分 \(\int_C \mathbf{F} \cdot d\mathbf{r}\) 等于区域 \(R\)（位于 \(C\) 下方、\(x\) 轴上方，密度 \(\delta = 1\)）的极转动惯量（polar moment of inertia）。

公式与已知条件

  • \(\mathbf{F} = (x^2 y + 31 y^3)\,\hat{\mathbf{i}}\)
  • \(C: y = f(x),\; x_1 < x_2,\; f > 0\)
  • 区域 \(R\) 的极转动惯量，密度 \(\delta = 1\)
解题入口

对闭合回路（\(C\) 加上 \(x\) 轴上的线段）应用格林定理，将环路线积分转化为 \(R\) 上 \((Q_x - P_y)\) 的二重积分，再把所得被积函数与极转动惯量的被积函数对应起来。

完成后检查

  • 确认 \(P = x^2 y + 31 y^3,\; Q = 0\)，从而 \(Q_x - P_y = -(x^2 + 93 y^2)\)。
  • 验证 \(x\) 轴上线段的贡献为零或已被恰当处理。
  • 检查 \(R\) 上的二重积分与极转动惯量的定义一致。

题目 2 极角的梯度、旋度与保守性 梯度场 · 旋度 · 路径无关性 · 保守场 · 极角 · 单连通区域
官方题面翻译可离线作答

设向量场 \(\displaystyle \mathbf{F}(x,y) = \frac{-y\,\hat{\mathbf{i}} + x\,\hat{\mathbf{j}}}{x^2 + y^2}\)。

公式与已知条件

  • \(\displaystyle \mathbf{F}(x,y) = \frac{-y\,\hat{\mathbf{i}} + x\,\hat{\mathbf{j}}}{x^2 + y^2}\)
  • \(\theta(x,y) = \tan^{-1}(y/x)\)
  • \(C_1,C_2\)：从 \((1,0)\) 到 \((-1,0)\) 的上、下半单位圆
解题入口

(a) 对 \(\theta\) 求偏导；(b) 利用梯度场/线积分基本定理；(c) 用角度参数化曲线；(d) 计算 \(Q_x - P_y\)；(e) 对比单连通的 \(x>0\) 与非单连通的挖去原点的平面。

完成后检查

  • 验证在 \(x > 0\) 上 \(\nabla\theta = \mathbf{F}\)。
  • 确认 (b) 的端点求值与 (c) 中可对照的直接计算结果一致。
  • 确认在整个定义域上旋度为零。
  • 确认 \(x > 0\) 上保守，但在整个挖去原点的平面上不保守。

题目 3 径向场的旋度与势函数 旋度 · 势函数 · 径向向量场 · 梯度
官方题面翻译可离线作答

设 \(r = \sqrt{x^2 + y^2}\)。

公式与已知条件

  • \(\mathbf{F} = r^n\,(x\,\hat{\mathbf{i}} + y\,\hat{\mathbf{j}})\)
  • \(r = \sqrt{x^2 + y^2}\)
解题入口

利用 \(r_x = x/r\) 与 \(r_y = y/r\) 对 \(r^n\) 求导；(b) 对 \(g'(r) = r^{n+1}\) 积分，并对 \(n = -2\) 单独处理（对数型势函数）。

完成后检查

  • 确认 (a) 中对一般 \(n\) 的旋度计算。
  • 确认对所有 \(n\) 除例外情形外都有 \(\nabla g = \mathbf{F}\)，并解决该例外情形。
