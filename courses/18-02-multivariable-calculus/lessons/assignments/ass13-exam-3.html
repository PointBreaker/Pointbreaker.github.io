覆盖 Unit IIIa 的全部内容：二重积分（直角、极坐标、变量替换/Jacobi）、向量场、线积分、功、路径无关、保守场、Green 定理（切向与法向/通量形式）、单连通区域。测验风格与 Practice 3A/3B 相近。

日期：2007-11-08 范围：Lectures 16–24 题型：计算 + 证明 + Green 定理应用 难度：中等

目标

本次测验检验你对 Unit IIIa 两大主题的掌握：多重积分与线积分。核心能力包括：对平面区域建立迭代积分（直角坐标、极坐标、变量替换）；计算向量场的线积分；识别保守场并用 FTC 简化；用 Green 定理把线积分与二重积分互相转换；理解单连通区域上保守场判据的适用条件。

核心思想：Auroux 在第 24 讲复习中指出，Unit IIIa 的主线是"两种积分、一座桥梁"——二重积分与线积分是两种不同的积分，Green 定理是它们之间的桥梁。看到闭路线积分 → 想到 Green 定理化为二重积分；看到形如 \(\iint_R (N_x-M_y)\,dA\) 的二重积分 → 也可反用 Green 定理。

核心知识要点

1. 二重积分

直角坐标：画区域 → 切片定限 → 迭代积分。

极坐标：\(dA=r\,dr\,d\theta\)，用于含 \(x^2+y^2\) 或圆形区域。

变量替换三步法：(1) 算 Jacobi \(\partial(u,v)/\partial(x,y)\) 或其逆；(2) 用新变量表示被积函数；(3) 在 \(uv\) 平面上画区域定限。

应用：

\[ M = \iint_R \delta\,dA,\quad \bar x = \frac{1}{M}\iint_R x\,\delta\,dA,\quad I_0 = \iint_R (x^2+y^2)\,\delta\,dA. \]

2. 线积分

定义与计算：参数化后代入，\(\int_C \vec{F}\cdot d\vec{r} = \int_{t_0}^{t_1} \vec{F}(\vec{r}(t))\cdot\vec{r}'(t)\,dt\)。

梯度场的 FTC：若 \(\vec{F}=\nabla f\)，则 \(\displaystyle\int_C \vec{F}\cdot d\vec{r} = f(P_1)-f(P_0)\)，与路径无关。

保守场判定：在单连通区域上，\(\vec{F}=\langle M,N\rangle\) 保守 ⇔ \(N_x=M_y\)（即 \(\operatorname{curl}\vec{F}=0\)）。

3. Green 定理

切向形式（work form）：

\[ \oint_C M\,dx + N\,dy = \iint_R \left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right)dA. \]

法向形式（flux form）：设 \(\vec{F}=P\hat{\imath}+Q\hat{\jmath}\)，则：

\[ \oint_C \vec{F}\cdot\hat{n}\,ds = \oint_C -Q\,dx + P\,dy = \iint_R \left(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}\right)dA = \iint_R \operatorname{div}\vec{F}\,dA. \]

面积公式（推论）：\(\displaystyle A = \oint_C x\,dy = \oint_C -y\,dx\)。Auroux 用此证明机械求积仪 (planimeter) 的原理。

注意：Green 定理要求 \(\vec{F}\) 在 \(C\) 所围区域 \(R\) 上处处可微。经典反例：\(\vec{F}=\dfrac{\langle -y,x\rangle}{x^2+y^2}\)，\(\operatorname{curl}\vec{F}=0\)（除原点外），但沿单位圆积分 = \(2\pi\)。原因是区域包含原点（奇点），不是单连通区域上的 Green 定理适用范围。

4. 单连通区域

定义：平面区域 \(R\) 是单连通 (simply connected) 的，如果 \(R\) 内任何闭路的内部完全包含在 \(R\) 内。直观说：没有"洞"。

在单连通区域上，\(N_x=M_y\) ⇔ 保守场。在非单连通区域上，这个等价可能不成立（如上反例）。

建立迭代积分

策略：画区域 → 判断竖条/横条切片 → 写内外限。Auroux 复习时提醒：不要复杂三角积分（如 \(\cos^4\theta\)）或分部积分——测验不会要求这些。

2

极坐标积分与转动惯量

代表：Practice 3A Problem 2（单位圆盘关于 \(y\) 轴的极转动惯量）。

策略：识别圆形区域 → 极坐标代入 → \(dA=r\,dr\,d\theta\)。注意：密度 = 到 \(y\) 轴距离 = \(|x|\)，被积函数含 \(x^2=r^2\cos^2\theta\)。

3

保守场与势函数

代表：Practice 3A Problem 3（含参保守场 + 求势 + 用 FTC 算积分）；3B Problem 3。

策略：令 \(N_x=M_y\) 解参数 → 求 \(f\)（反导数法或简单路径法）→ 用 FTC 得线积分。

4

变量替换与 Jacobi

代表：Practice 3A Problem 5（\(u=x^2/y,\ v=xy\)）；3B Problem 6（\(u=2x-y,\ v=x+y-1\)）。

策略：算 Jacobi → 转换被积函数 → 在 \(uv\) 平面上画新区域（通常更简单：矩形或圆）。Auroux 提示：测验中的 Jacobi 会是常数或简单表达式。

5

Green 定理应用（切向与法向）

代表：Practice 3A Problem 6（把 \(M\,dx\) 表为二重积分）；Problem 7（通量）；3B Problem 5（通量）。

策略：闭路线积分 → 考虑 Green 定理。切向形式用于 \(M\,dx+N\,dy\)；法向形式用于通量 \(\vec{F}\cdot\hat{n}\,ds\)。反用 Green 定理（二重积分 → 线积分）有时更简便。

常见错误

Green 定理方向搞反：Green 定理要求逆时针 (counterclockwise) 方向。顺时针闭路积分 = 逆时针积分的相反数。通量形式中 \(\hat{n}\) 是外法向（由逆时针方向旋转 90° 顺时针得到）。

单连通条件忽略：使用 \(N_x=M_y \Rightarrow\) 保守场时，必须确认区域是单连通的。含原点的向量场 \(\dfrac{\langle -y,x\rangle}{x^2+y^2}\) 是最常见的陷阱。

极坐标忘乘 \(r\)：\(dA=r\,dr\,d\theta\)。测验中这是高频失分点。

通量与功混淆：\(\int \vec{F}\cdot\hat{T}\,ds\) 是功 (work)（切向分量）；\(\int \vec{F}\cdot\hat{n}\,ds\) 是通量 (flux)（法向分量）。两者的 Green 定理形式不同。

题目 1 三角形的质心 质心 · 二重积分 · 对称性
官方题面翻译可离线作答

一个密度均匀为 \(\delta = 1\) 的三角形，顶点为 \((−2, 0)\)、\((0, 1)\)、\((2, 0)\)。设 \((\bar{x}, \bar{y})\) 为其质心。

公式与已知条件

  • 质心公式：\[\bar{x} = \frac{1}{M} \iint_R x\delta\,dA\]，\[\bar{y} = \frac{1}{M} \iint_R y\delta\,dA\]
  • 质量 \[M = \iint_R \delta\,dA\]
  • 已知：\(\delta = 1\)，顶点 \((−2, 0)\)、\((0, 1)\)、\((2, 0)\)
解题入口

(a) 根据三角形边界确定积分限，写出 \(\bar{y}\) 的累次积分；(b) 注意区域与密度均关于 \(y\) 轴对称。

完成后检查

  • \(\bar{x}\) 应能通过对称性直接判断
  • \(\bar{y}\) 的积分中，被积函数与积分区域均位于 \(x\) 轴上方，结果应为正

题目 2 单位圆盘的极转动惯量 极转动惯量 · 极坐标 · 二重积分
官方题面翻译可离线作答

单位圆盘 \(x^2 + y^2 \le 1\) 的密度为到 \(y\) 轴的距离。求其极转动惯量。

公式与已知条件

  • 极转动惯量：\[I_p = \iint_R (x^2 + y^2)\delta\,dA\]
  • 到 \(y\) 轴的距离：\(\delta = |x|\)
  • 单位圆盘：\[x^2 + y^2 \le 1\]
解题入口

采用极坐标变换，注意距离表达式与对称性。

完成后检查

  • 被积函数与区域均关于坐标轴对称，可化简计算
  • 结果应为正量

题目 3 保守向量场与曲线积分 保守向量场 · 势函数 · 曲线积分基本定理
官方题面翻译可离线作答

设向量场 \(\vec{F} = (a x^2 y + y^3 + 1)\hat{\imath} + (2 x^3 + b x y^2 + 2)\hat{\jmath}\)，其中 \(a\)、\(b\) 为常数。

公式与已知条件

  • 保守条件：\(\partial Q/\partial x = \partial P/\partial y\)，其中 \(P = a x^2 y + y^3 + 1\)，\(Q = 2 x^3 + b x y^2 + 2\)
  • 势函数满足：\(f_x = P\)，\(f_y = Q\)
  • 曲线积分基本定理：\[\int_C \nabla f \cdot d\vec{r} = f(\text{终点}) - f(\text{起点})\]
  • 曲线 \(C\)：\[x = e^t \cos t\]，\[y = e^t \sin t\]，\[t \in [0, \pi]\]
解题入口

(a) 令 \(\partial Q/\partial x = \partial P/\partial y\) 解出 \(a\)、\(b\)；(b) 先对 \(P\) 关于 \(x\) 积分，再利用 \(f_y = Q\) 确定含 \(y\) 的部分；(c) 利用 (b) 的势函数和曲线端点。

完成后检查

  • (a) 验证 \(\partial Q/\partial x = \partial P/\partial y\) 成立
  • (b) 验证 \(\nabla f = \vec{F}\)
  • (c) 确认曲线起点 \(t = 0\) 与终点 \(t = \pi\) 的坐标

题目 4 沿抛物线的曲线积分 曲线积分 · 参数化
官方题面翻译可离线作答

对于 \(\vec{F} = y x^3\hat{\imath} + y^2\hat{\jmath}\)，求 \(\int_C \vec{F} \cdot d\vec{r}\)，其中 \(C\) 是曲线 \(y = x^2\) 从 \((0, 0)\) 到 \((1, 1)\) 的一段。

公式与已知条件

  • \(\vec{F} = (y x^3, y^2)\)
  • 曲线 \(C\)：\[y = x^2\]，从 \((0, 0)\) 到 \((1, 1)\)
  • 参数化：\[\vec{r}(t) = (t, t^2)\]，\[t \in [0, 1]\]
  • \[\int_C \vec{F} \cdot d\vec{r} = \int_0^1 \vec{F}(\vec{r}(t)) \cdot \vec{r}'(t)\,dt\]
解题入口

将曲线用参数 \(t\) 表示，代入向量场后直接计算积分。

完成后检查

  • 参数化方向与端点 \((0,0) \to (1,1)\) 一致
  • 计算后可验证数值合理性

题目 5 变量替换与面积 变量替换 · 雅可比行列式 · 面积 · 二重积分
官方题面翻译可离线作答

设 \(R\) 为第一象限中由曲线 \(y = x^2\)、\(y = x^2/5\)、\(xy = 2\) 和 \(xy = 4\) 围成的区域。

公式与已知条件

  • \[u = x^2/y\]，\[v = xy\]
  • 雅可比关系：\[dx\,dy = \left|\frac{\partial(x,y)}{\partial(u,v)}\right| du\,dv = \left|\frac{\partial(u,v)}{\partial(x,y)}\right|^{-1} du\,dv\]
  • 面积 = \[\iint_R dx\,dy\]
  • 边界曲线：\[y = x^2\]、\[y = x^2/5\]、\[xy = 2\]、\[xy = 4\]
解题入口

(a) 先计算 \(\partial(u,v)/\partial(x,y)\)，再取倒数绝对值；(b) 将四条边界曲线转化为 \(uv\) 区域。

完成后检查

  • \(uv\) 区域应为矩形
  • 面积应为正

题目 6 格林定理与质量 格林定理 · 环量 · 质量
官方题面翻译可离线作答

设 \(C\) 是逆时针绕区域 \(R\) 一周的简单闭曲线，\(M = M(x, y)\)。

公式与已知条件

  • 格林定理（切向形式）：\[\oint_C M\,dx = -\iint_R \frac{\partial M}{\partial y}\,dA\]
  • 质量：\[m = \iint_R \delta\,dA = \iint_R (x + y)^2\,dA\]
  • 密度：\(\delta(x, y) = (x + y)^2\)
解题入口

(a) 直接应用格林定理的切向形式；(b) 令 \(-\partial M/\partial y = (x + y)^2\)，对 \(y\) 积分得到 \(M\)。

完成后检查

  • (a) 注意符号（逆时针为正方向）
  • (b) 对所得 \(M\) 验证 \(-\partial M/\partial y = (x + y)^2\)

题目 7 通量与格林定理 通量 · 格林定理法向形式 · 散度
官方题面翻译可离线作答

设 \(R\) 是由 \(x\) 轴、\(x = 1\) 和 \(y = x^3\) 围成的区域。

公式与已知条件

  • \(\vec{F} = (0, 1 + y^2)\)
  • 格林定理法向形式：\[\oint_C \vec{F} \cdot \vec{n}\,ds = \iint_R \operatorname{div}\vec{F}\,dA\]
  • \[\operatorname{div}\vec{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y}\]
  • 区域 \(R\)：由 \(x\) 轴、\(x = 1\)、\(y = x^3\) 围成
  • \(C_1\)：水平线段，\(C_2\)：竖直线段，\(C_3\)：曲线 \(y = x^3\) 段
解题入口

(a) 计算散度并在 \(R\) 上积分；(b) 分别在 \(C_1\)、\(C_2\) 上直接计算通量；(c) 总通量等于三侧通量之和。

完成后检查

  • 注意法向量指向外侧
  • (a) 的结果应等于 (b) 与 (c) 之和
