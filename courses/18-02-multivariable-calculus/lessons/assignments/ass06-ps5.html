Problem Set 5: Gradient, Directional Derivatives, and Lagrange Multipliers（梯度、方向导数与拉格朗日乘数法）

本习题集涵盖多元函数微分学的核心应用，包括梯度、方向导数、切平面以及拉格朗日乘数法在约束极值问题中的应用。A 部分为教材基础练习，B 部分为需要提交的综合题，重点训练在约束条件下求极值的能力。

本地官方资料整理中文自包含可离线作答

目标

  • 熟练计算多元函数的梯度向量 ∇f
  • 理解方向导数与梯度的关系：df/dŝ = ∇f · û，其中 û 为单位方向向量
  • 能够写出曲面 z = f(x,y) 在给定点处的切平面方程
  • 掌握最快下降方向的求法：−∇f 方向
  • 能够利用线性近似估计函数值的变化
  • 掌握拉格朗日乘数法求约束极值的方程组建立与求解

核心知识要点

梯度的几何意义

梯度 ∇f 指向函数增长最快的方向，其模 |∇f| 为方向导数的最大值。梯度与等高线垂直，沿梯度方向函数值变化最剧烈。

方向导数与夹角的关系

方向导数 df/dŝ = ∇f · û = |∇f| cos φ，其中 φ 为 ∇f 与 û 的夹角。cos φ = 1 时取最大值 |∇f|，cos φ = −1 时取最小值 −|∇f|，cos φ = 0 时方向导数为零。

切平面方程

曲面 z = f(x,y) 在点 (x₀,y₀,z₀) 处的切平面方程为 z − z₀ = f_x(x₀,y₀)(x−x₀) + f_y(x₀,y₀)(y−y₀)，梯度分量即为法向量的 x、y 分量。

最快下降方向

最快下降方向为 −∇f 方向（梯度的反方向）。线性近似利用切平面 L(x,y,z) 逼近函数值，可用于估计函数值变化时自变量的变化。

拉格朗日乘数法

在约束 g = c 下求 f 的极值，需解方程组 ∇f = λ∇g 且 g = c。最小化距离平方比最小化距离更简便，因为距离平方避免了根号。

典型题型与解题策略

1

基础练习优先

先完成 A 部分基础练习，巩固梯度与方向导数的计算，为 B 部分综合题打下基础。

2

明确问题目标

对于 B 部分，先明确问题目标（求方向、求极值、求近似），再选择合适方法。方向导数极值用梯度模，约束极值用拉格朗日乘数法。

3

距离平方的最小化

拉格朗日乘数题注意判断是求距离还是距离平方，后者通常更易求解（避免根号），因为极值点位置相同。

常见错误

方向导数的最值问题中，注意 û 必须是单位向量，否则需要先单位化

求最快下降方向时，方向是 −∇f 而非 ∇f

使用线性近似时，注意展开点与目标点的关系，近似仅在靠近展开点时有效

拉格朗日乘数法中，不要遗漏约束条件 g = c

解方程组时注意检验所有可能的解，包括退化情况（如 λ 取不同值对应不同点）

题目 1 方向导数极值 方向导数 · 梯度
官方题面翻译可离线作答

考虑函数 \(f(x, y) = x^3 - xy^2 - 4x^2 + 3x + x^2y\)。

  1. (a) 求方向导数 \(\frac{df}{d\hat{s}}\) 在点 \((1/2, 1)\) 处随单位方向 \(\hat{u}\) 变化时的最大值和最小值。
  2. (b) 指出最大值和最小值分别出现在哪个方向 \(\hat{u}\) 上。
  3. (c) 求使 \(\frac{df}{d\hat{s}} = 0\) 的方向 \(\hat{u}\)。
  4. (d) 计算 (a)-(c) 中涉及的 \(\frac{df}{d\hat{s}}\) 和方向角 \(\theta\) 的具体数值，并阐述方向 \(\hat{u}\)、等高线与梯度向量三者之间的几何关系。

公式与已知条件

  • \(f(x, y) = x^3 - xy^2 - 4x^2 + 3x + x^2y\)
  • 点 \((1/2, 1)\)
解题入口

方向导数 \(\frac{df}{d\hat{s}} = \nabla f \cdot \hat{u}\)。分析 \(\hat{u}\) 与 \(\nabla f\) 的夹角如何影响点积的取值。

完成后检查

  • 验证 \(\nabla f\) 在 \((1/2, 1)\) 处的计算
  • 确认 \(\frac{df}{d\hat{s}} = 0\) 的方向与梯度垂直

题目 2 最快下降方向与线性近似 梯度 · 最快下降方向 · 线性近似
官方题面翻译可离线作答

考虑函数 \(g(x, y, z) = x^2 + yz\)。

  1. (a) 求从点 \((2, -1, 1)\) 出发，使 \(g\) 下降最快的方向。
  2. (b) 沿 (a) 中找到的方向前进，利用线性近似估计 \(g = 2\) 时距离点 \((2, -1, 1)\) 最近的点的位置。不使用计算器，答案用分数表示。然后用计算器在你得到的点处求 \(g\) 的值（应接近 2）。

公式与已知条件

  • \(g(x, y, z) = x^2 + yz\)
  • 点 \((2, -1, 1)\)
  • 目标函数值 \(g = 2\)
解题入口

最快下降方向为 \(-\nabla g\) 方向。线性近似利用切平面 \(L(x,y,z)\) 逼近函数值。

完成后检查

  • 将估计点代入 \(g\) 计算，结果应接近 2

题目 3 拉格朗日乘数法精确求解 拉格朗日乘数法
官方题面翻译可离线作答

  1. (a) 使用拉格朗日乘数法写出距离点 \((2, -1, 1)\) 最近且满足 \(x^2 + yz = 2\) 的点所满足的方程组。（提示：最小化距离的平方更简便。）
  2. (b) 求解方程组，得到该点位置的数值近似（保留四位小数）。与 2(b) 的近似结果比较：2(b) 中每个坐标的近似值与精确解的差是否在 \(1/100\) 以内？

  • 点 \((2, -1, 1)\)

解题入口

最小化 \(D = (x-2)^2 + (y+1)^2 + (z-1)^2\)，约束为 \(x^2 + yz = 2\)，引入乘数 \(\lambda\) 建立方程组。

完成后检查

  • 将精确解与 2(b) 的近似解比较
  • 验证 \(\lambda = 2\) 的情况是否对应更远的点
