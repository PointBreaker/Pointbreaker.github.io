Problem Set 4: Least Squares, Area Optimization, and Chain Rule Matrices（最小二乘拟合、面积优化与链式法则矩阵）

本习题集围绕三个应用主题展开：基于正规方程的最小二乘拟合（含线性与指数模型比较）、单位圆内接三角形的面积优化（含临界点、边界与二阶导数检验），以及直角坐标与极坐标之间偏导数变换的矩阵推导与验证。

目标

  • 掌握最小二乘拟合的矩阵形式（正规方程 Az = r），能将求和式改写为向量积形式
  • 能够进行线性拟合与指数拟合的比较，理解对数线性化的方法
  • 能够建立单位圆内接三角形的面积函数 A(θ₁,θ₂)
  • 掌握区域上临界点与边界分析的方法，理解最大面积对应等边三角形
  • 掌握二阶导数检验（Hessian 行列式）判定临界点性质
  • 理解链式法则在坐标变换中的矩阵表示，能验证变换矩阵与其逆矩阵的关系

核心知识要点

正规方程的矩阵形式

最小二乘正规方程 Az = r 中，A 是 2×2 矩阵，元素为向量积（如 u·u′、u·x′、x·x′）；r 是 2×1 向量，分量为 u·y′ 和 x·y′。求和式被改写为向量积以便直接使用。

指数拟合的对数线性化

对 y 取 ln 后拟合直线 ln(y) = a₁x + b₁，再取指数还原为 y = e^(b₁) e^(a₁x)。这种方法将非线性拟合转化为线性拟合问题。

三角形面积的行列式表示

利用鞋带公式，单位圆内接三角形面积可写为 A = (1/2)|sin(θ₂−θ₁) + sin θ₁ − sin θ₂|。行列式公式的绝对值保证面积为正。

临界点、边界与二阶导数检验

内部令偏导为零求临界点，边界单独讨论（如 θ₁=θ₂、θ₁=0、θ₂=2π）。Hessian 行列式 D = f₁₁f₂₂ − f₁₂² 判定极值类型：D>0 且 f₁₁>0 为极小，D>0 且 f₁₁<0 为极大。

链式法则的矩阵形式

直角坐标到极坐标的偏导数变换可写为 [w_r; w_θ] = A[w_x; w_y]，其中 A 由坐标变换的偏导数构成。逆变换矩阵 B 满足 AB = I，可用三角恒等式验证。

1

拟合问题的矩阵化

2

面积优化的分步讨论

先用行列式写出面积表达式，再分内部临界点与边界两部分讨论。内部令偏导为零，边界逐一检验约束条件。

3

变量替换的矩阵验证

分别对 r、θ 用链式法则，整理成矩阵后利用三角恒等式验证 AB = I。注意 cos²θ + sin²θ = 1 的化简。

常见错误

最小二乘中向量积的下标与转置方向容易写反，注意 A 和 r 的维度一致性

极角排序（逆时针）决定了区域的约束条件 0 ≤ θ₁ ≤ θ₂ ≤ 2π，忽略会导致临界点遗漏

矩阵求逆验证时三角恒等式化简不彻底可能误判为单位矩阵

指数拟合后外推时注意模型适用范围，实际数据可能偏离指数趋势

题目 2 单位圆内接三角形——面积优化 单位圆上三角形的面积 · 区域上的临界点 · 边界分析 · 二阶导数检验
官方题面翻译可离线作答

在平面上考虑一个内接于单位圆的三角形，其中一个顶点位于 \((1, 0)\)，另外两个顶点按逆时针顺序分别由极角 \(\theta_1\) 和 \(\theta_2\) 确定。

  1. a) 用 \(\theta_1\) 和 \(\theta_2\) 表示该三角形的面积 \(A\)。\(\theta_1\) 和 \(\theta_2\) 的取值范围是什么？
  2. b) 求函数 \(A\) 在该区域内的临界点。
  3. c) 通过计算 \(A\) 在临界点处的取值以及它在定义域边界上的行为，求出 \(A\) 的最大值和最小值（需给出论证）。描述这两种情况对应的三角形形状。
  4. d) 使用二阶导数检验确认你在 (b) 中找到的临界点的性质。

公式与已知条件

  • 三个顶点：\((1, 0)\)，\((\cos \theta_1, \sin \theta_1)\)，\((\cos \theta_2, \sin \theta_2)\)
  • 面积 \(A = \frac{1}{2}|\sin(\theta_2 - \theta_1) + \sin \theta_1 - \sin \theta_2|\)（或等价形式）
  • 区域：\(0 \leq \theta_1 \leq \theta_2 \leq 2\pi\)（逆时针顺序）
解题入口

利用三个顶点的行列式公式（或鞋带公式）求面积。在区域内部令偏导数为零求临界点，再检查边界（\(\theta_1 = \theta_2\)、\(\theta_1 = 0\)、\(\theta_2 = 2\pi\) 等）。利用 \(A_{\theta_1\theta_1}\)、\(A_{\theta_2\theta_2}\) 及 Hessian 行列式进行二阶导数检验。

完成后检查

  • 最大面积应对应等边三角形。
  • 最小面积应对应退化三角形（面积为 0）。
  • 二阶导数检验的结论应与边界分析一致。

题目 3 链式法则变量替换矩阵（直角坐标 ↔ 极坐标） 链式法则 · 变量替换 · 偏导数变换的矩阵形式 · 逆矩阵验证
官方题面翻译可离线作答

设 \(w = f(x, y)\)，现从直角坐标变换到极坐标：\(x = r \cos \theta\)，\(y = r \sin \theta\)。

  1. a) 利用链式法则，推导矩阵形式的变量替换公式：\([w_r; w_\theta] = A [w_x; w_y]\)，将 \(2 \times 2\) 矩阵 \(A\) 的各分量写成 \(r\) 和 \(\theta\) 的函数。
  2. b) 利用公式 \(r = \sqrt{x^2 + y^2}\)，\(\theta = \tan^{-1}(y/x)\)，类似地推导逆变换公式：\([w_x; w_y] = B [w_r; w_\theta]\)，将 \(2 \times 2\) 矩阵 \(B\) 的各分量写成 \(x\) 和 \(y\) 的函数。
  3. c) 通过计算乘积 \(AB\) 并替换变量，验证 \(B = A^{-1}\)。
  4. d) 若在极坐标点 \(r = 5\)、\(\theta = \pi/2\) 处有 \(w_r = 2\)、\(w_\theta = 10\)，求同一点处的 \(w_x\) 和 \(w_y\)。

公式与已知条件

  • \(x = r \cos \theta\)，\(y = r \sin \theta\)
  • \(r = \sqrt{x^2 + y^2}\)，\(\theta = \tan^{-1}(y/x)\)
  • 已知：在 \(r = 5\)、\(\theta = \pi/2\) 处，\(w_r = 2\)、\(w_\theta = 10\)
  • 在 \(r = 5\)、\(\theta = \pi/2\) 处：\(x = 0\)，\(y = 5\)
解题入口

应用多元链式法则：\(w_r = w_x \cos \theta + w_y \sin \theta\)，\(w_\theta = -w_x r \sin \theta + w_y r \cos \theta\)，从而得到矩阵 \(A\)。对于 (b)，对 \(r\) 和 \(\theta\) 分别关于 \(x\) 和 \(y\) 求偏导。对于 (c)，相乘 \(AB\) 并用三角恒等式化简。对于 (d)，将 \(r = 5\)、\(\theta = \pi/2\) 代入 \(A\) 并求解 \(w_x\)、\(w_y\)。

完成后检查

  • \(AB\) 应化简为单位矩阵。
  • 求得的 \(w_x\)、\(w_y\) 在该点应满足链式法则方程。
