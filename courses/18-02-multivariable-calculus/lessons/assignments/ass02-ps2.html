Problem Set 2: Square Systems, Parametric Equations, and Kinematics（方阵系统、参数方程与运动学）

本习题集从方阵系统定理和平面方程出发，过渡到直线与曲线的参数方程，最后以速度、加速度、开普勒第二定律以及异面直线距离和齿轮运动等应用问题收尾。A 部分为站内等价练习，B 部分为官方题面翻译，注重方法训练与验证。

目标

  • 理解方阵系统定理中齐次方程组只有零解与非齐次方程组存在唯一解的关系
  • 掌握平面方程的点法式以及由已知条件确定法向量的方法
  • 能够写出直线与曲线的参数方程，并求曲线上指定点处的切线
  • 理解速度、加速度与位置向量的导数关系，掌握极坐标面积微元的推导
  • 掌握异面直线距离的两种求法：平行平面法与垂直线段法，并理解两种方法结果的一致性
  • 理解齿轮无滑动条件下的角速度关系，能建立弹性绳中点的运动参数方程

核心知识要点

方阵可逆的等价条件

n×n 方阵 A 可逆 ⟺ det(A) ≠ 0 ⟺ A𝐱 = 𝟎 只有零解 ⟺ 对任意 𝐛，A𝐱 = 𝐛 存在唯一解。这些等价关系是方阵系统定理的核心。

平面的点法式

平面点法式方程 a(x−x₀) + b(y−y₀) + c(z−z₀) = 0 中，法向量 ⟨a,b,c⟩ 与平面内任意向量垂直。已知平面上两点可求平面内向量，两向量叉积即得法向量。

参数方程的几何意义

直线参数方程 𝐫(t) = 𝐫₀ + t𝐯 中 𝐯 为方向向量；单位圆参数方程 x = cos t, y = sin t 中 t 为从正 x 轴量起的角度。切向量由对参数求导得到。

开普勒第二定律与面积微元

极坐标面积微元 dA = (1/2)r²dθ，两边除以 dt 得 dA/dt = (1/2)r²(dθ/dt)。该式为常数即开普勒第二定律，源于角动量守恒。

异面直线距离的两种求法

方法一：构造两个平行平面各含一条直线，求平面间距。方法二：设独立参数 t₁、t₂，利用连接向量与两方向向量均垂直建立方程组求最短连线。两种方法结果应一致。

典型题型与解题策略

1

方阵系统的推导路径

从齐次方程组只有零解出发，利用矩阵可逆性推导非齐次方程组解的存在唯一性，注意逻辑链条的完整性。

2

异面直线距离的独立参数法

两条直线的参数应独立变化（如 t₁ 和 t₂），利用连接向量与两方向向量均垂直建立方程组，解出参数后计算距离。

3

齿轮运动的向量表示

利用无滑动条件确定两齿轮角速度的大小和方向关系，再用从齿轮中心到钉的向量表示中点位置，最后对时间求导得速度与加速度。

常见错误

异面直线距离中两条直线的参数应独立变化，不可设为同一参数，否则无法表示两直线上任意点的连线

齿轮题中两齿轮转向相反，注意角速度方向与大小关系，无滑动意味着接触点线速度相同

平面方程题注意法向量的求解，避免取错平面上两向量的叉积方向

参数方程求导时注意链式法则的正确应用，切向量是对参数求导的结果

开普勒第二定律证明中注意面积微元的极坐标形式 dA = (1/2)r²dθ

题目 A-1 第 4 讲：方阵系统定理；平面方程 Square systems theorems · Equations of planes
站内等价练习可离线作答

以下是一组站内等价练习，覆盖方阵系统定理与平面方程两个主题。

  1. （方阵系统定理）设 \(A\) 为 \(n \times n\) 方阵。证明：若齐次线性方程组 \(A\mathbf{x} = \mathbf{0}\) 只有零解，则对任意 \(n\) 维向量 \(\mathbf{b}\)，非齐次方程组 \(A\mathbf{x} = \mathbf{b}\) 存在唯一解。
  2. （平面方程）求满足下列条件的平面方程：(a) 过点 \(P(2, -1, 3)\) 且法向量为 \(\mathbf{n} = \langle 1, 2, -1 \rangle\)；(b) 过三点 \(A(1, 0, 0)\)、\(B(0, 1, 0)\)、\(C(0, 0, 1)\)；(c) 与平面 \(2x - y + z = 5\) 平行且过原点。

公式与已知条件

  • \(n \times n\) 方阵 \(A\) 可逆 \(\iff \det(A) \neq 0 \iff A\mathbf{x} = \mathbf{0}\) 只有零解
  • 平面点法式方程：\(a(x - x_0) + b(y - y_0) + c(z - z_0) = 0\)，其中 \((a, b, c)\) 为法向量
解题入口

方阵系统部分从齐次方程组只有零解出发，利用矩阵可逆性推导；平面方程部分先确定法向量，再代入点法式。

完成后检查

  • 方阵系统：验证所给条件是否足以保证 \(A\) 可逆。
  • 平面方程：将所给定点代入所得方程检验是否满足；检查法向量是否与平面内向量垂直。

题目 A-2 第 5 讲：直线与曲线的参数方程 Parametric equations for lines · Parametric equations for curves
站内等价练习可离线作答

以下是一组站内等价练习，覆盖直线与曲线的参数方程两个主题。

  1. （直线的参数方程）求过点 \(P(1, 2, -1)\) 且与直线 \(L: x = 2t,\; y = 1 - t,\; z = 3 + 2t\) 平行的直线参数方程。
  2. （曲线的参数方程）将曲线 \(x^2 + y^2 = 1\)（单位圆）用参数 \(t\)（表示从正 \(x\) 轴量起的角度）写成参数方程；再求该曲线上对应 \(t = \pi/4\) 的点处的切线参数方程。

公式与已知条件

  • 直线参数方程：\(\mathbf{r}(t) = \mathbf{r}_0 + t\mathbf{v}\)，其中 \(\mathbf{r}_0\) 为直线上一点，\(\mathbf{v}\) 为方向向量
  • 单位圆参数方程：\(x = \cos t,\; y = \sin t\)
解题入口

直线部分先取已知直线的方向向量，再代入新点；曲线部分利用三角恒等式写出参数式，再求导得切向量。

完成后检查

  • 直线：检验方向向量是否与已知直线平行，且所给点是否在所得直线上。
  • 曲线：验证参数方程是否满足原方程；检查切向量是否与半径向量垂直。

题目 A-3 第 6 讲：速度、加速度与开普勒第二定律 Velocity · Acceleration · Kepler's second law
站内等价练习可离线作答

以下是一组站内等价练习，覆盖速度、加速度与开普勒第二定律三个主题。

  1. （速度与加速度）质点的运动方程为 \(\mathbf{r}(t) = \langle t^2, \sin t, e^t \rangle\)。求 \(t = 0\) 时的速度与加速度向量。
  2. （开普勒第二定律）行星绕太阳运动的轨道方程为 \(r(\theta) = \dfrac{p}{1 + e \cos \theta}\)（椭圆，\(0 \le e < 1\)）。利用极坐标面积公式，证明单位时间内向径扫过的面积 \(\dfrac{dA}{dt}\) 为常数。

公式与已知条件

  • 速度 \(\mathbf{v}(t) = \mathbf{r}'(t)\)，加速度 \(\mathbf{a}(t) = \mathbf{v}'(t) = \mathbf{r}''(t)\)
  • 开普勒第二定律：\(\dfrac{dA}{dt} = \dfrac{1}{2} r^2 \dfrac{d\theta}{dt} = \text{常数}\)
  • 极坐标面积微元：\(dA = \dfrac{1}{2} r^2 d\theta\)
解题入口

运动学部分直接对 \(\mathbf{r}(t)\) 求导；开普勒部分利用角动量守恒或极坐标面积微元推导。

完成后检查

  • 速度与加速度：代入 \(t = 0\) 后检查各分量计算是否正确。
  • 开普勒第二定律：验证 \(\dfrac{dA}{dt}\) 表达式中是否不含 \(\theta\)（即为常数）。

题目 B-1 两条异面直线间的距离 Distance between skew lines · Parallel planes · Parametric equations · Perpendicularity
官方题面翻译可离线作答

已知四点 \(A(2, 4, 0)\)、\(B(3, 1, 1)\)、\(C(1, 1, 3)\)、\(D(0, 5, 1)\)。求直线 \((AB)\) 与 \((CD)\) 之间的距离，即两直线上最近点之间的距离。用以下两种方法求解：

  1. a) 求一对平行平面，使得第一个平面过直线 \((AB)\)，第二个平面过直线 \((CD)\)，且两平面互相平行。然后求这两平面之间的距离。
  2. b) 写出直线 \((AB)\) 与 \((CD)\) 的参数方程，并求出参数值使得连接 \((AB)\) 上一点 \(P_1\) 与 \((CD)\) 上一点 \(P_2\) 的线段同时垂直于两条直线。该线段的长度即为两直线之间的距离。
  3. 注意：由于 \(P_1\) 和 \(P_2\) 的位置可以独立选取，两条直线上的参数应允许独立变化（例如分别记为 \(t_1\) 和 \(t_2\)）。

公式与已知条件

  • 点 \(A(2, 4, 0)\)、\(B(3, 1, 1)\)、\(C(1, 1, 3)\)、\(D(0, 5, 1)\)
解题入口

方法 (a)：构造两个平行平面，各包含一条直线。方法 (b)：使用独立参数 \(t_1\)、\(t_2\)，利用与两个方向向量均垂直的条件。

完成后检查

  • 两种方法所得距离应一致。

题目 B-2 齿轮与弹性绳中点的运动 Parametric equations · Circular motion · Velocity · Acceleration
官方题面翻译可离线作答

一机械装置由两个圆形齿轮组成：一个半径为 \(2\)，中心在 \((0, -2)\)；另一个半径为 \(1\)，中心在 \((0, 1)\)。半径为 \(2\) 的齿轮以单位角速度（\(1\) 弧度/秒）顺时针旋转，半径为 \(1\) 的齿轮在接触点无滑动地逆时针旋转。两齿轮边缘各有一小钉，两钉之间由一根弹性绳连接。初始时刻，两钉均位于原点。

  1. a) 写出弹性绳中点 \(P\) 的运动参数方程。（使用向量；先将位置向量用更简单的向量表示，再用 \(t\) 表示每个向量。）
  2. b)（周二）将点 \(P\) 的速度表示为 \(t\) 的函数，并计算 \(t = 0\) 时的速度与加速度。

公式与已知条件

  • 齿轮 1：半径 \(2\)，中心 \((0, -2)\)，顺时针，\(1\) 弧度/秒
  • 齿轮 2：半径 \(1\)，中心 \((0, 1)\)，逆时针，无滑动
  • 初始钉位置：均位于原点
解题入口

用从齿轮中心到钉的向量表示中点位置；利用齿轮间无滑动的角速度关系。

完成后检查

  • 计算 \(t = 0\) 时的速度与加速度。
