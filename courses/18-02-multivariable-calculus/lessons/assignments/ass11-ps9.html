Problem Set 9: Green's Theorem, Flux, and Geometric Applications（格林定理、通量与几何应用）

本习题集围绕格林定理及其应用展开，涵盖通量、法向形式、线积分求面积以及摆线等主题，并包含考试 3 的复习范围。A 部分为教材习题，站内以等价练习形式提供；B 部分为需提交的解答题，题面已完整给出。

目标

  • 掌握格林定理的环量形式与通量形式，并区分两者的适用场景。
  • 利用格林定理计算向量场沿闭合曲线的线积分与通量。
  • 理解格林定理的法向形式：通量等于散度在区域上的二重积分。
  • 会用线积分 \(\oint_C x\,dy\) 或 \(\oint_C -y\,dx\) 计算平面区域面积。
  • 能把摆线等参数曲线代入面积公式进行计算。
  • 理解单连通区域上旋度为零与保守性的等价关系。

核心知识要点

格林定理的两种形式

环量形式 \[\oint_C P\,dx+Q\,dy = \iint_R \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA\] 与通量形式 \[\oint_C \mathbf{F}\cdot\mathbf{n}\,ds = \iint_R \operatorname{div}\mathbf{F}\,dA.\] 前者关联旋度，后者关联散度。

通量与散度

通量衡量向量场穿过曲线的净流量；散度 \(\operatorname{div}\mathbf{F}=\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}\) 描述场在一点的源强。法向形式把边界上的通量与区域内的散度联系起来。

线积分求面积

取 \(P=-y,\ Q=0\) 或 \(P=0,\ Q=x\) 代入格林定理，得到 \[\operatorname{Area}(R)=\oint_C x\,dy=\oint_C -y\,dx.\] 对参数曲线直接代入计算即可。

格林定理的优化应用

要把线积分最大化，应让积分区域落在旋度为正的点集上；最优边界位于旋度变号的曲线处。

单连通区域与保守场

在单连通区域上，\(\frac{\partial Q}{\partial x}=\frac{\partial P}{\partial y}\) 等价于保守性；非单连通区域上该条件绕闭合回路积分可能非零。

典型题型与解题策略

1

线积分转二重积分

对闭合曲线的线积分，优先考虑用格林定理转化为二重积分，计算旋度后在区域上积分，往往比直接参数化更简洁。

2

区分通量与环量公式

通量用法向形式 \(\oint_C \mathbf{F}\cdot\mathbf{n}\,ds\)，环量用切向形式 \(\oint_C \mathbf{F}\cdot d\mathbf{r}\)，两者对应的被积函数分别是散度和旋度，不可混淆。

3

参数化注意方向与范围

参数化曲线时确保方向为正向（逆时针），参数范围覆盖完整曲线；摆线一拱对应 \(t\in[0,2\pi]\)。

常见错误

混淆曲线的正向（逆时针）与负向，导致符号错误。

通量计算中误用环量公式，或混淆 \(\mathbf{F}\cdot\mathbf{n}\,ds\) 与 \(\mathbf{F}\cdot d\mathbf{r}\)。

参数化时遗漏 Jacobian 因子或写错参数范围。

应用格林定理前未确认场在区域内处处可微（奇点需排除）。

题目 3 向量场穿过单位圆的通量 通量（flux） · 线积分（line integrals） · 格林定理（Green's theorem） · 向量场（vector fields）
官方题面翻译可离线作答

本题分为三部分，研究向量场 \(\mathbf{F} = xy\mathbf{i} + y^2\mathbf{j}\) 穿过逆时针方向单位圆的通量。

  1. a) 设 C 为逆时针方向的单位圆，向量场 \(\mathbf{F} = xy\mathbf{i} + y^2\mathbf{j}\)。问 C 的哪些部分对通量贡献为正？哪些部分贡献为负？
  2. b) 通过直接计算（求线积分）求 F 穿过 C 的通量，并结合 (a) 的结果进行解释。
  3. c) 利用格林定理求 F 穿过 C 的通量。

公式与已知条件

  • 向量场：\(\mathbf{F} = xy\mathbf{i} + y^2\mathbf{j}\)
  • 曲线 C：逆时针方向的单位圆，参数方程为 \(x = \cos t\)，\(y = \sin t\)，\(t \in [0, 2\pi]\)

完成后检查

  • 直接计算与格林定理结果应一致
  • 正负通量部分应与 \(\mathbf{F}\cdot\mathbf{n}\) 的符号对应
