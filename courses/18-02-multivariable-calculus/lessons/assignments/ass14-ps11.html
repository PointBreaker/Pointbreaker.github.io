Problem Set 11: Triple Integrals (三重积分)

把二重积分推广到三重：直角坐标、柱面坐标 (\(dV=r\,dr\,d\theta\,dz\))、球面坐标 (\(dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\))，以及引力应用（Newton 定理）。这是 Unit IIIb 的基石，Exam 4 的核心内容。

发布：2007-11-02 截止：2007-11-15 范围：Lectures 25, 26, 27, 28 难度：中等

目标

完成本次习题后，你应该能够：对空间区域建立三重积分（先找投影、再定上下曲面）；在柱面坐标与球面坐标下正确写出体积元与积分限；用三重积分求体积、质量、质心、转动惯量；用Newton 定理计算球对称物体的引力。

核心思想：三重积分 \(\iiint_R f\,dV\) 的计算关键是"投影 + 切片"：把空间区域投影到 \(xy\) 平面得二维区域 \(D\)，对每个 \((x,y)\in D\) 用垂直于 \(xy\) 平面的直线去切，得到 \(z\) 的上下界。Auroux 在第 25 讲强调：先画草图、找交线、确定投影区域。

核心知识要点

1. 直角坐标三重积分

设 \(R\) 是空间区域。把 \(R\) 投影到 \(xy\) 平面得区域 \(D\)。对每个 \((x,y)\in D\)，用垂直线切 \(R\)，得 \(z\) 的范围 \(z_0(x,y)\le z\le z_1(x,y)\)：

\[ \iiint_R f\,dV = \iint_D \left(\int_{z_0(x,y)}^{z_1(x,y)} f(x,y,z)\,dz\right) dA. \]

Auroux 的例子：两抛物面 \(z=x^2+y^2\) 与 \(z=4-x^2-y^2\) 之间的体积。交线在 \(z=2\) 平面，投影为圆盘 \(x^2+y^2\le 2\)：

\[ V = \int_{-\sqrt2}^{\sqrt2}\!\int_{-\sqrt{2-x^2}}^{\sqrt{2-x^2}}\!\int_{x^2+y^2}^{4-x^2-y^2} dz\,dy\,dx. \]

2. 柱面坐标 (cylindrical coordinates)

\(x=r\cos\theta,\ y=r\sin\theta,\ z=z\)，其中 \(r\ge0\) 是到 \(z\) 轴的距离。体积元：

\[ dV = r\,dr\,d\theta\,dz. \]

例子：圆锥 \(z=ar\) 与 \(z=b\) 之间的区域关于 \(z\) 轴的转动惯量（密度为 1）：

\[ I_z = \int_0^b\!\int_0^{2\pi}\!\int_0^{z/a} r^2\cdot r\,dr\,d\theta\,dz = \frac{\pi b^5}{10a^4}. \]

3. 球面坐标 (spherical coordinates)

\(\rho\) = 到原点距离，\(\varphi\) = 从 \(z\) 轴正方向的角度（北极=0，赤道=π/2，南极=π），\(\theta\) = 方位角。

\[ x=\rho\sin\varphi\cos\theta,\quad y=\rho\sin\varphi\sin\theta,\quad z=\rho\cos\varphi. \]

体积元（关键公式）：

\[ dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta. \]

记忆法：球面上面元 \(dS = \rho^2\sin\varphi\,d\varphi\,d\theta\)（"矩形"边长 \(\rho\,d\varphi\) 和 \(\rho\sin\varphi\,d\theta\)），再乘以径向厚度 \(d\rho\) 得体积元。

例子：单位球在平面 \(z=1/\sqrt2\) 上方的体积：

\[ V = \int_0^{2\pi}\!\int_0^{\pi/4}\!\int_{\sec\varphi/\sqrt2}^1 \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta. \]

注意：球面坐标的 \(\varphi\) 范围是 \([0,\pi]\)，不是 \([0,2\pi]\)。\(\theta\) 的范围是 \([0,2\pi]\)。混淆两者是常见错误。

4. 应用：质量、质心、转动惯量

  • 质量：\(\displaystyle M = \iiint_R \delta\,dV\)
  • 质心：\(\displaystyle \bar x = \frac{1}{M}\iiint_R x\,\delta\,dV\)（同理 \(\bar y,\bar z\)）
  • 关于 \(z\) 轴的转动惯量：\(\displaystyle I_z = \iiint_R (x^2+y^2)\,\delta\,dV = \iiint_R r^2\,\delta\,dV\)
  • 关于 \(x\) 轴的转动惯量：\(\displaystyle I_x = \iiint_R (y^2+z^2)\,\delta\,dV\)

对称性简化：若区域与密度关于 \(z\) 轴对称，则 \(\bar x=\bar y=0\)，无需计算。

5. 引力与 Newton 定理

质量 \(m\) 在原点，物体密度 \(\delta\) 在 \((x,y,z)\) 处。引力：

\[ \vec{F} = Gm\iiint_R \frac{\langle x,y,z\rangle}{\rho^3}\,\delta\,dV. \]

利用对称性：把物体对称轴放在 \(z\) 轴上，则 \(\vec{F}=\langle 0,0,F_z\rangle\)，且：

\[ F_z = Gm\iiint_R \frac{z}{\rho^3}\,\delta\,dV = Gm\iiint_R \frac{\cos\varphi}{\rho^2}\,\delta\,\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = Gm\iiint \delta\cos\varphi\sin\varphi\,d\rho\,d\varphi\,d\theta. \]

Newton 定理：均质球壳（或球体）对球外质点的引力等价于球心处等质量质点的引力。Auroux 用球面坐标详细证明：球半径 \(a\)、球心在 \(z\) 轴上距原点 \(a\) 处（与原点相切），则：

\[ F_z = Gm\delta\pi a = \frac{GMm}{a^2},\quad M=\frac43\pi a^3\delta. \]

典型题型与解题策略

1

建立三重积分（直角坐标）

代表：PS11 中两曲面之间的体积题；柱面/球面区域。

策略：画区域 → 找两曲面的交线 → 投影到 \(xy\) 平面得 \(D\) → 对 \((x,y)\in D\) 定 \(z\) 的上下限 → 化为累次积分。

2

柱面坐标积分

代表：PS11 中圆柱、圆锥、绕 \(z\) 轴旋转体。

策略：识别绕 \(z\) 轴的对称性 → 代换 \(x=r\cos\theta,\ y=r\sin\theta\) → \(dV=r\,dr\,d\theta\,dz\)。通常先对 \(r\) 积分（从 0 到边界曲线），再 \(\theta\)，再 \(z\)。

3

球面坐标积分

代表：PS11 中球形区域、锥形区域、球与平面的截口。

策略：识别球形/锥形边界 → 代换 \(x=\rho\sin\varphi\cos\theta\) 等 → \(dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\)。注意 \(\varphi\) 的范围由锥面或平面决定。

4

引力计算

代表：PS11 Problem 3（平均距离）；球体/球壳引力。

策略：把原点放在测试质点处，对称轴放在 \(z\) 轴上 → 用球坐标 → 对称性消去 \(x,y\) 分量 → 只算 \(F_z\)。

常见错误

柱面坐标忘乘 \(r\)：\(dV=r\,dr\,d\theta\,dz\)，不是 \(dr\,d\theta\,dz\)。与极坐标面积元 \(dA=r\,dr\,d\theta\) 同理。

球面坐标体积元记错：\(dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\)。\(\rho^2\) 来自球面面积元的缩放，\(\sin\varphi\) 来自纬圈半径 \(\rho\sin\varphi\)。

\(\varphi\) 与 \(\theta\) 范围混淆：\(\varphi\in[0,\pi]\)（极角），\(\theta\in[0,2\pi]\)（方位角）。写反会导致积分区域错误。

投影区域找错：三重积分的关键是正确找空间区域在 \(xy\) 平面的投影。方法是找上下曲面的交线，消去 \(z\) 得投影边界。
