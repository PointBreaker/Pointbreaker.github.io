目标

本复习页把 18.02 全课程的知识与工具梳理成一张"作战地图"。期末考要求你：识别题型 → 选择定理 → 正确计算 → 解释物理意义。核心能力包括：

  • 熟练运用三大定理（Green、Stokes、散度定理）在积分形式与微分形式之间转换。
  • 计算梯度、散度、旋度，并解释其几何/物理含义。
  • 从散度定理和 Stokes 定理推导 Maxwell 方程组的积分形式。
  • 在综合问题中选择正确的定理——这是期末考最大的区分点。

核心思想：18.02 的三大定理本质上说的是同一件事——边界上的量 = 内部的量的积分。Green 定理处理平面区域，Stokes 定理处理曲面边界，散度定理处理闭曲面。Maxwell 方程组把这四个 div/curl 关系写成物理定律，再用三大定理在积分与微分形式之间切换。

Unit IV 公式速查——向量分析三大定理

Del 算子：
\(\displaystyle\nabla=\Bigl\langle\frac{\partial}{\partial x},\frac{\partial}{\partial y},\frac{\partial}{\partial z}\Bigr\rangle\)
\(\nabla f=\langle f_x,f_y,f_z\rangle\)（梯度）
\(\nabla\cdot\vec F = P_x+Q_y+R_z\)（散度）
\(\displaystyle\nabla\times\vec F=\det\begin{pmatrix}\hat\imath&\hat\jmath&\hat k\\\partial_x&\partial_y&\partial_z\\P&Q&R\end{pmatrix}\)（旋度）

定理积分形式 ↔ 微分形式何时使用
Green（切向）\(\displaystyle\oint_C \vec F\cdot d\vec r=\iint_R (\nabla\times\vec F)\cdot\hat k\,dA\)平面闭曲线 ↔ 平面旋度（\(z\) 分量）
Green（法向/通量）\(\displaystyle\oint_C \vec F\cdot\hat n\,ds=\iint_R \nabla\cdot\vec F\,dA\)平面闭曲线 ↔ 平面散度
Stokes\(\displaystyle\oint_C \vec F\cdot d\vec r=\iint_S (\nabla\times\vec F)\cdot\hat n\,dS\)空间闭曲线 ↔ 任意以 \(C\) 为边界的曲面
散度定理\(\displaystyle\oiint_S \vec F\cdot\hat n\,dS=\iiint_D \nabla\cdot\vec F\,dV\)闭曲面 ↔ 内部区域散度

核心思想：三大定理的统一图景——边界上的积分 = 内部微分的积分。Green 定理是 Stokes 定理的特例（平面 + 平面区域）；散度定理是"通量—源"的恒等式。记忆口诀：线积分 ↔ 旋度（Stokes/Green 切向）；通量 ↔ 散度（散度定理/Green 法向）。

三大定理并排对比

期末考最常考的能力是在三大定理中做出正确选择。以下决策树帮你快速定位：

1

看积分类型：线积分还是面积分？

线积分 \(\displaystyle\oint \vec F\cdot d\vec r\) → 考虑 Stokes 定理（或平面情形的 Green 切向形式）。它把线积分转化为旋度的面积分。

通量积分 \(\displaystyle\oiint \vec F\cdot\hat n\,dS\) 或 \(\displaystyle\oint \vec F\cdot\hat n\,ds\) → 考虑 散度定理（或平面情形的 Green 法向形式）。它把通量转化为散度的体积分/二重积分。

2

看几何：平面还是空间？闭曲面还是开曲面？

平面闭曲线 → Green 定理（切向或法向）。

空间闭曲线 + 开曲面 → Stokes 定理。

闭曲面 → 散度定理。

3

看被积函数：旋度还是散度？

如果 \(\nabla\times\vec F=\vec 0\)（无旋），则线积分与路径无关，可用势函数。

如果 \(\nabla\cdot\vec F=0\)（无源），则通过闭曲面的通量为零。

如果 \(\vec F=\nabla f\)（保守场），则 \(\displaystyle\oint \vec F\cdot d\vec r=0\)。

注意：Stokes 定理中曲面 \(S\) 的定向必须与曲线 \(C\) 的方向成右手定则关系。法向量 \(\hat n\) 的方向错了，结果反号。散度定理中 \(\hat n\) 永远是外法向。

Maxwell 方程组

Maxwell 方程组是 18.02 的"毕业演出"——用 div 和 curl 统一描述电磁学。四个方程分为两组：散度方程描述"源"，旋度方程描述"感应"。

方程微分形式积分形式物理意义
Gauss-Coulomb\(\nabla\cdot\vec E=\dfrac{\rho}{\varepsilon_0}\)\(\oiint_S \vec E\cdot\hat n\,dS=\dfrac{Q}{\varepsilon_0}\)电荷是电场的源
磁场无源\(\nabla\cdot\vec B=0\)\(\oiint_S \vec B\cdot\hat n\,dS=0\)不存在磁单极子
Faraday\(\nabla\times\vec E=-\dfrac{\partial\vec B}{\partial t}\)\(\oint_C \vec E\cdot d\vec r=-\dfrac{d}{dt}\iint_S \vec B\cdot\hat n\,dS\)变化磁场产生电场（电磁感应）
Ampère-Maxwell\(\nabla\times\vec B=\mu_0\vec J+\varepsilon_0\mu_0\dfrac{\partial\vec E}{\partial t}\)\(\oint_C \vec B\cdot d\vec r=\mu_0 I+\varepsilon_0\mu_0\dfrac{d}{dt}\iint_S \vec E\cdot\hat n\,dS\)电流与变化电场产生磁场

核心思想：从微分形式到积分形式，只需对散度方程用散度定理、对旋度方程用 Stokes 定理。这正是 18.02 三大定理的物理应用——数学定理把"逐点"的场方程转化为"整体"的可测量（通量、电压、电动势）。

从微分形式推导积分形式

以 Faraday 定律为例：对 \(\nabla\times\vec E=-\partial\vec B/\partial t\) 在曲面 \(S\) 上积分，用 Stokes 定理：

\[\iint_S (\nabla\times\vec E)\cdot\hat n\,dS = \oint_C \vec E\cdot d\vec r = -\iint_S \frac{\partial\vec B}{\partial t}\cdot\hat n\,dS = -\frac{d}{dt}\iint_S \vec B\cdot\hat n\,dS.\]

以 Gauss-Coulomb 定律为例：对 \(\nabla\cdot\vec E=\rho/\varepsilon_0\) 在区域 \(D\) 上积分，用散度定理：

\[\iiint_D \nabla\cdot\vec E\,dV = \oiint_S \vec E\cdot\hat n\,dS = \frac{1}{\varepsilon_0}\iiint_D \rho\,dV = \frac{Q}{\varepsilon_0}.\]

基本恒等式（必记）：
\(\nabla\cdot(\nabla\times\vec F)=0\)（旋度无源）
\(\nabla\times(\nabla f)=\vec 0\)（梯度无旋）
\(\nabla\cdot(\nabla f)=\nabla^2 f\)（Laplace 算子）

典型题型与解题策略

1

识别题型 → 选择定理

决策流程：

  1. 题目给的是线积分、通量、还是体积分？
  2. 区域是平面还是空间？闭曲线还是闭曲面？
  3. 能否用定理把难算的积分转化为易算的积分？
  4. 检查 \(\nabla\cdot\vec F\) 或 \(\nabla\times\vec F\) 是否简单（零、常数、或简单函数）。
2

保守场与路径无关

判断方法：\(\nabla\times\vec F=\vec 0\) + 区域单连通 \(\Rightarrow\) 保守场。求势函数：线积分法或分量积分法（Practice 4B Problem 3 的两种方法）。

常见陷阱：\(\nabla\times\vec F=\vec 0\) 但区域有洞（非单连通）时，场可能不是保守场。

3

综合应用：选择曲面/曲线

Stokes 定理允许你选择任意以 \(C\) 为边界的曲面。技巧：选最简单的曲面（平面片、坐标面）使 \(\nabla\times\vec F\cdot\hat n\) 简化。

散度定理允许你加辅助面把开曲面补成闭曲面，再用闭曲面通量减去辅助面通量（Practice 4B Problem 4 的技巧）。

4

物理应用：引力与电磁

引力场 \(\vec F=-GMm\,\vec r/|\vec r|^3\) 的散度：\(\nabla\cdot\vec F=-4\pi GM\delta\)（Newton 定理）。

Maxwell 方程组把 div/curl 与物理量对应：散度 ↔ 源（电荷、磁荷），旋度 ↔ 感应（变化场）。

常见错误

定理选择错误：看到闭曲面通量就用散度定理，看到闭曲线线积分就用 Stokes/Green。如果题目问的是开曲面的通量，不能直接用散度定理——需要补辅助面。

定向错误：Stokes 定理中曲面定向与曲线方向必须满足右手定则。散度定理中永远是外法向。定向错了结果反号。

旋度/散度计算错误：旋度是行列式，注意 \(\partial_y R - \partial_z Q\) 的符号。散度是 \(P_x+Q_y+R_z\)，简单但容易漏项。

忘记 Jacobian：极坐标 \(r\)、柱坐标 \(r\)、球坐标 \(\rho^2\sin\phi\)。变量替换时 \(|J|\) 必须取绝对值。

混淆 div 和 curl 的物理意义：散度描述"源/汇"（流体冒出或被吸走），旋度描述"旋转"（力矩、角加速度）。Maxwell 中：散度方程 = 场源，旋度方程 = 感应。

保守场判定不完整：\(\nabla\times\vec F=\vec 0\) 是必要条件，但区域必须单连通才是充分条件。有洞的区域上可能存在非零的环量。
