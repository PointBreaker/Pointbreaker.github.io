系统复习第三单元（向量分析）：三重积分、曲面积分、散度定理、Stokes 定理，以及三大定理的综合应用策略。

授课：Denis Auroux 日期：2007-12-13 难度：中等

复习导览

本次复习课聚焦第三单元：Triple Integrals, Surface Integrals & Vector Calculus（Lecture 25–33）。这是课程最综合、最考验分析能力的部分，也是期末考试的重点。

核心思想：第三单元的精髓是三大定理——散度定理、Stokes 定理、微积分基本定理。它们建立了不同维度积分之间的联系，是整门课程的巅峰。

三重积分

三种坐标系下的体积元：
直角坐标：\(dV = dx\,dy\,dz\)
柱坐标：\(dV = r\,dr\,d\theta\,dz\)
球坐标：\(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)

选择策略：

  • 区域有旋转对称（圆柱、圆锥、旋转抛物面）→ 柱坐标。
  • 区域是球形或涉及到原点距离 → 球坐标。
  • 区域是长方体或边界是平面 → 直角坐标。

应用：体积、质量 \(M=\iiint\delta\,dV\)、质心、转动惯量、引力。

曲面积分与通量

通量：\(\Phi = \iint_S \vec F\cdot\hat n\,dS = \iint_S \vec F\cdot\vec{dS}\)。

面积元公式汇总：

  • 平面 \(z=a\)：\(\vec{dS}=\pm\hat k\,dx\,dy\)。
  • 球面 \(\rho=a\)：\(\hat n=\dfrac{1}{a}\langle x,y,z\rangle\)，\(dS=a^2\sin\phi\,d\phi\,d\theta\)。
  • 圆柱面 \(r=a\)：\(\hat n=\dfrac{1}{a}\langle x,y,0\rangle\)，\(dS=a\,dz\,d\theta\)。
  • 曲面 \(z=f(x,y)\)：\(\vec{dS}=\pm\langle -f_x,-f_y,1\rangle\,dx\,dy\)。

注意：考试时必须记住这些公式。关键是 \(\vec{dS}=\hat n\,dS\) 作为一个整体，不要拆开。

Del 算子与场论

三种微分运算：
梯度：\(\nabla f = \langle f_x,f_y,f_z\rangle\)
散度：\(\nabla\cdot\vec F = P_x+Q_y+R_z\)
旋度：\(\nabla\times\vec F = \langle R_y-Q_z,P_z-R_x,Q_x-P_y\rangle\)

基本恒等式：

\[\nabla\times(\nabla f)=\vec 0,\qquad \nabla\cdot(\nabla\times\vec F)=0.\]

梯度场判别：在单连通区域，\(\vec F=\nabla f \iff \nabla\times\vec F=\vec 0\)。

三大定理

散度定理（Gauss-Green）：
\[\oiint_S \vec F\cdot\vec{dS} = \iiint_D \nabla\cdot\vec F\,dV.\]

Stokes 定理：
\[\oint_C \vec F\cdot d\vec r = \iint_S (\nabla\times\vec F)\cdot\hat n\,dS.\]

微积分基本定理：
\[f(P_1)-f(P_0) = \int_C \nabla f\cdot d\vec r.\]

选择定理的策略

核心思想：
• 闭曲面上的通量 → 散度定理
• 闭曲线上的环量 → Stokes 定理
• 梯度场的线积分 → 微积分基本定理

关键观察：三大定理的两边都是我们已经学过的积分类型。看到 div 或 curl，就想到对应的定理。

解题策略

  1. 识别积分类型：是线积分、面积分还是体积分？是闭曲线/闭曲面吗？
  2. 考虑定理转化：闭曲面通量 → 散度定理化为体积分；闭曲线环量 → Stokes 定理化为面积分。
  3. 坐标选择：根据区域形状选直角/柱/球坐标。
  4. 对称性：利用对称性简化计算（如球对称引力的 \(F_x=F_y=0\)）。
  5. 验证：用不同方法交叉验证（如直接算通量 vs 散度定理）。

知识检查

问题 1：计算向量场通过闭曲面 \(S\) 的通量 \(\oiint_S \vec F\cdot\vec{dS}\)，最合适的定理是？

问题 2：计算球面 \(x^2+y^2+z^2\le 1\) 在锥面 \(z=\sqrt{x^2+y^2}\) 上方的体积，最适合用？

问题 3：\(\vec F=\langle x,y,z\rangle\) 穿过半径 \(a\) 的球面（外法向）的通量是？

本课要点

三重积分

三种坐标系，根据对称性选择，记住体积元。

曲面积分

通量 = \(\vec F\cdot\vec{dS}\)，记住各类曲面的面积元公式。

三大定理

散度定理、Stokes 定理、微积分基本定理，根据问题类型选择。

解题策略

识别类型 → 考虑转化 → 选坐标 → 用对称性 → 验证。
