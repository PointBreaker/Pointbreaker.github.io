Vector Fields in 3D; Surface Integrals (曲面积分与通量)

把平面向量场的通量推广到三维：定义 \(\iint_S \vec F\cdot\hat n\,dS\)，学会在不同曲面（平面、球面、柱面、曲面）上设置面积元，并用几何与计算两种方法求通量。

授课：Denis Auroux 日期：2007-11-15 难度：较难

学习目标

  • 理解三维向量场 \(\vec F = \langle P,Q,R\rangle\) 的物理实例（力场、速度场、梯度场）。
  • 定义通量 (flux) \(\displaystyle\Phi = \iint_S \vec F\cdot\hat n\,dS\)，并给出几何解释。
  • 记住平面、球面、柱面、曲面 \(z=f(x,y)\) 的面积元 \(\hat n\,dS\) 公式并会计算通量。
  • 了解参数曲面与隐式曲面的通量设置方法。

核心思想：通量衡量的是向量场"穿过"曲面的流量。如果 \(\vec F\) 是流体速度场，\(\vec F\cdot\hat n\,dS\) 就是单位时间内穿过面元 \(dS\) 的流体体积。符号取决于我们选取 \(\hat n\) 的方向——闭曲面通常取外法向。

三维向量场

在空间中每一点赋予一个向量：

\[\vec F(x,y,z) = P\,\hat\imath + Q\,\hat\jmath + R\,\hat k.\]

典型例子：

  • 引力场：\(\vec F = -c\,\dfrac{\langle x,y,z\rangle}{\rho^3}\)。
  • 静电场：\(\vec E\)（由电荷分布产生）。
  • 流速场：\(\vec v(x,y,z)\) 给出每点的流速。
  • 梯度场：\(\nabla f\)（如温度、压力的梯度）。

通量的定义

在二维中，通量是沿曲线的线积分 \(\displaystyle\int_C \vec F\cdot\hat n\,ds\)。在三维中，通量是沿曲面的曲面积分：

\[\Phi = \iint_S \vec F\cdot\hat n\,dS.\]

向量面积元：记 \(\vec{dS} = \hat n\,dS\)，则通量写作 \(\displaystyle\iint_S \vec F\cdot\vec{dS}\)。\(\vec{dS}\) 往往比分别求 \(\hat n\) 和 \(dS\) 更容易计算。

几何解释：把曲面切成小块 \(\Delta S\)，穿过每块的流体体积（单位时间）等于以 \(\Delta S\) 为底、\(\vec F\) 为第三边的平行六面体体积 = \((\vec F\cdot\hat n)\,\Delta S\)。对所有小块求和即得通量。

注意：每个曲面有两个可能的法向方向。闭曲面（如球面）通常取外法向。开曲面的方向需要题目指定或根据上下文约定。

面积元公式汇总

以下是本课要求记住的 \(\hat n\,dS\) 公式：

  1. 平面 \(z=a\)（平行于 \(xy\) 平面）：\(\hat n = \pm\hat k,\;dS=dx\,dy\)，所以 \(\vec{dS} = \pm\hat k\,dx\,dy\)。
  2. 球面 \(\rho=a\)（中心在原点）：\(\hat n = \dfrac{1}{a}\langle x,y,z\rangle\)，\(dS=a^2\sin\phi\,d\phi\,d\theta\)，用 \((\phi,\theta)\) 参数化。
  3. 圆柱面 \(r=a\)（中心在 \(z\) 轴）：\(\hat n = \dfrac{1}{a}\langle x,y,0\rangle\)（水平外法向），\(dS=a\,dz\,d\theta\)，用 \((z,\theta)\) 参数化。
  4. 曲面 \(z=f(x,y)\)：\(\vec{dS} = \pm\langle -f_x,\,-f_y,\,1\rangle\,dx\,dy\)，用 \((x,y)\) 参数化。

例 1：\(\vec F = \langle x,y,z\rangle\) 穿过半径 \(a\) 的球面

取外法向 \(\hat n = \dfrac{1}{a}\langle x,y,z\rangle\)，则 \(\vec F\cdot\hat n = \dfrac{x^2+y^2+z^2}{a} = a\)（在球面上 \(\rho=a\)）。因此

\[\Phi = \iint_S a\,dS = a\cdot 4\pi a^2 = 4\pi a^3.\]

例 2：\(\vec F = z\hat k\) 穿过半径 \(a\) 的球面

\(\vec F\cdot\hat n = z\cdot \dfrac{z}{a} = \dfrac{z^2}{a}\)。用球坐标 \(z=a\cos\phi\)，\(dS=a^2\sin\phi\,d\phi\,d\theta\)：

\[\Phi = \int_0^{2\pi}\int_0^{\pi} \frac{a^2\cos^2\phi}{a}\,a^2\sin\phi\,d\phi\,d\theta = 2\pi a^3\int_0^{\pi}\cos^2\phi\sin\phi\,d\phi = \frac{4\pi a^3}{3}.\]

核心思想：这个例子用散度定理可以一秒验证：\(\operatorname{div}\vec F = 1\)，所以 \(\Phi = \iiint 1\,dV = \dfrac{4}{3}\pi a^3\)。这正是下节课的内容。

曲面 \(z=f(x,y)\) 的通量

设 \(S\) 是 \(z=f(x,y)\) 在 \(xy\) 平面区域 \(R\) 上方的部分。把 \(S\) 切成小块：在 \((x,y)\) 处对应的小块近似为平行四边形，两边为

\[\langle \Delta x,0,\Delta x\,f_x\rangle,\qquad \langle 0,\Delta y,\Delta y\,f_y\rangle.\]

叉乘给出

\[\vec{\Delta S} = \langle -f_x,\,-f_y,\,1\rangle\,\Delta x\,\Delta y,\]

因此

\[\vec{dS} = \pm\langle -f_x,\,-f_y,\,1\rangle\,dx\,dy.\]

重要公式：对曲面 \(z=f(x,y)\)，
\[\boxed{\vec{dS} = \pm\langle -f_x,\,-f_y,\,1\rangle\,dx\,dy}\]
注意 \(\langle -f_x,-f_y,1\rangle\) 不是单位法向量，\(dx\,dy\) 不是面积元——只有乘积 \(\hat n\,dS\) 才有几何意义。

从它也可以还原出：\(\hat n = \dfrac{\langle -f_x,-f_y,1\rangle}{\sqrt{f_x^2+f_y^2+1}}\)，\(dS = \sqrt{f_x^2+f_y^2+1}\,dx\,dy\)。

例 3：\(\vec F=z\hat k\) 穿过抛物面 \(z=x^2+y^2\)

取上法向（指向抛物面内部），\(f_x=2x,\;f_y=2y\)，\(\vec{dS}=\langle -2x,-2y,1\rangle\,dx\,dy\)，\(z=x^2+y^2\)：

\[\Phi = \iint_S z\,dx\,dy = \iint_{\text{unit disk}}(x^2+y^2)\,dx\,dy = \int_0^{2\pi}\int_0^1 r^2\cdot r\,dr\,d\theta = \frac{\pi}{2}.\]

参数曲面与隐式曲面

参数曲面 \(\vec r = \vec r(u,v)\)：面积元

\[\vec{dS} = \pm\frac{\partial\vec r}{\partial u}\times\frac{\partial\vec r}{\partial v}\,du\,dv.\]

这个公式统一了前面所有公式，但考试通常不需要。

隐式曲面 \(g(x,y,z)=0\)：非单位法向量 \(\vec N = \nabla g\)，\(\hat n = \pm\vec N/|\vec N|\)。投影到 \(xy\) 平面时，面积收缩因子为 \(\cos\alpha = \dfrac{\vec N\cdot\hat k}{|\vec N|}\)，因此

\[dS = \frac{|\vec N|}{|\vec N\cdot\hat k|}\,dA,\qquad \vec{dS} = \pm\frac{\vec N}{\vec N\cdot\hat k}\,dx\,dy.\]

注意：如果曲面是竖直的（\(\vec N\cdot\hat k=0\)），就不能投影到 \(xy\) 平面，需要换一个投影方向（如 \(xz\) 平面）。

对曲面 \(z=f(x,y)\)，取 \(g=z-f(x,y)\)，则 \(\nabla g = \langle -f_x,-f_y,1\rangle\)，\(\vec N\cdot\hat k=1\)，就回到熟悉的 \(\vec{dS}=\langle -f_x,-f_y,1\rangle\,dx\,dy\)。

知识检查

问题 2：曲面 \(z=f(x,y)\) 的向量面积元 \(\vec{dS}\) 是？

问题 3：通量 \(\iint_S \vec F\cdot\hat n\,dS\) 的物理意义是？

本课要点

通量定义

\(\Phi=\iint_S \vec F\cdot\hat n\,dS\)，衡量场穿过曲面的流量。

面积元公式

平面、球面、柱面、曲面各有固定的 \(\hat n\,dS\) 表达式，务必记住。

几何 vs 计算

简单情况用几何（如 \(\vec F\cdot\hat n=\text{常数}\)），复杂情况用参数化计算。

方向选择

闭曲面取外法向，开曲面按题意约定方向。
