Spherical Coordinates; Surface Area (球坐标与表面积)

引入球坐标 \((\rho,\phi,\theta)\)，推导体积元 \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)，并用它求球冠体积，最后把引力问题化为三重积分。

授课：Denis Auroux 日期：2007-11-13 难度：中等

学习目标

  • 掌握球坐标 \((\rho,\phi,\theta)\) 的定义、几何含义及与直角坐标的转换。
  • 从曲面面积元 \(dS = a^2\sin\phi\,d\phi\,d\theta\) 推导体积元 \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)。
  • 用球坐标计算球冠体积，并建立引力积分。

核心思想：球坐标是描述球对称问题的天然语言。\(\rho\) 控制"离原点多远"，\(\phi\) 控制"从北极点往下转多少"，\(\theta\) 控制"经度"。体积元多出的 \(\rho^2\sin\phi\) 来自球面上"小矩形"的两条边长。

球坐标的定义

球坐标 \((\rho,\phi,\theta)\) 与直角坐标的关系：

\[\rho = \text{到原点的距离},\quad \phi = \text{从正 }z\text{ 轴向下的夹角},\quad \theta = \text{与柱坐标相同的经度}.\]

转换公式：
\[z = \rho\cos\phi,\qquad r = \rho\sin\phi,\]
\[x = \rho\sin\phi\cos\theta,\qquad y = \rho\sin\phi\sin\theta,\qquad \rho = \sqrt{x^2+y^2+z^2}.\]

几何直观：\(\phi\) 类似纬度，但 \(\phi=0\) 是北极，\(\phi=\pi/2\) 是赤道，\(\phi=\pi\) 是南极。

常见曲面

  • \(\rho=a\)：半径为 \(a\)、中心在原点的球面。
  • \(\phi=\pi/4\)：锥面 \(z=r=\sqrt{x^2+y^2}\)（半顶角 \(45^\circ\)）。
  • \(\phi=\pi/2\)：\(xy\) 平面（\(z=0\)）。
  • \(\theta=\theta_0\)：过 \(z\) 轴的半平面。

体积元的推导

先看半径为 \(a\) 的球面上的面积元。在球面上取一个"小矩形"，对应角度变化 \(\Delta\phi\) 与 \(\Delta\theta\)：

  • 沿 \(\phi\) 方向的边长 = 半径为 \(a\) 的圆弧 = \(a\,\Delta\phi\)。
  • 沿 \(\theta\) 方向的边长 = 半径为 \(r=a\sin\phi\) 的圆弧 = \(a\sin\phi\,\Delta\theta\)。

因此球面面积元为

\[dS = a^2\sin\phi\,d\phi\,d\theta.\]

核心思想：球面上不同纬度处，\(\theta\) 方向的"纬线圈"半径不同——在赤道（\(\phi=\pi/2\)）最大，在两极缩为点。这就是 \(\sin\phi\) 因子的来源。

对于体积元，再沿径向增加一层厚度 \(d\rho\)：

\[dV = d\rho\cdot dS = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta.\]

例：单位球在平面上方的体积

求单位球面 \(x^2+y^2+z^2\le 1\) 在平面 \(z=1/\sqrt{2}\) 上方的那部分体积。

在球坐标下，平面方程为 \(\rho\cos\phi = 1/\sqrt{2}\)，即 \(\rho = \sec\phi/\sqrt{2}\)。球面是 \(\rho=1\)。固定 \((\phi,\theta)\)，射线从平面进入、从球面离开，所以

\[\frac{\sec\phi}{\sqrt{2}}\le\rho\le1.\]

平面 \(z=r\) 对应 \(\phi=\pi/4\)，所以 \(0\le\phi\le\pi/4\)，\(0\le\theta\le2\pi\)。于是

\[V = \int_0^{2\pi}\int_0^{\pi/4}\int_{\sec\phi/\sqrt{2}}^{1} \rho^2\sin\phi\,d\rho\,d\phi\,d\theta.\]

计算可得

\[V = \frac{2\pi}{3}\Bigl(1-\frac{1}{\sqrt{2}}\Bigr) = \frac{2\pi - \sqrt{2}\,\pi}{3}.\]

注意：这个例子若用柱坐标或直角坐标会复杂得多。球坐标的优势在于：球面是 \(\rho=\text{常数}\)，锥面是 \(\phi=\text{常数}\)，都非常简单。

引力应用

质量为 \(m\) 的质点位于原点，质量为 \(\Delta M\) 的质点在 \((x,y,z)\) 处。Newton 万有引力给出

\[|\vec F| = \frac{G\,\Delta M\,m}{\rho^2},\qquad \operatorname{dir}(\vec F) = \langle x,y,z\rangle,\]

即

\[\vec F = \frac{G\,\Delta M\,m}{\rho^3}\langle x,y,z\rangle.\]

对于密度为 \(\delta\) 的连续物体，把 \(\Delta M = \delta\,dV\) 代入并积分：

\[\vec F = Gm\iiint_R \frac{\langle x,y,z\rangle}{\rho^3}\,\delta\,dV,\qquad F_z = Gm\iiint_R \frac{z}{\rho^3}\,\delta\,dV.\]

对称性简化：把物体放置得使 \(z\) 轴是对称轴，则 \(x,y\) 方向的分力抵消，只剩 \(F_z\)。再用球坐标：\(z=\rho\cos\phi\)，\(\rho^3\) 与分母约去一个 \(\rho^2\)，得到非常简洁的积分。

在球坐标下：

\[F_z = Gm\iiint_R \frac{\rho\cos\phi}{\rho^3}\,\delta\,\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = Gm\iiint_R \delta\cos\phi\sin\phi\,d\rho\,d\phi\,d\theta.\]

Newton 定理

定理（Newton）：均匀球壳（或均匀球体）对球外质点的引力，等价于全部质量集中在球心时的引力。

设半径为 \(a\) 的均匀球体（密度 \(\delta\)）与 \(xy\) 平面在原点相切，测试质点 \(m\) 位于原点。在过球心的竖直截面中，球面方程为 \(\rho = 2a\cos\phi\)（直径 \(2a\) 为斜边的内接直角三角形）。于是

\[F_z = Gm\int_0^{2\pi}\int_0^{\pi/2}\int_0^{2a\cos\phi} \delta\cos\phi\sin\phi\,d\rho\,d\phi\,d\theta = Gm\delta\pi a = \frac{GMm}{a^2},\]

其中 \(M = \dfrac{4}{3}\pi a^3\delta\) 是球体总质量。这正是把全部质量放在球心时的结果！

Newton 定理的深远意义：在计算行星间的引力时，可以把整个星球视为质点。这一定理是天体力学的基础。

本课要点

球坐标

\(\rho\) 为到原点距离，\(\phi\) 为从 \(z\) 轴向下夹角，\(\theta\) 为经度。

体积元

\(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)，来自球面面积元乘径向厚度。

球对称问题

球面、锥面、半平面在球坐标下都是"坐标面"，积分限简单。

Newton 定理

均匀球体对球外质点的引力等价于质量集中在球心。
